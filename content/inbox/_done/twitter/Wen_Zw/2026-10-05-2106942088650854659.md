> Saw what @badlogicgames has been building with Pi Durable lately and had to try it myself, so I made Pi Pocket.
> 
> The fun part: I kill -9 the server halfway through a run, and a new process just picks it back up from the same SQLite file. The test run that got cut off comes back as interrupted and runs again, and nothing that already finished runs twice.
> 
> Every model call and tool call is a checkpointed task, and crash recovery, multiplayer, and hot swappable extensions all come out of that.
> 
> Huge thanks to Mario and the @pidotdev team. Pi 1.0 is a great agent, Pi Durable is a really smart foundation, and building on both has been a blast.
