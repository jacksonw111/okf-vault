> 转发内容

> 给装机党递个必备的开源神器：reinstall。
> 
> 电脑重装系统这事儿，老办法得先下镜像、拿 PE/U 盘刻个启动盘、再钻 BIOS 调启动项，一整套折腾下来，人先累趴。
> 
> 这个项目干脆把流程一刀切了：一条命令下去，系统自己就重装了。
> 
> Windows 11、Windows 10、Windows Server 全罩得住，Debian、Ubuntu、Alpine、Rocky Linux、Fedora、OpenWrt 这些也能装。
> 
> 更狠的是，它能从 Linux 那边把 Windows 重装掉，也能从 Windows 把 Linux 换过来，甚至还能给没 IPMI 的云服务器、VPS 远程重装系统。
> 
> PE 免了，U 盘也免了，好些场景下脚本远程一跑，剩下的它自个儿就给你办完了。
> 
> 三天两头鼓捣电脑、服务器和 VPS 的，建议收着。
>
