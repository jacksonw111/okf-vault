> Amazon 出品的 Strands Agents 的 harness SDK 开源仓库，是一个用 Python / TypeScript 构建和运行 AI agent 的开源 SDK。
> 
> README 中列出了包含的可复用的 Agents 能力：
> 
> 生命周期控制：turn limits、token budgets、cancellation、stop reasons
> tools + structured output
> MCP
> multi-agent 模式
> memory + sessions
> model portability（模型可移植）
> streaming
> guardrails（护栏，错误运行前拦截）
> tracing（追踪，默认 trace 每个决策）
> evals
> 
> 仓库：https://github.com/strands-agents/harness-sdk
