> 转发内容

> 如果你的产品同时想接 Claude Code、Codex、Hermes，最烦的可能不是模型，而是每套 Agent 都要重新接一遍。
> 
> HarnessRouter 就是干这个的。
> 
> 它把不同 Agent Harness 统一到一个 API 后面。
> 
> 你的应用只需要接一次，后面可以切：
> 
> Code\Claude Code\Hermes\其他自定义 Harness
> 
> 它统一处理的东西包括：
> 
> >持久会话
> >流式执行进度
> >文件上传和产物获取
> >任务取消
> >执行 Trace
> >结构化错误
> >Tools / Skills 配置
> 
> 接口还兼容 OpenAI Responses API。
> 
> 比较实用的一点是，同一个任务可以直接换 Harness 和模型跑，不用把业务层重新改一遍。
> 
> 官方 benchmark 里，8 组 Harness × Model 配置跑同一个任务，最好和最差配置之间：
> 
> 成本相差 99.8%
> 端到端速度相差 3.2 倍
> 这也说明 Agent 产品后面真正需要做的，不只是“选哪个模型”，而是根据任务去选哪套 Harness + Model 组合。
> 
> 支持 Docker 自托管，也可以自己带 Provider API Key。
> 
> GitHub:https://github.com/HarnessRouter/harnessrouter
