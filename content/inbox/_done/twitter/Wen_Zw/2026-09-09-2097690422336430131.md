> Running each coding agent in a different stack gets messy fast.
> 
> HarnessRouter Community Edition is a self-hosted interface and API for running agent harnesses on your own machine.
> 
> It helps you run harness-based agent work from one place by packaging a console, a Responses-compatible API, and a runner inside one Docker container.
> 
> Key features:
> 
> • One-container setup – start a local instance with Docker, persistent data, and a browser console
> • Native harness support – run Codex, Claude Code, and Hermes through the same interface
> • Responses-compatible API – create harnesses, run turns, manage sessions, stream output, and cancel work through the API
> • Isolated session workspaces – each session gets its own workspace, conversation state, and checkpoint
> • Open protocol implementation – includes the Unified Harness Protocol specification, schemas, and conformance suite
> 
> It’s open-source (Apache License 2.0).
