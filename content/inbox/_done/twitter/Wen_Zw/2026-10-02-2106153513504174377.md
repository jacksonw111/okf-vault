> Cloudflare wants to become the internet’s everything company.
> 
> Now it wants developers to build the next Git platform on Cloudflare.
> 
> Cloudflare thinks GitHub was built for a world where humans write, review and merge code.
> 
> That starts to look very different when hundreds or thousands of AI agents are coding at the same time.
> 
> So Cloudflare built Artifacts, a Git-compatible system designed to create, fork and manage repositories at massive scale.
> 
> Now it’s giving developers that infrastructure and asking them to rethink what Git hosting should look like for AI agents.
> 
> They're even running a competition to see who can build the next Git platform on top of it.
> 
> Announcement here
> https://blog.cloudflare.com/next-git-platform-on-cloudflare/
