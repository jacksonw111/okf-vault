> 转发内容

> 家里的破监控摄像头有救了，GitHub 上这个项目简直是搞智能家居和视频流的技术狂魔写的神作！
> 
> 如果你被摄像头延时高、跨平台推流卡顿、多协议不兼容折磨过，兄弟们直接看这个。
> 
> 项目介绍
> AlexxIT / go2rtc
> 来自 GitHub 社区的超轻量级、零依赖摄像头流媒体服务器，目前在 GitHub 搞到了 10k+ Stars（MIT 协议）。用 Go 语言写的，单个二进制文件直接运行，占用资源低到能跑在树莓派上。  
> 
> 核心卖点
> 零延迟推流：支持 RTSP 转 WebRTC/MSE，延时直接压到 0.5 秒以内。  
> 
> 协议万能通吃：RTSP、RTMP、WebRTC、HomeKit、HLS 全搞定。  
> 
> 双向语音对讲：支持小米、Wyze 等多种摄像头的反向音频传输。  
> 
> 无缝无脑集成：无缝对接 Home Assistant 和 Frigate，自带 FFmpeg 按需转码。  
> 
> 私有化极速部署：完全本地运行，不走任何云端，隐私防护拉满。  
> 
> 🔗 项目链接：
> https://github.com/AlexxIT/go2rtc
