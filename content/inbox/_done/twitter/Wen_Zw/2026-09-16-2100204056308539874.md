> 转发内容

> 发现一个专门做动效视频的开源 skill 合集
> 
> 一条命令装进 Claude Code 或 Codex，就能让 AI 直接生成各种丝滑动效视频
> 
> 一共16个 skill ，能做：
> 
> 品牌宣传片、K线蜡烛图动画、黑胶唱片播放器、procedural 鱼群动画、Claude 打字机动画、SVG logo 动效、Remotion 3D 滚动长廊……
> 
> 每个 skill 对应一类具体的视觉输出，说一句话就能触发
> 
> 装完直接告诉 AI 你要做什么效果，它自己去调对应的 skill 跑出来
