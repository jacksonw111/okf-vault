> 转发内容

> 分享一个用于让 Agent 装修我们 Github 仓库主页的小技巧，我们可以告诉 Agent：“把 README 当成一份纵向演示文稿：用一套可复用的 SVG 组件设计首屏和章节标题，用 Markdown 承载真正的内容。”
> 
> 由于GitHub 不能自定义 CSS，所以我们先把首屏和章节标题设计成 SVG，再像普通图片一样插入 README。正文仍然使用 Markdown，兼顾美观、搜索和阅读。
> 
> 我在我的仓库 https://github.com/oil-oil/oil-ppt 使用这种方式做出了我觉得很不错的设计效果，相比于其他的主页会给人一种小惊喜感，而且整体的风格搭配也和我的 PPT 主题是一致的。
> 
> 这是我的 svg 的风格，给大家用于参考：SVG 主要遵循这套规则：
> 固定画布：首屏 1200 × 320，章节标题 1200 × 138
> 统一语言：浅色圆角容器、细网格、点阵、黄色短线
> 清楚层级：英文眉题 → 中文大标题 → 淡色章节编号
> 装饰克制：右侧点阵和数字只负责平衡画面
> 系统字体：避免 GitHub 加载不到外部字体
> 每个章节复用同一个模板，只替换标题、编号和眉题
