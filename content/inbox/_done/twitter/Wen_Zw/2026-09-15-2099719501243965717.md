> 腾讯云开源了 Octop：一个主打多用户、多智能体的本地私有化 AI 助手平台。
> 
> 它不仅是一个对话框，而是为团队和家庭打造的独立智能环境。一人单机部署，全团队或全家即可无缝共享多个定制化 AI 助手。
> 
> 核心能力与场景：
> • 完全本地与隐私安全：单进程启动，数据默认全部存储在本地 ~/.octop/ 的 SQLite 中，不用担心隐私泄露。
> • 多角色无缝切换：内置 16 种 MBTI 人格模板与专家库，不同家庭成员或团队角色可以按需切换专属 Agent。
> • 全渠道打通：自带强大的 Web 控制台，并原生支持接入飞书、钉钉、企业微信、QQ 和 Discord，日常在群聊里就能直接派发任务。
> • 深度面向开发者：支持双向 ACP（Agent Client Protocol）协议，既可以调用外部工具，也能直接将复杂代码任务委托给 Claude Code 或 OpenCode 等 IDE 工具。同时内置了用于网页自动化的 Browser AI 和终端协助的 Terminal AI。
> 
> 目前项目刚发布了 1.0.0 版本。如果你在寻找一个能部署在局域网内、默认打通办公 IM 软件，并且能统一管理本地知识库和 API 密钥的“数字中枢”，这个开源方案非常值得一试。
> 
> 项目地址：https://github.com/TencentCloud/Octop
