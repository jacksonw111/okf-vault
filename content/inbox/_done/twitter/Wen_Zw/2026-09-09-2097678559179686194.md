> Browser-Use 团队发布轻量级新项目：Browser Use Pi 🥧
> 
> 一个极致精简的 TypeScript Web Agent，由 Astra 基于真实浏览器评测驱动构建与打磨。
> 
> 核心亮点：
> 
> 去粗取精：提炼 Browser Use、Harness 与 BrowserCode 核心，剔除冗余启发式规则（Heuristics）与冗余代码
> 
> 底层架构：基于 Pi Mono + 持久化 V8 REPL + 原生 CDP，全 TypeScript 构建
> 
> 功能完备：自带云浏览器支持、持久会话、流式传输以及步骤限制
> 
> 安装命令：npm install @browser_use/pi
> 
> 开源地址：https://github.com/browser-use/browser-use-pi
> 
> #AI #WebAgent #TypeScript #OpenSource
