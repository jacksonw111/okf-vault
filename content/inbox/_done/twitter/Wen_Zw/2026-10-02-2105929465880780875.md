> "Generate a comprehensive, production-ready Design System documentation board for an Enterprise Automation Web App. The overall theme must be dark mode (using deep grays and slate tones) with a primary brand color of tech-focused blue. Please structure the layout into a clean, organized grid with the following distinct, labeled sections:
> 
> DS - 00 Overview:
> A text-heavy section for design principles and general usage rules.
> 
> DS - 01 Color:
> Include a 'Primitive palette' showing grayscale and primary color swatch scales (e.g., 100 to 900). Below that, include a 'Semantic roles' section mapping specific colors to backgrounds, text, borders, and interactive states (success, warning, error).
> 
> DS - 02 Typography:
> Display a complete type scale hierarchy (from small captions to large H1 headings) alongside a section for writing rules.
> 
> DS - 03 Foundations:
> Show visual examples and scales for spacing tokens, border radius sizes, and elevation/drop shadows.
> 
> DS - 04 Component Usage:
> A dedicated area explaining component behavior and anatomy guidelines.
> 
> DS - 05 Components:
> A core native component library showcasing UI elements in multiple states (default, hover, disabled). Must include primary and secondary Buttons, form Text Fields, status Badges, and Navigation items. The final output should look like a professional, organized Figma file ready for developer handoff, featuring clear section dividers, large section headers, and high-contrast typography."
