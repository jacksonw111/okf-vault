用终端加编码 agent 干活时，想看代码就得忍受满屏 diff 和 agent 的长篇文字汇报。

这是一个Rust 写的 herdr 插件，Claude Code、Codex、Gemini CLI 这类 MCP agent 配一个代码评审面板。你在面板里选中某几行代码、写下意见、打个标签（fix / verify / question / nit），批注会带着行号锚点结构化地传回给 agent 去改。

https://github.com/JonasBaeumer/herdr-file-annotator
