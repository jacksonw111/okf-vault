知微是个桌面财务管理应用，前端用 Qt/QML 搭界面，后端用 Java Spring Boot 处理数据。功能上能注册登录、记流水明细、管理资产账户、看统计图表、做预算控制。

项目是中南大学的学生作品，基于 Qt Creator 开发，界面截图展示了完整的操作流程。
