科研画图的提示词不用自己憋了，agent 从图库里挑几张摆成样板册，你挑一张，它拿你的数据照着画。

https://github.com/liouhai/plot-is-all-you-need

这是给 Claude Code 和 Codex 用的画图技能，挑图方式是让 agent 看图，不靠一堆规则去描述风格。图库公开部分有 95 张：14 张本仓库自己画的、带代码，81 张摘自开放获取论文，每张都配了鉴赏卡片，另外还有 350 条只存卡片没存图的条目。
