把实时新闻从多源抓取、向量索引到 AI 问答和流式分析串成一条完整流水线，解决新闻平台更新滞后、搜索缺上下文、分析不实时的问题。

https://github.com/jinit-00/PulseNews-Live-AI-News-Streaming-Platform

平台跑在 Python 3.11 + FastAPI + React 上，用 Docker 一次起全套服务，支持单机内存模式和 Kafka + Qdrant + Elasticsearch 集群模式两种跑法。数据流走 Apache Kafka，从全球 RSS 源持续收稿，入库前做去重、情感分析和关键词提取，再通过 WebSocket 推到前端，刷新页面才能看到新内容的操作省掉了。
