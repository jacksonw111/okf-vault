Obot 帮企业统一管理 AI 客户端使用的模型、MCP 服务、Skills、凭据、权限和审计记录。

https://github.com/obot-platform/obot

Obot 是 Obot AI 开源的 AI 治理平台。它用 MCP 和 LLM 网关，把 Claude Code、Codex、Cursor、VS Code 等客户端接到获准使用的模型和服务上。

团队可以自行部署 MCP Server 和 Agent，并用身份、权限、凭据和审计功能管住整个链路。
