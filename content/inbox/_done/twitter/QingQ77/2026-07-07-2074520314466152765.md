面向 sub2api / new-api 自托管 API 服务的多上游运营管理中心。

支持上游站点添加与同步、余额跟踪、分组倍率快照与历史、定时调价活动（到期自动恢复原倍率）。后端 Go 1.25，前端 Vue 3.5，数据库 PostgreSQL 16+、缓存 Redis 7+，提供 Docker Compose 一键部署。

https://github.com/deviseo/transit-hub
