给 Pi Coding Agent 一个原生 macOS 桌面界面，让长跑的编码会话和文件审查不必挤在终端里。

https://github.com/hieunc229/Pie

SwiftUI 写的原生 macOS 客户端，给 Pi Coding Agent 当桌面外壳，不做 fork。每个活跃会话启动一个 pi --mode rpc 进程，消息、凭据、扩展全归 Pi 管，应用自己只存最近项目、置顶、草稿和窗口布局。
