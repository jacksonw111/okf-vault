AI Agent 编排平台，通过 LLM 决策引擎实现感知→规划→执行→反馈的完整闭环。

https://github.com/nullpointexception-i/agent-sphere

一个 AI Agent 编排平台，基于 Java 21 + Spring Boot 3.4。它用 LLM 驱动决策，支持 OpenAI、DeepSeek、智谱等多个模型，提供内置工具、MCP 协议、CLI、浏览器操作等能力。核心特性包括 ReAct 执行循环、多级记忆系统、模型路由和故障回退、SSE 实时推送。
