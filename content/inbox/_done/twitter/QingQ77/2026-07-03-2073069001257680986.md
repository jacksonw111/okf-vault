在 macOS 上通过 USB MTP 协议原生传输文件到 Android 设备，无需第三方工具。

https://github.com/kalabhaftu/MacMTP

用 USB MTP 协议在 Mac 和 Android 设备之间传文件。前端用 Swift/SwiftUI 写，底层用 Go 的 MTP 引擎（基于 OpenMTP/Kalam）通过 C 桥接层集成。双面板文件浏览器（左边本地、右边设备），有批量传输带进度控制、冲突处理（覆盖/跳过/按大小比对）、拖拽、快捷键、暗色模式。支持 Apple Silicon 和 Intel，需要 macOS 14.0。
