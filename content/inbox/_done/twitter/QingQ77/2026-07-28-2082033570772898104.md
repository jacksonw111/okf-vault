帮助 coding agent 从长视频中提取带时间戳的可复用证据，避免逐帧采样带来的遗漏和上下文丢失。

https://github.com/mupozg823/timecode-agent

一个 Python 命令行工具，专为 coding agent 设计，用来处理长视频并生成可复用的时间戳证据账本。它采用"转录优先"策略——先提取时间轴转录文本和场景、音频、OCR、人脸等确定性信号，再按需进行视觉验证，而非固定采样所有帧。生成的检测点（checkpoints）、捕获来源和编辑决策存储在仅追加的账本中，支持 EDL、FCPXML、OTIO 等后期导出格式。
