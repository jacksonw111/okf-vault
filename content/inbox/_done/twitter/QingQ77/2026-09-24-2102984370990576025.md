把浏览器点击、填表这类操作交给本机跑的模型，省掉云端 API 调用和对应的账单。

https://github.com/APUS-AI-Lab/fast-browser-use

APUS AI Lab 把 Qwen3.5-9B / 35B-A3B 的权重搬进本机，靠 MLX 或 PyTorch 驱动浏览器操作。

做法是先扫一遍页面，只收当前可见、可点的元素，凑成一份候选动作清单，模型在一个 token 的 logits 上挑定一个，不逐字解码，也就吐不出页面里压根不存在的 CSS 或 XPath 选择器。
