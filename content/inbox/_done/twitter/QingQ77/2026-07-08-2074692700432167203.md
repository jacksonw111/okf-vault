Pi 编码 agent 的本地桌面 GUI（Tauri 框架）

Picot 是 Pi 编码 agent 的本地桌面 GUI，基于 Tauri 框架开发，是 deflating/tau 的维护分支。它内置 Pi 运行环境，支持多项目多窗口并行、多会话管理、实时流式聊天

提供包管理器 UI、费用仪表盘、LAN/移动端访问（QR 码）、语音输入、6 套主题等功能，完全本地运行，无需云端账户。

https://github.com/shixin-guo/picot
