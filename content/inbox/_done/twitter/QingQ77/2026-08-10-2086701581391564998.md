基于 Tauri 2 和 React 19 的开源桌面 Git 客户端，覆盖 Windows、macOS 和 Linux，支持 GitHub、GitLab 和 Bitbucket。它的 GitHub 操作全部走 gh CLI，应用不申请 OAuth 权限也不存令牌。

git 操作调用系统 git，所以登录过 gh 的 GitHub Enterprise 服务器也能直接使用。

界面保留 GitHub Desktop 那种容易上手的交互，把完整的 PR 生命周期搬进了应用：评审、评论、指派、审批、合并、解决冲突都不用开浏览器，另外还有 Actions 操作台、Issues/Discussions、Dependabot 等安全告警和仓库浏览克隆功能。
