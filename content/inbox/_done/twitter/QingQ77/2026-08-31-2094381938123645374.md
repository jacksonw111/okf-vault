CleeCode 是个 Rust 写的终端 IDE,界面基于 ratatui/crossterm,编辑器和文件树跟真正的 shell 终端共处一窗,中央不再需要切换。

编辑器该有的都有:200 多种语言高亮、多标签页、分屏、正则搜索替换、代码折叠、列选,还有 git 面板和语言服务器支持,Markdown 文件上会浮一条工具条,按钮显示实际会写入的字符,用久了自然就记下语法。

https://github.com/msavox/cleecode
