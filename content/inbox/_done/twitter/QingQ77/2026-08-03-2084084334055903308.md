Kumo 是 Cloudflare 开源的 React 组件库，面向现代 Web 应用。组件基于 Base UI 封装，键盘导航、焦点管理和 ARIA 属性都内置处理，符合 Cloudflare 的设计系统规范。

库内含约 45 个组件，覆盖按钮、对话框、日期选择、Toast、Tooltip 等常用场景，支持按组件细粒度引入以利于 tree-shaking，同时重新导出 Base UI 原语供高级用法。

https://github.com/cloudflare/kumo
