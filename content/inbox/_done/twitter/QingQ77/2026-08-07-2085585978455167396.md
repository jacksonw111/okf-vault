macOS 开发者要在十几个工具标签页之间来回切换才能拼出"我的工作状态"，Salience 把这些信息汇成一个图。

https://github.com/clegginabox/salience-macos

Salience 是跑在 macOS 上的桌面应用，跟着 git 分支走，把 PR、工单、CI、容器、部署这些相关数据自动关联成一张图，放在副屏上看。应用里没有收件箱和弹窗，推导引擎把值得注意的变化生成 situations，按紧急程度决定提醒强度。
