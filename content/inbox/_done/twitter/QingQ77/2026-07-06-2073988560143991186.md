一个自主智能体框架，本地或云端 LLM 都能用，桌面/服务端/终端三种跑法。

https://github.com/Veyllo-Labs/VAF

Python 写的智能体框架，支持本地 GGUF 模型和 OpenAI、Anthropic 等云 API。

三种运行模式：桌面模式（系统托盘 + 网页界面）、服务器模式（systemd 开机自启、HTTPS）、终端模式（TUI 聊天或单次 prompt）。

内置 100+ 工具，有编程/搜索/研究三个子智能体，持久化记忆用 pgvector + Redis，代码改动能用 Git 快照回退。
