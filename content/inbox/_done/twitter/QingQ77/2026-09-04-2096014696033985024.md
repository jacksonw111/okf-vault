TTT 是用 Go 写的一个跑在终端里的 IDE，想替代 VS Code 这类重型编辑器，单个二进制文件，不用折腾配置。

该有的都有：语法高亮、多光标、折叠、LSP 补全跳转、Git、全局搜索、自带终端、多目录工作区，还有 Lua 插件和主题可换。

https://github.com/eugenioenko/ttt
