把 GitHub 编码数据做成排行榜和趋势图，公开、私有、工作仓库都能统计。私有仓库在本机读取，服务端只收到汇总数字，仓库名称也不会默认上传。

https://github.com/yaroslavhaidash/gitstats

基于 Next.js、TypeScript、Drizzle ORM 和 Neon Postgres 的开源编码统计面板。登录 GitHub 并用邀请码组队后，用户可以按周、月或年比较代码增删量和提交数，个人页还会展示连续贡献、语言分布、活跃仓库和趋势图表。
