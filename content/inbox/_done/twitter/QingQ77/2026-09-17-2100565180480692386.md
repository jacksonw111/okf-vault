把 GitHub PR 的改动按关注度分组排序，生成一份从总览讲到代码细节的 HTML 页面，让人不用逐行翻 diff 就能判断 PR 该不该收。

https://github.com/VirtusLab/tulip

VirtusLab 出的 TypeScript CLI，装完在 PR 链接后面敲 tulip 就能跑。

它借用本机已登录的 claude CLI 做多轮分析（不用 API key）：Sonnet 给改动分组并按 Read closely / Read through / Skim 三档排序，Haiku 把每条改动归到组里、顺带丢掉 lockfile，Opus 逐组写讲解，最后拼成一张带 Mermaid 图、并排高亮 diff 和浮动目录的单页 HTML。
