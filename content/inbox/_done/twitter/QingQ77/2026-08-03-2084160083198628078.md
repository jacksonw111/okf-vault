让整个公司共用一个智能体：每个人有自己的隔离工作区，也能在频道和项目里一起协作，而不是各养各的个人助理。

https://github.com/yc-software/qm

QM 是 Y Combinator 开源的多人智能体框架，给初创公司用。每个员工有自己的隔离工作区，也能在 Slack 频道、群聊、项目里和智能体协作；人和房间各自带作用域，记忆、文件、密钥、权限、定时任务、Web 应用和持久化沙箱，互不干扰。

核心是无头 TypeScript/Node 服务，harness 和模型走接口，Pi、OpenCode、Codex、Claude Code 随时换
