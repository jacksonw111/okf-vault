NodeGraph 是 VS Code 扩展，读完论文后自动生成交互式知识图谱。每条观点都带原文引用，右键跳转到 PDF 对应位置核对。

支持两种工作流：让 AI agent（Claude Code、Codex 等）读 PDF 自动建图，或者手动拖拽搭建。节点内容支持 Markdown 表格、LaTeX（KaTeX）、行内图片和折叠章节，全在一张卡片里渲染。

https://github.com/Jeong-jin-Han/NodeGraph
