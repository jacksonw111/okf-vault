让 agent 在一个同步周期内拿到用户的完整本地上下文（邮件、文档、聊天、仓库），把「等几周才认识你」的冷启动期压到几分钟。

https://github.com/tinyhumansai/openhuman

Rust 写的开源 Agent Harness，它把你本机的数据压成带评分的 Markdown 记忆树存进 SQLite，再镜像成一个 Obsidian vault，打开就能翻、能改。

自动抓取每 20 分钟跑一次，TokenJuice 把工具输出送进模型之前先压一遍，官方给的上限是省 80% token。
