用 AI Agent 架构重构角色扮演体验，通过记忆账本、决策卡、自建面板与世界线存档解决传统角色扮演中上下文冗余、剧情不可控、结局单一的问题。

https://github.com/weidu12123/Liyuan

梨园是 AI Agent 为主的角色扮演应用，harness 层直接裁剪过程性内容，每轮省 53%–63% 上下文，同样窗口装的剧情翻倍。

关键剧情节点 agent 会停下来弹决策卡，由用户拍板走向；装备库、SVG 地图这类面板让 agent 自己生成、随剧情更新。
