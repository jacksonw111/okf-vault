把 Claude Code 的壳借给别的模型用，MCP、skills、CLAUDE.md 这些配置原样保留，还带一个真实会话评分工具，告诉你模型到底扛不扛得住。

https://github.com/Fanfulla/Lupin

Lupin 是跑在本地的小代理，Claude Code 的外壳不动，里面换成别的模型。MCP 服务器、skills、CLAUDE.md、hooks、记忆、插件都照旧，不用重配。

走哪条通道由它自己定：Kimi、DeepSeek、GLM、Ollama 这些本来就讲 Anthropic 协议的直连，OpenAI、Gemini 按量计费这类要翻译，ChatGPT 订阅和 Gemini Code Assist 订阅则是各自私有的协议，各配了一个翻译器，OAuth 登录。
