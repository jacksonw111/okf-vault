手机上写代码要在终端、编辑器、AI 之间来回切换，Mobile Harness 把这一套收进一个 App。

https://github.com/techjarves/Mobile-Harness

Mobile Harness 跑在安卓手机上，原生界面拿 Kotlin + Jetpack Compose 写成，底下挂一个 PRoot 用户空间里的 Ubuntu 20.04，不用 root。Claude Code 官方 CLI 装在里面，边想边改文件，项目、聊天记录和文件上下文跨会话留着。
