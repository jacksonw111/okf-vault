在终端里同时跑本机 Groc、Kimi 和 Claude 的 CLI，不用一条条手写参数，也不用挨个等完一家再跑下一家。

把本机 Grok CLI（grok-4.5）、Kimi Code CLI（K3 1M）和 Claude Code CLI（默认 Fable 5）串起来，支持真正同时开工。

batch 模式同时启动独立任务
dual 模式处理有先后依赖的任务
三家的流式事件实时往终端和日志里吐。
