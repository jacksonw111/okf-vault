给短视频/自媒体用的本地分镜台 Codex 插件，让 Codex 直接建视频项目、写分镜表，再用图片/视频生成能力把素材填回对应镜头。

以 Codex 插件形式分发，装好后在 Codex 里说一句“打开分镜台”就能拉起本地 Web 工作台（默认 127.0.0.1:43218），不用懂 MCP 或文件路径。
