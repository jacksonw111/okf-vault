SimpleCard 是一个自托管的数字商品发卡平台，负责把卡密、激活码、账号自动发给付款成功的买家，买卖全程无人值守。

https://github.com/runtimepoet/simplecard

后端用 Spring Boot 3.4 + Java 22 写 API，前端是 Next.js 16 + React 19 的门 storefront 与后台管理面板，数据库跑 PostgreSQL 18+，前后端用一个 pnpm 工作区 monorepo 统一管理。
