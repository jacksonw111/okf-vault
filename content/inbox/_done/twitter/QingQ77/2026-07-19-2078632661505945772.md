拿现代 Web 栈把一套老 Oracle APEX 项目管理应用重写了一遍。

用 React 19、NestJS 11 和 Supabase 重新做了一套项目组合管理（PPM）系统，替代原来的 Oracle APEX 版本。它能对九类记录做完整增删改查: 里程碑、行动项、问题、链接、资源、更新、状态报告、附件、人员，还带了四步项目向导、按字段记的历史审计和删除审计。
