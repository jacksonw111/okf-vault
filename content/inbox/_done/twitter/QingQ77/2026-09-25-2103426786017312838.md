输入一个网站首页地址，自动完成实时 SEO 审计，并用 PDF、XLSX 和 Markdown 给出可执行的改进清单

https://github.com/AgriciDaniel/jev-seo

一个本地 Python 命令行工具，也能装成 Claude Code skill。输入网站地址后，它会抓取页面、运行 52 项 SEO 检查、读取 PageSpeed 数据，再让 Jev 判断页面类型、搜索意图、内容质量、标题和描述。规则结果与模型判断会写进同一份 audit.json，并生成 PDF、Excel 和 Markdown 报告。
