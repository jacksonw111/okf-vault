本地读取 Claude Code 和 Codex 的会话记录，把 token、模型和费用摊在一张自建面板上，多台机器汇到同一个 hub。

https://github.com/LockedinLabs-AI/agent-console

LockedIn Labs 出的这个面板，打开就能看到最近 1 小时到 30 天的 token 怎么拆成 cache read、cache write、output 和 uncached input，各模型与各机器分别花了多少钱，当下每分钟吃掉多少 token、折合每小时几美元，每条会话一行 lane，外加上下文增长和缓存断裂的告警。
