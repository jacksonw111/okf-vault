> 今天发现了一个挺有意思的开源模型 Needle：
> 
> 这是一个专门跑在端侧的超微型自动化模型，体积只有 8MB 到 29MB。
> 
> 它专精两件事：理解用户指令然后调用工具，以及提取结构化 JSON。
> 
> 本地离线运行。零网络延迟，零 API 账单，设备断网也能秒级执行自动化。
> 
> 如果遇到搞不定的复杂任务，它还能输出置信度分数，自动转交给云端大模型兜底。
> 
> 适合场景：
> - 智能家居或硬件折腾，想在本地通过自然语言触发控制、调接口。
> 
> - 做客户端或本地小工具，想做自然语言意图识别，又不想每次都调云端 API 烧钱。
> 
> 项目地址：https://github.com/cactus-compute/needle
