> 转发内容

> sim-use v0.14.0 is out! Physical iPhones and iPads are now supported as experimental targets 📱
> 
> `sim-use ui`, the `tap '#id'`, and screenshot can now drive a plugged-in device directly by your agent with the CLI — no test runner, no re-signing, and no Developer Disk Image required.
> 
> Physical-device support currently covers basic UI description, tapping, and screenshots, with more actions coming soon in next releases!
> 
> This release also includes countless improvements to the existing iOS Simulator and Android emulator/device support. See more in the release note.
>
