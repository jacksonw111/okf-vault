> https://ambientcss.vercel.app/
> 
> Ambient CSS 非常漂亮，也没有见过类似的库，用物理光照模型给 CSS  React 组件做高光、阴影和表面材质 作者把同一套几何和灯光同时在 Blender里渲染 在浏览器里用 box-shadow 和 CSS 变量复现
> 
> 有不同光源 材质的效果 还有组件：按钮 旋钮 滑条 推子 开关等 
> 
> 你如果想做一个惊艳的站点，完全可以用这套系统来试试看
