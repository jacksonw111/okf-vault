> Cloudflare turned 16 this week 🎂
> 
> So here are 16 launches you should try first:
> 
> 1. Clef + Clef-flash: open-source decision models with deterministic outputs, fully compatible with the Jev API. #1 on Hacker News.
> http://blog.cloudflare.com/clef-decision-models
> 
> 2. cf: one agentic CLI for the entire Cloudflare API. Hand it to your coding agent and let it drive.
> http://blog.cloudflare.com/cloudflare-cf-cli-launch
> 
> 3. Workers KV Instant: sub-2ms p99 reads and 250ms global replication, powered by Quicksilver, Cloudflare's internal config store.
> http://blog.cloudflare.com/workers-kv-instant
> 
> 4. Artifacts: create, fork, and clone git repos from a Worker. Agents already speak git. There's a contest to build the next Git platform.
> http://blog.cloudflare.com/next-git-platform-on-cloudflare
> 
> 5. Cloudflare OS: an open-source agent workspace that knows how your company works and connects to your data and systems.
> http://blog.cloudflare.com/managed-cloudflare-os
> 
> 6. K2: serverless, ordered event streams on R2. Kafka-style streams with no brokers to run.
> http://blog.cloudflare.com/cloudflare-k2-streams
> 
> 7. Forge: open-source pipeline that runs in CI and generates SDKs, CLIs, and docs directly from your API definitions.
> http://blog.cloudflare.com/forge-open-source-generation-pipeline
> 
> 8. EmDash 1.0: stable open-source CMS for Astro with a secure plugin registry.
> http://blog.cloudflare.com/emdash-cms-plugin-registry
> 
> 9. Vinext 1.0: run your Next.js app on Vite. Migrate with npx vinext init.
> http://blog.cloudflare.com/vinext-nextjs-on-vite
> 
> 10. Workers Issues: production errors grouped and sent straight to your agent.
> http://blog.cloudflare.com/real-time-issue-detection
> 
> 11. Containers for agent sandboxes: 6x faster starts, and your agent picks the image and instance type for each sandbox.
> http://blog.cloudflare.com/faster-agent-sandboxes
> 
> 12. Cloudflare Traces (open beta): follow any request through WAF → cache → Worker → origin with one Ray ID.
> http://blog.cloudflare.com/cloudflare-tracing
> 
> 13. Auto Router: an edge classifier picks the right model for each request, so you stop paying frontier prices for easy prompts.
> http://blog.cloudflare.com/auto-router
> 
> 14. Web Search API in AI Gateway: real-time web context from Exa, Linkup, and Ceramic, on one bill.
> http://blog.cloudflare.com/introducing-web-search-api
> 
> 15. Threat Signals: open-source threat reports turned into indicators that plug straight into your WAF rules. Free for every Cloudflare account.
> http://blog.cloudflare.com/threat-signals
> 
> 16. Protected Quick Tunnels: share localhost with email auth, no account needed.
> http://blog.cloudflare.com/protected-quick-tunnels
> 
> And a lot more. Send this to the teammate who keeps asking "what should we try on Cloudflare?"
> 
> Everything in one place:
> http://cloudflare.com/birthday-week
> 
> Which one are you trying first?
