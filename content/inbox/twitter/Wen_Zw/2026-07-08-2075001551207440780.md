> 转发内容

> 离谱了，这玩意真有人做出来了！直接把浏览器魔改成了一个完整的电脑桌面系统。
> 
> GitHub 上挖出的 3.2k 星开源神器 kodbox，名义上是个 Web 文件管理器，实际上是个随身的云端 OS + 在线 IDE。不管你人在哪，用谁的电脑，只要打开浏览器，立马接管你的所有云盘和本地文件，还能直接写代码建网站，白嫖党狂喜！
> 
> 🔥 万物皆可挂载：本地盘、WebDAV、S3、阿里 OSS 等全能捏在一起集中管理。
> 🚀 桌面级操作感：全局拖拽、右键菜单、Ctrl+C/V 快捷键全都有，丝滑得不像网页。
> 👁️ 全能在线预览：上百种格式直接开，Office 文档、视频，甚至能在线直接解压包。
> 💻 行走的开发机：内置代码编辑器，支持 120 种语言高亮，随时随地敲代码。
> 🆓 极低配置门槛：Windows/Mac/Linux 全平台通吃，一台吃灰旧电脑就能跑。
> 
> 🔗 GitHub 传送门：https://github.com/kalcaddle/kodbox
