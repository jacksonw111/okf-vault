给 Claude Code、Codex、Cursor、OpenCode 等编码智能体提供本地 MCP 代码质量评分循环。

https://github.com/NiazMorshed2007/jev-review

一个本地运行的 MCP 服务器，基于 TypeSafe 的 Jev 评估服务为 AI 编码智能体提供结构化质量分数。通过 npx plugins add 直接从 GitHub 安装，支持 Claude Code、Codex、Cursor、OpenCode，运行时是本地 Node.js 20+ 进程，经 stdio 只暴露一个 jev_review 工具。
