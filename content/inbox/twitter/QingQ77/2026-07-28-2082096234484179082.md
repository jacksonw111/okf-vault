中长篇写作的上下文太长，OpenFic 用 Agent 系统加 RAG 帮你管住百万字级别的人物关系和剧情线。

https://github.com/syrizelink/OpenFic

Python 后端加跨平台前端的写作工具，背后跑 Agent 系统。装法有三种：Docker、pip 或直接下桌面版。Agent 能读到百万字级别的上下文——RAG 语义检索加多层压缩缓存，不是抽卡式一键出文。设定管理、角色卡、工作流和 Prompt 全都可以自己改。数据全在本地，支持主流模型 API
