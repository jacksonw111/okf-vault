两个月，50k是怎么做到的，给任意 agent 挂上一段 Markdown 提示词，把模型味儿的文字改成正常人说话的口气，事实一个不动。

https://github.com/blader/humanizer

一个纯 Markdown 的 agent skill，任何支持 skills 的 agent 都能装，npx skills add blader/humanizer --global一行安装。

以 25 条 AI 写作特征为检查表，条号按辨识强度和使用频率排序，前五条（Not X but Y 对比句、每节末尾的金句、听着深刻的格言、进正题前的铺垫、对着没人提出的反对意见辩论）单次出现即可判定，标注 weak alone 的几条要一段里同时命中多条才算。
