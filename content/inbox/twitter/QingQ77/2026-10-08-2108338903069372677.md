给 AI agent 一个能收发信的真实邮箱，人可以在 dashboard 里看同一份邮件并处理隔离件。

https://github.com/boringcomputers/goshen-email

Goshen Email 跑在 Cloudflare 上，一次 API 调用就能开一个 inbox，每个 agent 拿到独立地址、会话线程、附件和只能访问自己邮件的 API key。
