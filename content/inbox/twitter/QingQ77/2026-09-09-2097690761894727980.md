为 Linux 提供交互式磁盘分区浏览与挂载管理的终端界面工具。

一个基于 Textual 构建的 Linux 磁盘与分区浏览器，使用 Python 编写，要求 Python 3.10 及以上版本。它为每个分区展示可视化磁盘用量条，支持 Vim 风格的 jkhl 键盘导航和分区详情面板，可在已用空间与剩余空间两种视图之间切换。

https://github.com/Pratham-Chauhan/disk_view
