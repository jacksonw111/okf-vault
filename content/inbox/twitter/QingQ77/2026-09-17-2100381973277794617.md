把已装好的 Claude Code、Codex CLI 等编程 Agent 统一装进一个桌面应用里配账号、切模型、开会话。

https://github.com/agent-launch/agent-launcher

这是 agent-launch 组织开源的本地桌面工作台 Agent Launcher，基于 Electron + TypeScript

一处管理 6 款已安装的 Agent CLI（Claude Code、Codex CLI、OpenCode、Pi、Gemini CLI、Hermes Agent）。

它只链接系统里现有的 CLI 而不重装，首启向导负责环境检测、一键补装缺失 CLI、账号与 API Profile 配置
