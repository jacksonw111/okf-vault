一个人如何在不花一分钱 API 费用的前提下，用免费额度和开源权重跑起一套包含 140+ 自主代理、20+ 免费 LLM 通道、内容生产和销售自动化的完整业务系统。

https://github.com/BraxisAI/braxis-blueprint

作者花一年时间在 Oracle ARM 免费 VM 上搭了一套 AI 业务系统，这里放的是真实生产脚本，不是教程。

llm_router.py 把 Groq、NVIDIA NIM、Gemini、Mistral、OpenRouter 免费档和本地 Ollama 共 20 多条线路串成带回退和自调优的路由链，约 107 个 cron 任务全靠 cronwrap 的 flock 锁防重复进程。

业务端跑着每日 5 平台发 content、每周约 1000 封带 SPF/DKIM 的冷邮件、14 个 Stripe 商品自动发货，还有一座市长是 LLM 代理的 3D 城市。
