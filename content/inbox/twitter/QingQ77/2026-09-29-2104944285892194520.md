AutoJev 是 Tauri 加 React 加 Rust 写的桌面应用，provider、模型、路由规则都在一个界面里配。本机装了多个 AI agent 时，用一个本地网关统一收请求，按规则把它们路由到合适的模型。

协议认 OpenAI Responses、Chat Completions 和 Anthropic Messages 三种，流式和 function tool call 都能过。
