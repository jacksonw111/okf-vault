不给 AI 代理留一个绞尽脑汁配 key 的步骤，本地装上一个 Rust 二进制就能抓网页、搜东西、爬站，三年不折腾 API key 和账号。

https://github.com/dondai44423/donsetch

DonSeTch 把 HTTP/2、内容提取、PDF 解析、搜索聚合、爬虫这几层全用 Rust 自己写了，不依赖现成的开源网页工具链，最终就一个二进制文件。工具这边是 web_fetch、web_search、web_crawl 三个，接 MCP 就能进 Claude Code、Cursor、Pi，也能当 CLI 直接敲。
