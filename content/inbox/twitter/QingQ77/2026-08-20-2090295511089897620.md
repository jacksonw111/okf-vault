在裸机、边缘站点和私有数据中心复刻 AWS 的 EC2、EBS、S3、VPC、IAM 等 API 服务面，让原本跑在 AWS 上的软件不用改代码就能部署到自有硬件上。

https://github.com/mulgadc/spinifex

这家叫 Mulga 的公司把 Spinifex 做成 AGPL-3.0 开源，AWS CLI、SDK、Terraform 连上它就能用，还带了 ALB/NLB、EKS、ECR、ECS、RDS 等一整套服务面。

每次 API 请求先过网关做 SigV4 认证，再发到 NATS 总线，由对应的无状态守护进程应答；系统里没有 etcd、没有 Kubernetes、没有外部控制面，断网也能正常跑。
