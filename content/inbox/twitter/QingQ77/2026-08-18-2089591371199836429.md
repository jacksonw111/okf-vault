本机跑 DeepSeek Harness 时,这个桌面壳免掉手动敲 CLI、管端口那堆事,把 web 界面包成 macOS / Windows 原生应用。

https://github.com/dataelement/dsh-desktop

用 Electron 把 DeepSeek Harness 的 web 界面封装成桌面应用的壳,支持 macOS (Apple Silicon / Intel) 和 Windows x64。

启动时自动起一个 Harness 子进程、挑一个随机回环端口、存好 profiles/plugins/sessions,界面好了就直接打开,不用先起命令行。
