Eve Directory 是一个开放注册中心，用于发现、安装和贡献 Eve 智能体（agent）

通过 shadcn CLI 可以把智能体装进项目，也可以直接在网站上翻文件，不用登录就能看。社区用户用 GitHub 登录就能提交自己的智能体，想一次打包多个可以用 Composer。

https://github.com/nolly-studio/eve-directory
