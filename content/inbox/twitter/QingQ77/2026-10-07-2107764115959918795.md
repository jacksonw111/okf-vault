把 Pi 编码 agent 搬到手机浏览器里，支持多人同时看同一个会话、从任何回复分叉，服务器重启后继续跑。

https://github.com/TannerMidd/pi-pocket

一个 TypeScript 写的移动优先 Web 应用，把 Pi 编码 agent 装进浏览器，跑在自己机器或手机 Termux 上，不用云 VM。它基于 Pi Durable，把每次模型调用、工具调用和子 agent 都落进一个 SQLite 文件，中途重启服务器，任务会接着跑；被切断的工具调用在安全的前提下重跑。
