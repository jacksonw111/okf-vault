pi-discuss-mode 是 Pi Coding Agent 的一个扩展，提供一个只读的讨论模式。开了之后，编辑和写入工具全禁用，bash 只能跑安全命令（cat、grep、ls 等）。用户可以在不改一行代码的情况下看代码、聊架构、审 PR。灵感来自 Claude Code 的 plan mode。
