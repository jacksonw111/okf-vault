基于 Tauri v2 + React 19 + Rust 构建的跨平台桌面数据库管理工具，支持 PostgreSQL、MySQL/MariaDB 和 SQLite 三种数据库引擎。

提供交互式数据网格浏览、行级增删改查、SQL 编辑器等功能，并内置了基于 Rust 多线程的 SSH 隧道功能，支持密码和私钥认证。

https://github.com/Premod1/SiphonDB
