开发者日常关注的 GitHub 动态、Docker 状态和 SSH 服务器分散在不同工具和终端中。

https://github.com/veyselaksin/glance

macOS 原生桌面仪表盘，用 Go（Wails）+ React/TypeScript 开发，将 GitHub 活动、Docker 容器和 SSH 服务器三块信息合并到一个界面。

GitHub 通过 Device Flow 授权（不存储密码），可查看今日贡献和提交数。Docker 部分支持列出容器状态、CPU/内存占用、启停操作和日志流式查看。服务器功能支持 SSH 连接、内嵌终端和 CPU/内存/磁盘实时指标。
