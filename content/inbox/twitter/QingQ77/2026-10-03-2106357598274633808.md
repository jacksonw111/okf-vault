编码 agent 违反 AGENTS.md/CLAUDE.md 里 linter 查不了的软规则，Abide 在每次编辑和回合结束用决策模型逐条检查并让 agent 当场修复。

https://github.com/clintonimaroo/quietglass

Abide 是 Claude Code、Codex、OpenCode 三个 agent 的 hook 插件，把项目指令文件里的软规则编译成 .abide/rubric.json，每次编辑和回合结束对每条规则向 TypeSafe 的决策模型 Jev 问一个问题。Jev 只返回校准概率，0.8 以上让 agent 在同一回合修复，0.5 到 0.8 只给用户看一条 note，0.5 以下静默。
