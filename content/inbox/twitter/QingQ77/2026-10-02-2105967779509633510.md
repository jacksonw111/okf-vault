把各家 GTM 工具的调用方式和现成增长打法写成 markdown，agent 读完就能照着跑，不用再翻文档找 key 和端点。

https://github.com/GetBrew/growth-engineer

仓库里收了 78 家 GTM 公司和 51 条工作流，全部是 markdown 文件，MIT 协议，agent 读完就能照着执行。

文件分三种，Company 写公司怎么接、要什么凭证，Tool 写单个函数对应的 MCP 工具、CLI 命令或 API 端点，Workflow 是十步以内的跨工具流程，把输入、每个工具的配置和步骤都列出来，还要求 agent 在发消息、花钱、改数据前先问用户。
