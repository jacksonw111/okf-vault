Frog 是 wevm 团队用 TypeScript 写的 agent 摩擦日志工具。agent 卡在某个怪问题上时跑 frog log，把当时的情况和可复现材料一起归到 .agents/friction-log/，随引发问题的代码一起提交。

frog publish 把每条记录提成 GitHub issue，issue 一关，Frog 就开一个 frog/sync 合并请求把对应记录删掉。

https://github.com/wevm/frog
