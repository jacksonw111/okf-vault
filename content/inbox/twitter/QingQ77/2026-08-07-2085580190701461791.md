让产品和 AI Agent 共用一套自托管的邮件基础设施：产品用 REST API 发事务邮件，Agent 用 CLI 收件、等 OTP、起草回复，关键发送由人工在 dashboard 批准。

https://github.com/guangzhengli/mailworker

一个跑在 Cloudflare Workers 上的自托管邮件运行时，代码开源，部署到自己账户，一次部署能服务多个产品和域名。产品侧用一个类似 Resend 的 REST API 发事务邮件，支持附件、批量发送和 webhook；Agent 侧用 CLI 建收件箱、等邮件、提取 OTP、起草回复。
