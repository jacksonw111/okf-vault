SES 便宜但裸用太糙，SaaS 又按封收钱，OpenSend 自己架一层，群发、事务信、调 API 全包，面板和 SDK 调的是同一套接口。

https://github.com/R44VC0RP/opensend

构建在 Amazon SES 之上的自托管邮件系统，覆盖事务邮件、newsletter 和 campaign 群发，后端为 Hono/TypeScript API，对外提供 Web 面板、opensend-js SDK 和 MCP 服务器。
