现有的 AI agent 框架（如 CrewAI、AutoGen）需要用户自己编排 agent 协作流程，Foundry 是一个开源 AI 数字公司平台，技术栈为 NestJS + React（TypeScript），通过 Docker Compose 部署。用户创建公司后，系统自动生成从董事会到员工 agent 的组织结构，输入目标即可由 AI 自动拆解任务、分配执行并汇总结果。平台内置实时群聊、三层记忆系统（公司/部门/agent 级 + RAG）、成本控制与预算管理、人工审批流程。CEO Agent 约每 30 分钟自动巡查待办事项并驱动任务流转。
