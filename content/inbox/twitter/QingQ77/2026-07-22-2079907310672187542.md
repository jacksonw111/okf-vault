这个 Skill 在 Claude Code 或 Codex CLI 里加了一个「召集议会」的能力。

你提一个问题，它同时发给配置好的多个 AI CLI（比如 codex exec、gemini），各自独立回答，最后主机 Agent 当主席把各方意见揉成一份建议。

不额外花钱，因为用的是本地已有的 CLI，不是 SDK 直调 API。装起来很简单，跑 npx 就能装好，自动检测当前环境有哪些 CLI 可用，生成对应的配置文件。

https://github.com/0xwilliamortiz/agents-council
