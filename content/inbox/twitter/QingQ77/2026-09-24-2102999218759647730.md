把几小时的长视频自动切成适合短视频平台的精彩片段，导出不用重新编码。

https://github.com/KnowClip-ai/knowclip

KnowClip 是 KnowClip AI 智能剪辑的开源核心，桌面端用 Tauri 2 + React，后端是 Python FastAPI。它用本地 Paraformer-large 模型跑字级时间戳语音识别，再接入你自己填的 OpenAI 兼容 API Key 做高光分析，产出带标题、描述、话题标签、评分的片段卡片，勾选后批量导出走 ffmpeg -c copy 流复制，不解码不编码。
