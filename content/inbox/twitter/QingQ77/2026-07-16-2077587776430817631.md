GemType 让你在任意网站的文本框里用自己免费的 Gemini API key 做实时语法检查和一键改写，免去 Grammarly 的订阅费用与账号绑定。

一个免费开源的浏览器扩展与 Microsoft Word 插件，定位相当于 Grammarly 的替代品。它接入用户自己的 Google Gemini API key，文本只发往 Google 的接口，不经过任何中间服务器，也不收集账号或遥测数据。

https://github.com/riponcm/GemType
