# Kage (MengTo)

## 它是什么

Kage 是 MengTo 开源的一套「3D 滚动世界」landing page 实现：把整页拆成多个 section，每个 section 都是一段可穿行的 3D 场景，滚动事件驱动相机推进。代码包体极小——不到 1MB three.js + 代码、3MB 含高清 PNG。

## 为什么用它 / 适合什么场景

- 想做「滚动 = 穿越 3D 世界」的高品质 marketing / hero 页面。
- 寻找 three.js 实战参考（场景管理 / 滚动事件 / 性能预算）。
- 想把这套视觉范式套到自己的产品页 / 演示页。
- 学习 MengTo 配套 Skills（build-threejs-scroll-worlds / falling-leaves / pointer-trail-emitter）。

## 关键能力

| 能力 | 说明 |
|------|------|
| 极小代码包 | < 1MB three.js + JS |
| 高质量视觉 | 3MB 内含高分辨率 PNG 资源 |
| 多段 3D 场景 | 每段滚动切换到一个新 3D 视角 |
| Skills 配套 | 仓库附 three.js Skill 把套路沉淀下来 |
| 可现场预览 | mengto.github.io/kage 直接可玩 |
