# FigGenie-paper-diagram-skill

## 它是什么

[FigGenie-paper-diagram-skill](https://github.com/Sleepy-Avacado/FigGenie-paper-diagram-skill) 是 **Sleepy-Avacado** 维护的编码 Agent Skill——让 Agent 按**顶会排版规范**手工写出 SVG。

## 关键能力

| 能力 | 说明 |
|------|------|
| 输出格式 | SVG（手工写，非自动生成） |
| 导出 | PDF / PNG / PPTX |
| 附加产物 | 图注草稿同步生成 |
| 排版 | 顶会标准（学术论文级别） |
| 可编辑 | SVG 矢量，可继续手工 / 工具二次编辑 |

## 与「自动出图」工具的差异

| 维度 | 自动出图 | FigGenie |
|------|---------|---------|
| 生成方式 | AI 直接渲染 PNG | Agent 手工写 SVG |
| 排版精度 | 视觉好看但常出错位 | 顶会规范级排版 |
| 可编辑 | 改不动 | SVG 可继续编辑 |
| 投稿级 | 多数不能 | 是 |

## 适合人群

- AI / 系统方向研究者要投稿
- 写技术博客 / 文档需要专业架构图 / 机制图
- 团队内部技术分享材料
