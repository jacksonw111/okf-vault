# openai/math

## 它是什么

[openai/math](https://github.com/openai/math) 是 OpenAI 官方在 GitHub 开的新仓库：

- **形式化证明语言 Lean** 做数学
- 上线一天就冲到 GitHub 榜首
- OpenAI 在**自动定理证明 / 数学推理**方向的新动作

## 为什么重要

- **AI + 形式化数学**：LLM 在自然语言数学题上很强，但形式化（Lean / Coq）才是「机器可验证的证明」
- **OpenAI 入场**：从 GitHub star 表现看，社区关注度极高
- **形式化范式升级**：让 AI 写出的数学证明可以被 Lean 编译器检查，不再只是「看起来对」
