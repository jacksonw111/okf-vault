# RLink RemoteCtrl

## 它是什么
一个**Windows 上的开源远控 + 协作工具**：

- 临时帮人看电脑：给出 9 位设备 ID + 一次性验证码
- 自己的几台机器登录同一账户就能直连
- 最多 5 人开房间一起看屏幕，还能换人接手主屏
- 4K 120 / P2P 直传 / 5 人房间能换人接替主屏

## 为什么用它 / 适合什么场景
- 临时远程协助别人看电脑（不用双方都注册）。
- 多台 Windows 机器互联做轻量远控。
- 团队里最多 5 人一起看屏幕做协作 / 故障排查。
- 想要参数表比商业远控还「满」（4K 120 / P2P）的开源替代。

## 关键能力
| 能力 | 说明 |
|------|------|
| 平台 | Windows |
| 设备 ID | 9 位 + 一次性验证码 |
| 账号互联 | 多机器同账号直连 |
| 协作房间 | 最多 5 人 |
| 主屏接替 | 房间内可换人接替主屏 |
| 分辨率 | 4K 120 |
| 传输 | P2P 直传 |
| 自建代价 | 凑齐 VS 2022 + Qt 6.11 + 用 `/MD` 编出的 WebRTC（多数人卡在编译） |
