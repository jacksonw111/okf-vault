# Loopweek

## 它是什么

Loopweek 是一款 Android 上的极简周待办应用，把一周七天的待办事项塞进同一屏，左右滑切日期。设计上明确取舍：无账号、无云同步、无广告、无追踪，所有数据存本地 SQLite。

## 为什么用它 / 适合什么场景

- 想用「周」作为时间单位做日常规划。
- 关心隐私，不希望待办数据上云。
- 想要一个不打扰、不弹通知的轻量任务工具。

## 关键能力

| 能力 | 说明 |
|------|------|
| 一屏七日 | 一屏并排显示一周七天 |
| 离线优先 | 数据本地 SQLite 保存 |
| 零账号 | 无需注册 / 登录 |
| 无追踪 | 不埋点、不上云 |
| 极简 UI | 减法设计，去除一切多余控件 |
