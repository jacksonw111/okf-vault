# yoinks（终端视频下载器）

## 它是什么
[yoinks](https://github.com/pablostanley/yoinks) 是一款终端里的 **视频下载器**：与常见在线下载站的体验相反——**没有浏览器、没有弹窗、没有虚假下载按钮**，一条命令把视频抓到本地。适合爱用 CLI 抓视频但又嫌弃 yt-dlp / youtube-dl 配置麻烦或场景不对的用户。

## 为什么用它 / 适合什么场景
- 想在终端里下载视频，不愿被在线下载站的广告 / 弹窗恶心。
- 需要一个比 yt-dlp 更轻量、面向「抓得到就行」场景的小工具。
- 想给非技术同事一个「双击就能跑 / 一条命令就能用」的下载脚本。

## 关键能力
| 能力 | 说明 |
|------|------|
| 终端运行 | 全 CLI，无浏览器依赖 |
| 无广告 / 弹窗 | 不诱导、不跳转 |
| 一条命令 | 输入即下载 |
| 轻量 | 替代在线工具的繁琐流程 |
