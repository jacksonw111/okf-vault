# kubeez-scroll-world-video

## 它是什么

kubeez-scroll-world-video 是一个**零依赖的前端落地页引擎**：用滚动事件作时间轴，把视频当作可拖动的「世界」，做出镜头随滚动穿过连续场景的飞越效果。配套的 Kubeez Media 工作流生成一段黏土风格的汉堡世界视频作为素材，再丢给这个引擎做交互包装。

## 关键能力

| 能力 | 说明 |
|------|------|
| 滚动即时间轴 | 用户滚动 = 视频进度控制，无需复杂状态机 |
| 零依赖 | 单 HTML + 原生 JS / CSS，不引入 GSAP / Lenis 等动效库 |
| 视频做地图 | 把整段视频当作「世界地图」，滚动穿行穿越每个场景 |
| 落地页范式 | 适合品牌发布 / 活动预热 / 产品走查等需要「沉浸叙事」的单页 |

## 适合什么场景

- **品牌营销落地页**：用一段预渲染视频 + 滚动叙事替代传统的多 section 拼接
- **作品集封面**：让作品集首页有「镜头穿行」的临场感
- **发布会预热页**：纯前端、零后端、可静态托管到任何 CDN
