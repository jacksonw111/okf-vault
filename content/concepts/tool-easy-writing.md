# easy-writing（易创）

## 它是什么

[yilujian/easy-writing](https://github.com/yilujian/easy-writing) 是**纯本地**的写小说软件——稿子、设定、码字记录全部存用户电脑，**不用注册、断网也能写**。所有功能都按网文作者的工作流打磨：编辑器、章节管理、历史版本、码字统计、大纲与人物关系图。

定位：

- **离线 / 本地优先**：和云笔记类工具反着来，所有内容不出本机。
- **网文场景特化**：码字统计、章节管理、人物关系图是为长篇连载写的，不是通用 Markdown 编辑器。

## 为什么用它 / 适合什么场景

- 写长篇小说，希望工具稳定、离线可用。
- 不愿意把未发表稿件交到云端，担心泄密或服务停服。
- 想要码字统计 / 章节大纲 / 人物关系图这些网文特化功能，而不是再开一堆通用工具。

## 关键能力

| 能力 | 说明 |
|------|------|
| 本地存储 | 数据全在用户电脑，无云端依赖 |
| 离线可用 | 无需联网，断网也能写 |
| 章节管理 | 长篇连载结构化 |
| 历史版本 | 稿子可回溯 |
| 码字统计 | 跟踪每日 / 总字数 |
| 大纲 + 人物关系图 | 为网文场景特化 |
