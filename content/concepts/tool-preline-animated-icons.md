# PrelineUI Animated Icons

## 它是什么

[PrelineUI](https://preline.co) 计划推出的 **65 个全新动画图标库**（已展示其中 13 个示例）。每个图标是**单个 SVG 文件**，**自带 CSS 关键帧**——不需要 JS 初始化、不需要运行时、内联到页面即生效，颜色自动继承所在文字的 `currentColor`。

- 纯 SVG + 自包含 CSS
- 单文件 drop-in
- 主题无关（颜色 = 父级文字色）
- 无需 JS / 无需 init / 无需运行时

## 为什么用它 / 适合什么场景

- 想要「轻量动画」但不想引入 Framer Motion / GSAP 等动画库
- 单文件可塞进任何 stack（React / Vue / 纯 HTML 都行）
- 颜色跟随文字，深 / 浅主题自动适配
- 体积远小于动效 Lottie JSON

## 关键能力

| 能力 | 说明 |
|------|------|
| 自包含 SVG | 单文件 = 图标 + 关键帧 |
| 零运行时 | 不需要 JS |
| 颜色继承 | 用 `currentColor`，跟父级文字 |
| 单文件 inline | 直接粘贴到 markup |
| 65 个图标 | 即将完整推出 |
