# Oryx（原生单二进制 Markdown / 代码 / 电子书 / 漫画阅读器）

## 它是什么

[wmahfoudh/oryx](https://github.com/wmahfoudh/oryx) 是一个**不依赖浏览器 / Electron** 的**原生单二进制桌面阅读器**：Rust 写的，能极速渲染 **Markdown、代码、电子书（EPUB / Kindle）、漫画**，还能打出**带目录的 PDF**。

## 关键能力

| 能力 | 说明 |
|------|------|
| 原生单二进制 | 不依赖浏览器 / Electron |
| Markdown | CommonMark / GFM 表格 / 任务列表 |
| 代码高亮 | 100+ 种语言 |
| 数学公式 | LaTeX 渲染 |
| 电子书 | EPUB / Kindle |
| 漫画 | 主流格式 |
| 阿拉伯语 | RTL 排版支持 |
| PDF 导出 | 带目录 PDF |
| 极速首屏 | 8MB 文档 / 200MB 书百毫秒级出首屏 |
