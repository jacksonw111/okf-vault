# Amp（Sourcegraph 的 AI 编码代理 ampcode.com）

## 它是什么

**Amp** 是 Sourcegraph 出品的 AI 编码代理，官方域名为 **ampcode.com**。文档与生态站点（`ampcode.com/docs/using-amp`）系统说明了 amp 团队自己**怎么用 agent 的最佳实践**。

## 为什么看它 / 适合什么场景

- 想看一个**对 agent 理解超前**的团队的官方文档。
- **刚入门 agent 的新人**——不走弯路。
- 想学 amp 团队自己的 agent 工作流，而不是被各种第三方教程绕晕。

## 特点

- 文档明说 amp 对 agent 的认识一直是超前的。
- 文档本身就是一套**怎么用 agent 的实战教材**。
- 不止是 README——是有结构的使用指南。
