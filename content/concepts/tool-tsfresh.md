# tsfresh

## 它是什么

[tsfresh](https://tsfresh.readthedocs.io/) 是**时间序列自动特征工程库**：从任何时间序列里自动抽取 700+ 特征（基础统计到非线性动力学），再用数学方法筛掉不重要的；原来几天干的特征工程活，几分钟完成。

## 核心特性

| 特性 | 说明 |
|------|------|
| 700+ 特征 | 自动抽取 |
| 数学筛选 | 自动剔除无关特征 |
| 时间序列原生 | 支持多维时序 |
| Python 库 | scikit-learn 风格 API |

## 为什么用它 / 适合什么场景
- 想做时间序列预测 / 分类但不想手写特征工程。
- 数据科学项目想加速特征提取。
- 时间序列异常检测 / 预测。

## 关键能力

| 能力 | 说明 |
|------|------|
| 自动特征抽取 | 700+ 特征 |
| 数学筛选 | 保留有意义的特征 |
| 多维支持 | 多变量时序 |
| 与 sklearn 集成 | 兼容 ML pipeline |
| 速度提升 | 几天 → 几分钟 |
