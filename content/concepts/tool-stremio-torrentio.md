# Stremio + Torrentio

## 它是什么

[Stremio](https://github.com/Stremio/stremio-web) + [Torrentio](https://github.com/TheBeastLT/torrentio-scraper) 组合：免费开源的 **Netflix 替代方案**，**100% 去中心化、无需账号**。

## 特点

| 维度 | 说明 |
|------|------|
| 价格 | 完全免费 |
| 去中心化 | 无中心服务器 |
| 内容 | 4K 高质量 |
| 跨平台 | Windows / macOS / Linux / iOS / Android / 智能电视 |
| 账号 | 无需账号 |
| 语言 / 字幕 / 质量 | 全部可选 |
| 开源 | 100% 开源 |

## 工作机制

1. 装 Stremio 应用
2. 在 Stremio 里加 Torrentio 插件（搜索 \"torrentio\" 即可）
3. 选想看的内容，插件自动从各大种子站拉取可用流

## 为什么用它 / 适合什么场景

- 想找 Netflix 替代且不愿订阅。
- 重视开源 / 去中心化 / 隐私。
- 想在多个设备上看流媒体。

## 重要边界

⚠️ Torrentio 拉取的是**种子站内容**——使用前请确保符合当地法律与所看内容的版权状态。
