# FinanceDatabase

## 它是什么

[JerBouma/FinanceDatabase](https://github.com/JerBouma/FinanceDatabase) 是开源的**金融标的数据库**——收纳**超 30 万个投资标的**。

## 覆盖品类

| 品类 | 是否覆盖 |
|------|----------|
| 股票 | ✅ |
| ETF | ✅ |
| 基金 | ✅ |
| 指数 | ✅ |
| 外汇 | ✅ |
| 加密货币 | ✅ |
| 货币市场 | ✅ |

## 为什么用它 / 适合什么场景

- 做**量化研究 / 投研工具**需要一份**统一格式**的金融标的数据源。
- 想避免从多家数据商拼装数据集。
- 想把标的数据**下载到本地**做离线分析。

## 关键能力

| 能力 | 说明 |
|------|------|
| 30 万+ 标的 | 覆盖面广 |
| 多品类 | 一份数据库解决多数场景 |
| 高频更新 | 项目维护活跃 |
| 开源免费 | 不需要付费数据源 |
