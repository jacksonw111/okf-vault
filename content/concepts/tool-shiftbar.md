# ShiftBar（macOS 27 菜单栏主动折叠器）

## 它是什么

[ShiftBar](https://github.com/Superoutman/ShiftBar) 是 Superoutman 出品的 **macOS 菜单栏管理工具**：在 macOS 27 上**主动把用得少的菜单栏图标折叠起来**——不等系统在你拖到图标满之后才自动折叠。

## 关键操作

- 常驻菜单栏，**没有 Dock 图标**
- **折叠图标不会让它对应的应用退出**（与应用退出机制解耦）
- 点菜单栏胶囊图标可在**展开 / 折叠**之间切换
- **Shift-click + 按住 Shift 左右拖动**——拖到哪决定**左侧多少图标被藏起来**
- **右键一键把左边全藏了**

## 为什么用它 / 适合什么场景

- macOS 27 菜单栏图标太多，常驻太多看起来拥挤。
- 想**主动**折叠——而不是被动等系统塞满。
- 需要**精细控制**折叠范围（按 Shift 拖动决定左侧多少图标被藏）。
- 不想让折叠影响应用本身。

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | macOS 菜单栏常驻应用 |
| Dock | 无图标 |
| 触发 | 主动折叠 |
| 控制 | Shift-click + 拖动决定范围 |
| 副作用 | 折叠不会让应用退出 |
| 出品 | Superoutman |
