# 面向 Kotlin 开发者的 Rust 学习路径

通过 Kotlin 与 Rust 对照示例学习所有权、错误处理、trait、生命周期、异步与并发。

## 适用场景

- 适合已有 Kotlin 经验、希望系统迁移到 Rust 的开发者。
- 适合通过可运行示例对照语言语义，而不是只读抽象定义。

## 核心内容

| 内容 | 说明 |
|------|------|
| 对照学习 | 每节并列展示 Kotlin 与 Rust 写法，利用已有语言经验建立映射。 |
| 可运行示例 | 包含 17 个可通过 cargo run 执行的示例。 |
| 核心主题 | 覆盖所有权、Option、Result、枚举、trait、生命周期、async 与并发。 |
