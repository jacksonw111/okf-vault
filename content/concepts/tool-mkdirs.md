# Mkdirs

[Mkdirs](https://github.com/MkThingsHQ/mkdirs) 是一个基于 **Next.js + TypeScript + Tailwind CSS** 的目录网站模板，把"做一个 awesome-xxx / 产品目录站"这件事从几周压缩到几十分钟。

## 它是什么

一个开箱即用的目录站（directory site）模板，内置列表 / 分类 / 合集 / 标签 / 搜索、AI 提交表单、支付、认证、CMS 等模块，clone 下来改改就能上线。

## 为什么用它 / 适合什么场景

- **目录站 / awesome 列表**：工具目录、AI 工具导航、产品合集站。
- **目录 + 商业化**：内置支付，可直接挂订阅 / 单卖。
- **AI 提交**：用户可让 AI 帮填目录条目，模版已内置。
- **零基础也能搭**：模块化清晰，TypeScript + Tailwind 现代化。

## 关键能力

| 能力 | 说明 |
|------|------|
| Next.js + TS | 现代化框架，类型安全 |
| Tailwind CSS | 原子化样式系统 |
| 列表 / 分类 / 标签 | 目录站基础结构内置 |
| 搜索 | 站内全文搜索 |
| AI 提交 | AI 辅助填写 / 推荐条目 |
| 支付 / 认证 / CMS | 商业化模块开箱即用 |
| 合集 | 支持 curated collections |
