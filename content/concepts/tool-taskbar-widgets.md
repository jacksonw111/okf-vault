# TaskbarWidgets (pfcdev)

## 它是什么

[TaskbarWidgets](https://github.com/pfcdev/TaskbarWidgets) 在**不替换 Windows Shell**的前提下，把**天气、系统监控、媒体控制**等实用小组件**直接钉在 Windows 11 任务栏上**。

![TaskbarWidgets 截图](https://pbs.twimg.com/media/HOuZsdHbcAAc1OZ.jpg)

## 为什么用它 / 适合什么场景

- **不替换 Shell**：原生 Windows 11 体验，不动 explorer.exe，不引入第三方桌面。
- **小组件常驻**：天气 / 系统监控 / 媒体控制等直接放任务栏上，省去点开单独应用。
- **低门槛**：不需要换桌面、不需要学新窗口管理。

## 关键能力

| 能力 | 说明 |
|------|------|
| 天气小组件 | 任务栏直接看天气 |
| 系统监控 | CPU / 内存 / 网络等实时数据 |
| 媒体控制 | 任务栏直接切歌 / 暂停 |
| 不替换 Shell | 保留 Windows 11 原生任务栏行为 |
| 钉选/取消灵活 | 按需添加小组件，不强制全套 |
