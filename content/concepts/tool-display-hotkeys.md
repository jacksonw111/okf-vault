# DisplayHotKeys

## 它是什么

[DisplayHotKeys](https://github.com/jon-mil-92/DisplayHotKeys) 是个**轻量级 Windows 实用工具**：通过自定义热键，**一键切换**显示器的分辨率、刷新率、缩放模式、DPI 缩放比例和方向。Windows 自带的「显示设置」需要点开菜单 → 滚几层 → 改 → 应用，DisplayHotKeys 直接绑一个组合键搞定。

## 为什么用它 / 适合什么场景

- 经常在多个显示器配置文件间切来切去的开发 / 设计 / 演示场景（例如：办公室双屏 4K、回家笔记本单屏、客户现场投影仪）。
- 做直播 / 录屏需要时常切换「竖屏演示」「横屏全屏」方向。
- 游戏 / 创作场景需要在 1080p 高刷与 4K 高分辨率之间切换。

## 关键能力

| 能力 | 说明 |
|------|------|
| 热键切换 | 自定义快捷键触发 |
| 多参数切换 | 分辨率 / 刷新率 / 缩放 / DPI / 方向 |
| 配置记忆 | 一键还原到预设的显示器组合 |
| 免翻菜单 | 直接绕过「显示设置」深嵌套 |
