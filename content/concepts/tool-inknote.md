# InkNote（边写边渲染的 Markdown 桌面编辑器）

## 它是什么

[InkNote](https://github.com/likehao19/InkNote) 是一款**边写边渲染**的 Markdown 桌面编辑器：用户写 Markdown 时像在 Notion / Typora 那种文档软件里打字那样所见即所得，但文件落地时仍然是**标准 `.md` 文本**，不存私有格式。

技术栈是 **Tauri 2 + React + CodeMirror 6**，Windows / macOS / Linux 都能装。

## 为什么用它 / 适合什么场景

- 想要「文档软件那种流畅输入体验」，但又要 Markdown 文本能放进 Git 仓库 / Obsidian Vault / 任意 Markdown 工具继续编辑；
- 写 OKF、博客、笔记、技术文档，不想被某家专有格式绑定；
- 偏好 Tauri + CodeMirror 这种轻量、原生、与系统一致的桌面技术栈；
- 跨 Windows / macOS / Linux 三平台都要同一款工具。

## 关键能力

| 能力 | 说明 |
|------|------|
| 所见即所得 | 输入即渲染，无双栏来回切换 |
| 标准 Markdown | 文件落地仍是 `.md`，零专有格式 |
| 跨平台 | Windows / macOS / Linux 三端通用 |
| 技术栈 | Tauri 2 + React + CodeMirror 6 |
| 文件即文件 | 直接读写本地 `.md` 文件 |
