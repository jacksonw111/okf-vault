# scrit.to

## 它是什么

SwiftUI 的 `numberText` 动画在切换数字 / 文本时有一种很特别的视觉风格——数字不是简单 fade / slide，而是逐位滚动、错位、保持节奏感。`scrit.to` 把这套动画搬到 Web 上：一个轻量 JavaScript 库，专门做文本 / 数字切换的过渡动画，让网页上 text swap 也能获得 SwiftUI 那种视觉品质。

## 关键能力

| 能力 | 说明 |
|------|------|
| SwiftUI 风格文本动画 | 把 SwiftUI numberText 的视觉风格搬上 Web |
| 轻量 | 不依赖大型动画框架 |
| 数字 / 文本切换场景 | 适用计数器、状态文本、过渡文字等场景 |
