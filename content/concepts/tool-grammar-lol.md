# grammar-lol

## 它是什么

**系统级 AI 语法校正快捷键**——在任意桌面应用（邮件 / Slack / Notion / Word / 浏览器）里：

1. 选中一段文字
2. 双击 Right Shift
3. 调用自己的 ChatGPT 或 SuperGrok 订阅
4. AI 校正语法 / 拼写
5. 结果直接替换原文

不用切浏览器、不用复制粘贴、不用开 Grammarly 扩展。

![截图](https://pbs.twimg.com/media/HOZjqIeagAAbCRY.jpg)

## 解决的痛点

| 痛点 | grammar-lol 解法 |
|------|-----------------|
| Grammarly 扩展侵入性强 | 系统级快捷键，按需触发 |
| 复制粘贴到 ChatGPT 麻烦 | 一步到位 |
| 想用自己的订阅 | 直连 ChatGPT / SuperGrok API |
| 中文 / 英文混排工具少 | AI 通用校正 |

## 关键能力

| 能力 | 说明 |
|------|------|
| 全局快捷键 | 双 Right Shift |
| 任意应用 | 系统级文本替换 |
| 自带订阅 | ChatGPT / SuperGrok |
| 直接替换 | 不用回贴 |
| 跨平台 | Windows / macOS / Linux |

## 适合谁

- 每天大量写英文邮件 / 文档的非母语用户
- 不喜欢 Grammarly 订阅模式的人
- 想用最强模型（Grok）校正的人
- 重视隐私（不走第三方 SaaS 通道）
