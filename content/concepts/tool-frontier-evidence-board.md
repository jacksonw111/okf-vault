# Frontier Models Evidence Board

## 它是什么

[models.kylejeong.com](https://models.kylejeong.com) 是一个**用证据板风格（evidence board）**做的交互式站点，专门解释**前沿 AI 模型**及其**架构选择**。形式上模仿侦探小说里把线索贴在墙上的样子，把不同模型的训练数据 / 架构创新 / 能力维度 / 评测表现铺成可点击、可跳转的图谱。

## 为什么用它 / 适合什么场景

- **入门前沿模型**：相比论文 / 综述，看图看板上更直观；
- **架构对比**：把 GPT / Claude / Gemini / Llama 等家族的架构决策放在一起看异同；
- **教学 / 分享**：做 LLM 讲座或培训时拿来做引子；
- **研究回顾**：想快速回忆某篇论文的某条 evidence。

## 关键能力

| 能力 | 说明 |
|------|------|
| 证据板可视化 | 把架构 / 数据 / 能力维度铺成卡片矩阵 |
| 交互探索 | 节点可点击跳转深入 |
| 前沿模型覆盖 | 多个主流家族的架构对比 |
| 浏览器跑 | 纯静态站点，无后端 |
