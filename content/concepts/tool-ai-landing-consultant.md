# ai-landing-consultant（小微老板自托管 AI agent 顾问开箱包）

## 它是什么

[August06exe/ai-landing-consultant](https://github.com/August06exe/ai-landing-consultant) 是 August06exe 攒的**顾问开箱包**，**套在 Hermes Agent 上跑**，把「给小微老板交付一个自托管 AI agent」这件事切成 **11 步**：

> 访谈 → 定方案 → 做交付包 → 装机验证 → 陪跑进化

每一步都带**勾选式验收标尺**，让顾问式落地变成可复制产线，而非一次性手搓。

## 为什么用它 / 适合什么场景

- 帮不懂技术的小微老板 / 个体户**装一台每天在微信里自动干活的 AI agent**。
- 想把「AI 顾问交付」这件事**产品化 / 标准化**，而不是每单都从零写。
- Hermes Agent 用户想拿到一份针对微信场景的「11 步落地清单」。

## 关键能力

| 能力 | 说明 |
|------|------|
| 11 步标准化 | 访谈 / 方案 / 交付包 / 装机 / 陪跑，每步独立可交付 |
| 验收标尺勾选 | 每步配套可勾选的自检项，避免「差不多就行」 |
| 套在 Hermes Agent 上 | 复用成熟的 Agent 运行时，专注交付流程 |
| 微信场景 | 老板端 0 学习成本：在微信里跟 agent 对话 |

## 与相关概念的关系

- [Self-Hosted（自托管）](./term-self-hosted.md) — ai-landing-consultant 把自托管 AI agent 这件事做成了可复制的咨询产品
