# quant-wiki

## 它是什么

[quant-wiki](https://github.com/LLMQuant/quant-wiki) 是 **LLMQuant** 维护的**中文量化百科**——把**因子模型 / 事件驱动 / 执行成本 / 策略思路**等量化投资知识点系统整理，专门填平国内外量化信息差。

## 覆盖范围

| 主题 | 说明 |
|------|------|
| 因子模型 | 多因子构建 / 因子检验 / 因子衰减 |
| 事件驱动 | 公告 / 财报 / 宏观事件策略 |
| 执行成本 | 滑点 / 冲击成本 / 撮学理解 |
| 策略思路 | 趋势 / 反转 / 套利 / 统计套利 |

## 适合人群

- 量化学习者英文吃力、需要中文体系
- 国内做量化找不到系统资料
- 想对比国内外量化研究差异
