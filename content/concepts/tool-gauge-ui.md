# gauge-ui.dev

## 它是什么

[gauge-ui.dev](https://www.gauge-ui.dev) 是一个**仪表盘风格 UI 组件库**——按开发者的自述，他做船舶软件天天和仪表打交道，被折磨久了干脆自己写了一套组件对外开放。

## 为什么用它

- **真实仪表风格**：来自船舶 / 工业场景的视觉语言，和主流 SaaS 仪表盘的扁平卡片感拉开差异。
- **专业感**：当产品定位是工程 / 监控 / 运维 / 数据可视化时，传统仪表盘组件视觉过于「消费级」，这套能直接给项目加专业感。
- **按场景拼装**：每种仪表对应一个独立组件，按需引入即可。

## 典型场景

| 场景 | 适合原因 |
|------|---------|
| 工业监控 / SCADA 类前端 | 视觉语言和真实场景一致 |
| 服务器 / 集群监控大屏 | 数值盘 + 趋势 + 告警灯是天然组合 |
| 运维 / DevOps 看板 | 主机负载 / 流量 / 错误率等指标需要仪表化 |
| 数据分析工作台 | 多指标并行对照时仪表盘易扫读 |
| IoT 设备控制台 | 设备状态用仪表盘比表格更直观 |
