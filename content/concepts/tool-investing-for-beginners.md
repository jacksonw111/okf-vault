# investing-for-beginners（中文投资入门公开指南）

## 它是什么

[`investing-for-beginners`](https://github.com/xuchonglang/investing-for-beginners) 是一份面向**中文投资者**的公开投资入门指南，帮助零基础用户系统建立**美股、期权、加密货币**三大领域的知识框架与风险意识。

## 内容覆盖

| 领域 | 主要话题 |
|------|---------|
| 美股 | 交易时间、订单类型、财务报表、基础估值 |
| 期权 | 期权定价、希腊字母（Delta/Gamma/Theta/Vega）、波动率策略 |
| 加密货币 | 现货与合约、钱包安全、DeFi 机制、常见骗局 |

## 资源规模

- **100+** 篇精选文章
- **金融术语表**（按字母索引）
- 配套 GitHub 仓库维护，可通过 PR / Issue 反馈纠错

## 适用场景

- 第一次接触美股 / 期权 / 加密货币的中文用户
- 想系统补课又不想被「卖课割韭菜」内容污染
- 已经在交易但发现自己对术语和底层机制理解不深

## 注意事项

- 内容覆盖基础知识，**不构成投资建议**
- 加密货币与期权领域风险极高，请结合自身风险承受能力评估
