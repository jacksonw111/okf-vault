# tonkatsu-box

[tonkatsu-box](https://github.com/hacan359/tonkatsu_box) 是一款**Flutter 桌面 + Android 应用**,把游戏、电影、电视剧、动漫、视觉小说、漫画、图书等七类内容拉到同一个界面里搜、管、评,免去在不同平台间来回切。

## 它解决了什么

收藏爱好者常同时维护好几套账号:游戏在 Backloggd / Steam,番剧在 Bangumi / AniList,漫画/书在对应的各个 App……每改一处收藏就要点开一个 App。tonkatsu-box 用 Flutter 横跨桌面与 Android,接十多个公开数据源,把这一切塞进一个搜索框。

## 关键能力

| 能力 | 说明 |
|------|------|
| 跨端 Flutter | 桌面端 + Android 共一份代码 |
| 十余数据源 | IGDB / TMDB / AniList / VNDB / OpenLibrary / Google Books / ComicVine 等 |
| 七类内容 | 游戏 / 电影 / 剧集 / 动漫 / 视觉小说 / 漫画 / 图书 |
| 评注与状态管理 | 标记在看 / 已看 / 想看,评分、笔记、长评 |
| MIT 协议 | 自由修改、商业使用都可 |
