# Evangelion GRUB Theme

## 它是什么

[Aleph1-9012/Evangelion](https://github.com/Aleph1-9012/Evangelion) 是 **Aleph1-9012** 维护的 Linux GRUB 启动菜单主题包。它提供 **8 套 EVA（《新世纪福音战士》）风格的 GRUB 主题**和配套的**交互式安装脚本**——装一次脚本即可把整套主题部署到 `/boot/grub/themes/`，免去手动下载、解压、修改 `grub` 配置的步骤。

## 关键能力

| 能力 | 说明 |
|------|------|
| 8 套主题 | 多套 EVA 配色 / 排版可选，覆盖不同分辨率 |
| 交互式安装 | 一条命令进入交互式选择界面，不需要手写文件路径 |
| 自动备份 | 安装前自动备份原 `/etc/default/grub` 等关键文件 |
| 适用主流发行版 | Ubuntu / Debian / Fedora / Arch / Manjaro 等都可用 |

## 适合什么场景

- 想给 Linux 启动菜单加点个性、不愿忍受默认黑底白字的 EVA 粉丝。
- 想研究 GRUB 主题怎么打包、怎么分发（项目是开源「主题包 + 安装脚本」模式的样板）的开发者。
- 想把多个主题切换使用、按心情选开机画面的桌面玩家。
