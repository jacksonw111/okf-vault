# YourDynamicDashboard

## 它是什么
一个开源的浏览器新标签页替换工具，自带隐私工作台特性：可"自己捏"组件、拼布局，所有数据本地存储。

## 与"现成 new tab 扩展"的区别
- **可拼装**：组件按需加（书签 / 待办 / 时钟 / RSS / 笔记 / 天气 等），布局自己排
- **隐私优先**：不上云、不依赖账号
- **本地存储**：浏览器 IndexedDB / localStorage

## 关键能力
| 能力 | 说明 |
|------|------|
| 自定义组件 | 按需添加 |
| 自定义布局 | 自己捏面板 |
| 隐私优先 | 无云端依赖 |
| 本地存储 | 数据不外发 |
| 开源免费 | 完全透明 |
