# fluent-sensors（cechout/fluent-sensors）

## 它是什么
[`cechout/fluent-sensors`](https://github.com/cechout/fluent-sensors) 是一个 Windows 11 桌面监控工具：把 CPU、GPU、内存、温度、风扇等深层传感器数据，渲染到一套**长得像系统原生**的 Fluent UI 界面上。它解决的问题是「任务管理器太浅、HWMonitor 太丑、HWiNFO 太工程师」之间的空白。

## 为什么用它 / 适合什么场景
- 想要 Windows 11「原生味」的实时硬件监控，但不想每次开任务管理器再点层层菜单。
- 写代码 / 渲染 / 训练时想在副屏随时关注温度与功耗。
- 倾向 Fluent UI 设计语言，对老式监控工具的视觉风格有抵触。

## 关键能力
| 能力 | 说明 |
|------|------|
| 系统原生外观 | 走 Windows 11 Fluent 视觉语言，与系统设置风格一致 |
| 深层传感器 | CPU / GPU / 内存 / 温度 / 风扇转速覆盖 |
| 实时刷新 | 持续采样，适合长时间盯盘 |
| 干净面板 | 不堆图表、不塞广告，只保留关键指标 |
