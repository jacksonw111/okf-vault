# Writing Buddy（Obsidian 内置的 AI 写作助手 + 项目记忆）

## 它是什么

[Writing Buddy](https://github.com/onezeroooo/obsidian-writing-buddy) 是 onezeroooo 开源的 **Obsidian 写作助手插件**——把 AI 写作能力**深度集成进 Obsidian**：

| 能力 | 说明 |
|------|------|
| 改写 | AI 改写当前段落 |
| 续写 | AI 续写后续剧情 |
| **一致性检查** | 检查人物设定 / 情节是否前后一致 |
| **项目记忆** | 让模型参考整部稿件 / 人物关系 / 作者设定 |

## 为什么用它 / 适合什么场景

- 已经在 **Obsidian** 里写长篇（小说 / 剧本 / 长文）——不想切到 ChatGPT / Claude 网页打断心流。
- 想要 AI 助手**「理解整部稿件」**而不是只看当前段落——人物关系、设定、世界观不丢。
- 重视**一致性**——长篇写到后期，最容易出现「OOC / 设定冲突」。
- 想让 AI 改动**就地发生**——直接在 Obsidian 里改写 / 续写，而不是切窗口。

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | Obsidian 插件 |
| 写作能力 | 改写 / 续写 / 一致性检查 |
| 记忆 | 本地项目记忆（整部稿件 + 人物关系 + 作者设定） |
| 集成度 | 深度集成 Obsidian，无须切窗口 |
