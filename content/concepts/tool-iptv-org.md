# iptv-org/iptv（全球免费 IPTV 直播源大宝库）

## 它是什么
`iptv-org/iptv`（13 万+ 星）是社区维护的**全球公开电视直播频道仓库**，不止是一个 M3U 文件，而是整套生态：收录超过 12 000 个全球频道源、可按国家/语言/分类自由组合播放列表、内置 EPG 电子节目单、提供 API 方便开发自己的电视 App。兼容 VLC / Kodi / TiviMate / TVBox 等几乎所有 M3U 播放器。

## 为什么用它 / 适合什么场景
- 想**白嫖合法公开直播源**，看各国新闻、体育、电影、动漫、儿童、纪录片节目。
- 想做**自定义电视 App / 信息屏 / 酒店电视系统**：API 直接拉频道 + EPG。
- 想**离线 / 跨境 / 灾备**看电视，不依赖任何具体商业 IPTV 提供商。
- 对流媒体开发者：现成 M3U 解析、EPC XML、JSON、HTTP API 都已维护好。

## 关键能力
| 能力 | 说明 |
|------|------|
| 频道数 | 12 000+ 全球公开频道源（截至 2026-07） |
| 多维筛选 | 按国家 / 语言 / 地区 / 类型自由组合播放列表 |
| EPG 电子节目单 | 支持预告、回看 |
| API | HTTP API 方便自己开发 App |
| 社区维护 | 失效链接持续被替换修复 |
| 玩家兼容 | VLC / Kodi / TiviMate / TVBox 等 M3U 播放器 |
