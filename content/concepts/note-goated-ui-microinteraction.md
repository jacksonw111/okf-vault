# Goated UI / 微交互资源清单

## 它是什么

一份 UI 设计 + 微交互方向的精选资源清单，被社区列为「最值得关注的 goated 资源」。每个站点都是 UI / 微交互 / 动效领域里的代表作：

| 资源 | 内容 |
|------|------|
| [useLayouts](https://uselayouts.com) | 按页面段落分类的生产级版式灵感集合（hero / 导航 / 表单 / 卡片 / 团队 / 定价 等） |
| [Nexvyn UI](https://ui.nexvyn.dev) | UI 组件库 |
| [Motion](https://motion.dev) | 现代动效库 / 框架 |
| [Cult UI](https://cult-ui.com) | shadcn 风格的开源 UI 组件库 |
| [Spell UI](https://spell.sh) | 可直接安装的组件 / 模板集 |

## 适合谁用

- 想给项目选合适的版式 / 组件 / 动效参考
- 想集中收藏「高质量 UI 资源」以备查
- 在 shadcn 生态里挑组件库

## 为什么这几条「goated」

- **useLayouts** — 直接收录真实生产级网站版式，按段落分类，比设计稿更接近工程约束
- **Motion** — 现代 web 动效的事实标准之一
- **Cult UI / Spell UI** — shadcn 生态里风格鲜明的组件库
- **Nexvyn UI** — 风格鲜明的 UI 库
