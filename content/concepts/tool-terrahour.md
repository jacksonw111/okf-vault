# terrahour

## 它是什么

[terrahour](https://github.com/ACoci86/terrahour) 是 **ACoci86** 出品的**终端世界时钟**——纯 Python 写，**零第三方依赖**：

- 用**盲文字符**在终端画出带昼夜明暗 / 时间区分色的**世界地图**
- 每座城市在地图上**打点**
- 下方用 **24 小时横条**标出该城市的上班时段
- 最底一条**重叠行**显示所有城市同时在岗的窗口

## 为什么用它 / 适合什么场景

- **远程团队协调**：一眼看清「现在几点了」「今晚还有谁醒着」。
- **夏令时自动处理**：不必手动算。
- **零依赖**：纯 Python stdlib，扔进任何机器就跑。
- **终端美学派**：用 ASCII art 让时钟有质感。
