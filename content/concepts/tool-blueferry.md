# blueferry

[blueferry](https://github.com/erikwb/blueferry) 让 **Linux 桌面**通过**蓝牙**直接收发 **iPhone 的 iMessage 和短信**，**无需 Mac 中转、无需 iCloud 登录、无需云服务**。

## 它是什么

Linux 桌面与 iPhone 之间的蓝牙短信 / iMessage 桥接工具。常见做法是 Linux 用户必须借一台 Mac 或 iCloud 才能收发 iMessage；blueferry 把这条链路砍到 0，纯蓝牙直连。

## 为什么用它 / 适合什么场景

- **Linux 主力机用户**：日常 Linux 桌面、不愿开 Mac。
- **不依赖 Mac**：不必为收条 iMessage 而保留 Mac。
- **不依赖 iCloud**：账号体系与云服务完全脱离。
- **隐私优先**：链路最短，敏感消息不经第三方。

## 关键能力

| 能力 | 说明 |
|------|------|
| 蓝牙直连 | Linux 与 iPhone 通过蓝牙配对 |
| iMessage 收发 | 不需 Mac / iCloud 中转 |
| 短信收发 | 同步收 / 发 SMS |
| 无云依赖 | 链路最短，无云服务介入 |
| 无 iCloud 登录 | 苹果账号体系可脱钩 |
