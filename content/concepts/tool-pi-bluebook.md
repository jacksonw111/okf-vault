# pi-bluebook（Pi 中文零基础非官方手册）

## 它是什么

[xiaomoBoy/pi-bluebook](https://github.com/xiaomoBoy/pi-bluebook) 是一本面向**中文初学者**的 Pi（非官方）手册：从零开始，按 **「场景 → 概念 → 实操 → 验收」** 四段式展开，系统学习 Pi 编码代理的使用方法。

## 为什么用它 / 适合什么场景

- 第一次接触 Pi 但英文 README 读起来累。
- 想按场景（而不是按 API）学：先有目标，再拆概念，再上实操，再做验收。
- 教学中给非工程背景的同事 / 学生使用。
- 想作为中文 Pi 培训班的指定教材。

## 结构（按章节思路梳理）

| 章节 | 主题 |
|------|------|
| 场景 | 真实任务切入：为什么要用 Pi |
| 概念 | 必备前置知识：模型 / 上下文 / 工具 / 循环 |
| 实操 | 一步步怎么配置、怎么跑 |
| 验收 | 跑完之后如何确认结果可用 |
