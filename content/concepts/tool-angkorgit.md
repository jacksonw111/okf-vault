# AngkorGit

## 它是什么
[cheat2001/angkorgit](https://github.com/cheat2001/angkorgit) 是一个**跨平台的开源 Git 客户端**，体积仅约 **12 MB**，覆盖日常 Git 操作：

- 提交（commit）；
- 分支（branch / merge / rebase）；
- 冲突解决（conflict resolution）。

跨 **macOS / Windows / Linux** 三平台。

## 为什么用它 / 适合什么场景
- 不喜欢装几百 MB 的 SourceTree / GitHub Desktop 这种"全家桶"客户端；
- 想要一个轻量、二进制小巧、覆盖日常用法的 Git GUI；
- 想要开源、跨平台、不带 telemetry 的 Git 客户端。

## 关键能力
| 能力 | 说明 |
|------|------|
| 体积小 | 二进制 ~12 MB |
| 跨平台 | macOS / Windows / Linux |
| 日常提交 | commit / push / pull |
| 分支 | branch / merge / rebase |
| 冲突解决 | 可视化合并冲突工具 |
| 开源 | Apache / MIT 等宽松许可证 |
| 无 telemetry | 不偷偷上传数据 |
