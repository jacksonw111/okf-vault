# oil-cover（小红书封面生成 Skill）

## 它是什么

[oil-oil/oil-cover](https://github.com/oil-oil/oil-cover) 是给 Claude / Codex 装的**小红书封面生成 Skill**：针对 AI 工具实操类视频，「全自动一次性出图」而不是叠拼——用真实屏幕证据 + Apple 风产品视觉，整图一张生成，避免「中文错位 / 文字漂移」之类的常见出图事故。

## 关键能力

| 能力 | 说明 |
|------|------|
| 一键出图 | 一次 prompt 一张成图，不靠 Photoshop 二次拼 |
| Apple 风视觉 | 模仿 Apple 风格的产品视觉模板 |
| 屏幕证据直采 | 真实 UI / 截图作为视觉锚点，避免 LLM 瞎画 |
| 不本地拼字 | 解决模型拼中文常见的字形错乱 / 缺笔问题 |
