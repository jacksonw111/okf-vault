# api-balance-checker-extension（多 AI 中转站余额聚合）

## 它是什么

[`api-balance-checker-extension`](https://github.com/zhuifengshaonian6/api-balance-checker-extension) 是 zhuifengshaonian6 写的 **Chrome / Edge 浏览器扩展**——专为「**同时用多个 AI API 中转站（zhipu / kimi / 通义 / DeepSeek / 自建中转…）时余额要挨个登后台**」的痛点：

- 在浏览器里**一个小弹窗聚合**所有中转站的余额 / 到期时间
- **API Key 只存本地会话**——不交给任何第三方查询网站
- 支持常见中转站

## 为什么用它 / 适合什么场景

- 同时订阅 3+ 个中转站（避免被任何一家锁）
- 不想把 API Key 提供给第三方查询面板
- 频繁做「谁家还剩多少 / 谁家快过期了」盘点

## 关键能力

| 能力 | 说明 |
|------|------|
| 多源聚合 | 一次性看所有中转站余额 |
| Key 本地存 | 不外发 |
| 弹窗 UI | 浏览器角落唤起即可查 |
| 到期提醒 | 同框显示续费日期 |
| Chrome / Edge | Chromium 双端支持 |
