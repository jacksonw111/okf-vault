# Kumone（macOS 网易云原生客户端）

## 它是什么

[missuo/kumone](https://github.com/missuo/kumone) 是 macOS 上听网易云音乐的原生 SwiftUI 客户端：不套网页壳，直接连网易官方接口，把登录 / 推荐 / 歌单 / 播放 / 歌词 / 桌面歌词等功能装进一个本地 App。

## 为什么用它 / 适合什么场景

- 不想用网页版网易云套壳应用（Electron 类），想要 SwiftUI 原生体验。
- 想在 macOS 上拿网易云听歌但不想开浏览器。
- 重视性能：原生 App 比网页壳快、内存占用低、与系统菜单栏集成更顺。

## 关键能力

| 能力 | 说明 |
|------|------|
| SwiftUI 原生 | 真原生 macOS App，非网页壳 |
| 直连官方接口 | 不走第三方 API，资源更稳定 |
| 完整功能 | 登录 / 推荐 / 歌单 / 播放 / 歌词全覆盖 |
| 桌面歌词 | 支持桌面歌词悬浮显示 |
| 系统集成 | 菜单栏 / 媒体键 / 系统播放控件 |
