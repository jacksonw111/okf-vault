# 图标资源站精选

## 它是什么
一份面向前端项目的**图标站点清单**：覆盖了**通用图标库、动画图标、立体图标、形状 / 风格化图标**等不同细分方向。每个站点都有自己鲜明的风格与差异化定位——它们之间并不互斥，而是按场景互补。

## 9 个站点速览

| 站点 | 类型 / 风格 | 适合场景 |
|------|------------|---------|
| [itshover.com/icons](http://itshover.com/icons) | 通用图标合集 | 综合查找 |
| [web.iconly.pro](http://web.iconly.pro) | 风格化图标合集 | 落地页主视觉 |
| [nucleoapp.com](http://nucleoapp.com) | 通用图标库（含付费） | 全套系统图标 |
| [iconsax.io](http://iconsax.io) | 多风格图标族 | 同一套图标多种风格 |
| [isocons.app](http://isocons.app) | 立体 / 等距风格 | 营销页 Hero 区 |
| [hugeicons.com](http://hugeicons.com) | 海量通用图标 | 全套系统图标 |
| [morphicons.com](http://morphicons.com) | 形状变形图标 | 微动效点缀 |
| [lucide-animated.com](http://lucide-animated.com) | Lucide 动画版 | Lucide 用户的动效升级 |
| [movingicons.dev/icons](http://movingicons.dev/icons) | 运动图标 | 入场 / 悬停动效 |

## 选择建议

- **需要全套系统图标**（导航、表单、列表）→ Hugeicons / NucleoApp
- **需要 Hero 区大图标** → Iconly / Isocons
- **需要悬停 / 微动效** → Lucide Animated / Morphicons / MovingIcons
- **同一套图标要切换风格**（线性 / 填充 / 双色）→ Iconsax
- **不确定要哪个** → itshover / iconly 当搜索引擎用
