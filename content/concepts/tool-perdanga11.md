# Perdanga11（原生 Win32/C++ 启动器：替换 Windows 11 开始菜单）

## 它是什么

[Perdanga11](https://github.com/PerdangaSoftware/Perdanga11) 是 PerdangaSoftware 出品的 **原生 Win32/C++ 启动器**——**替换 Windows 11 开始菜单**，同时提供：

- **自定义分类**（按项目 / 场景分组）
- **拖放排序**（自己掌控常用项布局）
- **固定常用项**
- **一次启动多个程序**（多选 → 一键全开）
- **跨盘搜索**：扫描应用 / 桌面 / 用户目录 / 已连接磁盘中的**常见文档与媒体文件**

## 为什么用它 / 适合什么场景

- 嫌 Windows 11 开始菜单**搜索太慢 / 分类不自由**。
- 想要一个**原生 Win32 / C++**、**资源占用低**的启动器（不像 Electron 那样肥）。
- 经常需要**批量启动一组程序**（开发环境 / 测试场景）。
- 工作机磁盘多 + 文件散落，希望**一个搜索框统揽所有盘**。
