# OriginKit

[OriginKit](https://www.originkit.dev/) 是面向 **iOS App / SaaS 团队**的官网模板库,把「产品上线页」拆成一段段可复制的 HTML / React 段落。

## 关键能力

| 能力 | 说明 |
|------|------|
| 段落化结构 | Hero、Features、Pricing、FAQ、Testimonials 等独立组件,可拼装 |
| 视觉风格 | 现代 SaaS 风格,常与 Tailwind + shadcn 体系呼应 |
| 复制即用 | 直接复制代码片段到自己的项目里 |
| 多场景适配 | iOS App 着陆页 / 桌面 SaaS / 早期初创 |

## 适合什么场景

- iOS 开发者做 **App Store 配套官网**(因为 iOS App 必须挂外站)。
- 早期 SaaS / 副业项目,想要一个体面的营销页但没预算请设计师。
- 已有设计师,但**只需要一个起点模板**避免空白页卡壳。

## 与同类资源的差别

- **shadcn / shadcnim / 21st.dev**:更偏组件、UI 组件层面;OriginKit 是**整页**层面。
- **Tailwind UI**:收费;OriginKit 免费,可整页拼装。
- **Heroicons-animated** / 一类图标组件库:补的是 icon,OriginKit 补的是整页骨架。
