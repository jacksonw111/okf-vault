# Cyrene-Agent

## 它是什么

[Cyrene-Agent](https://github.com/Playa-0v0/Cyrene-Agent) 是一个**Windows 桌面 Live2D AI 伴侣应用**——把「崩坏：星穹铁道」里的昔涟人设搬到桌面上，作为可对话的 AI 伴侣。

## 关键能力

| 能力 | 说明 |
|------|------|
| Live2D 模型 | 在桌面渲染可动的 Live2D 角色 |
| 文本聊天 | 与角色对话 |
| 语音通话 | 角色说话、用户语音输入 |
| 个性化记忆 | 记住用户偏好与历史对话 |
| 工具调用 | LLM 可调用工具 |
| 外部渠道 | 接入飞书、微信等消息渠道 |
| 桌面形态 | Electron + TypeScript，Windows 原生窗口 |

## 适合谁

- 想要桌面 AI 伴侣的二次元玩家。
- 研究「角色扮演 AI + Live2D + 工具调用」组合的开发者。
- 任何想用星穹铁道 IP 做项目实验的玩家。
