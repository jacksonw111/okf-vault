# Hearth (echoo19)

## 它是什么
Hearth（`echoo19/hearth`）让用户**用自然语言描述想玩的游戏，AI 代理现场建好并在旁边跑起来**，不用学项目格式或引擎。

![Hearth 截图](https://pbs.twimg.com/media/HOso56PaAAA6lz7.jpg)

## 为什么用它 / 适合什么场景
- **零学习成本**：不会写代码 / 不会用引擎也能玩到自定义游戏。
- **即时生成**：描述完即生成 + 跑起来，需求 → 玩法迭代无摩擦。
- **教学 / 创意**：用自然语言和小朋友 / 学生一起探索游戏设计。

## 关键能力

| 能力 | 说明 |
|------|------|
| 自然语言 → 游戏 | 描述玩法 → AI 现场生成项目 |
| 现场运行 | 生成后直接跑，无需手动 build |
| 零格式要求 | 用户无需懂游戏引擎 / 文件结构 |
| 配方可迭代 | 多次指令调整玩法，调参式生成 |
