# next-ai-draw-io

## 它是什么
开源 AI 图表生成工具，基于 Next.js + draw.io，把大模型的自然语言理解能力直接嫁接到 draw.io 的图表编辑体验上。GitHub 33k+ 星，曾登 GitHub 热榜榜首。

## 为什么用它 / 适合什么场景
- 写方案、做汇报材料、设计系统架构时，需要快速产出规范图表。
- 不愿在画框、连线、布局上耗时间，只想"说一句话出图"。
- 草图或拍照的纸质稿需要转成正式电子图表。

## 关键能力
| 能力 | 说明 |
|------|------|
| 文字生图 | 一句自然语言指令生成架构图 / 流程图 / 思维导图 |
| 交互微调 | 生成后可在 draw.io 编辑器里交互式调整节点和连线 |
| 一键导出 | 改完直接导出 PNG / SVG / draw.io 源文件 |
| 草图转图 | 拍照上传手绘草图，AI 自动识别并转成规范图表 |
