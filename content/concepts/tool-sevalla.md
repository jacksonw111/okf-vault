# Sevalla

## 它是什么

Sevalla 是一款**应用部署托管平台**（PaaS），定位「**Deploy apps without managing infrastructure**」——把服务器、容器、CI/CD、证书、域名、扩缩容等基础设施全部托管，用户只管提交代码、绑定域名、看运行状态。

## 为什么用它 / 适合什么场景

- 个人 / 小团队项目不想自建 K8s / 服务器。
- 想用更轻量的 PaaS 替代 Vercel / Render / Railway / Fly.io 等（具体定位需自行比对）。
- 想把博客 / API / 全栈应用一站托管，省运维。

## 关键能力

| 能力 | 说明 |
|------|------|
| 一键部署 | Git 推送即部署 |
| 免运维基础设施 | 容器 / 服务器 / 网络托管 |
| 证书 / 域名 | 自动 HTTPS / 域名绑定 |
| 扩缩容 | 按流量自动调整 |
