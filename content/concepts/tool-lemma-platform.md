# Lemma（人 + AI agent 共享工作空间平台）

## 它是什么
开源的「人 + AI 智能体」协作平台，把人和 agent 当成同一个团队成员来组织：所有人 / agent 共用一套状态层（表格、文件、工作流、权限、审批、应用），活动集中在工作空间里，不再散落在聊天记录、Notion 页面、各类 SaaS 里。

## 为什么用它 / 适合什么场景
- 想让 AI agent 真正「加入团队」，而不是只通过聊天窗口被动响应请求。
- 多个 agent + 多人协作同一份数据时，希望用统一权限 / 审批 / 审计，而不是各 agent 各搭一套胶水代码。
- 自托管需求强，不愿把团队核心数据托管给闭源 SaaS。

## 关键能力
| 能力 | 说明 |
|------|------|
| 统一状态层 | 表格 / 文件 / 工作流 / 权限 / 审批 / 应用同一份数据 |
| 人 + Agent 同台 | 把 agent 视为团队成员，享受同等权限、审计、可见性 |
| 工作流编排 | 内置审批 / 触发器 / 步骤流转 |
| 权限与审计 | 细粒度 RBAC + 操作审计日志 |
