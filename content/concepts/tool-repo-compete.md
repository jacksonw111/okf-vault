# repo-compete

[repo-compete](https://github.com/lbj96347/compete) 是**面向 GitHub 仓库的自动竞品分析工具**——把仓库的代码结构、README、commit 信息综合起来,自动判断产品定位、发现同领域竞品,再生成带对比矩阵、雷达图、SWOT 等多维分析的可交互 HTML 报告。

## 它解决了什么

技术选型或立项时常问一个问题:「这个方向上还有谁在做」——但手动调研要扫一大圈 GitHub、抓 README 比对、画 SWOT,非常累。repo-compete 替工程师做这层「先看再选」的活。

## 关键能力

| 能力 | 说明 |
|------|------|
| 仓库定位识别 | 从代码结构 / README / 关键词抽取产品定位 |
| 竞品发现 | 自动跨 GitHub 找同类型项目并排序相关度 |
| 对比矩阵 | 把核心维度并列对比,HTML 直接打开看 |
| 雷达图 | 多维度可视化对比 |
| SWOT 分析 | 优势 / 劣势 / 机会 / 威胁四象限自动归类 |
| 报告可交互 | HTML 报告自带 hover / 筛选 |
