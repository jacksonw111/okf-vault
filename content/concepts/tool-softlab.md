# Softlab

## 它是什么

[Softlab](https://github.com/deity6/softlab) 是 **deity6** 出品的 **视觉交互效果拆解合集**——把页面上那些「**流动 / 撕裂 / 回弹**」的视觉交互拆开看怎么实现，每个效果都摊成 **WebGL / canvas / CSS** 的实时渲染代码。

定位是「**反 vibe coding 的视觉效果学习站**」——不看最终效果 gif，而是直接拿到最小可运行代码，**按效果拆**让学习者能复制 / 改造。

## 为什么用它 / 适合什么场景

- **前端开发者** 想自己造视觉交互（不靠 GSAP / Framer Motion 库）
- **设计师转代码**：看到好效果想拆解实现
- **动效学习**：覆盖流动 / 撕裂 / 回弹等基础物理感交互
- **教学示例丰富**：每个效果都能跑起来看

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | 视觉交互效果合集 |
| 技术栈 | WebGL / canvas / CSS |
| 效果类型 | 流动 / 撕裂 / 回弹 |
| 代码可运行 | 每个效果都给可运行代码 |
| 拆解维度 | 按视觉效果分类，不按技术栈分类 |
