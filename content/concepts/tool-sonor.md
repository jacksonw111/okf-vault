# Sonor（sonor-studio/Sonor）

## 它是什么

`sonor-studio/Sonor` 是一款 **macOS 原生语音转文字应用**，**完全本地运行**：底层 `whisper.cpp` + Apple Silicon Metal 加速，录音不需要联网、**数据不出设备**。自带模型管理器，可下载 Whisper 与 Gemma 模型，含**历史记录、自定义片段、助手和词典**功能。

## 为什么用它 / 适合什么场景

- 注重**隐私**，不愿把录音/口述内容上传云端；
- Apple Silicon Mac 想要**本地 Metal 加速**的实时语音转写；
- 需要在转写基础上做**自定义片段、术语词典**等垂直场景定制；
- 想把语音转写集成到日常工作流（笔记 / 命令 / 写作）。

## 关键能力

| 能力 | 说明 |
|------|------|
| 完全本地 | 录音不联网，数据不出设备 |
| whisper.cpp | 高质量开源 STT 引擎 |
| Metal 加速 | Apple Silicon GPU 加速 |
| 模型管理 | 内置 Whisper / Gemma 模型下载 |
| 历史记录 | 保留转写历史可回看 |
| 自定义片段 | 预设常用片段/句式 |
| 助手与词典 | 垂直场景可定制 |
