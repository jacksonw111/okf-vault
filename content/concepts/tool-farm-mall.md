# farm-mall

## 它是什么

[farm-mall](https://github.com/SoliBooster/farm-mall) 是一个**开源助农电商平台**，技术栈为 **Flask + MySQL**，源自本科毕业设计并完整开源。

定位：把「农户 / 农产」卖货需要的基础电商能力（账号、商品、购物车、订单）+ 个性化推荐做成一个可直接 fork 上手、二次开发学习或作为毕业设计参考的项目。

## 关键能力

| 模块 | 说明 |
|------|------|
| 用户系统 | 注册 / 登录 / 资料 |
| 商品管理 | 商品展示 / 分类 |
| 购物车 | 加入 / 修改 / 删除 |
| 订单管理 | 下单 / 状态流转 |
| 混合推荐 | 综合多种算法（协同过滤 + 内容 / 标签）的个性化推荐 |
| 数据存储 | MySQL 关系型数据库 |

## 适合谁

- 想学习 Flask + MySQL 全栈实战的学生 / 初级开发者。
- 需要毕业设计 / 课程项目参考的本科同学。
- 想搭一个小型助农 / 农产品电商平台的创业者，作为起步模板。
