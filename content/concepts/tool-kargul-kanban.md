# kargul/kanban

## 它是什么

[kargul/kanban](https://github.com/kargulstudio/kanban) 是 **kargulstudio** 开源的看板项目——配套演示视频展示其特色拖拽 / 卡片交互。

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | 看板（Kanban） |
| 交互 | 拖拽式管理 |
| 风格 | 现代 Web UI |
| 开源 | 仓库在 GitHub |

## 适合场景

- 想要一个轻量 Kanban 工具自部署
- 团队不想绑死 Trello / Jira
- 想参考现代 Kanban 的拖拽体验
