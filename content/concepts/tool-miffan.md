# Miffan（Android 原生多 AI 客户端）

## 它是什么

[Miffan](https://github.com/Ayuilos/Miffan) 是一款 Android 原生 AI 客户端，把：

- OpenAI 兼容接口
- Gemini
- Claude
- ChatGPT 订阅的 Codex 访问

全部收进同一个 App，每个助手还能再配**独立的提示词、工具、记忆与工作区**。

技术栈是 Kotlin + Jetpack Compose，脱胎于 RikkaHub 社区 fork，现已**独立维护**——包名、签名、版本线全部独立，可以与 RikkaHub 装在同一台设备上共存。

## 为什么用它 / 适合什么场景

- 想在 Android 上只装一个 App 就同时用多家 AI（OpenAI 兼容 / Gemini / Claude / Codex）；
- 想要给每个助手配置独立的 prompt、工具、记忆，互不干扰；
- 在用 RikkaHub 但希望迁移 / 共存到独立维护版本；
- 偏好 Android 原生 + Jetpack Compose 的轻量应用。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多服务聚合 | OpenAI 兼容 / Gemini / Claude / Codex |
| 每助手独立 | 提示词 / 工具 / 记忆 / 工作区 |
| 原生 Android | Kotlin + Jetpack Compose |
| RikkaHub 兼容 | 同台设备共存，包名签名独立 |
