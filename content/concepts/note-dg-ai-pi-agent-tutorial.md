# dg-ai-notes（Pi-Agent 10 章源码级教程笔记）

## 它是什么
[buchidonggua/dg-ai-notes](https://github.com/buchidonggua/dg-ai-notes) 是一份 **Pi-Agent 教程笔记**：10 章把 **Agent Loop / 工具系统 / 消息系统 / 事件驱动 / 会话管理 / 上下文工程** 全部拆开讲；每章固定三层——**这个概念是什么 / 源码里怎么写的 / 为什么这么设计**。三种阅读方式：Web 在线版（三栏带图）、本地 Markdown、PDF 离线版。

## 为什么用它 / 适合什么场景
- 想深入读 Pi-Agent 源码，但不想直接啃代码仓库。
- 在做自己的 Coding Agent / 通用 Agent，想参考 Pi-Agent 的设计取舍。
- 想要一份「既能当导论、又能当 reference」的 Agent 工程材料。

## 关键内容覆盖
| 章节族 | 主题 |
|--------|------|
| 基础层 | Agent Loop、消息系统、事件驱动 |

## 三种阅读方式
| 形态 | 适合场景 |
|------|----------|
| Web 在线版（三栏带图） | 阅读体验最好，代码 / 注释 / 图并排 |
| 本地 Markdown | 离线 / 编辑 / 复制 |
| PDF 离线版 | 打印 / Kindle / 不上网时阅读 |
