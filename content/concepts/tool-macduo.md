# MacDuo

## 它是什么

[DhananjayBhosale/MacDuo](https://github.com/DhananjayBhosale/MacDuo) 是 **Swift + Metal 写的 Mac 小工具**：让 MacBook 桌面跟随盖子开合角度呈现**六种物理感特效**——Duo / Ghost / Roll / Shutter / Flex / Iris。盖子停下两秒左右特效自动收尾，桌面恢复正常。

## 核心特性

| 特性 | 说明 |
|------|------|
| Swift + Metal | 原生 macOS |
| 6 种特效 | Duo / Ghost / Roll / Shutter / Flex / Iris |
| 跟随开合 | 转轴角度实时驱动 |
| 自动收尾 | 停两秒回正常桌面 |

## 为什么用它 / 适合什么场景
- 玩梗 / 拍视频要桌面特效。
- 给朋友同事炫酷 demo。
- 想研究 Metal shader + 转轴角度联动。

## 关键能力

| 能力 | 说明 |
|------|------|
| 6 特效 | 不同风格的物理感效果 |
| 转轴跟随 | 角度实时驱动 |
| 自动收尾 | 停两秒回正常 |
| Metal 渲染 | 原生 GPU |
