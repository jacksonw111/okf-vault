# tork

## 它是什么
终端里的 BT / 种子下载客户端，主打两个场景：搜索种子下载 + 一键拉取官方 Linux 发行版 ISO。

## 为什么用它 / 适合什么场景
- 想在服务器 / 无 GUI 环境下载 Linux ISO 而不想装桌面 BT 客户端。
- 想跳过浏览器广告丛林的种子搜索站，直接在终端里搜 / 下。
- 想用统一命令行界面同时管日常 BT 下载和镜像站抓取。

## 关键能力
| 能力 | 说明 |
|------|------|
| 终端原生 | TUI 操作，SSH / 服务器环境友好 |
| 种子搜索 | 集成搜索，不必打开浏览器 |
| Linux ISO 一键 | 直接拉取发行版官方镜像 |
