# Awesome Cloudflare Selfhosted

## 是什么

[theoephraim/awesome-cloudflare-selfhosted](https://github.com/theoephraim/awesome-cloudflare-selfhosted) 是 [theoephraim](https://github.com/theoephraim) 维护的一份 **Awesome 清单**，把所有「能在自己 Cloudflare 账户里直接部署 / 跑起来」的 SaaS 替代应用按维度分组收录。

清单按 **用途 / 许可证 / 平台依赖** 三维度交叉筛选——读者可以快速判断某项目能不能在自己的 Cloudflare Workers / Pages / D1 / R2 / Durable Objects 配额下跑、是否绑定具体 Cloudflare 计费特性。

## 覆盖的 15 个分类

- 分析统计
- 邮箱（邮件转发 / 反垃圾 / 临时收件）
- 文件分享
- 笔记同步
- 状态页
- （其余 10 类清单维护中）

## 适合谁

- 想用 Cloudflare 一站式替代 Notion / Dropbox / Plausible / Statuspage 等 SaaS 的个人或小团队。
- 寻找 Cloudflare Workers / Pages 上能跑的开源项目素材的开发者。
- 想给自己的 Cloudflare 账户配一套「零运维 / 不烧 VPS」的家庭工具栈。

## 与相关概念的关系

- [Self-Hosted（自托管）](./term-self-hosted.md) — 该清单是「自托管 + Cloudflare 平台依赖」这个特定交集的索引。
- [Cloudflarebase] — 与 Cloudflarebase 等同类 Cloudflare 资源聚合站互为补充。
