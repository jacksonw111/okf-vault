# netmon

自托管网络监控工具，通过定时测速与 ARP 扫描采集状态，并生成分析后推送到 Telegram。

## 适用场景

- 需要定时执行测速与 ARP 扫描，持续观察局域网和出口状态的场景。

## 关键能力

| 能力 | 说明 |
|------|------|
| 网络采集 | 定时执行测速与 ARP 扫描，持续观察局域网和出口状态。 |
| 自动分析 | 可调用语言模型生成风格化分析。 |
| 消息推送 | 把结果发送到 Telegram，适合无人值守提醒。 |
