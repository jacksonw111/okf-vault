# GreatUI

## 它是什么

`GreatUI` 是一个面向 React 项目的 UI 组件 / 页面模板集合，专注 dashboard / admin / 业务后台场景中常见的组件实现：图表卡片、表格、表单、统计模块、登录页等。它不是 shadcn / MUI 这种基础组件库，而是"已经拼好、能直接拿来用"的业务级页面与组件片段，目标是缩短"从 0 到能 demo"的距离。

## 关键能力

| 能力 | 说明 |
|------|------|
| 业务级组件集合 | dashboard / admin 场景常见组件的可复用实现 |
| React 项目导向 | 直接 npm 安装 / 复制即用 |
| 缩短 demo 周期 | 不用从基础组件搭起 |
