# Torollo（后端版 Packet Tracer）

## 它是什么

[Derssa/Torollo](https://github.com/Derssa/Torollo) 是一个**可视化的本地后端/网络架构实验场**，被定位为「后端版 Packet Tracer」。用户在画布里拖拽出服务节点，每画一个节点背后就是**真实运行的 Docker 容器**——画架构等于搭真环境。

## 为什么用它 / 适合什么场景

- 想学后端架构 / 系统设计，又不想在 Vagrant / docker compose 命令行里折腾。
- 教学中演示微服务 / 消息队列 / 缓存层之间的真实流量。
- 给客户演示架构方案，画完就能跑，而不是 PPT 上的方框。

## 关键能力

| 能力 | 说明 |
|------|------|
| 可视化拖拽 | 像画图一样拼装架构 |
| 真容器后端 | 每个节点都是真运行的 Docker |
| 本地实验场 | 全在本地跑，无需云资源 |
| 系统设计 / 网络教学 | 适合从零讲清服务依赖与流量走向 |
