# ServerBox

## 它是什么

[ServerBox](https://github.com/madeye/ServerBox) 是 **madeye** 出品的开源项目——把闲置的**安卓手机免 root** 变成一台**常开 SSH 的 Linux 服务器**，给有旧 Android 设备的用户复用硬件。

## 关键能力

| 能力 | 说明 |
|------|------|
| 免 root | 普通用户态即可启用 |
| 长开 SSH | 移动网络 / Wi-Fi 切换下保持 SSH 可达 |
| Linux 用户态 | 提供常见的 Linux 工具链与命令行环境 |
| 自托管 | 数据完全本地，无云依赖 |

## 适合场景

- 抽屉里还有一台旧安卓机（屏幕坏了也能用）
- 想在家里搭一台超低功耗的 Linux 服务器跑点小服务
- 学习 / 实验 Linux 不愿装双系统 / 虚拟机
