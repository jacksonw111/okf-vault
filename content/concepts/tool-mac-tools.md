# MacTools

## 它是什么
**免费开源的 macOS 菜单栏工具集**，SwiftUI + AppKit 写的原生 macOS 应用，macOS 14.0+ 可用，Homebrew 一键安装。自带 **30+ 个小工具**覆盖日常系统调节需求——把散落在「系统设置 → 显示器 / 电池 / 隐私…」各处的操作集中到菜单栏一键调用。

由 ggbond268 个人开发。

## 为什么用它 / 适合什么场景
- 不想为「调一下分辨率 / 开关夜览 / 设充电限制」专门装一个独立 App。
- 偏好把所有系统操作集中在菜单栏，节省 Dock 空间和窗口切换。
- 需要临时关闭系统休眠（比如长下载 / 大文件拷贝），又懒得去翻菜单。
- 想用 Homebrew 一键装 + 一键升级。
