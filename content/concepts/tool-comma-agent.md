# Comma

## 它是什么

[Comma](https://github.com/AFK-surf/Comma) 是 **AFK-surf** 出品的**长任务多 Agent 框架**——把日常请求变成**能长期跟踪的任务**：

- **跨设备保留上下文**：出门用手机，回家用电脑，状态无缝
- **多 Agent 循环**：多个 Agent 接力把活干完
- **任务可续可查**：不必守着屏幕

## 为什么用它 / 适合什么场景

- **AI 任务常常跨日**：研究、写作、收集资料都是几小时起步。
- **设备切换频繁**：通勤、外勤、居家切换不同终端。
- **多 Agent 接力**：复杂任务一个 Agent 顶不下来，多个 Agent 分工。
- **典型场景**：个人 AI 助理、研究类任务、跨日跟进项目。

## 关键能力

| 能力 | 说明 |
|------|------|
| 任务形态 | 长任务 / 跨日可续 |
| 跨设备 | 上下文保留 |
