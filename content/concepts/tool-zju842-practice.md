# zju842-practice

## 它是什么
浙江大学 842 考研真题**本地题库**，把 2009–2025 年的真题做成 Windows / macOS 解压即用的本地题库，按章节或整卷刷题。

> 现有 469 道题 / 287 张原题图，覆盖「信号与系统」与「数字电路」两科。

## 为什么用它 / 适合什么场景
- 准备浙江大学 842 考研 / 期末复习，希望在本地离线刷题。
- 希望个人答题记录与练习记录只存在自己电脑。
- 想用现成题库（免去下载 PDF + 自建 Anki / Excel 题库）。

## 关键能力
| 能力 | 说明 |
|------|------|
| 题型 | 真题（含原题图） |
| 题量 | 469 道 / 287 张图 |
| 学科 | 信号与系统 + 数字电路 |
| 形态 | 本地应用，浏览器答题 |
| 启动 | Windows 双击 `启动题库.cmd` / macOS 双击 `启动题库.command` |
| 依赖 | 不需 Node.js / Docker |
| 存储 | 个人答案与练习记录只在本机 |
