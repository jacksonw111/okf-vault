# Pinvou Agent

## 它是什么

[Pinvou Agent](https://github.com/Pinvou/pinvou-agent) 是一个**桌面 AI 工作台**，把**聊天 / 设计 / 写代码**三种 AI 用法收进同一个界面。目标不是让 AI 回一段话，而是让它**处理真实任务并交付可继续使用的文件或产物**。

![Pinvou Agent 截图](https://pbs.twimg.com/media/HOxAnALaUAA-Guy.jpg)

## 为什么用它 / 适合什么场景

- **三合一**：聊天 / 设计 / 写代码共用同一工作台，切换不需要换工具。
- **产物导向**：输出文件能继续在后续流程里被复用，不只是一段对话。
- **桌面优先**：常驻桌面应用，不依赖云端持续在线。

## 关键能力

| 能力 | 说明 |
|------|------|
| 聊天 | 与 AI 对话讨论任务 |
| 设计 | AI 辅助做视觉 / UI 决策 |
| 写代码 | 直接产出可继续编辑的代码文件 |
| 产物可复用 | 产出落到本地文件流，不是只回文本 |
