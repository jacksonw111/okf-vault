# Nyx Local AI（VS Code / Cursor 本地 AI 编码插件）

## 它是什么

[sthamann/nyx-local-ai](https://github.com/sthamann/nyx-local-ai) 是给 **VS Code / Cursor** 装的本地 AI 编码插件，把 Ollama、LM Studio、本地集群等**自有机器上跑的模型**作为主模型。**全程离线、不花 token 钱、不往云上数据**——体验对齐 Cursor 原生面板但不走云端。

## 关键能力

| 能力 | 说明 |
|------|------|
| 本地模型 | 接 Ollama / LM Studio / 本地集群 |
| 双 IDE | 同时支持 VS Code 与 Cursor |
| 全离线 | 不发任何请求到外部 |
| 无 token 费 | 用本地模型，无 API 配额与计费 |
| Cursor 体验 | 内联补全 / chat / agent panel 体验对齐 Cursor 原生 |
