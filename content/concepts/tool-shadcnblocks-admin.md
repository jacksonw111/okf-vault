# Shadcnblocks Admin Kit

## 它是什么

[shadcnblocks.com/admin-dashboard](https://www.shadcnblocks.com/admin-dashboard) 是 **Shadcn Blocks** 团队推出的 **admin dashboard 块**：基于 shadcn/ui 的 admin 仪表盘预设，含 **Payments / Dashboard 3** 等模块：

| 模块 | 说明 |
|------|------|
| Dashboard 3 | Insights carousel + chart-heavy 支付概览 |
| Payments | 支付管理模块 |
| 组件块 | 表格 / 图表 / 表单 / 导航 完整 |
| 自带主题 | shadcn 风格统一视觉 |

## 为什么用它 / 适合什么场景

- 想快速搭 SaaS / 后台 admin 仪表盘。
- 不想从零写 admin 布局 / 组件。
- 喜欢 shadcn/ui 风格。

## 关键能力

| 能力 | 说明 |
|------|------|
| shadcn 风格 | 与 shadcn/ui 生态一致 |
| 模块化 | 按模块 / 块复制 |
| 图表丰富 | chart-heavy |
| Carousel | Insights 走 carousel |
| 响应式 | 自适应布局 |
