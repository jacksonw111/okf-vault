# frontier（21 项质量标准方法包）

## 它是什么
`apoorvjain25/frontier` —— 一套 **由 Claude Fable 5 编写和审计的 21 项质量标准方法包**：目标是用 Claude Opus / Sonnet / GPT / Gemini 等模型生成**接近 Claude Fable 5 水平**的高质量交付物。换句话说，把顶级模型级的方法论拆成 21 条可对照的标准，灌注到 prompt / 工作流里，让"普通模型 + 标准方法包"也能逼近顶级模型输出质量。

## 为什么用它 / 适合什么场景
- 你常用 Opus / Sonnet / GPT / Gemini，但觉得输出质量还差点意思。
- 想**把"什么是好的输出"具体化为可对照标准**，而不是凭感觉。
- 适合：写作 / 设计 / 代码 / 评审工作流中的"质量门"。

## 关键能力
| 能力 | 说明 |
|------|------|
| 21 项质量标准 | 覆盖完整交付链路的可对照项 |
| Fable 5 审计 | 由顶级模型定义并核验 |
| 跨模型可移植 | 同一套方法用于 Opus / Sonnet / GPT / Gemini |
| 输出质量提升 | 目标接近 Claude Fable 5 水平 |
| 开源方法包 | 完全开源可嵌入工作流 |
