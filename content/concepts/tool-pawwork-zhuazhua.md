# PawWork_ZhuaZhua（点选 + 侧栏提问的 Chrome 扩展）

## 它是什么

[PawWork_ZhuaZhua](https://github.com/Player-YN/PawWork_ZhuaZhua) 是 Player-YN 做的 Chrome MV3 扩展，装进 Chromium 浏览器就能用。**开 Paw Mode** 后：

- 在当前页面**点选**图片 / 表格 / 文字 / 链接；
- 在侧栏里用自然语言说「想要什么」；
- 拿到**可继续编辑**的产物：Univer 表格、tldraw 画布（可导出 PPTX）、HTML 站点、文档画布。

省掉复制粘贴、手动排版的来回切换。

## 为什么用它 / 适合什么场景

- 在网页上看到一张表格 / 一段内容想立刻变成可编辑的表格 / 幻灯片 / 文档；
- 想把「截图 + 描述 + 重排」一步完成，而不是截图 → 提问 → 复制 → 整理；
- 偏好 Chromium 浏览器扩展形态的工具；
- 想要 AI 给出能直接编辑的结果，而不是只有文本回复。

## 关键能力

| 能力 | 说明 |
|------|------|
| 浏览器扩展 | Chrome MV3，Chromium 浏览器可装 |
| 点选 + 侧栏提问 | 选内容 → 自然语言说要什么 → 拿到可编辑产物 |
| 多形态产物 | Univer 表格 / tldraw 画布 / HTML 站点 / 文档画布 |
| PPTX 导出 | tldraw 画布可导出为 PPTX |
| 免切换 | 不再来回复制粘贴 |
