# video-ai-talking

## 它是什么

[yizhi-chengzi/video-ai-talking](https://github.com/yizhi-chengzi/video-ai-talking) 是「**真人出镜 + 字幕文案 → AI 配音对口型竖屏 MP4**」的一站式工具：上传一段真人拍摄的视频，写好字幕文案，工具会用 AI 生成配音并把口型对上，最终合成可直接发布的竖屏短片。

定位：

- **面向口播短视频**：自媒体 / 知识号 / 营销号，想出镜但不想自己念稿。
- **本地处理**：配音与合成在用户机器上完成，避免云端隐私问题。

## 为什么用它 / 适合什么场景

- 个人 IP 想量产口播视频，但时间或嗓子不够。
- 同一段素材要做多语言版本（先写多份字幕文案，AI 配音 + 对口型）。
- 希望保留本人形象作为可信度来源，但不想每次都重拍。

## 关键能力

| 能力 | 说明 |
|------|------|
| 真人出镜 | 用户上传一次素材，多个文案复用 |
| 字幕文案驱动 | 写好文字即可生成对应配音 |
| AI 配音 | 文案 → 语音 |
| AI 对口型 | 自动对齐口型到真人视频帧 |
| 竖屏输出 | 短视频平台友好的 MP4 |
