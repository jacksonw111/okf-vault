# hk-traffic-intelligence

## 它是什么

[hk-traffic-intelligence](https://github.com/keithligh/hk-traffic-intelligence) 是 **keithligh** 开源的**香港智慧城市交通看板**——把香港分散在各家网站上的**隧道时间 / 干道车速 / 口岸排队 / 天文台警告 / 下一班车船**数据汇总到同一张地图，出门前扫一眼就够。

## 关键能力

| 能力 | 说明 |
|------|------|
| 数据来源 | 隧道时间 / 干道车速 / 口岸排队 / 天文台警告 / 车船班次 |
| 栈 | Next.js + React + MapLibre GL + Tailwind CSS |
| 部署 | Cloudflare Worker（边缘，全球可访问） |
| 语言 | 默认繁体中文，可切简体中文 / 英文 |
| 注册 | 无需注册、无需安装 |

## 适合场景

- 香港居民 / 通勤者出门前查路况
- 香港旅客想避开口岸高峰
- 对「出门前 5 分钟看清交通状态」有强烈需求
