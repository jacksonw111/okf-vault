# pgapp

用纯文本 .pgapp 文件描述应用，并由 PostgreSQL 自动建表和生成交互式 HTML 的应用构建工具。

## 适用场景

- 需要单个可版本管理的 .pgapp 文件描述整套应用的场景。

## 关键能力

| 能力 | 说明 |
|------|------|
| 文本即应用 | 单个可版本管理的 .pgapp 文件描述整套应用。 |
| 数据库驱动 | 读取描述后自动在 PostgreSQL 建表并生成交互式页面。 |
| 应用组件 | 提供 13 种组件并支持多租户场景。 |
