# Create UI（AI Native Figma 设计系统 + React 组件库）

## 它是什么

[createui.co](https://createui.co) 是一个**AI 原生的 Figma 设计系统 + React 组件库**：免费起步，按需付费扩展——核心定位是「**给 AI 编码 Agent 直接用**的设计资产」。

## 关键能力

| 能力 | 说明 |
|------|------|
| AI 原生 | 设计 token / 组件直接给 Agent 消费 |
| Figma 设计系统 | 在 Figma 里维护 |
| React 组件库 | 直接落地到代码 |
| 配套代码 | 复制就能用 |
| 免费起步 | 核心代码免费，按需付费扩展 |

## 适合谁

- 想用 Figma 设计系统但又想要能跑起来的 React 代码
- 想让 AI agent 直接消费设计 token
- 小团队 / 个人开发者想一次性拿到 Figma + 代码
