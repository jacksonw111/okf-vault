# lazychat

## 它是什么

[lazychat](https://github.com/Perpeer/lazychat) 是 Perpeer 开源的**终端聚合工具**：

- 把 **Claude Code / Codex** 等 AI 编码 Agent 塞进同一个终端界面
- 顺便把 **Git** 和 **shell** 也摆在旁边
- 让编码 Agent 的会话 + 版本控制 + 命令行三件事一屏搞定

## 为什么用它 / 适合什么场景

- **窗口爆炸症**：开 Claude Code 一个、Codex 一个、shell 一个、git GUI 一个……拉一堆
- **同一会话混编**：在 Agent 里写代码 / 跑命令 / 看 diff 不用切窗口
- **终端优先派**：愿意用 TUI 而非 GUI

## 关键能力

| 能力 | 说明 |
| ------ | ------ |
| 形态 | 终端应用（TUI） |
| Agent 面板 | Claude Code / Codex 等 |
| Git 集成 | 在同一界面看 diff / commit / branch |
| Shell 集成 | 命令行随时跑 |
| 单窗口 | 一个终端搞定「编码 Agent + git + shell」 |
