# Duolingo 风格 shadcn 组件库

## 它是什么

多领国（Duolingo）风格的 **shadcn 组件库**——基于 shadcn 的「复制代码即可用」模式，把多领国家喻户晓的**游戏卡通风格**封装成可直接 `<DuolingoButton />` 调用的组件。

适合营销站、教育产品、想让应用多一分趣味感的开发者。

## 关键能力

| 能力 | 说明 |
|------|------|
| shadcn 兼容 | 沿用 shadcn 的「copy-paste 即用」分发模式 |
| 游戏卡通风 | 厚边描边 + 高饱和色块 + 卡通字体的多领国视觉语言 |
| 趣味交互 | 弹性 hover / 点击反馈 / 成就式动效 |
| React + Tailwind | 与 shadcn 主线技术栈一致 |

## 适合什么场景

- 做语言学习 / 教育产品 / 儿童向应用想找现成「卡通风」UI 库的前端开发者。
- 想给营销站 / 落地页增加「品牌记忆点 + 趣味感」的设计 / 前端。
- 想研究 shadcn 生态下「风格化变体」怎么组织的工程师。

## 与相关概念的关系

- [shadcn 生态] — 是 shadcn 生态下「风格化变体」方向的一个补充。
- [ObsidianUI](./note-obsidianui.md) — 同样是「按风格聚合的 UI 资源库」，但 ObsidianUI 专注动效，这个专注游戏卡通视觉。
