# GEORank

## 它是什么

GEORank 是面向 **GEO（Generative Engine Optimization）** 的**开源自托管工作台**：诊断品牌在 **ChatGPT / Claude / Perplexity** 等 AI 搜索里的可见性，并落成 **30 / 60 / 90 天行动方案**。

## 完整流水线

```
发现 → 诊断（Schema / 结构 / Meta / 可读性 / 引用信号 / AI 可见性）
     → AI 问答 → 出方案 → 拓词 → 结构化 → 后台管理
```

## 内置工具

| 工具 | 用途 |
|------|------|
| JSON-LD 生成器 | 自动生成结构化数据 |
| llms.txt 生成器 | 给 AI 爬虫看的\"网站说明书\" |
| AI 友好度评分 | 内容对 AI 的可读性打分 |
| GEO 标题生成器 | 标题 GEO 优化 |
| 知识库生成器 | 站点知识库构建 |

## 解决的具体问题

1. AI 能否准确理解你的公司 / 产品 / 专业能力？
2. 官网内容是否有\"能被 AI 摘要 / 引用 / 推荐\"的结构？
3. Schema / 页面结构 / Meta / 引用信号 / 可读性——先优化哪个？
4. 一次诊断，生成 30 / 60 / 90 天行动方案

## 为什么用它 / 适合什么场景

- 营销 / SEO / GEO 服务公司可私有化部署 + 二次开发。
- 想给客户做 GEO 服务（咨询公司 / 营销机构 / 独立顾问）。
- 内部 GEO 工具箱。

## 重要边界

⚠️ README 明确：「**不出售排名，不保证任何模型一定推荐某个品牌**」——只帮做结构性优化。
