# amicro

## 它是什么
`SubhanHQ/amicro` 是一个**免费开源的 React UI 组件库**（站点 [amicro.vercel.app](https://amicro.vercel.app)），聚合了**图表（Graphs）**、**Loader**、**通用组件（Components）** 等常见 UI 需求，目标是让 React 项目**只装一个库**就能拿到日常 UI 所需的多数零件。

## 为什么用它 / 适合什么场景
- React 项目起步阶段，不想为图表 / Loader 各装一个库（recharts + react-spinners + 各种 kit…）。
- 个人项目 / side project / MVP：需要现成 UI 又不想花钱买付费 kit。
- 喜欢「一站式 UI 包」而不是按需装一堆小库。
- 学习 React 组件库怎么打包 / 怎么组织 API。

## 关键能力
| 能力 | 说明 |
|------|------|
| 图表 | 内置多种 React 图表组件（柱状 / 折线 / 饼图…） |
| Loader | 多种加载 / 进度动画组件 |
| 通用组件 | 按钮 / 卡片 / 输入框 / Modal 等常见 UI |
| 免费 + 开源 | 无 license 费用，源码可改可商用 |
| React 集成 | 标准 React 组件，按需 import |
