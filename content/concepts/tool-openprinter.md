# Openprinter

## 它是什么

[Openprinter](https://www.opentools.studio/) 是一个**开源打印机项目**，主张把打印机从「昂贵黑盒」变成「人人能复制、改造、维护」的开放硬件。

设计哲学是「**结构尽量简单**」——用通用可加工零件 + 3D 打印件，把打印机拆解到普通人能复刻的程度。

## 关键设计

| 设计点 | 说明 |
|--------|------|
| 结构极简 | 部件数量与装配步骤都尽可能少 |
| 通用零件 | 多数部件可在通用机加工 / 3D 打印上完成 |
| 可复制 | 个人 / 小工作室也能复刻一台 |
| 可改造 | 模块化结构，便于二次开发 |
| 可维护 | 拆装简单，故障点清晰 |

## 适合谁

- 想自己 DIY 一台打印机的硬件玩家。
- 对「打印机是黑盒、坏了只能换」不满的创客。
- 想研究打印机结构的开源硬件学习者。
