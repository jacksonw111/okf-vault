# PanelUI

## 它是什么

[PanelUI](https://github.com/panel-ui/PanelUI) 是构建在 **Expo / React Native** 之上的 **UI 组件库 + Flow 节点编辑器**。除了常规组件，其最具特色的 **Flow 组件** 把 pan、zoom、可拖拽节点、动画边线全套原生跑在 Expo 上，免去 WebView 桥接。

## 为什么用它 / 适合什么场景

- **React Native 上的节点编辑器**：想做工作流 / 思维导图 / 自动化画布，不再需要包装 react-flow；
- **Expo 优先**：Expo 工具链里的项目可以直接接入；
- **动画原生**：节点连线动效由原生层处理，60 fps 不抖。

## 关键能力

| 能力 | 说明 |
|------|------|
| Flow 节点编辑器 | pan / zoom / 可拖拽节点 / 动画边线 |
| React Native 组件库 | 与 Expo 工具链一致 |
| 原生动画 | 连线 / 节点移动不经 WebView |
| 开源 MIT | GitHub 仓库 panel-ui/PanelUI |
