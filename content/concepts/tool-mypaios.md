# Mypaios（mypaios/mypaios）

## 它是什么

**Mypaios** 是一款用 **Python/FastAPI** 编写的**自托管、本地优先 AI 工作台**，由 Vishal Pawar 开发，**MIT** 协议开源。

它把「**十余项功能**」集中在一个应用里：

- 聊天
- 智能体（Agent）
- Cookbook 模型下载推荐
- 深度研究
- 模型盲测对比
- 文档编辑
- 记忆 / 技能
- 邮件智能整理
- 日历
- 语音 / 视频分析

模型后端可接：**vLLM、llama.cpp、Ollama、OpenRouter、OpenAI** 等。

## 为什么用它 / 适合什么场景

- 想**一站式**自托管 AI 工具，不想装 N 个小软件。
- **模型可换**：从本地小模型到云端大模型无缝切换。
- **本地优先**：记忆 / 文档 / 数据全在本地，敏感场景友好。
- **开源 MIT**：商用友好，可改造。

## 关键能力

| 能力 | 说明 |
|------|------|
| 聊天 + Agent | 基础对话 + 工具调用 Agent |
| Cookbook 模型推荐 | 帮你挑合适模型 + 下载 |
| 深度研究 | 多轮检索 + 综述生成 |
| 模型盲测对比 | 同一 prompt 并排对比多家模型 |
| 文档编辑 | 内嵌 Markdown 编辑器 |
| 记忆 / 技能 | 跨会话记忆 + 可调用技能库 |
| 邮件智能整理 | 自动归类 / 起草 / 回复 |
| 日历 | AI 助手直接操作日程 |
| 音视频分析 | 媒体文件转写 / 摘要 |
| 多 Provider 后端 | vLLM / llama.cpp / Ollama / OpenRouter / OpenAI |
