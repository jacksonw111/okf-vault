# UI「难用」20 个修正视角

## 它是什么

整理自日语 UX 推主的「UI の『使いにくい』を直す 20 の視点」——把心理学 / 认知科学的经典原则翻译成 UI 设计可操作的修正视角，分四组共 20 条具体规则。

## 四组原则

### ① まとまりを見せる（让分组看得见）
- **靠近的元素看起来一组**（格式塔接近律）
- **被视线略过的变化会被忽略**
- **远而小的按钮不容易瞄准**

### ② 記憶を助ける（帮用户记忆）
- **「想起来的成本」比「看着选」高**——把可选项摆出来
- **统一的命名 / 位置减少记忆负担**

### ③ 迷いを減らす（减少迷茫）
- **明示当前所在位置**
- **明示下一步可以做什么**
- **明示已选了什么 / 还差什么**

### ④ 操作と体験を整える（操作与体验对齐）
- **操作反馈要即时**
- **错误可恢复**
- **路径要可预期**

## 为什么用它 / 适合什么场景
- UI 设计评审时找问题。
- 设计新人理解「为什么这个不顺眼」。
- 与既有设计原则互补。

## 关键能力

| 能力 | 说明 |
|------|------|
| 20 条规则 | 涵盖四种 UI 修正视角 |
| 配图 | 每条配「怎么用」图示 |
| 跨文化 | 日语原文但原则通用 |
| 可操作 | 不止原则，每条都有具体应用 |
