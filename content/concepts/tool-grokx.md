# grokx（tangf-ai/grokx）

## 它是什么
[`tangf-ai/grokx`](https://github.com/tangf-ai/grokx) 把 xAI 的 **Grok Build** 引擎**绑进**一个桌面窗口：用户不必装命令行工具、不必配环境变量，双击打开应用就能在 GUI 里与 Grok 聊天、写代码。

## 为什么用它 / 适合什么场景
- 想用 Grok 的能力，但不想 / 不会配命令行。
- 团队里有非技术同事，想给他们一个「开箱即用」的 Grok 客户端。
- 桌面应用形态更符合 Windows / macOS 普通用户习惯。

## 关键能力
| 能力 | 说明 |
|------|------|
| 零命令行 | 桌面应用形态，免装 CLI 工具 |
| 内嵌 Grok Build 引擎 | 直接调用 xAI Grok 模型能力 |
| 聊天 + 编码 | 既能对话也能写代码 |
| 跨平台 GUI | 桌面应用跨 Windows / macOS / Linux |
