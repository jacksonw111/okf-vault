# spiralist（照片 → 一笔画工具 / 3D 打印文件生成器）

## 它是什么

[spiralist](https://github.com/winchxyz/spiralist) 是一个把**任意照片**转成「**一笔连续画完**」艺术作品的工具，**全流程在浏览器**里完成：

1. 上传照片
2. 选择风格：**钢笔 / 铅笔 / 绘画**
3. 生成一笔画的 SVG / G-code 路径
4. **浏览器中观看落笔过程**（带动画回放）
5. **导出图像**或**生成 3D 打印文件**（G-code / STL 等）

## 为什么用它 / 适合什么场景

- 想做**送给朋友 / 同事的定制礼物**——把对方照片转成手绘风笔画，再交给笔式绘图仪 / 3D 打印机落地。
- 喜欢「**spirograph / 万花尺**」一笔连续画的美学，想批量生成自己的图案。
- 想在**网页上完成**全部流程（不上传图像到云端），看重隐私。
- 想把单线艺术落到**实物**——3D 打印 / 激光雕刻 / 笔式 plotter。
