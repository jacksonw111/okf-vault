# GemType

[GemType](https://github.com/riponcm/GemType) 是一个**免费开源的浏览器扩展 + Microsoft Word 插件**,定位为 **Grammarly 的免费替代**——它调用用户自己的 Google Gemini API key,文本只发往 Google 接口,不经过任何中间服务器,不绑定账号、不收集遥测。

## 它解决了什么

Grammarly 体验好但要付费 + 绑定账号 + 上传到 Grammarly 服务器——很多人只是想要「实时语法检查 + 一键改写」就够了。GemType 用用户自己的 Gemini 免费 key,在 Gmail / Google Docs / Twitter / 任意文本框里植入同样的能力,数据流仅在用户 ↔ Google 之间。

## 关键能力

| 能力 | 说明 |
|------|------|
| 浏览器扩展 | Chrome / Edge 等浏览器即装即用 |
| Word 插件 | Microsoft Word 也支持,长文档写作场景 |
| 自带 Gemini API key | 用户配自己的 key,无需中间服务 |
| 实时语法检查 | 输入即检查,提示纠错与建议 |
| 一键改写 | 选中句子 / 段落按一下自动改写到更地道表达 |
| 隐私优先 | 文本只发往 Google,不收集使用遥测 |
