# Codex

## 定义

**Codex** 是 OpenAI 出品的 AI 编码 Agent，覆盖 CLI / IDE 插件（VS Code、JetBrains）/ Web App / iOS App 等多种形态。它提供终端命令执行、文件读写、计算机使用（Computer Use，能读屏 + 模拟键鼠）、长跑任务调度等能力，是与 Claude Code 同梯队的事实编码 Agent 之一。

## 要点

- **官网**：[openai.com/codex](https://openai.com/codex/)
- **形态**：CLI（`codex` 命令）/ IDE 插件 / Web App / iOS / 桌面
- **核心能力**：
  - **Computer Use**：可读屏 + 模拟键鼠，驱动 GUI 应用
  - **代码读写**：跨文件重构、自动 PR、PR Review
  - **长跑任务**：后台跑数小时任务 + 状态面板
  - **MCP 接入**：可挂任意 MCP 服务器
- **生态**：Codex App / Codex CLI / Codex iOS / Codex Mini（更轻量）
