# prd-outputs-interactive（零散材料整理成 PRD 主稿）

## 它是什么

一套把**零散输入**收敛成**单一 PRD 主稿**的产出流程：需求说明、会议纪要、原型反馈这些碎片喂进去，输出一份「可实现、可验收、可持续更新」的产品需求文档。遇到写不下去的地方不瞎编——**把关键缺口攒成一份交互式问卷**，一次性向人确认。

![](https://pbs.twimg.com/media/HRRTV51bYAAMS8J.jpg)

## 为什么用它 / 适合什么场景

- 需求散在聊天记录、会议纪要、原型批注里，没人愿意手工合并成一份文档。
- 直接让模型写 PRD 容易在信息缺失处产生臆造；「集中提问」比「边写边猜」更可控。
- PRD 需要长期维护，希望有一份稳定的主稿而非每次重写。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多源汇总 | 需求说明 / 会议纪要 / 原型反馈等异构材料统一入稿 |
| 三个质量目标 | 可实现（工程能落地）、可验收（有验收标准）、可持续更新 |
| 缺口问卷 | 关键信息缺失时集中生成交互式问卷，避免逐点打断与臆造 |
