# CozyClay（npx 一键起手的 3D 动画工作室）

## 它是什么

[`CozyClay`](https://github.com/NomaDamas/CozyClay) 是 NomaDamas 写的浏览器内 3D 动画工作台（Web + Three.js）：

```
npx cozyclay
→ 浏览器打开 127.0.0.1:5180 → 完整 3D 动画工作室
```

不需要安装依赖，不需要编译。功能：

- **搭景**：W/E/R gizmo 平移 / 旋转 / 缩放拖放道具与角色
- **俯视图**：画二维路径，角色按路径走位
- **时间线**：动作拆成多个 **Prompt Block** 接力跑

## 为什么用它 / 适合什么场景

- 想做 3D 动画但不想装 Blender / Maya
- 想让 AI 按时间线接力创作（每个 Block 一个 Prompt）
- 想完全本地起步，`npx` 一行跑起来

## 关键能力

| 能力 | 说明 |
|------|------|
| 一键起手 | `npx cozyclay` 启动 |
| W/E/R gizmo | 拖放 / 旋转 / 缩放 |
| 俯视走位 | 二维路径给角色 |
| 时间线 | 多 Prompt Block 接力 |
| 浏览器内 | 无安装 / 无编译 |
| 跨平台 | Node + Web 技术栈 |
