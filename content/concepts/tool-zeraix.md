# Zeraix（本地优先 AI 桌面工作区）

## 它是什么

[Zeraix](https://github.com/zeraix/zeraix) 是一个**桌面形态的本地优先 AI 工作区**，把私有本地模型、工具调用、文件存储、AI 智能体都装在同一台个人电脑上。除了可用之外，仓库本身也用作「在普通消费级硬件上高效推理现代模型」的实验场。

## 关键能力

| 能力 | 说明 |
|------|------|
| 本地模型 | 跑私有模型，不向云端泄露 |
| AI 智能体 | 集成工具调用 + 文件操作的 agent 运行时 |
| 桌面端 | 桌面应用形态，不是 Web/CLI |
| 推理优化研究 | 项目同时承担「让模型在个人硬件上跑得更快」的研发任务 |
