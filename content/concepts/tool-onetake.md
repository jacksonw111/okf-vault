# onetake（产品动效短片：连续转场）

## 它是什么

[onetake](https://github.com/feitangyuan/onetake) 是 feitangyuan 出品的工具：让 Claude 做的产品动效短片**不再像翻 PPT**——每个画面之间都有一个元素「**活下来、看得见地变成下一个画面**」，同一台摄影机从头跟到尾不剪断。

## 为什么用它 / 适合什么场景

- 想给产品做**有「电影感」的动效演示**——而不是 PPT 翻页。
- 想让 AI 编码 Agent 自动产出**连续转场**的 demo 视频。
- 觉得现在的产品动效太「碎片化」——希望画面之间有**视觉延续**。
