# Code-Quote（GitHub README 动态编程名言卡片）

## 它是什么

[Itz-Anya/Code-Quote](https://github.com/Itz-Anya/Code-Quote) 是一个**给 GitHub README 加一张每次访问自动换的编程名言卡片**的小工具。

用法类似 GitHub 常用的「Stats Card / Visitor Count」之类动态徽章：在 README 里嵌一行 Markdown 图片或链接，每次页面加载都从 Code-Quote 服务拿一张新名言卡片，避免手动维护 README 顶部的引言区。

## 为什么用它 / 适合什么场景

- 想给 GitHub 个人主页 / 项目 README 加点变化、但又不想每周手动换引言。
- 想要一个**零维护**的「动态装饰元素」提升 README 质感。
- 想给 README 顶部「每天 / 每次访问来一句」的小巧思找一个现成服务。

## 关键能力

| 能力 | 说明 |
|------|------|
| 每次访问换一句 | 服务端每次请求换一张卡片，无需手动更新 |
| Markdown 一行嵌入 | 类似 Stats Card 的接入方式 |
| 编程名言语料 | 围绕「代码 / 编程」主题的引言库 |
| 零维护 | 写一次 README 链接就完事 |
