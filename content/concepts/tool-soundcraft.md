# SoundCraft

## 它是什么

[SoundCraft](https://github.com/storytold/soundcraft) 是 storytold 用**纯 Rust** 重做的**开源数字音频工作站**（DAW）：

- 工作流覆盖 **Pro Tools** 的常用模式
- 让**每个操作都能被命令行或 AI Agent 调用**——为 AI 写音乐 / 配乐打开通道

## 为什么用它 / 适合什么场景

- **Pro Tools 老用户**：熟悉 Pro Tools 工作流的音频工程师
- **不想付 AVID 月费**：开源 + 商用友好
- **Agent 友好**：CLI / MCP 让 AI 自动出配乐 / 混音脚本
- **配乐 / 视频后期**：让 Agent 帮忙生成或调整背景音乐

## 关键能力

| 能力 | 说明 |
| ------ | ------ |
| 引擎 | Rust 写 |
| 工作流 | 沿用 Pro Tools 范式（轨道 / 编辑 / 混音 / 自动化） |
| Agent 友好 | 操作可通过 CLI 调用 |
| 跨平台 | Rust 二进制 |
| 形态 | 开源 DAW |
