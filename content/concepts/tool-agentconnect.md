# AgentConnect

## 它是什么

[agentconnect-md/agentconnect](https://github.com/agentconnect-md/agentconnect) 解决「智能体都缩在各人终端里跑，队友看不到、接不上手」的问题——把人和一堆智能体拽到**同一个聊天和工作流**里一起干。

## 为什么用它 / 适合什么场景

- 多个 agent 跑在不同人 / 不同机器上，想共享上下文、避免重复造轮子。
- 想让团队成员从同一个面板里**同时看 agent 在做什么、能把任务接过去继续做**。
- 不想给每个 agent 各写一套协作层。

## 关键能力

| 能力 | 说明 |
|------|------|
| 人 + agent 同台 | 人类成员与多个智能体共享同一会话视图 |
| 共享上下文 | 一次同步周期内各方拉到完整状态 |
| 工作流串联 | 把多 agent 的任务放进同一可推进的工作流 |
| 跨终端 | 各 agent 仍可跑在各自终端，对外接口被聚合 |
