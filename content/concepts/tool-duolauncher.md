# DuoLauncher（折叠屏原生 Android 桌面）

## 它是什么

[jakesgoodapps/DuoLauncher](https://github.com/jakesgoodapps/DuoLauncher) 是个**折叠屏原生 Android 桌面**（Launcher）。要求 **Android 12+**，仍在 Beta。

## 关键能力

| 能力 | 说明 |
|------|------|
| 折叠屏原生 | 针对大屏 / 折叠形态优化 |
| 常驻 Dock | 右侧固定 Dock，竖屏也能用 |
| 展开多任务区 | 折开后 Home 旁边多一块工作区 |
| Android 12+ | 最低系统要求 |

## 关键能力示意

- **竖屏**：屏幕右侧一条常驻 Dock
- **折开**：右侧多出第二块工作区，Home / 工作区并存
- 不依赖第三方桌面框架，原生 Android
