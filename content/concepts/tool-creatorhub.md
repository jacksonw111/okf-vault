# creatorhub

## 它是什么

[creatorhub](https://github.com/3441293738/creatorhub) 是一个**多平台内容运营自动化工具**——用 Playwright 驱动真实浏览器，在统一 Web 面板里管理抖音、小红书、快手三个平台的：

- 账号
- 作品（视频 / 笔记）
- 评论监控
- 下载
- 发布

适合多平台运营 / 内容搬运 / 矩阵号玩家。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多平台支持 | 抖音 / 小红书 / 快手 三平台 |
| 真实浏览器 | Playwright 模拟真人操作，避免被检测 |
| 统一面板 | Web UI 管理多账号 |
| 评论监控 | 监听作品下的评论 / @ |
| 自动下载 | 抓取对标作品素材 |
| 自动发布 | 按计划跨平台同步发布 |
