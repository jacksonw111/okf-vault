# nvim-camel

一个 Neovim 插件，**在编辑器窗口里显示一只会走路的 ASCII 骆驼动画**——没有别的事，就是让你写代码时心情好一点。

## 它是什么

- 纯装饰性插件（whimsy/decoration），**不影响代码、不参与 LSP、不接 LLM**；
- 适合加在 `init.lua` / `init.vim` 里活跃一下 coding 氛围。

## 为什么装它

- 写代码写到麻木时，看一只骆驼在 buffer 里走路有点治愈；
- 演示 Neovim 自定义 UI 浮层/动画有多容易的小例子。

## 关键能力

| 能力 | 说明 |
|------|------|
| 动画显示 | 骆驼在 Neovim 窗口里循环走路 |
| 配置简单 | 一行 plugin spec 就装上 |
| 零依赖 | 纯 Lua / Vimscript，不拉外部资源 |
