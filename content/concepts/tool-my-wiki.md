# My Wiki (NimaChu)

## 它是什么

[My Wiki](https://github.com/NimaChu/my-wiki) 解决**本地资料散落各处、难以持续整理和准确复用**的问题——**让本地 AI Agent 把原始资料整理成可追溯、可复用的原子知识库**。

![My Wiki 截图](https://pbs.twimg.com/media/HOxq3jgaQAAcDIx.jpg)

## 为什么用它 / 适合什么场景

- **资料散落归一**：散落在文档 / 笔记 / 文件里的原始资料集中整理。
- **可追溯**：每条知识能回到原始资料，不做"断章取义"。
- **可复用**：原子粒度，可被不同任务组合引用。
- **本地优先**：敏感资料不出本机。

## 关键能力

| 能力 | 说明 |
|------|------|
| 资料汇总 | 把散落的本地原始资料收集起来 |
| AI Agent 自动整理 | 让本地 AI Agent 处理切分 / 标注 / 关联 |
| 原子知识库 | 知识拆到原子粒度，便于复用 |
| 可追溯 | 每条知识能反向查到原始出处 |
| 本地优先 | 敏感资料不出本机 |
