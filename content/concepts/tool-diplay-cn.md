# DiPlay-CN

## 它是什么

[DiPlay-CN](https://github.com/serein-morii/DiPlay-CN) 是 **serein-morii** 出品的开源项目——比亚迪车机不自带 CarPlay，这套工具往兼容的比亚迪安卓车机上装一个 CarPlay 应用。

## 关键能力

| 能力 | 说明 |
|------|------|
| 连接方式 | 有线 / 无线都能连 |
| 兼容 | 部分比亚迪安卓车机（非全部） |
| 本地化 | 简中界面 |
| 优化 | 比亚迪车机本地化适配 |
| 开源 | MIT 协议 |

## 适合场景

- 比亚迪车主想要 CarPlay 体验（且车机在兼容名单）
- 不想换车但想升级车机连接性
- 喜欢本地化 / 开源工具的车主

## 注意

- 比亚迪不同车型 / 车机系统可能不通用
- 安装涉及车机系统改造，需自行评估保修 / 安全风险
