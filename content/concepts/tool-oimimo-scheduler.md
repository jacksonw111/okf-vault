# oimimo 画师排单助手

## 它是什么
[mimo9708/oimimo-scheduler](https://github.com/mimo9708/oimimo-scheduler) 是**独立插画师的一体化排单工作流工具**。

痛点：自由插画师接单后通常要管这些事——微信 / 邮件 / 平台消息里散落的**订单信息**、**截稿日期**、**改稿次数**、**收款进度**、**月度统计**——它们分散在不同地方，到了月底对账完全靠回忆。

oimimo 把这条流水线**统一收进一个本地工具**：

1. **接单**——录入甲方需求、报价、截稿日；
2. **排期**——按截稿日 / 优先级排进日历；
3. **跟进**——改稿记录、沟通节点、文件版本；
4. **收款**——款项状态、到账提醒；
5. **统计**——月度 / 年度营收、客单价、来源分布；
6. **归档**——完成项目存进本地档案库。

## 为什么用它 / 适合什么场景
- 独立插画师 / 设计师 / 自由创作者需要**统一管理**接单到归档；
- 想把**财务数据**与**创作数据**整合在同一处，避免多工具切换；
- 关心**数据所有权**——全部订单、收款、统计留在本机；
- 想做**年度复盘**——历史项目、客户、收入趋势随时可查。
