# OPC Skills

## 它是什么

**OPC Skills** 是 ReScienceLab 维护的一套面向「一人公司 / 独立开发者」场景的 Agent Skill 包。OPC = One Person Company。目前收录 10 个 Skill，瞄准独立开发中那些重复且琐碎、又无法完全砍掉的工作：SEO 优化、域名比价、Logo 生成、去 Reddit / X 挖需求等。

## 为什么用它 / 适合什么场景

- 一个人在写代码 + 还要管 SEO / 域名 / Logo / 用户访谈这些「副业级杂活」时。
- 想把这些活甩给 Agent 而不是自己做，但不知道有哪些 Skill 已经写好可复用。
- 同时使用多种 Agent 工具（Claude Code、Cursor、Codex 等），希望 Skill 一次写好到处能跑。

## 关键能力

| 能力 | 说明 |
|------|------|
| Skill 数 | 10 个（持续收录中） |
| 覆盖任务 | SEO 优化、域名比价、Logo 生成、Reddit / X 需求挖掘 等 |
| Agent 兼容数 | 16 个主流 Agent（Claude Code、Cursor、Codex 等） |
| 适用对象 | 独立开发者 / 一人公司 |
