# TrenTorch

## 它是什么
受哈佛 TinyTorch 启发的自学型深度学习框架，纯 Python + NumPy（MIT 协议，唯一第三方依赖是 NumPy），通过 20 个渐进模块带你从零手写一个类 PyTorch 框架，覆盖张量、激活、层、损失、数据加载、自动微分、优化器、训练、卷积、词元化、嵌入、注意力、Transformer、性能分析、量化、压缩、加速、记忆化、基准测试与毕业项目。

## 模块清单
1. 张量（Tensor）
2. 激活函数（Activation）
3. 层（Layer）
4. 损失函数（Loss）
5. 数据加载（DataLoader）
6. 自动微分（Autograd）
7. 优化器（Optimizer）
8. 训练（Train）
9. 卷积（Convolution）
10. 词元化（Tokenization）
11. 嵌入（Embedding）
12. 注意力（Attention）
13. Transformer
14. 性能分析（Profile）
15. 量化（Quantization）
16. 压缩（Compression）
17. 加速（Acceleration）
18. 记忆化（Memoization）
19. 基准测试（Benchmark）
20. 毕业项目（Capstone）

## 适用场景
- 想"真正理解" PyTorch / TensorFlow 内部实现的开发者
- 教学场景：ML 入门课的实战配套
- 想要可控、可读、最小依赖 ML 框架做研究的人

## 关键能力
| 能力 | 说明 |
|------|------|
| 零核心依赖 | 唯一外部依赖是 NumPy |
| 渐进式学习 | 20 个模块按依赖顺序展开 |
| 完整覆盖 | 从基础张量到 Transformer 再到量化 |
| MIT 协议 | 商用 / 教学免费 |
