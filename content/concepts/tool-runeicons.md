# Rune Icons

## 它是什么

[Rune Icons](https://runeicons.com) 是一个**每个图标都提供 5 种风格的开源图标库**：outline（线框）/ duotone（双色）/ fill（填充）/ pixelated（像素）/ glass（玻璃）。一次选择，覆盖多种视觉风格。

## 核心特性

| 特性 | 说明 |
|------|------|
| 5 种风格 | outline / duotone / fill / pixelated / glass |
| 开源 | 自由使用 |
| 一次设计 | 多风格变体 |
| 全覆盖 | 同一图标在多风格间一致 |

## 为什么用它 / 适合什么场景
- 不同页面需要不同视觉风格但图标语义统一。
- 想要像素 / 玻璃等差异化风格。
- 不想为风格切换维护多套图标库。

## 关键能力

| 能力 | 说明 |
|------|------|
| 5 风格 | 一图标多版本 |
| outline | 线框基础款 |
| duotone | 双色进阶款 |
| fill | 实心填充 |
| pixelated | 像素风 |
| glass | 玻璃质感 |
