# MyGo

## 它是什么

[MyGo](https://mygo.egoist.dev) 是 **egoist**（localhost_4173）维护的 **Go Web 组件库**——提供 **54 个原生组件** + 基于 **libghostty** 的 Terminal 插件，让 Go 服务直接产出富 Web / 桌面界面。

## 关键能力

| 能力 | 说明 |
|------|------|
| 组件数 | 54 个原生组件 |
| Terminal 插件 | 基于 libghostty（与 Ghostty 同源） |
| 形态 | 浏览器 / 桌面均可 |
| 语言 | Go |

## 适合场景

- 后端是 Go 但想直接给运营 / 客户一个可点的 UI
- 想内嵌一个真 Terminal 给用户跑命令
- 不想拉一堆前端框架到 Go 项目里
