# Kobra

## 它是什么

[Kobra](https://kobra.systems) 是一套 **80+ 动效组件库**，**自带音效**、**shadcn/ui 1:1 替代品**——可直接在原 shadcn 项目里替换使用，不改 API 习惯。底层基于 **Tailwind**、**Base UI** 与 **shadcn/lint**。

## 为什么用它 / 适合什么场景

- 想要 shadcn 的开发体验但希望组件默认带微动效 / 音效。
- 给产品加记忆点（动效 + 反馈音）又不想自己写全套。
- 已经在用 shadcn/lint 做设计系统约束，希望组件直接通过校验。

## 关键能力

| 能力 | 说明 |
|------|------|
| 80+ 动效组件 | 覆盖常见 UI 控件 |
| 音效 | 每次动作有配套反馈音，提升交互质感 |
| shadcn 1:1 替代 | 迁移成本接近零 |
| Tailwind 底层 | 与主流 Tailwind 项目无缝集成 |
| Base UI | Zag.js 团队的无样式行为层，跨框架一致 |
| shadcn/lint | 自带设计系统 Lint，不破坏设计规范 |
