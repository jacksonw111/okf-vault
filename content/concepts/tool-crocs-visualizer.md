# Crocs Visualizer（浏览器里定制洞洞鞋）

## 它是什么
Crocs Visualizer 是一个浏览器端运行的 Crocs 洞洞鞋定制 / 配饰预览工具。用户可以给整双鞋换颜色（鞋身 / 鞋带 / 鞋底分别可调），再把字母 / 数字 / 卡通挂件（Jibbitz）拖到任意一个鞋孔位置上，整个定制过程所见即所得。

## 为什么用它 / 适合什么场景
- 想送人 / 自购 Crocs 但想先在浏览器里看效果再去线下 / 线上店下单。
- 想做 Crocs 配饰周边的卖家 / 工作室，把它作为「让顾客先 DIY 再下单」的工具。
- 想学 Three.js / 浏览器端实时 3D 配置器的同学，一个轻量可读的项目模板。

## 关键能力
| 能力 | 说明 |
|------|------|
| 浏览器内实时渲染 | 无需安装，打开即用 |
| 鞋身换色 | 鞋面 / 鞋带 / 鞋底三种部件分别配色 |
| Jibbitz 拖拽挂件 | 字母 / 数字挂件拖到鞋孔即贴合 |
| 实时预览 | 颜色 / 挂件改变秒级反馈 |
| 轻量前端 | 单页项目，纯前端实现 |

## 一句话总结
**「先在浏览器里调一双自己的 Crocs 再去下单」——所见即所得的洞洞鞋定制器。**
