# Design Engineer Tools

## 它是什么

[designengineer.tools](https://designengineer.tools) 是 **James Warner** 维护的 **面向 Web 端「设计工程师」**（Design Engineer）的工具精选目录。

「设计工程师」 = 既做视觉设计又写前端代码的角色。这个目录按工作流分类整理了**设计 + 前端一体化**常用工具，覆盖设计 token、组件、字体、调色板、原型、动效、CSS 工具、可访问性检查等。

## 为什么用它 / 适合什么场景

- **新项目选型**：设计 + 前端工具一站式目录，不必到处搜；
- **设计工程师**：自身定位需要做工程化的设计师可作参考资源池；
- **工具审计**：周期性检查自己的工作流是否还缺关键工具。

## 关键能力

| 能力 | 说明 |
|------|------|
| 分类目录 | 按工作流（设计 / 前端 / 测试 / 部署）分门别类 |
| 持续更新 | 工具列表随生态更新 |
| 设计师 + 工程师视角 | 兼顾美学与工程实现 |
