# OpenStock（开源股票行情与公司研究工具）

## 它是什么

[OpenStock](https://github.com/Open-Dev-Society/OpenStock) 是 **Open-Dev-Society** 出品的**免费开源**股票应用，目标是替代**按月付费的专业市场平台**。

技术栈：**Next.js 15 + TypeScript + MongoDB**。

## 核心能力

| 能力 | 说明 |
|------|------|
| 实时行情 | 跟踪自选股 / 指数 / 板块的实时价格 |
| 自选股管理 | 个性化关注列表 |
| K 线图 | 多周期 K 线展示 |
| 市场热力图 | 行业 / 板块的整体涨跌分布 |
| 公司基本面 | 接入 TradingView 嵌入组件展示 |
| 财务数据 | TradingView 嵌入 |

## 为什么用它 / 适合什么场景

- **个人投资者**不想每月订阅 Bloomberg / 雪球 Pro / Wind。
- 想**自托管**（自己的数据库 + 自己的数据源）。
- 想要**实时跟踪 + 基本面**两端都覆盖的应用——OpenStock 把行情与 TradingView 的研究组件拼成一体。
- 喜欢 Next.js 生态、想自己二次开发或集成。

## 关键能力

| 维度 | 说明 |
|------|------|
| 形态 | Web 应用 |
| 技术栈 | Next.js 15 / TypeScript / MongoDB |
| 行情 | 自带实时跟踪 + 自选股 + K 线 + 热力图 |
| 基本面 | TradingView 嵌入式组件 |
| 替代 | 按月付费的市场数据平台 |
| 开源 | 全部代码可自托管、可二开 |
