# OpenDisplay

## 它是什么
自托管开源工具，把闲置的 iPhone / iPad 变成 Mac 的第二 / 第三块扩展屏，定位为 Apple Sidecar、Duet Display、Luna Display 的免费替代。

## 为什么用它 / 适合什么场景
- 抽屉里躺着闲置的 iPad，想榨干它做副屏但不想付订阅。
- 需要自托管 / 数据不出本地，对第三方屏幕镜像服务的隐私顾虑。
- 临时差旅 / 调试环境，没有额外显示器时的应急副屏方案。

## 关键能力
| 能力 | 说明 |
|------|------|
| 多端复用 | iPhone / iPad 等 iOS 设备秒变 Mac 副屏 |
| 自托管 | 服务端跑在本地，屏幕流数据不出内网 |
| 零订阅 | 替代 Sidecar / Duet / Luna Display 的付费模式 |
