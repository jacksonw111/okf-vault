# dialkit

## 它是什么

[dialkit](https://dialkit.dev) 是面向**编辑器 / playground 类应用**的 UI 套件：sliders、color pickers、springs、timeline 等「Figma-like」高频组件预先封装好，**拷贝即用**，免去从零设计 + 实现。

定位：

- **编辑器场景特化**：不是通用组件库，而是把「做设计 / 编辑工具时反复要画的那几样」打包好。
- **拿来即用**：跳颜色、跳排版的坑，把精力集中在产品本身上。

## 为什么用它 / 适合什么场景

- 正在搭 Figma-like 编辑器、设计工具、配置 playground，需要 sliders / pickers / timeline。
- 不想每个项目都重写一遍 spring 动效、color picker 的色相 / 饱和度交互。
- 想用现成的「专业感」组件快速搭出可演示的原型。

## 关键能力

| 能力 | 说明 |
|------|------|
| Sliders | 各类滑块（数值、范围、双 thumb 等） |
| Color pickers | 色相 / 饱和度 / 透明度选择 |
| Springs | 弹性 / spring 动效 |
| Timeline | 时间轴 / 关键帧 UI |
| 编辑器就绪 | 专为「设计 / 编辑」场景设计 |
