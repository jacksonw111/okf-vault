# bloub (tranmautritam/bloub)

## 它是什么
`bloub.vercel.app` 是一个 Grok Bot 风格的吉祥物（Mascot）生成器：在浏览器里画线稿、上色、摆姿势，最后把吉祥物导出为 **SVG 动画**，可作为头像、品牌角色或轻量级动效素材直接使用。

## 为什么用它 / 适合什么场景
- 给产品 / 项目快速产出一个有辨识度的吉祥物，又不想请设计师。
- 需要 SVG 格式的动效图标（缩放不失真，可被 React / 纯 HTML / Figma 直接消费）。
- 个人创作者想给博客 / Newsletter / 社交媒体账号统一视觉角色。

## 关键能力
| 能力 | 说明 |
|------|------|
| 浏览器内绘制 + 上色 | 不依赖桌面软件，所见即所得 |
| Grok Bot 风格预设 | 默认范式偏「圆润卡通」，可二次调整 |
| SVG 动画导出 | 输出是矢量 + 动效，可直接嵌入网页或 Figma |
| 在线即开即用 | 部署在 Vercel，无需注册 |
