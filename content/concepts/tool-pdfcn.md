# pdfcn

## 它是什么

`shadcn-labs/pdfcn` 是 shadcn 团队（同一伙出 shadcn/ui）推出的 **React PDF 组件库**，口号「PDF generation as easy as copy-paste」：
- 基于两个渲染引擎 **Takumi** + **Forme**
- 走 shadcn 一贯的复制粘贴模式：组件装进项目，**代码归你所有、零锁定**
- 表格 / 表单 / 图表 / 发票 / 报表等常见文档结构**现成组件**
- **TypeScript 类型齐全**
- 支持**共享主题**（shadcn 主题可直接套用）

## 为什么用它 / 适合什么场景

- React 项目里要生成 PDF（发票、报表、合同、证书、收据）。
- 不想被某个 PDF 库绑架（react-pdf / jsPDF 等要么 API 繁琐要么输出丑）。
- 想要 shadcn 一致的开发体验（TSX、组件组合、主题系统）。
- 想要**可复制可改造**的源码，不依赖第三方二进制运行时。

## 关键能力

| 能力 | 说明 |
|------|------|
| Takumi + Forme 双引擎 | 灵活选择渲染方式 |
| 复制粘贴模式 | 代码归你，可任意改 |
| 文档结构组件 | 表格 / 表单 / 图表 / 发票 / 报表 |
| TypeScript | 类型完整 |
| 共享主题 | 直接套 shadcn 主题 |
| 零锁定 | 没有运行时依赖，可完全 fork |
