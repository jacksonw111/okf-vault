# Markify

## 它是什么

**Markify** 是 [spaquet](https://github.com/spaquet) 维护的 macOS 原生 Markdown 编辑器。它的差异化点是**单一文档的"渲染 / 源码"切换**——按 `⌘/` 在渲染视图和 Markdown 源码视图之间切换，**光标位置与滚动位置保留**，从而避免传统"左右分屏对照预览"占用屏幕宽度。

## 为什么用它 / 适合什么场景

- 不喜欢左右分屏对照 Markdown 预览（吃宽度、对小屏 macOS 特别不友好）。
- 经常在写的同时切回源码调整格式，希望切换时**光标不跳回顶部**。
- 偏好 macOS 原生体验的 Markdown 编辑器。

## 关键能力

| 能力 | 说明 |
|------|------|
| 平台 | macOS |
| 视图切换 | `⌘/` 在渲染 / 源码之间切换 |
| 状态保留 | 切换后光标位置、滚动位置保留 |
| 预览方式 | 单窗口切换（非左右分屏） |
