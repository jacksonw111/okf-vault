# aicss.dev

## 它是什么
`aicss.dev` 是一个面向**设计工程师（design engineers）**的资源站，收录「用纯 CSS 实现 AI 界面效果」的实例、技巧与参考代码。受众是想搭 AI 产品界面、又偏好纯 CSS 而非 JS 重方案的工程师。

## 为什么用它 / 适合什么场景
- 搭 AI 对话 / Agent / 工具类界面时，需要「呼吸感 / 渐变流光 / 气泡动效」等视觉元素但不想堆 JS。
- 想要直接 copy-paste 的纯 CSS 片段：聊天气泡、loading 状态、流式光标、消息渐显等。
- 学习参考：把零散 CSS 技巧集中起来，便于团队内做样式规范沉淀。

## 关键能力
| 能力 | 说明 |
|------|------|
| AI 界面专题 | 聚焦 AI 产品的视觉模式，不是泛前端资源站 |
| 纯 CSS 优先 | 不依赖额外 JS 库，开箱即用 |
| 案例 + 代码 | 直接看效果再抄实现 |
| 设计工程师视角 | 同时服务设计与工程两类读者 |
