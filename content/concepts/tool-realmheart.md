# Realmheart

## 它是什么
[kzahed610/Realmheart](https://github.com/kzahed610/Realmheart) 是**用 C++ + GTK 4 写的平铺桌面 Shell**，把通常需要凑齐的多个独立程序塞进同一个 shell：

- 状态栏
- 启动器
- 通知
- 壁纸引擎
- 电源菜单

整套**外观参照动画《The Beginning After the End》**（TBATE）风格做——这是该项目的核心差异化：把「功能齐全的平铺 Shell」与「特定动画美学」绑在一起。

## 为什么用它 / 适合什么场景
- Linux 用户想要一个**开箱即用**的平铺桌面环境（不用 Hyprland + Waybar + Rofi + 各路小工具凑齐）；
- 《The Beginning After the End》动画 / 轻小说粉丝想**整套桌面视觉统一**到该 IP；
- 喜欢 GTK 4 / C++ 实现的轻量 shell，不想跑完整 GNOME / KDE；
- 想体验一个**审美驱动**的开源平铺 Shell。

## 关键能力
| 能力 | 说明 |
|------|------|
| 一体 Shell | 状态栏 / 启动器 / 通知 / 壁纸 / 电源菜单合一 |
| 实现栈 | C++ + GTK 4 |
| 平铺支持 | 内建平铺窗口管理 |
| 视觉风格 | 《The Beginning After the End》动画主题 |
| 轻量 | 不依赖完整桌面环境 |
| 主题化 | 围绕特定 IP 美学展开统一视觉 |
