# Inspora

## 它是什么

一个**现代产品 UI 设计灵感站**：聚合当前主流产品的界面截图与设计细节，供设计师 / 前端在动手前浏览参考。定位类似 Dribbble / Mobbin，但更聚焦「**现代产品 UI 实战参考**」。

## 为什么用它 / 适合什么场景

- 启动新产品 / 重设计前想看看"现在的同类产品长什么样"。
- 找不到合适的设计参考、想一站式浏览多家产品的 UI 截图。
- 写自家 DESIGN.md 时需要真实样本作为锚点。

## 关键能力

| 能力 | 说明 |
|------|------|
| 内容形态 | 产品 UI 截图 / 设计细节 |
| 定位 | 现代产品 UI 参考 |
| 适用对象 | 设计师 / 前端 / 写 DESIGN.md 的人 |
