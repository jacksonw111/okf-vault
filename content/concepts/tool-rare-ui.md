# Rare UI

## 它是什么
免费开源的 React 组件库。每个组件都做了精细的视觉打磨且风格独特，不走 Material / shadcn 那种"通用简洁"路线，适合产品里"想要点不一样"的场景。

## 关键能力
| 能力 | 说明 |
|------|------|
| 免费 + 开源 | 公开仓库免费可用 |
| shadcn CLI 集成 | 一行命令复制组件到自己项目 |
| 自有代码 | 复制后代码属于你，可改可改 |
| 风格独特 | 不走通用 Material 模板 |

## 适用场景
- 想要差异化 UI 的 SaaS / 工具产品
- 不想从零设计组件库的独立开发者
- 想在 shadcn 默认风格之外补充"另一种味道"
