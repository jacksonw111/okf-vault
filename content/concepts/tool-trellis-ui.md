# Trellis UI（框架无关的 Web 分形布局 UI 库）

## 它是什么

[Trellis UI](https://trellisui.com/) 是 DanFessler 出品的**框架无关（framework-agnostic）Web UI 组件库**，专精于**分形布局（fractal layouts）**——把「整体与局部按同一规则递归排版」的页面结构。

「分形布局」核心思路：每个布局单元（卡片 / 面板 / 网格）内部仍然按与外层相同的比例与节奏排版，让信息密度高却不失秩序。

## 为什么用它 / 适合什么场景

- 信息密度高的**仪表盘 / 控制台 / 后台管理类**页面——既要把大量信息塞进屏幕，又不让用户觉得拥挤。
- 想要**「一以贯之」的视觉节奏**：每个组件放大缩小后视觉密度感觉一样。
- 不被某个前端框架绑定：团队用 React / Vue / Svelte / Solid 都能装。
- 想给现有应用**引入分形栅格体系**而不重写整个 UI。

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | Web UI 组件库 |
| 框架支持 | 框架无关（React / Vue / Svelte / Solid 等都可接入） |
| 核心抽象 | 分形布局（fractal layouts） |
| 适用场景 | 仪表盘 / 数据密集型后台 / 信息架构 |
| 出品 | DanFessler |
