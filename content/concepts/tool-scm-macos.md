# SCM（macOS 本地视觉媒体语义搜索）

## 它是什么

[SCM](https://github.com/allenv0/SCM) 是 **allenv0** 开源的 **macOS 专用 Electron 应用**，用 **本地视觉模型** 给指定文件夹里的 **照片和视频** 建索引——媒体不离开本机，模型权重下载一次后全程离线。

定位是「**帧级语义搜索**」：不是简单的文件名 / EXIF 检索，而是「这张照片里有什么」「这段视频的第几分几秒是什么画面」的向量化语义查询。

## 为什么用它 / 适合什么场景

- **媒体不出本地**：照片 / 视频是隐私敏感内容，本地索引是关键
- **模型权重一次性下载后全程离线**：不依赖云 API
- **macOS 原生体验**：Electron 打包，开箱即用
- **设计 / 摄影 / 视频剪辑从业者**：本地素材库越来越大后，文件名检索失效，语义搜索能找回

## 关键能力

| 能力 | 说明 |
|------|------|
| 平台 | macOS 专用 |
| 形态 | Electron 应用 |
| 索引 | 本地视觉模型向量化 |
| 离线 | 模型权重一次下载，全离线工作 |
| 范围 | 任意文件夹下的照片 + 视频 |
| 粒度 | 拆到帧级 |
