# ai_travel_agent（RajveerSingh-24/ai_travel_agent）

## 它是什么
[`RajveerSingh-24/ai_travel_agent`](https://github.com/RajveerSingh-24/ai_travel_agent) 是一个**对话式** AI 旅行规划代理：把通常要跨平台拼凑的「日期 + 预算 + 地点 + 偏好」等约束收拢到一个对话流程里，自动解析需求、补齐信息、搜索机票酒店，并在「下单前」强制要求人工确认，避免 AI 自主扣款。

## 为什么用它 / 适合什么场景
- 跨 Expedia / Booking / Skyscanner / 各航司官网拼凑太累，想让 AI 把前置搜索跑完。
- 想要一个不会「自动下单」的安全旅行规划助手。
- 反复规划同类出差行程，需要可复用模板。

## 关键能力
| 能力 | 说明 |
|------|------|
| 多约束对话输入 | 日期 / 预算 / 地点 / 偏好一次性给齐 |
| 主动补齐信息 | 模糊需求会主动反问，不靠用户填表 |
| 多源搜索 | 跨平台聚合机票 / 酒店候选 |
| 人工确认机制 | 下单 / 预订前必须显式确认 |
