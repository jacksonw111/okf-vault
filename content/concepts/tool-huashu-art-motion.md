# Huashu Art Motion（话术动效 Skill）

## 它是什么

**Huashu Art Motion**（花数话术动效）是 alchaincyf 开源的 Claude Code / Codex / Gemini CLI 等编码 Agent 可加载的 Skill——把「**一段话 + 视觉动效**」的短视频生成流程固化为可复用的工作流，按 Skill 模板一键出可发布的社交媒体短片。

## 为什么用它 / 适合什么场景

- **社媒短视频量产**：教程 / 引流 / 引战 / 鸡汤类话术动效一次输入、批量出片
- **Skill 化复用**：写一次 Skill，Claude Code 等 Agent 可反复调用；不再每次从零 prompt
- **与 Claude Code 生态兼容**：作为 Skill 仓库，按 SKILL.md 规范加载

## 关键能力

| 能力 | 说明 |
|------|------|
| 模板化话术 | 模板化文案 + 节奏 + 视觉动效 |
| 多 Agent 兼容 | Claude Code / Codex / Gemini CLI |
| 可二次编辑 | 输出工程文件可继续调整 |
| 短视频输出 | MP4 视频，可直接发抖音 / 视频号 / X |
