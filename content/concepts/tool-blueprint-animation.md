# blueprint-animation（UX 决策可动画化讲解）

## 它是什么

[blueprint-animation](https://github.com/moguzbulbul/blueprint-animation) 是 moguzbulbul 出品的 **Claude Skill**：把 UX 设计决策**在页面上一帧一帧动画化地讲出来**——给设计稿加上会动的「说明层」，让评审 / 用户一眼看明白「为什么这样设计」。

## 为什么用它 / 适合什么场景

- 想做**会动的设计评审 / 演示**：让决策过程可视化，而不是静态截图。
- 想让用户在产品里「**看懂设计师为什么这么选**」（如 hero 区域、布局、交互流程）。
- 已在用 Claude / Claude Code，希望快速生成 UX 解释动画。
- 设计 / 前端团队需要更直观的设计 rationale 沟通工具。
