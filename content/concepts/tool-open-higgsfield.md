# Open Higgsfield

## 它是什么
[wide-trace/open-higgsfield](https://github.com/wide-trace/open-higgsfield) 是**把图像生成 + 视频生成统一进一个免费开源 Web 工作室**的工具，定位为商业版 **Higgsfield AI** 的开源替代。

- **40 个模型集成**：12 个图像模型 + 28 个视频模型；
- **单提示词栏**：跨模型共享 prompt 入口；
- **每模型独立设置项**：保留各自模型的参数面板（步数、CFG、宽高、风格等）；
- **历史画廊**：所有生成结果都进统一画廊，方便回看、对照、复用。

## 为什么用它 / 适合什么场景
- 想用一个工作台**跨图像 / 视频模型**反复试效果，不想切 10 个不同网站；
- 不想订阅 Higgsfield AI 之类的付费服务——开源版免费、模型自选；
- 需要**历史画廊**做对照与素材复用；
- 团队 / 个人用同一套 prompt 调多个模型，便于横向比较输出质量。
