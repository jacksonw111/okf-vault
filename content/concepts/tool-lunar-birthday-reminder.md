# 忆辰 · 阴历生日提醒 (programer-man/lunar-birthday-reminder)

## 它是什么
`programer-man/lunar-birthday-reminder` 是一个**以阴历生日为基准**的生日提醒 App，针对中国 / 东亚常见的「过阴历生日」习惯做专门支持：提前 1~7 天的预告通知 + 到点反复提醒均可独立设置，避免只记阳历而漏掉亲友真正的阴历生日。

## 为什么用它 / 适合什么场景
- 家中长辈 / 亲友按阴历过生日，但你的手机日历只支持阳历，提醒会逐年漂移。
- 想精细控制提醒节奏：提前几天就开始预警、当天反复提醒直到点过。
- 想给「农历 / 阴历」类应用找一个轻量、可自托管或本地安装的方案。

## 关键能力
| 能力 | 说明 |
|------|------|
| 阴历基准 | 围绕农历日期计算，不会因阳历漂移而错过 |
| 提前 1~7 天预告 | 可独立设置提前提醒窗口 |
| 到点反复通知 | 当天可设多次重复提醒 |
| 独立可调 | 预告与到点提醒是分开的两组设置 |
