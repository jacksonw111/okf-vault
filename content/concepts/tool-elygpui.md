# Elygpui

## 它是什么

[Elygpui](https://elygpui.com) 是 **ZacharyZhang** 维护的 **GPUI 组件市场**——收录 **1272 个 GPUI 组件**，覆盖表格 / 按钮 / 表单 / 图表 / 布局等典型 UI 场景，为「Rust 原生 GPU 加速桌面应用」开发者提供现成积木。

## 为什么用它 / 适合什么场景

- **GPUI 起步太陡**：直接基于 GPUI 写桌面应用组件量大；Elygpui 把现成组件准备好。
- **生态先行**：作者希望该项目能让 GPUI 成为新一代主流桌面 UI 框架。
- **典型场景**：金融终端 / 监控大屏 / 表格密集工具 / Coding Agent 控制平面。

## 关键能力

| 能力 | 说明 |
|------|------|
| 组件数 | 1272 |
| 底层框架 | GPUI |
| 场景覆盖 | 表格 / 按钮 / 表单 / 图表 / 布局 |
