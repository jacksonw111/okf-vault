# delphi.tools

## 它是什么

[delphi.tools](https://delphi.tools) 是由**独立设计师**开发的**开源 indie tools 资源站**，当前版本 **2.1.0**：

- 更全面的工具收录
- 有意思的**原创插画贴纸**
- 面向独立开发者 / 设计师

## 为什么用它 / 适合什么场景

- 独立开发者找好用的小工具。
- 喜欢 indie 风格的设计师寻找灵感 / 视觉资源。
- 想看独立设计师的原创插画 / 贴纸风格。
