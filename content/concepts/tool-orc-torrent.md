# Orc-Torrent (The-animus-project)

## 它是什么

[Orc-Torrent](https://github.com/The-animus-project/Orc-Torrent) 是一个**跨 Windows、macOS、Linux 和 Android 的下载客户端**，把**本机 Rust 下载引擎**和**面向 VPN 的隐私保护**封装进一套统一界面。

![Orc-Torrent 截图](https://pbs.twimg.com/media/HOxg-KoaAAAwGSz.jpg)

## 为什么用它 / 适合什么场景

- **真跨平台**：四端（Windows / macOS / Linux / Android）共用同一界面与逻辑。
- **Rust 内核**：本机 Rust 下载引擎，性能与安全兼顾。
- **VPN 隐私保护**：内置对 VPN 的友好支持。
- **统一界面**：不用为不同平台各学一个客户端。

## 关键能力

| 能力 | 说明 |
|------|------|
| 跨平台 | Windows / macOS / Linux / Android |
| Rust 内核 | 本机下载引擎，非 Electron |
| VPN 友好 | 面向 VPN 使用场景优化 |
| 统一界面 | 四端同一套 UI 体验 |
| 下载加速 | Rust 引擎原生高性能 |
