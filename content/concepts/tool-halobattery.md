# HaloBattery

## 它是什么

[HaloBattery](https://github.com/HeyOkay/HaloBattery) 是 **HeyOkay** 出品的 Windows 工具——把无线鼠标 / 耳机 / 手柄等设备的电量读数**统一搬到系统托盘**，每台设备一个图标，无需安装任何厂商工具。

## 关键能力

| 能力 | 说明 |
|------|------|
| 统一显示 | 蓝牙 / 2.4G 设备的电量在 Windows 托盘集中展示 |
| 无需厂商软件 | 不依赖罗技 G Hub、雷蛇 Synapse 等 |
| 一图标一设备 | 视觉清晰 |
| Windows 平台 | 专门为 Windows 设计 |

## 适合场景

- 桌面摆了一堆无线外设的人（鼠标 + 键盘 + 耳机 + 手柄）
- 不想装一堆厂商驱动 / 后台工具
- 想在系统托盘一眼看到所有设备剩余电量
