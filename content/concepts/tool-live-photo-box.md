# Live Photo Box（iPhone 实况照片查看与修复）

## 它是什么
`LengxiQwQ/live-photo-box` 是 Windows 桌面端的小工具，专门解决跨平台转移 iPhone **Live Photo（实况照片）** 后常见的几个问题：

| 问题 | 表现 |
|------|------|
| 跨设备传输丢失 | 静态图 + 短视频无法配对回放 |
| 配对损坏 | 视频/图像元数据错位 |
| 画面拉伸 | 长宽比没正确还原 |

Live Photo Box 把查看 / 修复 / 重新打包 集中在一个桌面 UI。

## 为什么用它 / 适合什么场景
- 把 Live Photo 从 iPhone 拷到 Windows 后发现变成了"不会动的 JPEG"或者"动不了的 MP4"，这个工具帮你**重新封装回 Live Photo**。
- 想批量管理 iPhone 实况照片档案。
- 适合：iPhone 用户换 Windows 工作机 / 想从云盘/QQ/微信回传 Live Photo 的场景。
- 对比 HEIC/JPEG 通用工具：本工具专门处理 JPEG + HEIC + MOV 的**配对关系**，不是单纯格式转换。

## 关键能力
| 能力 | 说明 |
|------|------|
| 查看 | Windows 上直接回放 Live Photo |
| 修复 | 重新封包，恢复正确动效 |
| 重新配对 | 把错位的图/视频绑回原对 |
| 修正拉伸 | 修正常见长宽比错误 |
