# life-ipo（衡 · 人生 IPO）

## 它是什么
[gtlhuyidan-sketch/life-ipo](https://github.com/gtlhuyidan-sketch/life-ipo)（衡 · 人生 IPO）**建立统一的个人数据操作系统**，把传统记账软件回答不了的问题补全——

- 传统记账：只回答「**钱去了哪里**」；
- 衡 · 人生 IPO：把 **财务 / 健康 / 知识 / 人脉 / AI 决策 / 团队执行**放进同一套**可度量、可规划、可复盘**的闭环；
- 终极问题：**「我拥有什么 / 哪些资产在增值 / 下一阶段最值得投入什么」**。

## 为什么用它 / 适合什么场景
- 觉得记账软件视角太窄——只想看支出 / 收入，不解决"人生投入产出"问题；
- 想把多个生活维度（钱、健康、人脉、知识）统一度量；
- 想知道「下一阶段该把时间 / 钱 / 注意力投到哪里最划算」；
- 想给个人决策（"要不要学 X / 要不要换工作 / 要不要投 Y"）一个量化基础。

## 关键能力
| 能力 | 说明 |
|------|------|
| 多维度数据 | 财务 / 健康 / 知识 / 人脉 / 决策 / 团队 |
| 统一度量 | 一套指标语言跨域对比 |
| 可规划 | 不只回看历史，可做规划 |
| 可复盘 | 阶段回顾 + 投入产出比 |
| 闭环 | 数据 → 决策 → 行动 → 反馈 |
| 个人 IPO 视角 | 把人生当一家公司来运营 |
