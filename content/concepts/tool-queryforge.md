# QueryForge

把自然语言转换为可审计 SQL 的数据查询工具，通过语义层与策略治理约束生成结果。

## 适用场景

- 需要查询必须经过统一语义层，避免模型自行猜测业务定义的场景。

## 关键能力

| 能力 | 说明 |
|------|------|
| 语义约束 | 查询必须经过统一语义层，避免模型自行猜测业务定义。 |
| 策略治理 | 对生成 SQL 应用明确策略和边界。 |
| 可审计 | 让生成 SQL 像应用代码一样可检查、可管理。 |
