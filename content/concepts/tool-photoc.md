# Photoc（终端拍摄整理工具）

## 它是什么

[Photoc](https://github.com/ahmetomerv/photoc) 是 **ahmetomerv** 开源的 **终端拍摄整理工具**——在终端里完成一次拍摄的整理工作。

具体覆盖：
- **汇总**：把分散在各处的原始素材归一
- **读元数据**：从 EXIF 提取相机 / 镜头 / 时间 / GPS
- **挑糊片和重复**：自动 / 半自动挑出模糊 / 重复照片
- **改名归类**：按规则重命名 / 分文件夹
- **联系表**：生成 contact sheet
- **压缩副本**：批量压缩副本
- **GPS 抹除**：分享前抹掉 EXIF 里的 GPS

## 为什么用它 / 适合什么场景

- **摄影 / 旅行拍摄**：每次出门都几百张，统一整理
- **隐私敏感**：分享前抹掉 GPS 防止位置泄漏
- **极简 / 终端党**：不想开 Lightroom / Bridge
- **批处理**：批量挑糊片 + 改名的活儿 GUI 工具繁琐
