# dsh-market (dsh-market/dsh-market)

## 它是什么
`dsh-market/dsh-market` 是 **DeepSeek Harness (DSH) 的官方插件市场**：在 DSH 设置里打开 Plugin Market 即可使用，收录目录里聚合了 **800 多个社区插件**，支持分类筛选、按星数 / 新旧排序，**说明文案双语跟随界面语言**。

## 为什么用它 / 适合什么场景
- 想给 DSH 装新能力但又不想手动 git clone 一堆仓库。
- 选插件时希望按「社区评价 + 时间」筛选，避免踩坑老旧插件。
- 英文 / 中文用户都能无缝使用同一份市场。

## 关键能力
| 能力 | 说明 |
|------|------|
| DSH 内置 | 在设置里打开 Plugin Market 即用 |
| 800+ 插件 | 收录目录覆盖大部分社区作品 |
| 分类筛选 | 按插件类别快速定位 |
| 星数 / 新旧排序 | 用社区评价过滤冷门 / 过期插件 |
| 双语说明 | 中英说明跟随界面语言切换 |
