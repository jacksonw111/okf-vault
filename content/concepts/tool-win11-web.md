# Win11 Web

## 它是什么

Win11 Web 是单 HTML 文件浏览器内复刻 Windows 11 桌面环境的项目，与 macOS Web 同属「无构建 / 无框架 / 单文件」风格。打开 HTML 即可看到开始菜单、任务栏、窗口管理、通知中心等核心 Win11 界面交互。

## 为什么用它 / 适合什么场景

- 演示 / 教学 Win11 桌面交互，免装虚拟机。
- 给非 Windows 用户展示 Win11 用起来什么样。
- 研究「单文件复刻桌面 OS」的设计参考。

## 关键能力

| 能力 | 说明 |
|------|------|
| 单文件 HTML | 下载即双击运行 |
| 无构建无框架 | 不依赖 React / Vue / 构建工具 |
| 桌面环境复刻 | 开始菜单、任务栏、窗口、通知中心 |
| 跨浏览器 | 现代浏览器即可运行 |
