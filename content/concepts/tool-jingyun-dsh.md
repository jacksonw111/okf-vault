# jingyun-dsh（DeepSeek Harness 商业闭环扩展）

## 它是什么

[jingyunstudio/jingyun-dsh](https://github.com/jingyunstudio/jingyun-dsh) 是给 **DeepSeek Harness (DSH)** 加的**商业化扩展**：补齐会员体系、支付、算力调度与应用市场，让 AI 开发者能把**智能体、技能、工作流**快速封装成可售卖的独立桌面产品。

## 为什么用它 / 适合什么场景

- 在 DSH 上做了技能 / agent / 工作流，想直接面向终端用户卖。
- 不想自己搭会员系统、订单、计费、付费下载整套基础设施。
- 想做一个**桌面端 AI 应用商店**而不是网页 SaaS。

## 关键能力

| 能力 | 说明 |
|------|------|
| 会员体系 | 等级 / 权益 / 续费 |
| 支付 | 内置支付通道 |
| 算力调度 | 给售卖的应用分配推理资源 |
| 应用市场 | 桌面端商店，列出可售卖应用 |
| 封装工具 | 把 agent / 技能 / 工作流打包成独立产品 |
