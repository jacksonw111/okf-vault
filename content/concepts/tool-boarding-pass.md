# boarding-pass

## 它是什么

[jal-co/boarding-pass](https://github.com/jal-co/boarding-pass) 是一套**开源的登机牌风格 React 组件**，用于：

- 航班行程展示
- 票务凭证
- 活动入场券
- 任何需要「票面信息」视觉风格的场景

## 为什么用它 / 适合什么场景

- 做票务 / 出行 / 活动类 App / 网站需要登机牌视觉。
- 想给 UI 增加「**票 / 凭证**」的趣味视觉元素。
- 学习 React 组件的视觉风格设计。

## 关键能力

| 能力 | 说明 |
|------|------|
| 登机牌视觉 | 锯齿边 + 票面 + 二维码 + 信息分层 |
| React 组件 | 即装即用 |
| 可定制 | 改字段 / 改主题 |
| 开源 | 代码可改 |
| 演示站 | <https://boarding-pass-eosin.vercel.app/> |
