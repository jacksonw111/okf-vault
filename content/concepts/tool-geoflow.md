# GEOFlow 3.0

## 它是什么

[yaojingang/GEOFlow](https://github.com/yaojingang/GEOFlow) **3.0** 围绕 **GEO（Generative Engine Optimization，生成式引擎优化）**的**统一后台**，整合：

| 模块 | 说明 |
|------|------|
| **AI 知识库** | 给 GEO 用的知识存储 |
| **AI 内容生产** | 自动生成 GEO 友好内容 |
| **AI 质检** | 检查内容 GEO 适配度 |
| **多站点分发** | 一处生产，多处发布 |
| **更新工具** | 独立更新工具，支持备份 / 回滚 |

## 为什么用它 / 适合什么场景

- 想做 GEO（让 AI 搜索推荐自家品牌 / 内容）。
- 想统一管理多个站点的 GEO 内容。
- 需要可回滚的版本控制（重要字段误改能秒回）。

## 关键能力

| 能力 | 说明 |
|------|------|
| GEO 一体化 | 知识库 + 内容 + 质检 + 分发 |
| 多站点分发 | 一处生产，多处发布 |
| 备份 / 回滚 | 独立更新工具 |
| AI 质检 | 内容 GEO 适配度自动检查 |
| 自托管 | 数据自控 |
