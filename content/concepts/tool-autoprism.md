# AutoPrism

[AutoPrism](https://github.com/CharlesJ-ABu/AutoPrism) 把汽车 / 投研方向的**全球新闻、供应链异动、竞品参数**交给 AI 降噪整理,再以**3D 地球 + 2D 战术地图**形式实时展示。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多源新闻 | 抓取全球汽车 / 投研相关公开新闻 |
| AI 降噪 | 自动过滤无关信息,保留关键事件 |
| 异动归因 | 标注事件与供应链 / 竞品的因果关系 |
| 3D 地球视图 | 在地图上定位事件,看地域分布 |
| 2D 战术地图 | 行业层 / 厂商层 / 区域层多层级展示 |
| 实时刷新 | 数据流持续更新 |

## 适合什么场景

- **汽车行业研究员 / 投资人**:动态跟踪车企、供应链、市场异动。
- **企业战略部门**:监控关键竞品的新闻动向,做「情报面板」。
- **关注全球供应链**:从电池 / 芯片 / 原材料层面看事件影响。
