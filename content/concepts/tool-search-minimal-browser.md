# Search（macOS 极简浏览器）

## 它是什么

[Search](https://github.com/driceroland/Search) 是一个 macOS 极简浏览器：把界面砍到只剩一排标签页 + 一个网页，装出来仅 3 MB。没有工具栏、起始页、推荐侧栏，也不需要登录账号。

## 关键能力

| 能力 | 说明 |
|------|------|
| 极简界面 | 只有一排标签页 + 网页本身 |
| 体积小 | 安装包仅 3 MB |
| 标签位置 | 标签栏可切到顶部或左侧 |
| 无账号 | 不需要登录 |
| 无起始页 | 不强加任何「门户」内容 |

## 适用场景

- macOS 用户想摆脱「内容门户化」浏览器
- 想要轻量、不带任何冗余 UI 的浏览工具
- 想要「装完就能用」且没有推荐流 / 账号体系的浏览器
