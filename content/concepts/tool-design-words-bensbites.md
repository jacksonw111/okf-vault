# design-words

## 它是什么

[bensbites/design-words](https://bensbites.com/design-words/) 是 **bentossell 维护的设计词典**：点选风格即可预览，附**可直接复制给 Agent 的 prompt**——把「我想做这种风格」翻译成 Agent 听得懂的语言。

## 核心特性

| 特性 | 说明 |
|------|------|
| 风格词典 | 选风格看预览 |
| Agent prompt | 一键复制 |
| 持续完善 | bentossell 在做 |
| 跨风格 | 覆盖多类设计风格 |

## 为什么用它 / 适合什么场景
- 想给 AI Agent 描述「这种风格」。
- 找设计词汇的统一说法。
- 与 Agent 协作时减少反复「再浓一点」沟通。

## 关键能力

| 能力 | 说明 |
|------|------|
| 选风格 | 多风格可选 |
| 即看即用 | 预览 + prompt |
| Agent 友好 | prompt 模板 |
| 持续更新 | 作者维护中 |
