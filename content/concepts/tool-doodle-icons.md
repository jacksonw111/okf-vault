# doodle-icons

## 它是什么

[oreo-design/doodle-icons](https://github.com/oreo-design/doodle-icons) 是一套**手绘风 SVG 图标库**：152 个图标，每个都先以**逐笔自绘**的方式呈现绘制过程，再用「**沸腾线**」动画让线条持续轻微抖动，给 UI 增加手作温度。配套发布 **React 组件**和 **AI agent skill**，可直接装入项目或喂给 Claude Code / Codex。

## 为什么用它 / 适合什么场景

- 想要一种「不像 icon font 那么冰冷」的手作 UI 风格。
- 在做品牌官网 / SaaS 着陆页 / 儿童 / 教育 / 文化类产品。
- 想给 AI 编码 agent 喂一套现成的视觉资源 skill。

## 关键能力

| 能力 | 说明 |
|------|------|
| 152 图标 | 覆盖常用动作 / 类别 / 物体 |
| 手绘自绘 | 每个图标都带\"逐笔画出\"的动画 |
| 沸腾线 | 线条持续轻微抖动，有手作感 |
| React 组件 | 即装即用，TypeScript 支持 |
| AI agent skill | 配套 skill 格式，Claude Code / Codex 可直接调用 |
