# Focenda（macOS 专注与任务一体客户端）

## 它是什么

Mac 上管专注、任务和日历往往要同时开两三个软件。Focenda 把**计时器、看板、日程、速记、提醒**收进一个原生客户端，数据全在本地跑。

视频：<https://video.twimg.com/tweet_video/HRRXgQ-aEAEuRN4.mp4>

## 为什么用它 / 适合什么场景

- 番茄钟一个 App、待办一个 App、日历又一个，切换成本高且数据割裂。
- 不希望任务与日程同步到第三方云端。

## 关键能力

| 能力 | 说明 |
|------|------|
| 计时器 | 专注计时 / 番茄钟 |
| 看板 | 任务以看板形式组织 |
| 日程 | 内置日历视图 |
| 速记 | 随手记录，不必切到笔记应用 |
| 提醒 | 到点提醒 |
| 运行方式 | macOS 原生客户端，全部本地运行 |
