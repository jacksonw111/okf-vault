# MujicaUI

## 它是什么

[MujicaUI](https://github.com/ZacharyZhang-NY/MujicaUI) 是 **ZacharyZhang** 基于 **MyGo** 框架做的**约 500 个小组件**的组件库——给 MyGo 生态补一个「**够用就行**」的组件仓。

## 关键能力

| 能力 | 说明 |
|------|------|
| 规模 | ~500 组件 |
| 宿主 | MyGo（Go Web 组件库） |
| 形态 | 小组件为主，组合灵活 |
| 预览 | <https://mujicaui.zacharyzhang.com> |

## 适合场景

- 用 MyGo 搭 Go 服务但缺现成组件
- 想找「覆盖广 + 单件轻」的 Go UI 仓
- 偏好中文 / 东亚开发者作品
