# Doubao Work 指南

## 它是什么

`Doubao Work` 是字节跳动面向多 Agent 协同场景的工作台产品（依托豆包大模型），功能多但缺乏系统化的中文上手路径。`DoubaoWorkGuide` 把从安装登录到多 Agent 工作流的使用方法整理成可复用教程，并以 31 个真实任务为示范，展示如何把材料、要求、工具组织成可交付的成果。

## 适用场景

- 第一次使用 Doubao Work 不知如何入手
- 想找"任务怎么拆 / Agent 怎么编排"的可复用范例
- 想对比 Doubao Work 与其他多 Agent 工作台的工作流差异

## 内容要点

- 基础：安装 / 登录 / 单 Agent 跑通最小任务
- 进阶：多 Agent 编排、上下文共享、工具调用链
- 实战：31 个真实任务拆解（材料 → 要求 → 工具 → 交付物）
