# awesome-llm-apps（118k+ Star AI Agent 与 RAG 应用合集）

## 它是什么

> 118k+ Star 的合集——属于「看过 awesome 列表就知道」级别。

## 为什么用它 / 适合什么场景

- 想搭一个 RAG / Agent demo 但不想从零写——**clone 下来改改就能用**。
