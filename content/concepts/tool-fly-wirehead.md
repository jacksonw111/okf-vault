# fly-wirehead（果蝇全脑连接组仿真）

## 它是什么

[mattyhempstead/fly-wirehead](https://github.com/mattyhempstead/fly-wirehead) 是个**果蝇全脑连接组（connectome）仿真**项目：把**真实昆虫短视频**作为视觉刺激，每播一帧就驱动**16 万多神经元 / 两千多万个连接**的神经动力学 50 毫秒。**多巴胺放电率**与**全网脉冲数**实时画出来，浏览器里看一只「接线的果蝇刷手机」。

## 为什么用它 / 适合什么场景

- 神经科学 / 计算神经学：**真实 connectome 数据 + 真实视觉刺激**做研究。
- 教学演示：让学生直观感受 connectome 规模与神经活动。
- 可视化项目：神经活动 → 动作的实时映射范本。

## 关键能力

| 能力 | 说明 |
|------|------|
| 全脑连接组仿真 | 16 万神经元 / 2 千万连接 |
| 本地计算 | 全在本地算，浏览器渲染 |
| 视觉刺激输入 | 手机屏幕画面即刺激 |
| 50 毫秒步进 | 每帧视觉刺激驱动 50 ms 神经活动 |
| 神经活动实时可视化 | 多巴胺放电率 + 全网脉冲数 |
| 动作覆盖层 | 神经活动映射为果蝇动作 |
