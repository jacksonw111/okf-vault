# stonkfly

## 它是什么

[nftechie/stonkfly](https://github.com/nftechie/stonkfly) 是一个**用果蝇连接组仿真驱动加密货币交易的实验项目**：把价格画成图表喂给果蝇神经元仿真，用神经发放决定买 / 卖。

## 核心特性

| 特性 | 说明 |
|------|------|
| 果蝇连接组 | 完整神经元级仿真 |
| Coinbase 现货 | 接 Coinbase 实盘接口 |
| 神经发放决策 | 用发放频率编码买卖信号 |
| 实验性质 | 探索神经科学 × 交易 |

## 为什么用它 / 适合什么场景
- 研究神经科学 + 金融交易的交叉。
- 做教学 demo / 趣味项目。
- 探索「生物启发算法」的边界。

## 关键能力

| 能力 | 说明 |
|------|------|
| 完整连接组 | 25 万神经元级别仿真 |
| 实时价格 | Coinbase 现货接入 |
| 神经决策 | 发放信号 → 买卖 |
| 跨学科 | 神经科学 × 量化 |
