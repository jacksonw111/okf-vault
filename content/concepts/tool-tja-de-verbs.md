# tja

## 它是什么
[tja](https://github.com/progapandist/tja) 是一个**用 Go 写的终端老虎机式德语动词学习工具**。它的核心创意：德语的可分动词由**前缀 × 词干**组成，工具就用**两个转轮**分别装前缀和词干，**互相过滤**——无论怎么转，停下的组合一定是个真实存在的德语动词。

这把「过词汇表」本身做成了一个**可玩的、节奏感强的小游戏**：转动转轮 = 复习；空格键随机抽词 = 抽题；切到抽卡模式 = 自测。

## 为什么用它 / 适合什么场景
- 学德语被「可分动词前缀配词干」绕晕，需要一个**反复过组合**的工具；
- 喜欢**老虎机 / 抽卡式**节奏的学习反馈（比纯闪卡更上瘾）；
- 想要**纯终端**的轻量学习工具（不依赖 GUI、不联网）；
- 想把「德语动词支配关系 / 变位」做成可玩关卡。

## 关键能力

| 能力 | 说明 |
|------|------|
| 双转轮 | 前缀轮 × 词干轮，互相过滤 |
| 真实词保证 | 转轮组合约束在前缀—词干真存在的动词集合内 |
| 老虎机交互 | 随时停、随时转 |
| 转轮可切换 | 可单独锁定前缀或词干轮 |
| 空格抽词 | 随机抽词测试 |
| 抽卡模式 | 切换到测试自测模式 |
| 终端原生 | Go 写的 CLI，无 GUI 依赖 |
| 教育友好 | 适合课堂 / 自学 |
