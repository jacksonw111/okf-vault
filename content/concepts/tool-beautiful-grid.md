# BeautifulGrid

## 它是什么

业务系统里那种行多列多、需要虚拟滚动 / 排序 / 筛选 / 编辑 / 合计 / 行选择等多种交互的表格，常常需要自己把多个 React 表格组件拼装。`BeautifulGrid` 把这些高频需求打包成单一 React 组件，定位"快 / 全 / 好看"——大规模数据下保持流畅、覆盖常见表格交互、UI 默认不丑。

## 关键能力

| 能力 | 说明 |
|------|------|
| 大数据流畅渲染 | 面向业务系统常见"万行级"表格 |
| 全功能交互 | 排序 / 筛选 / 编辑 / 合计 / 选择 等覆盖 |
| 默认观感在线 | UI 默认样式即用，不丑 |
