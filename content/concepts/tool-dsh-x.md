# DSH-X（DeepSeek Harness Windows 图形启动器）

## 它是什么

[DSH-X](https://github.com/yyh-001/DSH-X) 是 **DeepSeek Harness 的 Windows 桌面图形启动器**：

> 给 DeepSeek Harness 做一个 Windows 图形启动器，把版本安装、启停、更新、卸载和插件开关从命令行搬到界面上。

## 为什么用它 / 适合什么场景

- 想在 Windows 上使用 DeepSeek Harness 但**不熟命令行**。
- 想要一个**统一入口**管理多版本 + 插件，避免手动改环境变量 / 路径。
- 想给团队非技术成员提供「**开箱即用**」的桌面客户端。

## 关键能力

| 能力 | 说明 |
|------|------|
| 安装 | 一键安装不同版本的 DeepSeek Harness |
| 启停 | 图形化启动 / 停止后台服务 |
| 更新 | 一键升级版本 |
| 卸载 | 清理已安装版本 |
| 插件开关 | 启用 / 禁用插件 |
