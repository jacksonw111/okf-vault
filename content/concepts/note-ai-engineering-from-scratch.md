# ai-engineering-from-scratch

## 它是什么

[ai-engineering-from-scratch](https://github.com/rohitg00/ai-engineering-from-scratch) 是 **rohitg00** 维护的开源 AI 工程课程——把从线性代数到多智能体系统的完整路径整理成 **523 节课**。

## 课程特色

| 特色 | 说明 |
|------|------|
| 节数 | 523 节（量级扎实） |
| 起点 | 线性代数（从原始数学开始） |
| 实现 | 每节课亲手实现算法（不只看 API） |
| 终点 | 多智能体系统 |
| 风格 | 不空谈、会讲内部原理 |

## 解决的问题

- 「多数人会调 API 却讲不清模型内部原理」
- AI 学习资料零散、缺系统路径
- 想从「调 API 工程师」升级到「懂内部原理的工程师」

## 适合人群

- 刚入行 AI 工程、想补数学 / 内部原理的开发者
- 想从「调 API」升级到「懂原理」的工程师
- 自学路线不清晰、需要完整路径的学习者
