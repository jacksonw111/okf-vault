# sprout（终端习惯打卡）

## 它是什么

[sprout](https://github.com/kb019/sprout) 是一个终端习惯打卡工具：敲一行命令记一笔，不必为「今天跑步了 / 看了书」再装一个要注册登录的 App。

## 关键能力

| 能力 | 说明 |
|------|------|
| 终端原生 | 敲一行命令记一笔 |
| 无注册登录 | 数据本地 |
| 极简 | 没有任何多余功能 |
| 可脚本化 | 能接进 shell / cron / dotfiles 工作流 |

## 适用场景

- 习惯简单到「几个动作计数」级别的极简用户
- 想避免在习惯 App 上注册 / 同步 / 看广告
- 想把习惯追踪接进现有终端 / dotfiles 工作流
