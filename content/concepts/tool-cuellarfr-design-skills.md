# cuellarfr / Design Skills for AI Agents

## 它是什么

[Design Skills for AI Agents](https://cuellarfr.github.io/design-skills) 是 Carlos Cuéllar 维护的设计技能合集，给 AI 编码工具注入「真实可执行的设计知识」——启发式、研究方法、系统思维与可用框架，覆盖 Claude Code / Cursor / Codex 等 40+ agent。

## 它解决的问题

AI 编码 agent 能写代码，但 UI 风格往往「AI 味」明显：配色各自发挥、间距不一致、组件选择靠模型直觉。Design Skills 把设计知识拆成可被 agent 加载的「技能」，让编码过程直接产出符合设计规范的成品。

## 关键能力

| 能力 | 说明 |
|------|------|
| 启发式规则 | 提炼自真实设计经验的可用规则 |
| 研究方法 | 用户研究 / 可用性评估 / 信息架构方法 |
| 系统思维 | 设计系统层面的统一语言 |
| 框架模板 | 配色 / 字体 / 间距 / 组件选择框架 |
| 多 agent 兼容 | 兼容 Claude Code / Cursor / Codex 等 40+ agent |

## 适合谁

- 给 Claude Code / Cursor 装设计知识，让产出不再「AI 味」
- 想要在没有设计师的情况下让 agent 输出符合规范的 UI
- 想给现有 agent 工作流加一层「设计 lint」
