# Kenote

## 它是什么
[Kenote](https://github.com/yetemgetaB/Kenote) 是 **Raycast Notes 的开源平替**——一个**轻量、极简、跨平台**的 Markdown 笔记应用。技术栈 **Tauri + React**，支持 Windows / macOS / Linux。本地存储，不上云；UI 风格**接近 Raycast**（简洁、命令面板式交互）。

差异化亮点：**所见即所得（WYSIWYG）**——输入 Markdown 格式（标题、加粗、引用、列表）时**即时渲染**，不用切来切去预览。Mac 用户即使没有买 Raycast，也能在自家机器上拿到类似的本地快速记录体验。

## 为什么用它 / 适合什么场景
- 喜欢 Raycast Notes 的体验但**只在 Mac**——Kenote 让你在 Win / Linux 也能用；
- 想要**即时渲染**的 Markdown 编辑体验（不用来回切预览）；
- 想要**Tauri + React** 写的轻量本地笔记（不上云、可读源码）；
- 想要一个**比 Obsidian 轻**的「快速 Markdown 速记」工具。

## 关键能力

| 能力 | 说明 |
|------|------|
| 跨平台 | Windows / macOS / Linux 三端 |
| Tauri 内核 | 比 Electron 更轻，原生窗口 |
| React 前端 | 熟悉的组件开发栈 |
| 本地存储 | 笔记不上云，文件在自己机器上 |
| Raycast 风格 | 命令面板、极简 UI |
| WYSIWYG | 输入 Markdown 即时渲染，免切预览 |
| 轻量 | 比 Obsidian 启动快、体积小 |
| 开源可改 | 任何 GitHub 用户都可 fork 定制 |
