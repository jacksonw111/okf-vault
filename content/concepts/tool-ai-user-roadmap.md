# AI User Roadmap

## 它是什么
一份给"AI 使用者"而非"AI 制造者"准备的入门到进阶学习路线图，整理了对应的工具、文章、课程与练习方法，目标是从零起步到能用 AI 完成真实任务。

## 为什么用它 / 适合什么场景
- 想系统学用 AI 但被海量教程淹没，需要一份"哪一步先看什么"的导航。
- 想给团队 / 家人做 AI 扫盲培训，直接用这份路线图当课程大纲。
- 与"AI Engineer Roadmap"互补：那份面向开发者，本份面向普通使用者。

## 关键能力
| 能力 | 说明 |
|------|------|
| 阶段化路径 | 入门 → 进阶 → 完成真实任务，逐级递进 |
| 资源聚合 | 每个阶段配工具 / 文章 / 课程 / 实践方法 |
| 使用者视角 | 聚焦"如何用 AI"，而非"如何造 AI 模型" |
