# inlark

## 它是什么

[inlark](https://github.com/inlark/inlark) 是 **inlark** 出品的开源邮件客户端——自己架的邮件服务器或小提供商账号，客户端要么是「Windows XP 时代样子」，要么按月收钱，要么把你的信转一圈别人家的云。inlark 直接连服务器、键盘驱动、多账号并一个收件箱。

## 关键特点

| 特点 | 说明 |
|------|------|
| 直连服务器 | 不经过第三方 |
| 多账号 | 一个收件箱统一管理 |
| 键盘驱动 | 键盘党友好 |
| 不注册 | 无需账号体系 |
| 隐私 | 不同步、不上报 |

## 适合场景

- 自建邮件服务器（Mailcow / Mailcow / Stalwart 等）的用户
- 用小提供商（如 ProtonMail / Fastmail 自托管版 / Migadu）的用户
- 想摆脱大厂邮件客户端追踪
- 喜欢键盘流操作的邮件重度用户

## 与传统邮件客户端的对比

| 客户端 | 风格 | 隐私 |
|--------|------|------|
| Outlook / Apple Mail | 现代 | 把数据回传云 |
| Thunderbird | 老派 | 中性 |
| inlark | **键盘驱动 + 极简** | **直连、不上报** |
