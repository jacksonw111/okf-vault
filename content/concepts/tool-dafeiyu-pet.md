# 大肥鱼宠物 (DeepSeek 桌宠)

## 它是什么

「大肥鱼宠物」是一款 Python + PySide6 写的透明桌面宠物，主角是 DeepSeek V4 Pro 在社区里的二创角色「鲸鱼娘·大肥鱼」。它在桌面上一只透明的小鱼形象，能走、能拖、能喂、能搭话，给 DeepSeek 粉丝一个陪伴型桌宠。

## 为什么用它 / 适合什么场景

- DeepSeek 社区粉丝想养一只透明桌宠。
- 想要非萌系 / 非猫狗 / 带点二创梗的桌面陪伴。
- 关心「开源 AI 桌宠」可改造性。

## 关键能力

| 能力 | 说明 |
|------|------|
| 透明窗口 | PySide6 实现的可拖动透明窗 |
| 走动行为 | 自主移动、响应鼠标拖拽 |
| 喂食互动 | 可与宠物做轻量交互 |
| 搭话对话 | 内置对话能力 |
| DeepSeek 二创 | 围绕 DeepSeek 社区角色 |
