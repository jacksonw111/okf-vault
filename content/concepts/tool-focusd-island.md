# FocuSD Island（Windows 透明悬浮岛工具面板）

## 它是什么
[FocuSD Island](https://github.com/zzliu93-debug/FocuSD) 是一款 Windows 本地工具面板：把屏幕顶部划分出一块 **透明悬浮岛**，随时点开就能用——把待办、笔记、剪切板历史、媒体控制、AI 编码会话状态等「日常杂事」收纳到一起。不进任务栏、不抢当前窗口焦点，主屏留出来给正经工作。

## 为什么用它 / 适合什么场景
- Windows 上缺一个像 macOS Stage Manager / iOS Dynamic Island 那样「不打扰但随时可达」的杂事面板。
- 工作流里频繁切换「记一笔待办 / 抄一段临时文本 / 切歌 / 看一眼 AI 编码进展」。
- 想把多款碎片化小工具的入口合并到一处。

## 关键能力
| 能力 | 说明 |
|------|------|
| 透明悬浮 | 屏幕顶部常驻一块透明岛，非激活时近乎隐形 |
| 待办 / 笔记 | 内置轻量记录，抬手即写 |
| 剪切板 | 留一份历史可回看 |
| 媒体控制 | 切歌 / 暂停 / 下一首 |
| AI 编程状态 | 把本地 AI 编码会话的运行情况打到面板上 |
| 不进任务栏 | 不占托盘 / 不抢焦点 |
