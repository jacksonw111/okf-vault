# logo-generator-skill

[logo-generator-skill](https://github.com/op7418/logo-generator-skill) 是为 **AI 编码 agent** 准备的 logo 生成 Skill:一次跑完即可拿到 **6 种风格变体** + 一份高端感展示页。

## 关键能力

| 能力 | 说明 |
|------|------|
| 6 种变体 | 同一关键词不同视觉风格(几何 / 字形 / 抽象 / 经典等) |
| 输出格式 | SVG(矢量、可直接放 README 与品牌系统) |
| 展示页 | 自带高端感 logo 墙(深色背景 / 大尺寸排版) |
| 触发入口 | Skill,装到 Claude Code / Codex 等 agent 后对话触发 |

## 适合什么场景

- 给新项目起的**第一版 logo**:先跑 6 个候选挑一个迭代,不必花钱请设计。
- README 顶部 / 文档站需要一张像样的品牌位但又不想存 PNG。
- 做 SaaS / 副业项目,**视觉资产快速到位**,专注代码本身。

## 与同类资源的差别

| 资源 | 风格 | logo-generator-skill |
|------|------|----------------------|
| pixel2motion | 给现有 logo 加动效 | 不出 logo,只动效化已有图 |
| Vercel / vercel.com/design | 通用设计系统 | 只给设计系统,不出具体 logo |
| Ideogram / Midjourney | AI 出图(PNG 为主) | 一次 6 版 SVG,工程友好 |
