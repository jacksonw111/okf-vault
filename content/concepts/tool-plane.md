# Plane（makeplane/plane，自托管项目管理平台）

## 它是什么

[Plane](https://github.com/makeplane/plane) 是 makeplane 开源的项目管理平台：对标 Jira / Linear / Monday / ClickUp，管 issue、跑迭代、拆模块、排路线图都在一处。

## 关键能力

| 能力 | 说明 |
|------|------|
| Issue 管理 | 完整 issue 生命周期 |
| Cycle / Sprint | 跑迭代（cycle） |
| 模块拆解 | 按模块组织工作项 |
| 路线图 | 排版本节奏的路线图 |
| 富文本编辑器 | 工作项支持富文本 + 文件上传 |
| 子属性 | 工作项可加子属性 |
| 关联引用 | 可引用 / 关联其它 issue |

## 它解决的问题

不想用 Jira / Linear / Monday / ClickUp 这类商业 SaaS？想自己部署、掌控数据？Plane 是 JIRA / Linear 的开源自托管替代。

## 适用场景

- 团队项目管理替代 Jira / Linear
- 需要自托管（数据可控 / 长期成本低）
- 想从商业 SaaS 迁出
