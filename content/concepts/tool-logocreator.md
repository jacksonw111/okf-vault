# LogoCreator（开源 Logo 品牌包生成器）

## 它是什么

**LogoCreator** 是 Nutlope 开源的 Logo + 品牌包生成器——把品牌名丢进去，几秒出一整套商用级品牌包（Logo 主图 / 变体 / SVG / PNG / 配色 / 字体建议），无需注册、无需登录、无需付费，自己配 API key 就能跑（支持自托管）。

## 为什么用它 / 适合什么场景

- **替代 Logo 设计外包**：对个人 / 小团队 / MVP，1 个名字 → 1 套品牌物料，零等待
- **自托管可控**：自己跑、自己接模型 API、品牌内容不外流
- **可二次开发**：MIT / Apache 协议，便于嵌入自己产品（如落地页 / 域名注册后流程）

## 关键能力

| 能力 | 说明 |
|------|------|
| 一键出图 | 品牌名 → Logo 主图 + 多种变体 |
| 多格式导出 | SVG（矢量）/ PNG（位图） |
| 配色 / 字体建议 | 自动给出一组品牌色与字体搭配 |
| 自配 API key | 接入 OpenAI / Anthropic / 其他 LLM 提供商 |
| 自托管 | Next.js 单仓库，可 Docker 一行拉起 |
