# quantskills

[quantskills](https://github.com/quantskills/quantskills) 是 **QuantSkills 组织** 维护的导航仓库——把旗下几十个量化「技能(skills)」与「智能体(agents)」按分类整理成可点击索引页,方便量化开发者快速找到、安装、复用因子与研究/交易相关的标准化资产。

## 它解决了什么

量化开发里经常有一堆零散的技能实现:因子、回测、报告、风险控制……成熟组织把这些能力拆成单一 skill 发布,但开发者要逐个搜仓库。quantskills 把组织的资产聚合在一处,类似「组织级 Skill Marketplace」。

## 关键能力

| 能力 | 说明 |
|------|------|
| 分类索引 | 按因子 / 研究 / 交易 / 报告等分类清晰呈现 |
| 一键可装 | 每个 skill 给出仓库链接与安装说明 |
| 标准化资产 | 所有 skill 统一输入输出协议,降低互操作成本 |
| 智能体支持 | 部分 skill 可直接当 Agent 工具调用 |
