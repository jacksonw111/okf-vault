# awesome-zhuiju-free

## 它是什么

[awesome-zhuiju-free](https://github.com/laoma2053/awesome-zhuiju-free) 是 **laoma2053** 维护的 GitHub 清单——一次性整理 **117 个免费影视资源站**，覆盖在线影视、网盘、IPTV 等多种入口。

## 三个特别之处

| 特点 | 说明 |
|------|------|
| 人工筛选 | 主打少广告、少跳转 |
| 自动检测 | 每天跑一遍可用性，失效站点会标记 |
| 完全开源 | 欢迎社区一起提交 / 更新 |

## 适合场景

- 想找片时当个**导航**用
- 给长辈 / 朋友做一个「少广告版」入口
- 自建一套影视导航站

## 注意事项

- 第三方免费资源站**自行甄别**，不要随便输入账号 / 密码 / 付款信息
- 失效站点的出现是常态，配套的自动检测尽量把这点盖住
