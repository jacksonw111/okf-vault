# helium-new-tab（Helium 浏览器非官方新标签页扩展）

## 它是什么

[helium-new-tab](https://github.com/exsesx/helium-new-tab) 是 exsesx 开源的 **Helium 浏览器非官方新标签页扩展**——视觉参考 **Helium 官方品牌包**与 **Prism**，**无后台、无追踪**。

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | 浏览器扩展（新标签页替换） |
| 平台 | Helium 浏览器 |
| 设计 | 参考 Helium 官方品牌包 / Prism |
| 隐私 | 无后台、无追踪 |
| 功能 | 搜索框 + 时钟 |
| 语言 | **37 种界面语言** |
| 外观 | 本地化定制 |

## 为什么用它 / 适合什么场景

- 用 Helium 浏览器但嫌默认新标签页「**太素 / 太丑 / 没搜索**」。
- 拒绝 Chrome 默认新标签页的「**满屏推荐 / 追踪**」——想要一个**纯本地、纯干净**的替代。
- 想要 Helium 视觉语言下的小定制（搜索 + 时钟 + 主题切换）。
- 多语言团队 / 跨国用户——37 种语言覆盖度高。
