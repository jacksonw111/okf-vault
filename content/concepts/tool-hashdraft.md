# hashdraft

[hashdraft](https://github.com/necromind/hashdraft) 是一款**Windows 上的 Markdown 阅读编辑软件**。它强调三个特点:

1. **启动快** — 没有重型 Electron / 浏览器内核, 直接看 Markdown 文件就开
2. **完全本地** — 不需要账号, 不上云, 不装依赖
3. **单窗口三模式** — 编辑 / 预览 / 分屏任选; **分屏时两边滚动同步**

## 它和 Typora / Obsidian 的差别

| 维度 | Typora / Obsidian / VSCode | hashdraft |
|------|------|------|
| 启动速度 | 较慢 (尤其 Obsidian / VSCode) | 极快 |
| 资源占用 | 较重 | 轻 |
| 联网需求 | 可选 | **纯离线** |
| 多模式 | 通常单窗口切换 | 单窗口三模式直接切换 |

适合「就想快点打开一个 .md 编辑, 不需要任何生态」的人。

## 关键能力

| 能力 | 说明 |
|------|------|
| 三模式 | 编辑 / 预览 / 分屏 单窗口切换 |
| 滚动同步 | 分屏模式下, 原文与渲染结果滚动联动 |
| 零依赖 | 不装额外运行时, 不依赖浏览器 |
| 离线可用 | 不需要账号、不可上网也能 100% 跑 |
| Windows 原生 | 启动快, 系统集成度高 |
