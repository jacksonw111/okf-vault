# deepseek-harness-handbook（zoahdev/deepseek-harness-handbook）

## 它是什么
[`zoahdev/deepseek-harness-handbook`](https://github.com/zoahdev/deepseek-harness-handbook) 是一份针对 **DeepSeek Harness（dsh）** 的中文零基础手册：**17 章正文 + 实测附录**，从安装、上手一直讲到「自己给 dsh 写插件」，填补官方文档对中文零基础读者不友好的空白。

## 为什么用它 / 适合什么场景
- 看到 dsh 火但英文 / 跳跃式文档挡住了非开发者读者。
- 想搭团队 / 公司内部培训材料，把 dsh 当作「AI 编码代理标准」来推。
- 想要一个能跟着一步步操作的「菜谱式」中文材料。

## 关键能力
| 能力 | 说明 |
|------|------|
| 17 章正文 | 系统覆盖 dsh 的概念 / 安装 / 使用 / 调试 |
| 实测附录 | 真实跑过的踩坑清单与插件范例 |
| 中文零基础 | 默认读者是不会写代码的产品 / 运营 / 设计 |
| 覆盖写插件 | 终点是会自己编写 dsh 插件，超越官方教程深度 |
