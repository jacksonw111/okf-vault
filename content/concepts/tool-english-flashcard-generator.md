# english-flashcard-generator（Anki 闪卡自动化生成）

## 它是什么

[english-flashcard-generator](https://github.com/Amin-naghdbishi/english-flashcard-generator) 是一款面向英语学习者的 Anki 闪卡自动化生成工具，目标是把每张卡片 5–10 分钟的手工制作压缩到 3 秒以内。输入词汇 / 例句等原始材料，工具自动产出可直接导入 Anki 的卡片（含释义、例句、配图、音频等字段），省去手工逐张排版的繁琐。

## 为什么用它 / 适合什么场景

- 备考 IELTS / TOEFL / GRE，想批量补词汇量但被 Anki 制卡劝退；
- 教学者要把一份词表批量转换为 Anki 卡；
- 希望卡片自带释义 / 例句 / 配图 / 音频，而不是只有单词 + 中文意思；
- 想用 Anki 的间隔重复算法但又不想重复手工填字段。

## 关键能力

| 能力 | 说明 |
|------|------|
| 自动制卡 | 把单卡 5–10 分钟手工成本压到 3 秒以内 |
| Anki 兼容 | 输出可直接导入 Anki 的卡片格式 |
| 富字段 | 释义 / 例句 / 配图 / 音频等字段自动填充 |
| 适用英语 | 面向英语学习场景设计 |
