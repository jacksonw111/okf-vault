# shuohao-skills

## 它是什么

[`shuohao-skills`](https://github.com/eternityspring/shuohao-skills) 是 eternityspring 开源的「说话方式 / 措辞风格」技能包——把一种特定的表达范式（主持人、段子手、老师、知乎腔等）沉淀成 Code Agent 可挂载的 SKILL.md 类模块，让 AI 在保持任务能力的同时切换到目标腔调。

## 为什么用它 / 适合什么场景

- 想让 CLI Agent 的回复有稳定的人设口吻（而不是被默认调成「职业顾问腔」）
- 想在不同场景切换语气而不用每次重新写提示词
- 想给团队共用一套「我们的 AI 应该这样说话」的可分发规则包
- 适合做短视频脚本 / 公众号 / 培训讲稿等需要稳定 style 的内容生产

## 关键能力

| 能力 | 说明 |
|------|------|
| 角色化措辞 | 让 Agent 切换指定人设 |
| 可挂载 Skill | 跟其他 SKILL.md 生态对接 |
| 风格沉淀 | 文本化风格规则，方便团队复用 |
| 框架无关 | Claude Code / Codex / 其他 harness 均可加载 |
