# HeyAgent

## 它是什么
HeyAgent 是一个跑在你本地电脑上的桌面 Agent。它能在「真实系统」上动鼠标键盘、打开应用、控制浏览器、自动建 Google 文档；同时支持通过 Telegram Bot 接受远程指令，出门在外也能让家里 / 工位的电脑继续干活。

## 为什么用它 / 适合什么场景
- 想让自己的笔记本 / 台式机变身「能被远端遥控的 AI 助手」，而不是依赖云端 sandbox。
- 远程办公 / 异地协作场景，需要手机临时启动家里电脑上的工作流。
- 本地化办公自动化（GUI 操作流、文档模板批量生成）。

## 关键能力
| 能力 | 说明 |
|------|------|
| 本地操作 | 鼠标 / 键盘 / 应用 / 浏览器 |
| 文档自动化 | 自动建 Google 文档 |
| 远程指令 | Telegram Bot |
| 形态 | 本机常驻 Agent |
| 许可 | 开源 |
