# LiveMarkDownEditor

基于 .NET 10 WPF 的 Windows 所见即所得 Markdown 编辑器，底层文件始终保持纯 Markdown。

## 适用场景

- 需要在编辑过程中直接呈现格式效果的场景。

## 关键能力

| 能力 | 说明 |
|------|------|
| 所见即所得 | 在编辑过程中直接呈现格式效果。 |
| 开放格式 | 文件仍是纯 Markdown，便于迁移、搜索和版本控制。 |
