# 《深入理解计算机系统》第三版中文 Markdown 版

## 它是什么

[csapp-zh-markdown](https://github.com/SunnyMaria/csapp-zh-markdown) 把经典教材 **《深入理解计算机系统（CSAPP）》第三版** 整理为 Markdown：

- **正文**：前言 + 第 1–12 章中文 Markdown
- **练习题**：238 道题答案
- **实验**：八个配套实验（Architecture Lab / Bomb Lab / Attack Lab 等）的中文说明
- **形态**：可在线阅读、离线保存

## 为什么用它 / 适合什么场景

- 不想买实体书 / 不便携带大部头，但想读 CSAPP。
- 想用 Markdown 笔记工具（Obsidian / VS Code）边读边做笔记、做高亮。
- 想把 CSAPP 实验材料集中在一份文件里，不必切到 PDF / 网页。
