# Google《Agent Engineering》1 小时课程

## 它是什么
Google 官方发布的 1 小时长 Agent Engineering 视频课，把"做 AI agent"这一整条工程链压缩进一小时：第一个 agent、agent 记忆（短 / 持久 / 长）、agent 循环、长任务、MCP vs API、多 agent 系统。

## 课程时间线（来自原始剪藏）
| 时间点 | 主题 |
|--------|------|
| 00:00 | 怎样搭建你的第一个 AI agent |
| 08:24 | Agent 记忆（短 / 持久 / 长） |
| 28:34 | Agent 循环与长跑 agent |
| 40:04 | MCP vs API（这一段被普遍认为值回票价） |
| 1:00:22 | 多 agent 系统 |

## 价值定位
- 一小时覆盖主流 agent 工程栈，是入门 / 速成 agent 开发的"性价比"路径。
- 配套文章 + 自我改进练习，主张"看完就自己搭一个能自我改进的 agent 系统"。
