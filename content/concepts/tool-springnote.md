# SpringNote（Flutter + Rust 实习 / 日常记录 + 个人知识库）

## 它是什么
Flutter + Rust 写的桌面应用，专为「懒得整理又想要知识库」的用户设计：随手写的零散便签会被 AI 自动整理并随时间累积成可生长的个人知识库；定期生成日 / 周 / 月报；还提供「回忆书」界面，像聊天一样翻出过去的旧记忆。

## 为什么用它 / 适合什么场景
- 实习生 / 上班族需要写实习日志 / 工作日报，但又很难坚持每天整理。
- 想用「回忆书」式聊天 UI 翻旧记忆，比传统时间线更易回看。
- 偏好 Flutter + Rust 桌面应用（跨平台、性能好、离线可用）。

## 关键能力
| 能力 | 说明 |
|------|------|
| 随手记 | 写便签无需考虑结构，AI 后期整理 |
| 自动整理 | AI 把零散便签聚类 / 标签化 / 关联 |
| 日 / 周 / 月报 | 自动生成多周期总结 |
| 回忆书 | 像聊天一样翻阅旧记忆的对话式 UI |
| 跨平台桌面 | Flutter + Rust，原生体验 |
