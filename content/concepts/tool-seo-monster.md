# seo-monster

## 它是什么
一个**面向 AI 助手的 SEO 工具集（MCP）**：把 70 个常用 SEO 工具（GSC 18 个 / GA4 / PageSpeed / Cloudflare 13 个等）封装成 MCP，让你在 Claude / Cursor / Codex 里直接问出 SEO 结论。

> 70 个工具里 GSC 占 18 个，天天开的无非那几个查询类；Cloudflare 那 13 个得域名真挂在 CF 上才不白搭。

## 为什么用它 / 适合什么场景
- 已经在用 AI 助手写代码 / 写文案，希望 SEO 数据也能直接在对话里问出来。
- 不想再去学一个 SEO 面板 UI（GSC 原生 UI 学习曲线高）。
- 网站或部分子域跑在 Cloudflare 上，要把 CF 数据纳入分析。

## 关键能力
| 能力 | 说明 |
|------|------|
| 工具总数 | 70 个 SEO 工具 |
| 数据源 | Google Search Console / GA4 / PageSpeed / Cloudflare |
| 接入方式 | MCP server，对接 Claude / Cursor / Codex 等 |
| 价值 | 一句话出 SEO 结论，无需面板 |
