# Arc Library

## 它是什么

[Arc Library](https://github.com/kuratlielia/arc-library) 是一个 **React 组件 / 区块源码库**，把 **101 个组件** 与 **22 个区块** 的源码直接交给开发者——装到本地后这些 `.tsx` / 样式文件就属于用户自己，可以自由改写再编译，不必再像 npm 包那样锁版本、追 changelog。

## 为什么用它 / 适合什么场景

- **不想从零攒 UI**：按钮、图表、动效、卡片、表单这些常用零件本来就要自己写一遍，Arc Library 把它们一次性给齐。
- **可改源码**：跟 npm 包不同，下载下来的就是源文件，组件不满意就直接改组件，不会出现「package 太死、改不动」的困境。
- **典型场景**：新 React 项目起步、PoC / MVP 想快速搭出像样的界面、内部工具 / Dashboard 想用统一设计语言。

## 关键能力

| 能力 | 说明 |
|------|------|
| 组件数 | 101 个 |
| 区块数 | 22 个 |
| 交付方式 | 源文件（非 npm 包），用户持有 |
| 可改写 | 直接编辑组件源码，编译进自己的项目 |
| 适用栈 | React |
