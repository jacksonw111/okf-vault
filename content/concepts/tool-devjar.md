# DevJar

## 它是什么
一个零配置 React 原型沙箱。无需本地安装、不写 build config，打开就能写组件、装依赖、跑多页路由、做静态站点导出。

## 关键能力
| 能力 | 说明 |
|------|------|
| Live React Preview | Fast Refresh 实时热更新 |
| Multiple Pages Routing | 多页路由开箱即用 |
| NPM Imports | 直接 import 第三方包 |
| Tailwind CSS | 默认支持 Tailwind |
| CSS / JSON / 资源导入 | 静态资源直接 require |
| 静态站点导出 | 一键导出可直接托管的静态产物 |
| 零配置 | 不需要本地装任何东西 |

## 适用场景
- 临时验证 React 想法 / 写 demo 给同事看
- 招聘 / 面试场景里让候选人现场写 React
- 教学：让学生无需配环境就能写组件
- 写一个静态 Landing / 文档站原型
