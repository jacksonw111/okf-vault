# openclaw-marketing-skills

## 它是什么
OpenClaw 智能体的营销技能包——把 37 个营销场景技能化（CRO、文案、SEO、付费广告、邮件、增长、留存、销售、策略），并支持对接 Google Ads、Search Console、Meta Ads、X / Twitter 的实时数据。

## 为什么用它 / 适合什么场景
- 想让 OpenClaw 这种通用 agent 拥有"营销军火库"，直接帮自己做增长。
- 不想自己写广告投放 / 邮件营销 / 文案 / SEO 的 prompt 模板，直接装技能。
- 需要在一次对话里调多个营销渠道的实时数据做决策。

## 关键能力
| 能力 | 说明 |
|------|------|
| 37 个营销技能 | CRO、文案、SEO、付费广告、邮件、增长、留存、销售、策略 |
| 多数据源接入 | Google Ads / Search Console / Meta Ads / X |
| 实时数据 | 直接拉取账户最新数据做决策 |
| 场景化 | 不止"通用营销"，每个技能面向具体场景 |
