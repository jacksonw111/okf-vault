# GlassQuota (chen10191200-hue)

## 它是什么

[GlassQuota](https://github.com/chen10191200-hue/GlassQuota) 是一个**实时显示 Codex / Gemini / Claude 三个 API 剩余用量**的 macOS 工具。无需逐个打开网页或客户端查看，把配额状态直接送到桌面上。

## 为什么用它 / 适合什么场景

- **多 provider 一屏**：同时显示 Codex / Gemini / Claude 三个 API 的剩余用量。
- **避免打断**：不需要切浏览器 / 切客户端看用量。
- **macOS 原生体验**：菜单栏 / 桌面常驻，符合 macOS 习惯。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多 API 配额实时显示 | Codex / Gemini / Claude 三个 provider 一屏 |
| 桌面常驻 | macOS 菜单栏 / 桌面集成 |
| 不切应用 | 无需打开网页或客户端 |
| 一目了然 | 剩余配额 / 已用量可视化 |
