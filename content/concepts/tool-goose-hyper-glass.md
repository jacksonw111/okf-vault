# Goose Hyper Glass（Minecraftgoose/GooseHyperGlassCDN）

## 它是什么

`Minecraftgoose/GooseHyperGlassCDN` 是一个**用 WebGL 渲染的「液态玻璃」UI 组件库**：

- 用 **Custom Elements** 实现，**不依赖任何前端框架**；
- 内置 **7 种组件**：开关、滑块、底部标签栏、按钮组、弹窗、滚动容器等；
- 通过 `<liquid-glass>` 标签引入组件，内容通过 **JS API** 设置。

## 为什么用它 / 适合什么场景

- 想要苹果 Vision Pro / iOS 那种**液态玻璃质感** 但不想引入完整设计系统；
- 项目**不能用 / 不想上** React / Vue / Svelte（用 vanilla / 静态站 / 微前端）；
- 想用**单个标签**加一点玻璃特效，避免重复造 WebGL 效果；
- CDN 直引，离线项目也能快速试。

## 关键能力

| 能力 | 说明 |
|------|------|
| WebGL 液态玻璃 | GPU 渲染玻璃质感效果 |
| Custom Elements | 原生 Web Components 标准支持 |
| 零框架依赖 | 不依赖 React / Vue / Svelte |
| 7 种组件 | 开关 / 滑块 / 底部标签栏 / 按钮组 / 弹窗 / 滚动容器 等 |
| JS API 控内容 | 通过 JS 动态设置组件内文 |
| CDN 引入 | `<script>` + `<liquid-glass>` 即用 |
