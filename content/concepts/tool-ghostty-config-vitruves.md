# ghostty-config（Vitruves：TUI 改 Ghostty 配置）

## 它是什么

[ghostty-config](https://github.com/Vitruves/ghostty-config) 是 Vitruves 出品的工具：用 **TUI 菜单**修改 **Ghostty 终端**的**主题 / 字体 / 窗口**等配置——不必再手写配置文件。

## 为什么用它 / 适合什么场景

- 想用 **Ghostty** 但懒得手写 `~/.config/ghostty/config`。
- 想在终端里**可视化**选主题 / 改字体 / 调窗口参数。
- 想快速切换不同主题——不必找配置文件。
- 偏好 TUI 工具（不想离开终端）。

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | TUI 菜单工具 |
| 目标 | Ghostty 终端配置 |
| 可改项 | 主题 / 字体 / 窗口参数 |
