# Synapse CE

## 它是什么
授权安全测试 / 防御性安全的统一治理控制平面：把软件成分分析（SCA）、侦察、证据采集、报告生成全部塞进一个工作流，替代"一堆零散工具 + 手写报告"的旧模式。

## 为什么用它 / 适合什么场景
- 做红队 / 渗透 / SCA 时，工具切换成本高 + 报告难统一。
- 需要可治理的"谁在什么时候对什么目标做了什么"的审计轨迹。
- 想给安全服务交付团队搭一个可复用的"侦察 → 利用 → 证据 → 报告"管线。

## 关键能力
| 能力 | 说明 |
|------|------|
| SCA | 软件成分分析，识别依赖与漏洞 |
| 侦察 | 目标信息收集与编排 |
| 证据采集 | 把操作证据自动落地成可审计记录 |
| 报告 | 统一模板的安全报告输出 |
| 治理平面 | 一切操作可追溯 / 可管控 |
