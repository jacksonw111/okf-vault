# deepseek-fat-fish

## 它是什么

`deepseek-fat-fish` 是一段纯前端的小挂件：在网页上加一只 DeepSeek 主题的肥鱼，它会跟随鼠标转头、偶尔眨眼。整套实现不依赖后端，纯 JavaScript + 资源文件；角色素材与逻辑解耦，把图片资源换成别的角色（柴犬、招财猫、品牌吉祥物）即变成另一个挂件，可用于个人主页、产品落地页、品牌官网加一点俏皮元素。

## 关键能力

| 能力 | 说明 |
|------|------|
| 鼠标跟随转头 | 实时根据鼠标位置转向 |
| 偶发眨眼动画 | 增加"活着"感 |
| 角色可替换 | 替换素材即可换角色，复用整套交互逻辑 |
