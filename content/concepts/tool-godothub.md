# GodotHub

## 它是什么

**Godot 引擎的 Unity Hub 风格项目管理器**——Godot 引擎本身没有官方桌面项目管理器，用户得手动：

- 下载 Godot 各版本（zip 解压）
- 管理多个项目
- 切换引擎版本
- 配 Git / 模板 / 资产

GodotHub 把这些集中到一个桌面应用里：

- 项目列表（按引擎版本分组）
- 引擎版本一键装 / 切换
- 模板管理
- Git 操作（clone / commit / push）
- 资产 / 插件浏览

![截图](https://pbs.twimg.com/media/HOXilZ0bsAA5_LM.jpg)

## 关键能力

| 能力 | 说明 |
|------|------|
| 项目集中管理 | 一处看所有项目 |
| 引擎版本切换 | 不用手动解压 zip |
| 模板管理 | 复用项目骨架 |
| Git 集成 | 不开终端也能 commit / push |
| 桌面原生 | 跑在系统桌面 |
| 开源 | 自托管 |

## 适合谁

- Godot 引擎重度用户
- 同时维护多个 Godot 项目（团队 / 个人）
- 想统一 Godot 工作流的教学者 / 学生
