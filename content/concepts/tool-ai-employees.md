# ai-employees

## 它是什么
一个**「AI 员工」调度模板包**：把 8 个常见业务岗位（销售 / 客服 / 内容 / 运营 / 数据 / ……）做成带日程的 AI 员工文件夹——

> 装在自己电脑上、跑在已有的 AI Agent 里；每天早晨交一份简报；所有「发送 / 花钱」的动作都停在待确认状态。

## 为什么用它 / 适合什么场景
- 想让 AI 帮你按日程跑日常业务（销售 / 客服 / 内容 等），而不是手动起会话。
- 关注「AI 越权」风险——所有对外动作（发送 / 花钱）必须人工确认。
- 不想自建调度框架，希望直接用现成的 8 个岗位模板。

## 关键能力
| 能力 | 说明 |
|------|------|
| 岗位数 | 8 个常见业务岗位 |
| 形态 | AI 员工文件夹 |
