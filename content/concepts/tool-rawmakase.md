# RAWmakase（pch/rawmakase，跨平台 RAW 显影）

## 它是什么

[RAWmakase](https://github.com/pch/rawmakase) 是 pch 开源的本地 RAW 显影工具，主打 Linux / macOS 用户：能打开相机 RAW 文件，用 Lightroom 同款滑块显影体验，导出 JPEG 或 16 位 TIFF，还能把现有的 Lightroom 目录（含评分 / 关键词）迁过来。

## 关键能力

| 能力 | 说明 |
|------|------|
| RAW 显影 | 打开相机 RAW 文件 |
| Lightroom 滑块 | 复刻 Lightroom 的滑块显影体验 |
| 多格式导出 | JPEG / 16 位 TIFF |
| 目录迁移 | 把 Lightroom 目录（含评分 / 关键词）迁过来 |
| 跨平台 | Linux + macOS 原生 |

## 它解决的问题

不想买 Lightroom、也不想用 darktable 的复杂 UI？RAWmakase 提供更轻量的替代方案，特别适合 macOS 用户。
