# TrendRadar

## 它是什么

**多平台热榜聚合 + 关键词过滤 + 多通道推送**——把「刷热点」从「来回切 5 个 App」变成「一次配置 + 定时推送」：

1. 自动抓取多平台热榜（知乎 / 微博 / Hacker News 等）
2. 按自定义关键词筛选匹配的新闻
3. 通过 10+ 推送通道通知（飞书 / 钉钉 / Telegram / 企业微信 / 微信 / 邮件等）
4. 30 秒 fork GitHub Actions 一键部署

![截图](https://pbs.twimg.com/media/HOc_Vn4bUAEqAp8.jpg)

## 关键能力

| 能力 | 说明 |
|------|------|
| 多源聚合 | 知乎 / 微博 / HN 等主流热榜 |
| 关键词筛选 | 只推想看的方向 |
| 多通道推送 | 飞书 / 钉钉 / Telegram / 微信 / 邮件 / 10+ |
| GitHub Actions | Fork 即跑，零服务器 |
| 30 秒部署 | README 一条命令 |
| 定时执行 | Actions cron |

## 适合谁

- 自媒体 / 内容创作者（追热点）
- 投资人 / 行业研究者（行业新闻雷达）
- 运营 / 市场（关注品牌相关话题）
- 不想被推送疲劳淹没的人（关键词过滤 + 多通道）
