# FDE 完整指南 (范冰)

## 是什么

「FDE 完整指南」是范冰（XDash《增长黑客》作者）写的一本免费公开电子书，把硅谷近年兴起的「前线部署工程师」(Forward Deployed Engineer, FDE) 这一岗位系统地拆开研究。全书分三部分：FDE 是什么、一次真实交付走完整流程、谁在做。

## 全书结构

| 部分 | 内容 |
|------|------|
| 第一部分 | FDE 是什么——角色定义、能力模型、与传统 SE / SA / PM 的区别 |
| 第二部分 | 一次完整交付的全流程——找对问题、赢得客户、激活部署、守住续约、扩大收入、规模化复制 |
| 第三部分 | 谁在做——150 个可核查案例，覆盖 Palantir / OpenAI / Anthropic / Harvey / Sierra 及国内首批实践者 |

## 适用人群

- 想理解「FDE」这种硅谷新岗位的技术 / 产品 / 销售从业者。
- 准备加入 AI 公司前线交付团队的人。
- 研究 AI 产品商业化路径的从业者与学者。
- 想了解 Palantir / OpenAI 等公司「技术 × 销售」融合模式的读者。
