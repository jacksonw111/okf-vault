# MonkeyCode

## 它是什么

[MonkeyCode](https://github.com/chaitin/MonkeyCode) 是 **长亭科技（chaitin）** 开源的**企业级 AI 开发平台**——补齐「个人 Vibe Coding 工具一大堆、团队协作的 AI 开发平台反而不多」这一段空白。

## 为什么用它 / 适合什么场景

- **团队场景下「流程集中管理」**：需求 → 开发 → 验证 → 审查全在一处，告别「代码在个人 IDE 里跑、需求在飞书里追、review 在 PR 里卡」。
- **多模型可选**：GLM、Kimi、Qwen、DeepSeek 都能接，团队可按成本 / 性能混搭。
- **移动端原生**：离开工位也能审批 / 跟进。
- **浏览器即用**：不折腾本地环境，新成员 onboarding 极快。

## 关键能力

| 能力 | 说明 |
|------|------|
| 入口 | 浏览器即用 |
| 流程 | 需求 / 开发 / 验证 / 审查一条龙 |
| 模型 | GLM / Kimi / Qwen / DeepSeek 等 |
| 移动端 | 原生支持 |
| 开源 | 长亭科技出品 |
