# 《深入理解 AI Agent：设计原理与工程实践》（chemark 版）

## 它是什么

chemark 在 GitHub 上开源的中文 AI Agent 电子书，主题与 bojieli 整理的同名书高度一致（都围绕 **Agent = LLM + 上下文 + 工具** 公式展开），目标受众是想「从原理吃透到落地上手」的开发者，而不是只会套 API 的人。

## 与同主题既有概念的关系

- 与 [`note-ai-agent-book`](./note-ai-agent-book.md)（bojieli 版）：两本书主题、命名、公式高度一致，但作者 / 仓库不同。两者并行收录，便于读者按作者偏好与章节安排自行取舍。

## 关键定位

- 把 Agent 工程化的每个主要侧面系统化展开（Harness、上下文工程、工具、多 Agent 等）。
- 以工程实践为导向，而非纯学术综述。
