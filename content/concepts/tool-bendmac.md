# BendMac

## 它是什么

[IuCC123/BendMac](https://github.com/IuCC123/BendMac) 是个**macOS 菜单栏应用**：合上 MacBook 盖子时，桌面画面随转轴角度**实时弯曲、模糊、透视变形**，灵感来自 Bendy 应用与 iPhone Duo 折叠动画。

## 核心特性

| 特性 | 说明 |
|------|------|
| 菜单栏常驻 | 不占桌面空间 |
| 实时跟随 | 盖子转到哪特效到哪 |
| 弯曲变形 | 真实物理感 |
| 模糊 / 透视 | 多重视觉层叠 |
| 灵感来源 | Bendy / iPhone Duo |

## 为什么用它 / 适合什么场景
- 玩梗 / 拍视频要「折叠 MacBook」效果。
- 想给同事朋友炫酷 demo。
- 桌面整活 / 桌搭爱好者。

## 关键能力

| 能力 | 说明 |
|------|------|
| 转轴角度读取 | 实时跟随 |
| 弯曲变形 | 物理感效果 |
| 模糊 / 透视 | 多重视觉 |
| 菜单栏常驻 | 开关方便 |
