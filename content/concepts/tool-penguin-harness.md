# Penguin Harness（Prism-Shadow/penguin-harness）

## 它是什么

`Prism-Shadow/penguin-harness` 是一个**开源的 AI 代理构建框架**，让**代理自动创建和优化其他代理**。工具集极简、token 省、对 DeepSeek 等开源模型深度优化；说一句话即可生成完整应用，代理能跑基准测试自我优化，内置**办公、开发、AI 应用、代理调优四大类技能**。

## 为什么用它 / 适合什么场景

- 想用「一句话 → 一个完整应用」的方式快速搭原型；
- 希望代理能**自我优化**（跑基准 + 调优），而不是写死流程；
- 主要使用 DeepSeek 等开源模型，需要**针对开源模型优化 token / 工具调用**的场景；
- 不想为常见任务写大量胶水代码——四大类技能已内置。

## 关键能力

| 能力 | 说明 |
|------|------|
| 代理自举 | 代理自动创建和优化其他代理 |
| 一句话生成应用 | 自然语言 → 完整可运行应用 |
| 基准自优化 | 代理可跑基准并据此调优 |
| 内置四大技能 | 办公 / 开发 / AI 应用 / 代理调优 |
| 工具极简 | 工具集精简，token 消耗低 |
| 开源模型友好 | 对 DeepSeek 等深度优化 |
