# awesome-education

## 它是什么

[awesome-education](https://github.com/wowlusitong/awesome-education) 是一个**教育优惠与学生权益清单仓库**，把「学生 / 教职工 / 学术机构」可享受的折扣与免费权益集中整理。

形态上是 awesome-list（清单型 README），适合作为「办学生证 / 在校期间，能薅哪些羊毛」的索引。

## 涵盖范围

| 类别 | 例子 |
|------|------|
| 开发工具 | JetBrains 全家桶、GitHub Student Developer Pack |
| 操作系统 / 平台 | Apple 教育商店、Microsoft Imagine |
| 云服务 | 腾讯云学生机、阿里云学生 VPS |
| 学术组织 | CCF 学生会员、ACM 学生会员 |
| 设计 / 创作 | Figma 教育版、Autodesk 学生许可 |
| 学术资源 | 期刊 / 数据库 / 在线课程学生权限 |

## 适合谁

- 在校学生 / 研究生 / 博士生，希望一次性了解所有可薅的羊毛。
- 刚办完学生身份，不知道「学生证除了坐公交打折还能干嘛」的同学。
- 想给团队 / 实验室整理「科研可申请的资源」清单的负责人。
