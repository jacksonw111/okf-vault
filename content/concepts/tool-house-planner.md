# house-planner

## 它是什么

[house-planner](https://github.com/egmalt/house-planner) 是 **egmalt** 开源的**自建房规划工具**——跑在自己服务器上，覆盖**平面图、管线设计、材料报价**三个核心环节，给自建房用户一体化 DIY 方案。

## 关键能力

| 能力 | 说明 |
|------|------|
| 平面图 | 户型绘制与编辑 |
| 管线设计 | 水电管线走向规划 |
| 材料报价 | 配套材料用量 + 价格估算 |
| 自部署 | 数据完全在自家服务器，无云依赖 |

## 适合场景

- 准备在老家 / 自留地自建房的用户
- 想避开商业 CAD / 设计软件的高门槛与按月付费
- 数据敏感（房屋信息不愿上云）
