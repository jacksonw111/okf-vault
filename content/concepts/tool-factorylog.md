# factorylog

## 它是什么

[factorylog](https://github.com/flaviocopes/factorylog) 是 **flaviocopes** 出品的 macOS 工具——让 Codex / Cursor 等编码 Agent **每完成一件事写一行报告**，按项目和按天 / 按周排列成时间线。

## 解决什么问题

- 多 Agent 并行时说不清「今天这些 Agent 到底干了什么」
- 想做项目复盘 / 客户汇报却没记录
- Agent 完成的事件散在各处，要手动汇总

## 关键能力

| 能力 | 说明 |
|------|------|
| 自动报告 | Agent 每完成一件事 → 写一行报告 |
| 多维度聚合 | 按项目、按天、按周 |
| 平台 | macOS |
| 兼容 | Codex / Cursor 等 |

## 适合场景

- 团队同时跑多个 Agent，需要给项目 / 客户出工作日报
- 个人想给每天 / 每周 Agent 工作做复盘
- 想给「AI 编码到底产出了什么」做可视化
