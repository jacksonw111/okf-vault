# kiri

## 它是什么
[yuxino/kiri](https://github.com/yuxino/kiri) 是**把截图 / 标注 / OCR / 录屏四件套统一收进同一个本地桌面工作区**的工具。痛点：日常截一张图、画几笔、想 OCR 提取文字、录一段操作——往往要装 Snipaste / 画图 / tesseract / OBS / 录屏软件五六个，文件还散落在 Pictures、Documents、Desktop 各个地方。

kiri 提供的整合：

- **截图**：框选 / 窗口 / 全屏各种模式，输出到 kiri 自管的工作区；
- **标注**：直接在截图上画箭头、圈、涂改、打码；
- **OCR**：截图里的文字一键识别成可复制文本；
- **录屏**：录制屏幕操作（含声音）；
- 所有产物**落本机**，不依赖云账号、不上传到第三方服务。

## 为什么用它 / 适合什么场景
- 想用一个工具替代 Snipaste + 标注工具 + OCR 工具 + 录屏软件的「全家桶」；
- 工作流涉及**截图 → 标注 → 提取文字 → 录操作过程**的连续动作，跨工具切换成本高；
- 关心**隐私与本地所有权**——所有产出留在本机、不经云端；
- 需要把截图、OCR 结果、录屏作为**证据 / 归档**保存的工程 / 设计 / 客服场景。

## 关键能力
| 能力 | 说明 |
|------|------|
| 截图 | 框选 / 窗口 / 全屏等模式 |
| 标注 | 在截图上画箭头、圈、涂改、打码 |
| OCR | 截图文字一键识别为可编辑文本 |
| 录屏 | 录制屏幕操作（含音频） |
| 本地优先 | 截图与录屏文件全部落本机 |
| 零云账号 | 无需注册、无需登录、无云同步 |
| 整合体验 | 四个动作在同一工作区连续完成 |
