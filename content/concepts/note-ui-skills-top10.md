# UI Skills Top 10

UI-Skills(http://ui-skills.com) 是一个**社区精选 UI/前端类 Skill 集合平台**。下面是被高赞推荐过的 **Top 10**——可作为「前端 Agent 时代每个 Agent 都该装的 Skill」清单的起点。

## Top 10 清单

| 序号 | Skill 名 | 关注主题 |
|------|----------|----------|
| 1 | `emil-design-eng` | Emil Kowalski(animations.dev 作者)的视觉/动效设计语言 |
| 2 | `make-interfaces-feel-better` | 让界面手感更好——交互细节 / 微动效 / 反馈感 |
| 3 | `12-principles-of-animation` | 经典 12 动画原则,放 agent 仓里约束动效产出 |
| 4 | `fixing-accessibility` | 可访问性修缮——ARIA / 焦点 / 对比度自助 |
| 5 | `shadcn` | shadcn/ui 的设计系统约定 |
| 6 | `vercel-react-best-practices` | Vercel 维护的 React 最佳实践合集 |
| 7 | `react-doctor` | 给 React 项目做体检 / 反模式扫描 |
| 8 | `vitest` | Vitest 的 agent 使用规范 |
| 9 | `pnpm` | pnpm 的使用规范 |
| 10 | `playwright-cli` | Playwright CLI 的 agent 使用规范 |

## 适合什么场景

- 团队刚开始给 Agent 装 Skills,不知道装哪些——本清单可做**种子清单**。
- 给前端 Agent 评估哪些 Skills 高频反复用,做依赖收敛。
- 调研 Agent 时代下「Style / Practice / Tooling」三类 Skill 的划分。

## 怎么用

每个 Skill 在原域名下都有详情页和安装说明: `http://ui-skills.com/skills/<owner>/<skill-name>`
