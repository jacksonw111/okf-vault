# how-to-live-better

## 它是什么
**单文件离线电子书**：把开源书《高性价比人生指南》的 32 节正文压成一个**自包含 HTML 文件**——手机上打开就能离线阅读和检索。

## 为什么用它 / 适合什么场景
- 想要一本「装在手机里随时翻」的人生指南书。
- 没有网络也能读、也能全文检索。
- 不想装 app、不想联网账号化——一个 HTML 文件搞定。

## 关键能力
| 能力 | 说明 |
|------|------|
| 形态 | 单个自包含 HTML 文件 |
| 内容 | 《高性价比人生指南》32 节正文 |
| 离线 | 完全离线 |
| 检索 | 文件内可检索 |
| 部署 | 手机直接打开 |
