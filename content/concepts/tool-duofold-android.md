# DuoFold Android（iPhone Duo 风格整屏翻折动效）

## 它是什么

[jcx396905-gif/DuoFold-Android](https://github.com/jcx396905-gif/DuoFold-Android) 把 **iPhone Duo 风格的整屏翻折动效**搬到了普通 Android 手机上：手机倾斜时整个屏幕实时**透视投影**，叠加**磨砂、明暗与景深**，**无需折叠屏硬件，无需 Root**。

## 关键能力

| 能力 | 说明 |
|------|------|
| 整屏翻折 | 屏幕整体跟随陀螺仪折叠 |
| 实时透视 | 倾斜时屏幕边缘透视投影 |
| 磨砂 / 明暗 / 景深 | 三层视觉特效叠加 |
| 陀螺仪驱动 | 跟随设备姿态实时更新 |
| 普通手机可用 | 不需要折叠屏 |
| 无需 Root | 普通 Android 即可跑 |
