# quickdraw

[quickdraw](https://github.com/quickdrawjs/quickdraw) 是一个 **MIT 许可、无需 license fee** 的无限画布白板 SDK，作为 **tldraw 的开源替代**：可直接嵌入 React、React Native 和纯 JS 应用。

## 它是什么

开源的白板 / 无限画布 SDK。tldraw 是行业知名白板，但其许可与商业模式对一些项目不友好；quickdraw 提供 MIT 完全免费、零授权费的替代方案。

## 为什么用它 / 适合什么场景

- **商业项目必读**：tldraw 商用条款对一些场景有限制，quickdraw 是纯 MIT 替代。
- **嵌入 React / RN 应用**：作为组件直接集成。
- **白板 / 思维导图 / 流程图**：底层画布能力。
- **无 license fee**：彻底规避未来授权变更风险。

## 关键能力

| 能力 | 说明 |
|------|------|
| 无限画布 | 白板基础体验 |
| MIT 许可 | 完全免费、商用无虞 |
| 零授权费 | 无未来授权变更风险 |
| React 嵌入 | 直接以组件形式用 |
| React Native 兼容 | 移动端也能用 |
| 纯 JS 支持 | 不绑死框架 |
| tldraw 替代 | 类似白板 API 设计 |
