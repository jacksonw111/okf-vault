# DuoLikeAnimation

## 它是什么

[elijah-semyonov/DuoLikeAnimation](https://github.com/elijah-semyonov/DuoLikeAnimation) 是一个**模拟 iPhone Duo 折叠翻折动画的 SwiftUI 实现**：不依赖真折叠屏硬件，只用 SwiftUI shader + 陀螺仪，让普通 iPhone 倾斜时也能演出折叠屏一半翻过去的视觉效果。

## 核心特性

| 特性 | 说明 |
|------|------|
| SwiftUI shader | 渲染折叠翻折效果 |
| 陀螺仪驱动 | 跟设备倾斜联动 |
| 硬件无关 | 不需要真折叠屏 |
| 动画效果 | 模拟 iPhone Duo 折叠动画 |

## 为什么用它 / 适合什么场景
- 想在普通 iPhone 上预览折叠屏效果。
- 做原型 / demo 给客户看「如果折叠会怎样」。
- 研究 SwiftUI shader + 陀螺仪联动。

## 关键能力

| 能力 | 说明 |
|------|------|
| shader 渲染 | SwiftUI 着色器动画 |
| 陀螺仪输入 | 跟随设备倾斜 |
| 折叠翻折 | 模拟半屏翻折视觉 |
| 单设备可用 | 不需折叠屏 |
