# zhuzhiliao（竹知了）

## 它是什么

imsai-sh 写的零依赖单文件 HTML 玩具，把童年竹知了「一转就哇哇叫」的物理感搬到浏览器里：摇一摇 / 甩一甩就发声，断网也能玩。

## 为什么用过它 / 适合什么场景

- 想做一个「开箱即玩」的怀旧玩具分享给朋友，无需服务器 / 部署。
- 想用 HTML5 Audio API + 设备运动传感器做交互式声音玩具。
- 学习单文件 HTML 应用的「无构建 / 零依赖」极简模式。

## 关键能力

| 能力 | 说明 |
|------|------|
| 单文件 HTML | 一个 .html 文件就是整个应用，无外部依赖 |
| 设备传感器 | 晃动 / 旋转触发音效 |
| 离线可玩 | 断网不影响，纯前端 audio API |
| 怀旧还原 | 传统竹知了玩具的声音体验搬到浏览器 |
