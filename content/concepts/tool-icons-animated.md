# icons-animated

## 它是什么

[icons-animated](https://github.com/ln-dev7/icons-animated) 是 **ln-dev7** 维护的**「动效图标合集」**——把 Heroicons、Hugeicons、Tabler、Phosphor 等主流图标库的**标志性几何形态**做成可循环动效：

- **保留 outline 原生形状**：动效不破坏原始图标识别度
- **按图形单独编排**：每个图标按自己的形状配动效，不是一刀切
- **跨库统一**：「choreography」风格一致，但适配每种 shape

## 为什么用它 / 适合什么场景

- **让 UI 更有「活感」**：AI 写前端时代，差异化往往在细节——动效图标就是那一类细节。
- **免去自己写动画**：不必每个图标手写一个 SVG / Framer Motion。
- **多库统一**：原本 Heroicons / Tabler 各做各的，现在动效编排统一了。

## 关键能力

| 能力 | 说明 |
|------|------|
| 支持的库 | Heroicons（131 个）、Hugeicons、Tabler、Phosphor |
| 形态 | 保留 outline 原生几何 |
| 编排 | 按图形独立编排动效 |
| 风格 | 统一 choreography |
| 开源 | GitHub 维护 |
