# Bencho.dev

## 它是什么

[cabralorenzo](https://x.com/cabralorenzo) 推出的 **Bencho.dev**：一个**交互式 UI blocks 库**——可以探索、调参、benchmark、并直接拿到自己项目里。

## 起源故事

> 起源于业余时间的小实验——把作者的设计思维 + 风格 + Claude 一起推到交互、组件和细节的极致。
> 然后发现这值得认真做下去。

## 为什么用它 / 适合什么场景

- 想要可调参 / 可 benchmark 的 UI 组件。
- 喜欢持续更新的设计资源（每周新增）。
- 想给团队分享可「试一下」的组件库。

## 关键能力

| 能力 | 说明 |
|------|------|
| 交互式 | 浏览器里直接试 |
| 可调参 | 参数实时调整 |
| Bench | 性能 / 体积 benchmark |
| 可带走 | blocks 直接拿到项目 |
| 周更 | 每周新增 |
