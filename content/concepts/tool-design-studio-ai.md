# Design Studio AI（开源设计台，人 + Agent 同一份文档）

## 它是什么

[bestagentkits/design-studio-ai](https://github.com/bestagentkits/design-studio-ai) 是个**开源设计台**：网页、幻灯片、报告、线框图、3D、时间线视频都能画。**人和 Agent 围着同一份版本文档转**——对话下指令改图，也能上手直接拖。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多媒介 | 网页 / 幻灯片 / 报告 / 线框图 / 3D / 时间线视频 |
| 同一份文档 | 人和 Agent 操作同一个版本 |
| 双交互 | 对话下指令改图 + 直接拖拽 |
| 2D 骨骼动画 | 角色动画、关键帧 |
| 3D 建模 / 绑骨 | 3D 角色与材质灯光 |
| 时间线视频 | 关键帧 + 视频导出 |

## 适合谁

- 想让 Agent 和人**协作**而不是接力
- 一个人 / 小团队需要 2D + 3D + 视频一体化工作流
- 想避免「设计稿改了三次但代码不知道」
