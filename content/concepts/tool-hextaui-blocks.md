# HextaUI Blocks

## 定义

**HextaUI Blocks** 是 [`tool-hextaui`](tool-hextaui.md) 在 v3 版本引入的**区块（Blocks）合集**——把 hero / features / pricing / CTA / footer / testimonial / faq 等**页面级组合**提前拼好，按行业模板（SaaS / 电商 / 作品集 / 博客 / 落地页）分组，让用户整段拷到项目里使用；与基础组件库（60+ 单组件）形成「单组件 + 页面块」双层覆盖。

## 要点

- **官方网站**：[hextaui.com](https://hextaui.com)
- **来源**：HextaUI v3（preetsuthar17 维护）
- **形态**：shadcn 风的「复制粘贴组件」模式，CLI 整段下载
- **基础组件 + 区块**：基础组件 = 按钮 / 输入 / 弹窗；Blocks = 整页组合
- **典型场景**：SaaS 落地页 / 产品官网 / 营销页快速搭建
