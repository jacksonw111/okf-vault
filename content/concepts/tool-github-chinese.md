# github-chinese

[github-chinese](https://github.com/pon168809/github-chinese) 是一款 **GitHub 界面中文化浏览器用户脚本**,依托 Tampermonkey / Violentmonkey / Greasemonkey 等脚本管理器运行,覆盖菜单栏、标题、按钮等界面元素,把英文 GitHub 翻译为中文。

## 它解决了什么

GitHub 官方不做 UI 本地化(只做文档),中文用户读菜单/按钮要靠记忆。github-chinese 通过 userscript 注入「文案字典」实时翻译,不污染 GitHub 功能、不请求服务端、不留状态。

## 关键能力

| 能力 | 说明 |
|------|------|
| userscript 即装即用 | Tampermonkey / Violentmonkey / Greasemonkey 通吃 |
| 客户端字典 | 不依赖第三方服务,纯前端替换 |
| 覆盖主线界面 | 菜单栏 / 标题 / 按钮 / 提示 |
