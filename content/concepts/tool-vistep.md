# vistep

## 它是什么
vistep 是 int64ago 开源的可视化教学项目：用**短篇可视化故事**配**可交互实验**讲清日常生活里的机械、科学与计算原理（如简单机械、杠杆、滑轮、波、电路等），支持中英双语。

## 为什么用它 / 适合什么场景
- 给中小学生/初学者讲物理/工程/计算的直观原理。
- 想让"看得见的物理"成为科普内容的标准组件。
- 双语教学场景。

## 关键能力
| 能力 | 说明 |
|------|------|
| 可视化故事 | 短篇叙事 + 动画/示意 |
| 可交互实验 | 浏览器内动手拨参数看效果 |
| 双语 | 中文 / 英文 |
| 面向日常 | 选题贴近生活场景 |
