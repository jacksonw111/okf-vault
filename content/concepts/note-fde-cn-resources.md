# FDE 中文学习与面试资料库（VanGong1999/FDE）

## 它是什么

由 [VanGong1999](https://github.com/VanGong1999) 维护的 GitHub 资料库，**面向中文读者**系统整理 FDE（Forward Deployed Engineer，AI 前线部署工程师）这个岗位的相关内容。覆盖：

- 角色认知
- 交付方法论
- 企业 AI 落地
- 面试通关
- 可复制的工作模板

## 与已有 FDE 资料的关系

知识库里已有两份相关资料：

- **[FDE 完整指南 (范冰)](./note-fde-guidance-book.md)** — 范冰 (XDash) 的免费电子书，体系化拆解 FDE 岗位（是什么 / 交付流程 / 150 案例）。
- **[FDE 101 (dotey)](./note-fde-101-dotey.md)** — dotey 维护的 FDE 入门级解读。

本资料库（VanGong1999/FDE）侧重**中文读者的实战路径**——从方法论到面试 / 模板，定位偏"求职 + 落地"，与上面两份资料形成互补。

## 适用人群

- 想在国内做 / 转型 FDE 岗位的中文读者。
- 在准备 FDE 相关面试、需要中文案例与话术的人。
- 想抄一份"可复制的工作模板"快速进入交付节奏的人。
