# page-mascot（交互式吉祥物 Skill）

## 它是什么

[koboyo.com/page-mascot](https://koboyo.com/page-mascot) 是 nilbuild 写的 **Skill**：输入一个角色名，生成一个会跟随鼠标、点击有反应的吉祥物。

> Made a skill for interactive mascots
>
> `/page-mascot [your character]`
>
> It generates a mascot that follows your cursor and reacts when you poke it

## 关键能力

| 能力 | 说明 |
|------|------|
| 跟随鼠标 | 吉祥物随指针移动 |
| 交互反应 | 点击 / 戳一下有反馈 |
| Skill 命令 | `/page-mascot [character]` 一行调用 |
| 角色化 | 任意角色都能生成 |

## 适合谁

- 给 SaaS 落地页 / 个人主页加点「萌」感
- 想给 brand 加个 mascot 但又不想请插画师
- 想试试 LLM 直接生成可交互 UI
