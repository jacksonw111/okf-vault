# Langflow

## 它是什么

[langflow-ai/langflow](https://github.com/langflow-ai/langflow) 是 GitHub 上 **150k+ star** 的**拖拽式 AI 工作流**：把 LLM / 向量库 / 工具节点像积木一样拼起来，不用从零写胶水代码；内置可视化调试，能把流程发布成 API 或导出 JSON。

## 核心特性

| 特性 | 说明 |
|------|------|
| 拖拽式 | 节点拼装工作流 |
| 多组件 | LLM / 向量库 / 工具 |
| 可视化调试 | 每步输入输出可见 |
| 一键发布 API | 流程变接口 |
| 导出 JSON | 流程可移植 |
| 企业维护 | DataStax 长期投入 |

## 为什么用它 / 适合什么场景
- 想快速搭个 RAG / Agent 链路验证想法。
- 不愿意从零写前后端胶水。
- 团队里非工程师也要能搭 AI 流程。

## 关键能力

| 能力 | 说明 |
|------|------|
| 拖拽式拼装 | 不用写代码 |
| 可视化调试 | 输入输出实时可见 |
| API 发布 | 流程直接变接口 |
| JSON 导出 | 流程可移植 |
| 150k+ star | 社区验证 |
| 企业支持 | DataStax 长期维护 |
