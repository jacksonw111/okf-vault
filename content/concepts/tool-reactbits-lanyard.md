# ReactBits Lanyard 组件

## 它是什么

[ReactBits Lanyard](https://reactbits.dev/components/lanyard) 是 davidhaz 在 [reactbits.dev](https://reactbits.dev/) 上**完全重做**的 Lanyard 组件：

- 把 **Discord Lanyard** 公开的 Presence 数据（在线状态、当前活动、Spotify 听歌信息）绑成**可放进 React 项目即用**的交互卡片
- 相比旧版：**更多定制项** + **更顺滑的动画**

## 适合什么场景

- 个人主页 / 作品集想展示「我在线 / 我在听什么歌」
- 团队 Dashboard 想接入成员 Discord 状态
- 喜欢 React Bits 风格（drop-in、零样板）的开发者

## 关键能力

| 能力 | 说明 |
|------|------|
| Lanyard 数据 | 在线 / 离线 / 闲置 / 请勿打扰 |
| 活动展示 | 当前 Discord 活动（游戏 / 应用） |
| Spotify 联动 | 显示正在听的歌 |
| 动画 | 更顺滑的过渡效果 |
| 可定制 | 颜色 / 布局 / 信息密度可调 |
| 形态 | React 组件，drop-in 即用 |
