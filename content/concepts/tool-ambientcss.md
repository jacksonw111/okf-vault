# Ambient CSS

## 它是什么

[Ambient CSS](https://ambientcss.vercel.app/) 是一个**用物理光照模型生成 CSS 高光 / 阴影 / 材质**的库：作者把同一套几何和灯光同时在 Blender 里渲染作为参考，然后在浏览器里用 `box-shadow` 和 CSS 变量复现。

## 核心特性

| 特性 | 说明 |
|------|------|
| 物理光照 | 真实模型，非经验估算 |
| 多光源 | 不同光源 / 材质效果 |
| 浏览器复现 | box-shadow + CSS 变量 |
| Blender 同步 | 参考图与组件一致 |

## 为什么用它 / 适合什么场景
- 想要「惊艳视觉」的高光 / 阴影 UI。
- 做品牌官网 / SaaS 着陆页想与众不同。
- 研究 CSS 物理光照实现。

## 关键能力

| 能力 | 说明 |
|------|------|
| 物理光照 | 真实模型 |
| 多光源 | 不同光位 / 强度 |
| 多材质 | 高光 / 阴影 / 表面 |
| 组件库 | 按钮 / 旋钮 / 滑条 / 推子 / 开关 |
| Blender 同步 | 与 3D 渲染一致 |
