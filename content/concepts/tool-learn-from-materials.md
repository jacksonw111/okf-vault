# learn-from-materials

## 它是什么

[dmoshehun-prog/learn-from-materials](https://github.com/dmoshehun-prog/learn-from-materials) 是给 AI 编程工具用的**多材料学习 Skill**：书 / PDF / 课件 / 网页一堆材料丢进来，转成**带页码出处**、可**逐条核验**的知识库和离线学习网页。

## 核心特性

| 特性 | 说明 |
|------|------|
| 多源材料 | 书 / PDF / 课件 / 网页 |
| 页码出处 | 每条引用都标页码 |
| 离线学习 | 输出离线网页可断网看 |
| 可核验 | 逐条对原文 |

## 为什么用它 / 适合什么场景
- 想系统读一堆资料但怕 AI 编。
- 想离线保存一份可核验知识库。
- 教 AI 拆解 / 学习材料的标准流程。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多源聚合 | 书 / PDF / 课件 / 网页 |
| 页码标注 | 引用可回溯 |
| 离线网页 | 断网可学 |
| 逐条核验 | 防 AI 幻觉 |
| 知识库化 | 结构化整理 |
