# Hand-drawn Explainer Video Nikola

## 它是什么

[hi-nikola/hand-drawn-explainer-video-nikola](https://github.com/hi-nikola/hand-drawn-explainer-video-nikola) 是**手绘解说视频生成器**：把主题 / 文稿 / SRT 拆成画面，**按旁白节奏一笔一笔画出来**，再合成配音、字幕、时间轴和 MP4。

## 核心特性

| 特性 | 说明 |
|------|------|
| 输入灵活 | 主题 / 文稿 / SRT 字幕 |
| 一笔一画 | 按节奏逐笔绘制 |
| 全套合成 | 配音 / 字幕 / 时间轴 / MP4 |
| 手绘风 | 区别于 AI 摄影 |

## 为什么用它 / 适合什么场景
- 做解说 / 科普类短视频。
- 想用「手绘风」区别于通用 AI 视频。
- 把文章 / SRT 字幕快速转成视频。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多输入 | 主题 / 文稿 / SRT |
| 手绘动画 | 逐笔绘制 |
| 全套输出 | 配音 + 字幕 + 时间轴 |
| MP4 | 直接发布 |
