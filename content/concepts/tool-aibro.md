# AIBro（Mac 本地工作区）

## 它是什么

[zihenghe04/AIBro](https://github.com/zihenghe04/AIBro) 是一个**Mac 本地优先的工作区应用**，由作者一人开发、AGPL 开源。它试图把桌面端、移动端、同步服务都覆盖了，让读论文、改文件、本地检索这些日常事在一块面板里完成。

桌面端两条比较硬的能力：

1. **Diff 审阅**：把改前 / 改后或不同来源的对照整理到同一块面板
2. **本地 BM25 检索**：内置 BM25 全文检索引擎，本地索引、本地查询

## 关键能力

| 能力 | 说明 |
|------|------|
| 一人全栈 | 桌面 + 移动 + 同步都由单人维护 |
| 本地优先 | 数据在自己机器上 |
| AGPL 开源 | 强 copyleft，可自由 fork |
| Diff 审阅 | 桌面端原生支持的版本 / 来源对比 |
| BM25 检索 | 本地经典信息检索算法，索引 / 查询都在本机 |
| 多端协同 | 桌面 + 移动 + 同步服务一套体系 |

## 适合什么场景

- 在 Mac 上读论文 / 改代码 / 整理文档、想在一个 App 内完成「打开文件 → 搜索片段 → 对照 diff」的研究 / 写作型用户。
- 偏好本地优先、AGPL 强 copyleft 也接受的开源用户。
- 想要一套「桌面 + 移动 + 同步」都由同一个开源项目维护的工作区生态。
