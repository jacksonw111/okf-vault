# Habo

## 它是什么

Flutter 写的开源习惯追踪应用——主打：

- **隐私**：端到端加密同步
- **跨平台**：Android + iOS
- **Material You**：自适应主题

![截图示例](https://pbs.twimg.com/media/HOXGAz6aEAAV6Io.jpg)

## 功能清单

| 功能 | 说明 |
|------|------|
| 多种完成类型 | 是 / 否、数值、跳过 |
| 备注记录 | 每次打卡可写原因 |
| 智能提醒 | 不打扰、按时推 |
| 日历视图 | 看整月 / 整年 |
| 统计趋势 | 折线 / 热力图 |
| 主题 | 深色 / 浅色 / OLED |
| Material You | 颜色取自壁纸 |

## 关键能力

| 能力 | 说明 |
|------|------|
| 端到端加密 | 服务端不可读 |
| 跨平台 | Android + iOS |
| Flutter 单代码库 | 一份代码两平台 |
| Material You | 现代 Android 视觉 |
| 开源 | 可自托管同步 |
