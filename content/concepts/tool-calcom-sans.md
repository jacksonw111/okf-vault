# cal.com/sans

## 它是什么

**cal.com/sans** 是 [Cal.com](https://github.com/calcom) 开源的一款**可变字体（variable font）**——主打"用一个字体文件覆盖 UI 全部字号"。

设计目标很具体：

- 覆盖 **8pt 正文 → 45pt 标题**的字号范围。
- 当替换 Inter / SF Pro / Roboto 等常见 UI 字体时，**保持垂直比例一致**。
- 这样做的好处：按钮、徽章、输入框等组件**不用再为新字体重新调间距**。

## 为什么用它 / 适合什么场景

- 想换掉 Inter / SF Pro / Roboto，但又怕引入新字体后**整套 UI 间距需要返工**。
- 想要一个开源、可商用的可变字体。
- 希望字体在正文 / 标题之间过渡自然而不需要"正文用一套、标题再换一套"。

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | 可变字体（一个文件覆盖多字号） |
| 字号覆盖 | 8pt 正文 ~ 45pt 标题 |
| 替换目标 | Inter / SF Pro / Roboto 等 UI 字体 |
| 垂直比例 | 与上述字体一致，组件间距不需要返工 |
| 授权 | 开源 |
| 维护方 | Cal.com |
