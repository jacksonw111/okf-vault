# Shoin / 書院

## 它是什么
[nol00p/Shoin](https://github.com/nol00p/Shoin) 是用 **Rust** 写的**终端 Markdown 编辑器**，名字取自日式「書院」（书斋）：界面只有居中的一列文字，菜单 / 文件树 / 状态行 / 工具栏**统统没有**——需要某个面板就按一个键唤起，用完即走，回到纯文字。

设计哲学接近「**回到纸笔**」：

- 屏幕中央就一段文字，四周全空；
- 无侧栏、无缩略图、无打开文件列表；
- 想保存？按一个键。想打开？按一个键；
- 适合在终端里长篇写作、记笔记、写博客草稿。

## 为什么用它 / 适合什么场景
- 写长文 / 博客 / 笔记时**不想被 IDE 式侧栏 / 标签页分心**；
- 终端党 + Rust 党想要一个**真正为写作设计的** Markdown 工具；
- 想用最少按键完成「写 → 保存 → 退出」的最短路径；
- 喜欢「**禅模式**」编辑器（类似 FocusWriter、Q10 的终端版思路）。

## 关键能力

| 能力 | 说明 |
|------|------|
| 极简 UI | 只有一列文字，零装饰 |
| 按需面板 | 文件树 / 菜单 / 命令按一个键才出现 |
| Markdown 原生 | 专为 `.md` 工作流设计 |
| Rust 实现 | 单二进制、跨平台、启动快 |
| 沉浸写作 | 视觉噪音最小化 |
