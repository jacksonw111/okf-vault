# AgentTrail

## 它是什么

编码 Agent 跑起来后，最难受的是"我不在时它到底在干嘛 / 改了哪些文件 / 在哪个步骤卡住了"。`AgentTrail` 把代理的实时工作状态画成一张可缩放的项目地图——文件、目录、计划节点都是地图上的元素，状态变化通过颜色 / 连线 / 动画呈现；用户走开回来时一眼能看出代理当前在做什么、有没有推进。

## 关键能力

| 能力 | 说明 |
|------|------|
| 可缩放的项目地图 | 全局 / 局部都能看，单文件可放大 |
| 实时状态可视化 | 改哪些文件 / 卡哪个步骤 / 计划进度都在地图上 |
| 适合"离开再回来"工作流 | 解决 Agent 后台跑时心里没底的痛点 |
