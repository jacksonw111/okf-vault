# The Minimalist Entrepreneur Skills（slavingia/skills）

## 它是什么

[slavingia/skills](https://github.com/slavingia/skills) 是 Gumroad 创始人 Sahil Lavingia 把《The Minimalist Entrepreneur》（中文版《小而美》）一书方法论整理成 AI Agent 可直接调用的 Skills 集合。覆盖独立开发、个人品牌的几个常见场景与步骤。

## 内容来源

- 原书：《The Minimalist Entrepreneur》（Sahil Lavingia）
- 中文版：《小而美》——一本关于独立开发的书，故事与方法论都非常真实 / 接地气
- 转化：作者亲自把方法论打包成 Agent Skills

## 适用场景

- 想做个人产品 / 个人品牌，但不想从零摸索
- 想让 AI Agent 按「小而美」的方法论给建议 / 拆任务
- 已读过原书，想把方法论结构化喂给 Agent

## 关键能力

| 能力 | 说明 |
|------|------|
| Skills 化方法论 | 把书里散落的方法论点变成可调用的 Skill |
| 多场景覆盖 | 拆成几个常见场景与步骤 |
| Agent 可调用 | 直接对接 Claude Code / Codex 等 agent |
