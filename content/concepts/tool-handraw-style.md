# handraw-style

## 它是什么

[yang0/handraw-style](https://github.com/yang0/handraw-style) 是**手绘风格菜单库**：把 **261 种手绘风格全部编号**——选一个编号 + 主题，得到对应的中英文生图提示词，需要时还能调用编号参考图。

## 核心特性

| 特性 | 说明 |
|------|------|
| 261 风格 | 海量覆盖 |
| 编号化 | 选号即用 |
| 双语提示词 | 中英都有 |
| 参考图可调 | 编号关联 |

## 为什么用它 / 适合什么场景
- 想快速在 261 种手绘风格里挑一个。
- 配 Nikola 等手绘视频生成器。
- 不想每次自己写风格提示词。

## 关键能力

| 能力 | 说明 |
|------|------|
| 261 风格 | 编号菜单 |
| 双语提示词 | 中文 + 英文 |
| 编号参考图 | 视觉化检索 |
| 主题输入 | 主题 + 编号 = 提示词 |
