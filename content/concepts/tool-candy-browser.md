# Candy Browser（Kotlin + Compose 安卓浏览器）

## 它是什么

一个开源安卓浏览器：Kotlin + Jetpack Compose 实现，界面走 **Material 3 Expressive** 那套动态取色（跟随壁纸 / 系统主题变色）。许可 MPL 2.0，Android 13 起步。

![](https://pbs.twimg.com/media/HRRaVwKawAATFsi.jpg)

## 关键能力

| 项 | 说明 |
|----|------|
| 技术栈 | Kotlin + Jetpack Compose |
| 设计语言 | Material 3 Expressive，动态取色 |
| 许可 | MPL 2.0 |
| 系统要求 | Android 13 及以上 |

## 为什么值得看

- 想学 Jetpack Compose 与 Material 3 Expressive 在**完整应用**（而非 demo）里的落地方式，浏览器是一个复杂度足够的样本。
