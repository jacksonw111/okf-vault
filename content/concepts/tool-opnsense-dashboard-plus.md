# OPNsense Dashboard Plus

## 它是什么

**OPNsense Dashboard Plus** 是 claudioguareschi 维护的 OPNsense 仪表盘增强插件集——在 OPNsense 自带 dashboard 基础上**加 11 个增强 widget**，并提供一个把防火墙实时流量与封锁记录画在世界地图上的「**Firewall Map+**」。

## 为什么用它 / 适合什么场景

- **网络可视化**：实时流量 + 封锁记录画在地图上，一眼看出攻击源 / 流量方向
- **运维提效**：替代 OPNsense 自带朴素 widget，更适合 SOC / NOC 日常盯盘
- **自托管**：与 OPNsense 同生态，跑在自己防火墙里

## 关键能力

| 能力 | 说明 |
|------|------|
| 11 个增强 widget | 替换 OPNsense 默认 dashboard |
| Firewall Map+ | 流量与封锁 IP 地理可视化 |
| 实时数据 | 直接挂 OPNsense 接口拿实时数据 |
| 自托管 | 与 OPNsense 部署在同一台机器 |
| 开源 | 可定制 / 二次开发 |
