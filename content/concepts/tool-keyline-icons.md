# Keyline Icons

## 它是什么
[Keyline Icons](https://keylineicons.com) 是**专门为 shadcn 生态打磨的开源 Keyline 风格图标集**。Keyline 是现代 UI 图标常见的一致笔画骨架：每条线对齐到固定栅格、拐角统一弧度、视觉重量在不同尺寸下都稳定。围绕这个风格，库内每个图标都用同一套几何规范画。

首批发布六天内已迭代六版：从 503 增至 585 个图标，三个包（React / MCP / CLI）累计 2,025 次下载，每周约 1,250 人访问站点；0.2.0 一次补了 34 个图标（盾牌家族、选择栅格、百分比、标签、工具与电源等），并按社区请求加入了扳手 / 锤子 / 卷笔刀 / 直尺。

## 为什么用它 / 适合什么场景
- 项目基于 shadcn / Tailwind，需要**视觉重量与 shadcn 默认风格一致**的图标；
- 想在 React 应用 / MCP 服务 / CLI 工具中复用同一套图标资源（三个 npm 包同源）；
- 在 Figma 里设计时希望图标库和实现端**像素级对齐**（含 Figma 社区文件 + Figma 插件）；
- 不想被署名条款或付费授权捆住——MIT、无署名、可商用。

## 关键能力
| 能力 | 说明 |
|------|------|
| 图标数量 | 585 个（首发六天增长 16%） |

| 协议 | MIT，零署名要求 |
| 迭代节奏 | 0.2.0 已补 34 图标；社区请求可被接纳进下一版 |
