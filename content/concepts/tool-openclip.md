# OpenClip

## 它是什么

[ganeshmshetty/openclip](https://github.com/ganeshmshetty/openclip) 是一款**开源 macOS 文本效率工具**。在任何 App 中选中文字后，OpenClip 会在选区旁浮出一条操作栏，提供复制 / 变换大小写 / 算式求值 / AI 改写等动作；按 `⌥⌘C` 还能打开覆盖整个动作库的模糊搜索面板，常用动作按使用频率排在前面。

## 为什么用它 / 适合什么场景

- 需要跨 App 复用同一套文本动作（改写 / 翻译 / 求值 / 复制等）。
- 想用模糊搜索一键调用一条不常用动作，不必逐个去菜单里找。
- AI 改写、解释等高频任务想免去切窗口的摩擦。

## 关键能力

| 能力 | 说明 |
|------|------|
| 浮窗操作栏 | 选中文本后在选区旁浮出动作按钮，原位即可执行 |
| 模糊搜索面板 | `⌥⌘C` 一键唤起，按使用频率排序常用动作 |
| 算式求值 | 把选中文字当算式直接算出结果回填 |
| AI 改写 | 对选中段落直接做 AI 改写 / 翻译 / 解释 |
| 跨 App | 任何 macOS 应用里都能唤起，不绑死某一编辑器 |
