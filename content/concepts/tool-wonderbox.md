# WonderBox（Mac 本机系统工具箱）

## 它是什么

[WonderBox](https://github.com/jasonwong1991/WonderBox) 是 jasonwong1991 开源的 **Mac 本机系统工具箱**——把日常系统维护工具**集中到一个 app**：

| 功能 | 说明 |
|------|------|
| 系统监测 | CPU / 内存 / 磁盘 / 网络 |
| 内存优化 | 释放缓存 / 主动清理 |
| 缓存清理 | 系统 / 应用缓存 |
| 应用卸载 | 完整卸载（含残留文件） |
| 磁盘分析 | 大文件 / 占用可视化 |
| 风扇控制 | 手动调速 |
| 防休眠 | 防止系统进入休眠 |

## 为什么用它 / 适合什么场景

- 想要一个**不联网的 Mac 系统工具箱**——不上传任何遥测。
- 嫌 macOS 自带的「**存储管理**」功能分散、藏得深。
- 需要手动**控制风扇转速**（游戏 / 渲染 / 高负载）。
- 想**批量卸载应用并清理残留**，避免应用删了但配置还在。

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | Mac 本机应用 |
| 隐私 | 完全本地运行 |
| 模块 | 监测 / 优化 / 清理 / 卸载 / 磁盘 / 风扇 / 防休眠 |
