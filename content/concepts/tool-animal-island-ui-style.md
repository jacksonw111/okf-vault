# animal-island-ui-style

## 它是什么

[guokaigdg/animal-island-ui](https://github.com/guokaigdg/animal-island-ui) 是一个**动森风格的设计 Skill**：把"温暖 / 自然 / 圆润 / 轻游戏化"的岛屿 UI 视觉语言沉淀成一套设计 Token + 组件规则。

## 两种作图方式

### 01. 先生成网页，再截图导出图片

最简单稳定的方法——让 Agent 创建固定尺寸的 HTML 海报，按 Skill 规范排版，再浏览器截图导出 PNG。

适合：文章封面 / 知识卡片 / 数据海报 / 教程流程图 / 小红书或公众号配图 / 中文社交媒体图片。

### 02. 提炼视觉体系，再交给生图模型

提炼视觉风格给图像生成模型用，输出包含：风格定位、配色、造型语言、材质、字体、构图、正反向提示词等。

适合：场景插画 / 概念性配图 / 无文字封面 / 背景素材。

进阶玩法：**先生成无文字主体插画 + HTML 海报叠标题文字 + 浏览器截图**——兼顾表现力与中文排版准确性。

## 为什么用它 / 适合什么场景

- 想做\"动森风\"的海报 / 配图 / UI。
- 想给 AI 喂一套\"温暖游戏化\"的设计语言。
