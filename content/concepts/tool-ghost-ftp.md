# Ghost-FTP

## 它是什么

[bren-wp/Ghost-FTP](https://github.com/bren-wp/Ghost-FTP) 是一款 Windows / Linux 桌面端的 **FTP / FTPS / SFTP** 客户端：站点保存、排队上传 / 下载、**直接改远端文本**等功能塞进同一个窗口；并**砍掉遥测和账号登录**——纯本地工具，不收集任何用户数据。

## 为什么用它 / 适合什么场景

- 还在维护老 FTP 服务器、想换 FileZilla 但又怕遥测。
- 想用一个工具同时管 FTP / FTPS / SFTP，不装三个客户端。
- 想直接在 GUI 里改远端文件，不用下载 → 编辑 → 上传。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多协议 | FTP / FTPS / SFTP 共用界面 |
| 站点保存 | 一次配置多次复用 |
| 传输队列 | 多文件排队上传 / 下载 |
| 远端编辑 | 直接打开远端文本编辑保存 |
| 跨平台 | Windows + Linux |
| 隐私 | 无遥测、无账号登录 |
