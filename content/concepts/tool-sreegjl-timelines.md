# timelines（sreegjl/timelines）

[sreegjl/timelines](https://github.com/sreegjl/timelines) 是一个**本地优先的时间线创建工具**,专注于**世界构建（worldbuilding）和历史研究**场景下的交互式时间线可视化。

## 它解决的问题

写小说 / 编剧本 / 做游戏世界观，或者做历史 / 史料研究，经常需要：
- 把零散事件按时间排成一条线
- 同一个时间点挂多个事件 + 角色 + 地点
- 能缩放 / 跳转 / 关联的交互视图

通用时间线工具大多偏向项目管理（甘特图），世界构建需要的「事件 + 角色 + 地点 + 章节定位」它支持得很少；纯文本编辑器又缺乏视觉化。

本工具的定位是**给创意写作者 / 历史研究者**一个本地、轻量、可交互的时间线工作台。

## 关键能力

| 能力 | 说明 |
|------|------|
| 本地优先 | 数据存在本地，不必依赖云服务 |
| 免费开源 | MIT 类开源协议 |
| 交互式时间线 | 可缩放 / 跳转 / 关联事件 |
| 面向世界构建 | 适配虚构 / 半虚构世界的事件—角色—地点体系 |
| 历史研究适配 | 支持史料排比、年代换算 |

## 适用场景

- 写奇幻 / 科幻小说需要构建世界观时间线
- 历史爱好者整理朝代 / 战役 / 人物年表
- TRPG / 跑团 DM 管理多线剧情时间
- 游戏策划记录版本与剧情节点
