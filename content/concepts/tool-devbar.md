# DevBar（页面元素批注直发编码 Agent）

## 它是什么

一条注入页面的工具栏，把「设计走查」和「让 Agent 改代码」接在一起：**点选页面上的任意元素 → 写下修改意见 → 一键发给编码 Agent，或复制到剪贴板**贴进任意 AI 编辑器。

## 为什么用它 / 适合什么场景

- 走查时看到某个按钮间距不对，描述「哪个按钮」往往比描述「怎么改」更费劲——直接点选元素省掉这段沟通。
- 设计 / 产品同事不写代码，也能产出 Agent 可直接执行的修改指令。

## 关键能力

| 能力 | 说明 |
|------|------|
| 元素点选 | 工具栏内选中页面任意元素作为批注锚点 |
| 批注 | 对选中元素留下修改说明 |
| 出口 | 发送给编码 Agent，或复制到剪贴板 |
| 可定制 | 100% 免费，可自定义外观并通过官方 API 集成 |
