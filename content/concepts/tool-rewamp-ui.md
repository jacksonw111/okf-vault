# Rewamp UI

## 它是什么
一个**新发布的开源 UI 组件库**，定位现代站点：70+ 组件，覆盖从 shader 与动画到 navbar / 按钮 / 卡片的基础件与动效件，copy-paste 可用。

## 为什么用它 / 适合什么场景
- 想一站式拿到「基础件 + 动效件 + 视觉件」的 UI 库。
- 需要给 Landing / Docs / Marketing 站拼一套组件而不想拼多个库。
- 喜欢现代站点常见的 shader 背景 / 滚动动画 / 卡片 hover 效果。

## 关键能力
| 能力 | 说明 |
|------|------|
| 组件数 | 70+ |
| 覆盖 | shader / 动画 / navbar / 按钮 / 卡片等 |
| 授权 | 完全免费 |
| 形态 | 站点直接 copy-paste |
