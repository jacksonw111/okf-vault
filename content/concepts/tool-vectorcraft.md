# VectorCraft

## 它是什么

[VectorCraft](https://github.com/storytold/vectorcraft) 是 storytold 团队用**纯 Rust** 写的**开源矢量绘图程序**：

- 按 **Illustrator** 的布局、工具、菜单、面板、快捷键做 **clean-room 重写**
- 跨平台原生：macOS / Windows / Linux / FreeBSD
- 同一套代码通过 **WebAssembly** 跑在浏览器
- 让 **AI Agent 通过 MCP 直接操作画布**

## 为什么用它 / 适合什么场景

- **Illustrator 老用户**：习惯 Adobe 范式的人
- **不想付 Adobe 月费**：开源 + 商用友好
- **跨平台一致体验**：桌面 / 浏览器都用同一套代码
- **Agent 画矢量图**：MCP 让 Agent 自动出 logo / icon / 海报

## 关键能力

| 能力 | 说明 |
| ------ | ------ |
| 引擎 | Rust 写 |
| 工作流 | Illustrator 布局 / 工具 / 面板 / 快捷键一致 |
| 跨平台 | macOS / Windows / Linux / FreeBSD 原生 |
| 浏览器 | 同一代码经 WebAssembly 运行 |
| MCP | Agent 可调用操作画布 |
| 形态 | 开源矢量绘图 |
