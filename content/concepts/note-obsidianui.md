# ObsidianUI（开源动效组件库）

## 是什么

[obsidianui.dev](https://obsidianui.dev) 是一个**开源动效组件库**。它把「以前做炫酷交互得自己硬啃」的常见 UI 模式**预制为可直接复用的组件**，让前端开发者用「现成积木」拼装出高级感交互。

## 覆盖的组件类型

| 类型 | 示例 |
|------|------|
| 按钮 | 悬浮变形 / 涟漪 / 描边跟随 |
| 菜单 | 弹性展开 / 视差堆叠 |
| 画廊 | 3D 翻转 / 鼠标驱动视差 |
| 滚动动效 | 滚动驱动位移 / 模糊 / 显隐 |
| 光标特效 | 跟随光斑 / 涟漪扩散 / 磁性吸附 |
| 文字揭示 | 字符级动画 / 渐显 / 擦除 |

## 适合谁

- 想给作品集 / 落地页 / SaaS 营销站加「高级感」动效但不想从头实现的前端开发者。
- 设计 / 前端从业者寻找「动效参考实现 + 可复用代码」的资源站。
- 想研究「滚动驱动动画 + 光标交互」实现细节的工程师。
