# m3e-canvas

## 它是什么

`m3e-canvas` 是一个面向 Material 3 Expressive（M3E）规范的开源 UI 设计师工具：用户在网页上组装 UI（拖组件、调样式），工具会自动产出可直接喂给 AI 编码 Agent 的 prompt（Codex / Coze / Doubao / Gemini Apps 等）。特别适合 Android 应用的 vibe coding——先用 m3e-canvas 把 UI"摆"出来，再把产出的 prompt 丢给编码 Agent 生成代码。

## 关键能力

| 能力 | 说明 |
|------|------|
| 可视化 UI 装配 | 拖组件 / 调样式即所见即所得 |
| 自动生成 AI prompt | 装配完成即可产出 Agent 友好的 prompt |
| Material 3 Expressive 规范 | 默认走 M3E 设计语言 |
| 多 Agent 兼容 | Codex / Coze / Doubao / Gemini Apps 等可直接消费 |
