# cmdOS（键盘优先的浏览器命令终端 Chrome 扩展）

## 它是什么
`22a31a0527/cmdOS` 是一个**键盘优先**的浏览器 Chrome 扩展：
- `Alt+S` 唤出命令栏
- 集中执行**搜索 / 浏览器命令 / 网页快捷操作**
- 数据**本地存储**（不上传到任何服务器）

## 为什么用它 / 适合什么场景
- 想给 Chrome 装一个 **Spotlight / Raycast 风格的命令面板**：所有动作按几个键完成。
- 想让浏览器**键盘可控**而不是鼠标堆操作。
- 重视隐私（不想让任何 SaaS 记录命令历史）。
- 适合：重度键盘用户 / 隐私党 / 不想用付费命令面板的 Chrome 用户。

## 关键能力
| 能力 | 说明 |
|------|------|
| Alt+S 唤出 | 全局快捷键 |
| 命令统一 | 搜索 / 浏览器操作 / 页面快捷键集中 |
| 本地数据 | 不联网、零上传 |
| 键盘优先 | 不依赖鼠标 |
| Chrome 扩展 | 一键安装 |
