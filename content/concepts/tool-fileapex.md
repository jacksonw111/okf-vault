# FileApex（byhowiecreations/FileApex）

## 它是什么
[`byhowiecreations/FileApex`](https://github.com/byhowiecreations/FileApex) 解决「同一局域网内的 Android、macOS、Windows 设备想互传、群发文件」的痛点：不必搭服务器，也不必手动敲 IP，FileApex 把这些设备**直接配对**起来传输文件。

## 为什么用它 / 适合什么场景
- 想在公司 / 家里局域网内把手机拍的照片直接拖到电脑 / 反向传过去，不依赖云盘。
- 团队临时「把这一份 demo 推到所有设备上」——群发到多台设备时省事。
- 不想装某品牌官方「全家桶」类同步工具。

## 关键能力
| 能力 | 说明 |
|------|------|
| 跨平台 | 同时支持 Android / macOS / Windows |
| 局域网直连 | 不依赖外网 / 不上传云 |
| 自动配对 | 设备发现免手动敲 IP |
| 单传 / 群发 | 支持一对一与一对多推送 |
