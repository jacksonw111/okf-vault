# rakazo (akazo)

## 它是什么
`elie222/rakazo`（项目品牌名 **akazo**）是一个**开源替代 Grok Bot / Grok 风格聊天应用**的多端项目。整套系统用 **Cursor + Grok 4.6** 构建，**一份代码库**同时产出 **Web**、**桌面 (Electron)** 和 **移动端** 三种形态，对希望自托管或私有化部署「类 Grok 体验」的人非常友好。

## 为什么用它 / 适合什么场景
- 想用 Grok 风格（实时信息、长上下文、幽默感）的聊天体验，但不想被绑死 xAI 账户。
- 需要把聊天机器人作为产品 / 服务分发，自带 Web / 桌面 / 移动三端。
- 公司内部 / 学校内部要一个可控、有版权的对话 UI。
- 拿来当 Cursor + Grok 4.6 全栈 demo 看怎么用 Cursor 串起多端开发。

## 关键能力
| 能力 | 说明 |
|------|------|
| 一库三端 | 单代码库生成 Web、Electron 桌面、移动端（React Native / Capacitor 等） |
| Grok 风格 UI | 仿照 Grok Bot 的交互与视觉风格 |
| Grok 4.6 接入 | 默认连 Grok 4.6，可换 OpenAI / Anthropic / 本地模型 |
| 开源可改 | 比 Grok 官方 bot 多一层定制能力：UI、品牌、模型、数据都归自己 |
