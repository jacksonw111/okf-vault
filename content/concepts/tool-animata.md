# animata

## 它是什么

[animata.design](https://animata.design) 是一个**免费开源的手绘动画组件库**：

| 维度 | 说明 |
|------|------|
| 组件数量 | 155+ |
| 风格 | 手绘动画 |
| 收录标准 | 每个组件**先在实际产品里跑过**才收录 |
| 可访问性 | 键盘焦点 / 屏幕阅读器 / 弱动效降级**全部内置** |
| 协议 | MIT 永久免费 |

## 为什么用它 / 适合什么场景

- 想要**手绘 + 动画**风的 UI（亲切、有温度）。
- 重视可访问性，不想每个组件自己处理焦点 / SR。
- 想做有质感的「Loading / 微交互」。

## 关键能力

| 能力 | 说明 |
|------|------|
| 155+ 组件 | 手绘动画 |
| 实测验证 | 每个组件都跑过 |
| 键盘焦点 | a11y 内置 |
| 屏幕阅读器 | SR 友好 |
| 弱动效降级 | `prefers-reduced-motion` 自动降级 |
| MIT 永久免费 | 商用 OK |
