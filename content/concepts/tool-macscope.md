# macscope

## 它是什么
[rsm23/macscope](https://github.com/rsm23/macscope) 是一个**原生 macOS 应用**，把**系统监控 + 进程管理 + macOS 控制 + 常用小工具**集成到**单个原生界面**里，专为 Apple Silicon Mac 优化。

它替代了日常要打开多个 App 才能完成的事：

- **系统监控** → 替代 `活动监视器` / `iStat Menus` 的部分功能；
- **进程管理** → 比「强制退出」窗口更直观；
- **macOS 控制开关** → 集中放置平时藏在「系统设置」深处的开关；
- **常用小工具** → 屏幕清洁、磁盘清理、缓存刷新等。

## 为什么用它 / 适合什么场景
- 想**少开几个 App**——把零碎系统管理动作收进一个窗口；
- 喜欢「**瑞士军刀式**」桌面工具（类似 Windows 上的 PowerToys）；
- 想要**Apple Silicon 原生**（不是 Electron，不是 Rosetta）；
- 想避免被多个付费系统工具订阅割肉。

## 关键能力

| 能力 | 说明 |
|------|------|
| 系统监控 | CPU / 内存 / 磁盘 / 网络 / 风扇 |
| 进程管理 | 一键查 / 杀进程，定位资源占用 |
| macOS 控制 | 集中化系统设置开关 |
| 小工具合集 | 屏幕清洁、磁盘清理等常用动作 |
| Apple Silicon 原生 | M1+ 优化，非 Rosetta |
