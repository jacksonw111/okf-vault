# InkOS

面向电子墨水屏的内容系统，在服务端抓取并重排网页内容，设备端只接收页面帧与点击区域。

## 适用场景

- 需要使用 Chromium 抓取 RSS 或网页，提取语义结构并按屏幕尺寸重排的场景。

## 关键能力

| 能力 | 说明 |
|------|------|
| 服务端处理 | 使用 Chromium 抓取 RSS 或网页，提取语义结构并按屏幕尺寸重排。 |
| 轻量设备端 | ESP32 只接收渲染好的页面帧和点击区域，降低计算与耗电。 |
