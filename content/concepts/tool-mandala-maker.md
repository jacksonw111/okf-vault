# Mandala Maker

## 它是什么
一个**网页曼陀罗画板**：用户随手画一笔，工具会按选定的折数绕中心复制、并在每个折内镜像，画完一键导出 PNG 或 SVG。

> 想随手画曼陀罗、又不想装软件——开网页就能画。

## 为什么用它 / 适合什么场景
- 临时想画曼陀罗 / 对称图案但不想装专业软件。
- 给艺术 / 冥想 / 教学场景做对称构图演示。
- 需要 PNG / SVG 两种导出格式，分别用于展示或后续矢量加工。

## 关键能力
| 能力 | 说明 |
|------|------|
| 形态 | 网页画板 |
| 对称算法 | 按选定折数绕中心复制、折内镜像 |
| 导出 | PNG / SVG |
| 安装 | 无需安装 |
| 部署 | GitHub Pages 静态托管 |
