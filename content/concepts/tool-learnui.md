# learnui

## 它是什么

[`learnui`](https://github.com/joeseesun/learnui) 是一个**中英双语 UI 视觉词典**网站。看见某个界面元素、视觉风格，你想用 AI 编程代理复刻却不知道怎么描述？它告诉你那个东西**到底叫什么**——精准的术语名字比一长串形容词对 LLM 更有效。

## 解决什么痛点

- 想让 AI 做「那种空灵带点水墨感的卡片」——但「水墨感」会被各种模型理解成不同东西；
- 看见一张截图想描述给 agent：「那个角有点斜切、底下有点阴影、中间字体是衬线的」——其实这些都有**专业术语**；
- 设计师与开发者之间、设计师与 AI 之间的「翻译鸿沟」。

## 关键能力

| 能力 | 说明 |
|------|------|
| 中英对照 | 同时给中文 + 英文术语名，方便跨语言 prompt |
| 视觉示例 | 每条术语配视觉示意，所见即所名 |
| AI 友好术语 | 术语直接是 AI 能识别 / 学习的标准词，不是生造黑话 |
| 词典形态 | 翻一翻找需要的词，不强制读完整教程 |
