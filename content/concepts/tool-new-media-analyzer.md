# new-media-analyzer（新媒体内容复盘工具）

## 它是什么

[new-media-analyzer](https://github.com/binghe1980/new-media-analyzer) 把新媒体运营里最常用的三个平台——**抖音、公众号、小红书**——的账号内容抓下来、转写成文字，再用**图表**与 **AI 报告**做内容复盘。

## 工作流

1. **抓取**：从抖音 / 公众号 / 小红书抓取账号内容（视频脚本 / 图文 / 标题等）。
2. **转写**：把视频 / 图片内容转写为可检索文字。
3. **可视化**：用图表展示内容主题分布、热度趋势、互动数据等。
4. **AI 报告**：调用 LLM 对复盘结果生成结构化分析。

## 为什么用它

- 「**数据复盘**」是新媒体运营的核心环节，但跨平台数据散落——抖音看视频数据、公众号看阅读数据、小红书看种草数据，**没有统一视角**。
- new-media-analyzer 把三平台拉到一个仪表盘上，便于发现跨平台的内容偏好差异。
- 「**AI 报告**」让不会写分析报告的人也能拿到结构化总结。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多平台抓取 | 抖音 / 公众号 / 小红书 |
| 内容转写 | 视频 / 图文 → 文字 |
| 图表可视化 | 主题 / 热度 / 互动维度 |
| AI 报告 | 自动生成结构化复盘 |
| 自托管 | 数据不出本地 |
