# ai-agent-guide

[ai-agent-guide](https://github.com/fuzhengwei/ai-agent-guide) 是一套**中文 AI Agent 入门进阶可视化教程**,把 21 章内容做成带动画流程图的可视化课本,每章配题库和随时提问的 AI 助教,整个站纯静态。

## 内容结构

6 大篇章,21 章:

| 篇章 | 覆盖内容 |
|------|----------|
| 1 | 大模型基础 |
| 2 | Function Calling |
| 3 | MCP(模型上下文协议) |
| 4 | Skills(代理技能包) |
| 5 | 多 Agent / LangGraph |
| 6 | RAG / 评测可观测 / 安全防护 / 部署运维 / 2026 趋势 |

## 每章三页签

- 📖 **文章** — 主讲内容
- 🧠 **八股** — 概念速记 / 面试题风
- 📝 **考试** — 选择 / 填空 / 简答,自测

## 配套能力

| 能力 | 说明 |
|------|------|
| 可视化流程图 | 章节内嵌动画流程图,降低初学门槛 |
| AI 助教 | 章节末尾挂着对话窗,可对当前章节提问 |
| 纯静态 | 无后端依赖,Nginx 一行 serve |
| 可二次部署 | Fork 即可拥有自己的学习站点 |

## 适合什么场景

- 中文世界 AI Agent 工程师**入门路径**(尤其求职 / 转岗)。
- 高校 / 培训机构的 AI Agent 课程**教学底版**(免费、可改造)。
- 想给团队做**内部分享 / onboarding 资料**时的现成起点。
