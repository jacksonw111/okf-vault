# CourtMind

## 它是什么

[CourtMind](https://github.com/HuangZeLinCute/CourtMind) 是一个**羽毛球比赛视频结构化分析工具**：

> 把羽毛球比赛视频自动转成球场标定、球员与羽毛球轨迹、Rally 切分和击球统计，再让 LLM 基于这些结构化数据回答对局问题。

## 为什么用它 / 适合什么场景

- 业余羽毛球 / 校队训练需要复盘比赛但**没有专业数据团队**。
- 想用自然语言问「**这一分为什么丢**」而不是手动看录像。
- 想把视频分析结果导入训练计划 / 战术讲解。

## 关键能力

| 能力 | 说明 |
|------|------|
| 球场标定 | 自动识别球场边界 |
| 球员轨迹 | 追踪每位球员移动 |
| 羽毛球轨迹 | 羽毛球飞行路径 |
| Rally 切分 | 自动按回合划分 |
| 击球统计 | 出手数 / 类型 / 落点 |
| LLM 问答 | 用自然语言查对局问题 |
