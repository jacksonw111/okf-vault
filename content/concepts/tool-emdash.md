# EmDash

## 它是什么

[EmDash](https://emdashcms.com/blog/emdash-1-1) 是 **EmDashCMS** 维护的开源 AI Coding 后台任务运行器——把多 Agent / 多任务的并行执行收进统一入口。

## 关键能力

| 能力 | 说明 |
|------|------|
| 升级 | `pnpm up --latest emdash` 一行命令完成 1.1 升级 |
| 后台任务 | AI 编码任务可以脱离前台跑 |
| 并行 | 多 Agent / 多任务可同时调度 |
| 生态 | 与 Cursor / Claude Code 等 CLI 协同 |

## 适合场景

- 一天要跑多个 AI 编码任务并行
- 想让 Agent 在后台「挂着」而不是占前台
- 已用 pnpm 生态
