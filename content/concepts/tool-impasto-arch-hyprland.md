# Impasto（Arch Linux + Hyprland + Quickshell 一体化桌面）

## 它是什么

[andreumassanet/impasto](https://github.com/andreumassanet/impasto) 为 **Arch Linux + Hyprland** 配一套**开箱即用的 Quickshell 桌面环境**：一条安装脚本装好「灵动岛式」状态栏、桌面小组件、笔记任务与全套应用主题，**换壁纸时整套配色跟着走**。

## 关键能力

| 能力 | 说明 |
|------|------|
| 一键安装 | 一条安装脚本装好整套 |
| 灵动岛状态栏 | 顶部居中状态栏 |
| 桌面小组件 | 笔记、任务等小组件 |
| 主题联动 | 换壁纸自动换整套配色 |
| Hyprland 原生 | 跑在 Hyprland 合成器上 |
| Quickshell | Quickshell 状态栏框架 |
| Arch 专精 | Arch Linux 生态 |

## 适合谁

- 跑 Arch + Hyprland，想一次性配好整套桌面
- 想要「灵动岛式」状态栏
- 想用 Pywal 风格的壁纸自动主题
