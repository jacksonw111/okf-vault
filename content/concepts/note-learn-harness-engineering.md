# Learn Harness Engineering

## 它是什么

[Learn Harness Engineering](https://walkinglabs.github.io/learn-harness-engineering/en/) 是 **walkinglabs** 维护的 Harness Engineering **开源学习站**——用**可视化 / 交互**的方式把 Harness 设计的核心概念（Loop / Context / Tool / Memory / Eval / Sandbox 等）讲清楚。

## 为什么用它 / 适合谁

- **Harness 工程学习曲线陡**：从「LLM 调 API」到「把 LLM 包成稳定产品」中间要补大量工程知识。
- **可视化降低门槛**：把抽象概念用图 + 交互演示，不必啃论文。
- **团队培训用**：可以作为公司内部「Harness 入门」的指定资源。
