# webcam-settings（把摄像头硬件参数摆出来）

## 它是什么

[webcam-settings](https://github.com/tadas-subonis/webcam-settings) 是一款**摄像头参数调整工具**：很多摄像头软件只给你看画面、把硬件参数藏起来；这款工具把摄像头**真正支持的设置项**全部摆出来——曝光、白平衡、对比度、增益等。

原生跨平台（Windows / macOS / Linux），能调参、能存配置、能查占用，还带 **CLI** 方便自动化 / 脚本控制。

## 为什么用它 / 适合什么场景

- 视频会议 / 直播 / 录制时想要可控、可复现的摄像头参数；
- 想给不同场景（白天 / 夜晚 / 投影仪）保存预设并一键切换；
- 喜欢命令行自动化（脚本里调摄像头）；
- 偏好开源、跨平台、不绑定某家摄像头的工具。

## 关键能力

| 能力 | 说明 |
|------|------|
| 暴露真实参数 | 显示摄像头硬件真实支持的设置 |
| 跨平台 | Windows / macOS / Linux |
| 配置保存 | 把当前设置存为预设 |
| 占用查询 | 查看摄像头当前状态 |
| CLI | 可脚本化 / 自动化 |
