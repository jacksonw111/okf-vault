# Warp

## 定义

**Warp** 是一个用 Rust 写的**现代化终端模拟器**——以 GPU 渲染（高刷新率）、「输入框 + 输出区融合」（命令与结果同处一条记录流）、AI 命令补全 / 自然语言转 shell、原生团队共享 session 与 workflow 为核心差异化能力；面向 macOS / Linux / Windows。

## 要点

- **官网**：[warp.dev](https://warp.dev)
- **核心能力**：
  - GPU 渲染（流畅动画 / 60fps 滚动）
  - 输入框 + 输出流合并（更现代的 UX）
  - AI 命令补全（自然语言 → shell）
  - **Warp Drive**（团队共享 workflow / env / prompt 模板）
  - **Notebooks**（把常用命令 / 文档组织成团队知识库）
- **特点**：闭源（但免费）；现代 macOS / Linux / Windows 原生客户端
- **典型用户**：开发者 / DevOps / 团队
