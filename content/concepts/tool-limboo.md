# Limboo（limboo-ai/limboo）

## 它是什么

`limboo-ai/limboo` 是一款**为 AI 编程代理搭「完整工作环境」的本地桌面应用**：它让**多个 AI 编程代理**在一个**统一的安全体系**下高效协作。

定位是给「同时开多个 Claude Code / Codex / Cursor 干活」的场景提供**统一的工作区**——隔离代理之间的工作目录、凭据、配置文件，避免互相覆盖。

## 为什么用它 / 适合什么场景

- 经常**并发开多个 AI 编程代理**（一个写后端、一个写前端、一个做测试），但**工作目录 / 凭据互相串味**；
- 想在桌面端有**统一入口**调度多个代理，而不是各自起一个终端窗口；
- 重视**安全隔离**——不同代理读写权限不同，敏感凭据不外泄；
- 本地优先：希望工作环境跑在自己的机器上，不想把代码 / 凭据上传云端。

## 关键能力

| 能力 | 说明 |
|------|------|
| 完整工作环境 | 给代理搭一站式「可工作的工作区」 |
| 多代理协作 | 同时管理多个 AI 编程代理 |
| 统一安全体系 | 隔离代理间的工作目录 / 凭据 / 文件 |
| 本地桌面 | 桌面 App 形态，无需云端 |
| 减少串味 | 防止多个代理覆盖彼此产物 |
| 调度入口 | 单一入口集中启动 / 监控 / 终止代理 |
