# xialingguo-ip

## 它是什么

[peggykangkang02/xialingguo-ip](https://github.com/peggykangkang02/xialingguo-ip) 是一套**封面生成 Skill**：给 AI 博主做推文 / 公众号 / 出海教程封面用；9 种默认风格，21:9 横版比例，但比例可改。

## 核心特性

| 特性 | 说明 |
|------|------|
| 9 种风格 | 默认覆盖多数题材 |
| 21:9 默认 | 适合横幅封面 |
| 比例可改 | 任意尺寸 |
| Skill 形态 | 装到 Claude Code / Codex 等 |

## 为什么用它 / 适合什么场景
- 经常发推文 / 公众号 / 教程要封面。
- 想统一视觉风格又有变化。
- 想用 AI 一键生成不必每次自己排版。

## 关键能力

| 能力 | 说明 |
|------|------|
| 9 风格 | 默认覆盖不同题材 |
| 21:9 | 标准横幅比例 |
| 比例可调 | 任意尺寸 |
| Skill 安装 | 一键安装调用 |
