# ultron-by-sagar-builds（SAGAR-TAMANG/ultron-by-sagar-builds）

## 它是什么

[`ultron-by-sagar-builds`](https://github.com/SAGAR-TAMANG/ultron-by-sagar-builds) 是 SAGAR-TAMANG 做的**手势驱动全息 UI Demo**：

- 技术栈：Next.js（应用框架） + Three.js（3D 渲染） + MediaPipe（摄像头手势识别）；
- 视觉风格：致敬《钢铁侠》里 J.A.R.V.I.S. 那种「全息球 + 浮空菜单」；
- 交互方式：通过摄像头捕捉手部动作，**用手「推 / 拉 / 旋转」操控 3D 球形界面**。

## 关键能力

| 能力 | 说明 |
|------|------|
| MediaPipe 手势识别 | 浏览器端、纯前端、不依赖后端 |
| Three.js 3D 渲染 | 全息球 + 浮空 UI |
| Next.js 工程化 | 适合作为 Web 3D UI 的起点工程 |
| 摄像机交互 | 无需额外硬件，笔记本自带摄像头即可体验 |

## 适合什么场景

- 想做「手势交互 Web 应用」的入门参考工程；
- 科幻风 / 全息风 UI 设计演示；
- MediaPipe + Three.js 组合方案的 quickstart；
- 创意 Demo / 个人作品集项目。
