# china-antique-maplibre

## 它是什么
china-antique-maplibre 是一套开源的中国历史地图 MapLibre 渲染栈。它用 MapLibre GL 把「复古羊皮纸质感」的卫星底图、地形阴影、水域叠加到一起，输出适合历史短视频 / 纪录片镜头的视觉效果。

## 为什么用它 / 适合什么场景
- 做历史 / 地理向短视频，想用「带画风的地图」做镜头背景。
- 历史题材网站 / 教学课件需要一份视觉统一的「古代地图」作底图。
- 想做自己的「古代中国地理可视化」项目，不想从零配 MapLibre 样式。

## 关键能力
| 能力 | 说明 |
|------|------|
| 底层 | MapLibre GL |
| 风格 | 复古羊皮纸 |
| 图层 | 卫星底图 / 地形阴影 / 水域叠加 |
| 输出 | 历史短视频镜头 / 教学地图 |
| 主题 | 中国历史 |
