# refactoring-ui-plugin（Refactoring UI 书 → Claude Plugin）

## 它是什么

[refactoring-ui-plugin](https://github.com/gnurio/refactoring-ui-plugin) 是 gnurio 出品的 **Claude Plugin**：把经典 UI 书《**Refactoring UI**》（作者 Adam Wathan / Steve Schoger）的内容转成可被 Claude 加载的插件，让 Claude 学会按这本书的原则把「做得很糙的界面」修得**更专业、更可读**。

## 为什么用它 / 适合什么场景

- 在用 Claude / Claude Code，希望它能按《Refactoring UI》原则审查 / 改造 UI。
- 团队已经读过这本书、想把它落到工具里——让所有代码改动都默认遵循。
- 想要「**开箱即用的 UI 改造助手**」而不是临时 prompt。

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | Claude Plugin |
| 理论依据 | Refactoring UI（Adam Wathan / Steve Schoger） |
