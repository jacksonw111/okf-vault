# creator-agent

## 它是什么

[yvetteYSY/creator-agent](https://github.com/yvetteYSY/creator-agent) 是**创作者的私有内容 Agent**：把自己的文档 / 音频 / 视频扔进库，让观众问问题时 Agent **只按你批准的内容回答**，每句话都给出**引用出处**；私密内容默认锁定，试玩不花模型钱。

## 核心特性

| 特性 | 说明 |
|------|------|
| 多模态入库 | 文档 / 音频 / 视频 |
| 引用式回答 | 句句标注来源 |
| 内容审核 | 只回答已批准内容 |
| 私密默认锁 | 不开放的内容默认隐藏 |
| 免费试玩 | 本地 / 不花模型钱 |

## 为什么用它 / 适合什么场景
- 想给观众一个「我的内容专属问答助手」。
- 想保护没发布的内容不被泄露。
- 不想付云端 API 又想要 RAG 体验。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多模态导入 | 文档 / 音频 / 视频统一 |
| 引用溯源 | 每句给链接 / 时间戳 |
| 内容白名单 | 拒绝回答未批准内容 |
| 私密锁定 | 内部素材默认不外露 |
| 本地优先 | 试玩不烧 API 钱 |
