# Designeer（人工筛选的设计工程目录）

## 它是什么

[Designeer](https://designeer.xyz/) 是一个聚焦「设计工程（Design Engineering）」领域的全景目录：420 个工具、17 个分区、132 位创作者名录。每个条目都由作者本人打开、试用、按界面打磨度评估后才收录，**不靠自动化抓取、不接受付费收录**。

## 适合谁用

- 想系统了解「设计工程」领域有哪些工具
- 设计师 / 前端工程师找资源时被自动化目录的「海量低质」劝退
- 想看创作者名录 / 分区地图，对领域全景有把握

## 关键能力

| 能力 | 说明 |
|------|------|
| 人工实测 | 每条由作者打开、试用、按界面打磨度评估 |
| 17 分区 | 全景分区地图，方便按子领域找 |
| 132 位创作者 | 收录创作者名录 |
| 420 个工具 | 工具全集 |
| 无付费收录 | 不卖榜，保持中立 |
| 无自动抓取 | 避免收录大量低质量站点 |

## 与同类目录的差异

- vs 自动化目录：每条都有「人看过」背书
- vs 商业榜单：完全不卖榜
- vs 单点收录（如 Unikist / useLayouts）：Designeer 覆盖「工具 + 创作者 + 分区」三层
