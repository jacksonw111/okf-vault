# Easel

## 它是什么

[ZJU-REAL/Easel](https://github.com/ZJU-REAL/Easel) 是**浙大 REAL Lab** 等团队打造的**开源 AI 社媒运营智能体**：从「一个想法」出发，走完**发现热点 → 策划选题 → 创作内容 → 真实发布 → 复盘归因**的完整链路，覆盖**小红书、抖音、知乎、B 站**等平台。

定位：

- **不只是给建议，而是直接出成品**：把 OpenClaw Agent、账号画像、112 个内容技能和真实媒体工具串起来，Agent 直接产出可发布内容。
- **覆盖多平台**：国内主流社媒一次性接入。

## 为什么用它 / 适合什么场景

- 自媒体 / MCN 团队希望 Agent 不只「写文案」，而是真的把图文 / 视频发出去并跟踪表现。
- 多平台运营（小红书 + 抖音 + 知乎 + B 站），希望一份 SOP 跨平台复用。
- 关注「复盘归因」——内容发出后想自动汇总表现数据、迭代策略。

## 关键能力

| 能力 | 说明 |
|------|------|
| 端到端流程 | 热点 → 选题 → 内容 → 发布 → 复盘 |
| 多平台 | 小红书 / 抖音 / 知乎 / B 站 |

| 复盘归因 | 发后跟踪表现，迭代策略 |
