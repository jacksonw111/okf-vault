# Mesh Avatar Studio

## 它是什么

[Mesh Avatar Studio](https://github.com/shinshin86/mesh-avatar-studio) 是 **shinshin86** 开源的 **2D 网格头像编辑器**——把「**一张正面半身插画**」作为输入，输出会眨眼、说话、转头、呼吸、摆头发的动态头像，**绑骨骼那步不用自己手动做**。

定位是「**插画师 + 编码代理**」的协作工具：你只管画，骨架 / 形变 / 动画曲线交给 agent 与工具处理。

## 为什么用它 / 适合什么场景

- **插画师不写代码也能产动态头像**——输入一张静态图即可
- **Agent 友好**：整套流程是「图 → 网格 → 骨架 → 形变 → 动画」的 pipeline，能直接被编码代理驱动
- **本地运行**：媒体不离开本机
- 适合做 Live2D 风格的轻量头像、虚拟形象播报、社交头像小动画

## 关键能力

| 能力 | 说明 |
|------|------|
| 输入 | 一张正面半身插画 |
| 输出 | 会眨眼 / 说话 / 转头 / 呼吸 / 摆头发的动态头像 |
| 骨骼 | 自动绑定，无需手工对点 |
| 运行 | 本机 |
| 适合 | 编码代理流水线化生成 |
