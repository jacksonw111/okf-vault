# text-effects.colorion

## 它是什么
[text-effects.colorion.co](https://text-effects.colorion.co) 是一个**免费的文字效果集合**：**81 款开箱即用的文字特效**，由 CSS / WebGL 实现，主打「**落地页 / 营销页 / Hero 区**的视觉点缀」。

定位类似「**文字动效的 swatches**」——打开页面就能逐个看效果，喜欢的直接 copy 代码片段或者照着思路复刻。

## 为什么用它 / 适合什么场景
- 落地页 / 营销页 Hero 区需要**一眼抓住眼球**的文字特效，又不想从零写动画；
- 想要**免费**且**可直接借鉴**的文字动效实现（81 款覆盖足够多风格）；
- 设计 / 前端工程师找**文字动效的灵感**和参考实现；
- 想快速验证某个文字动效的可行性——先在站点里试一遍，再决定要不要搬进产品。
