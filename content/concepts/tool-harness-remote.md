# harness-remote（giuliastro/harness-remote）

## 它是什么

`giuliastro/harness-remote` 是一个**手机端遥控应用**，用来远程控制 **AI 编程助手**（如 OpenCode、Oh My Pi）。不在工位也能查看任务进度、发送指令。

## 为什么用它 / 适合什么场景

- 长任务（跑测试、重构、批量改文件）需要离开工位时，不想中断；
- 想在通勤 / 外出的间隙继续推进 agent 任务；
- 同时管理多台机器上的多个 AI 编码会话，希望有统一移动入口。

## 关键能力

| 能力 | 说明 |
|------|------|
| 移动端控制 | 手机查看 AI 编程助手任务进度 |
| 远程发指令 | 在手机端继续给 agent 派活 |
| 多 agent 支持 | 兼容 OpenCode、Oh My Pi 等 |
