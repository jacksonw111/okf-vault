# Magiviz (ItusiAI/Open-Magiviz)

## 它是什么
[`ItusiAI/Open-Magiviz`](https://github.com/ItusiAI/Open-Magiviz) 是一个**开源、基于 AI 的智能视频创作平台**，前后端均以 **MIT 协议**开源。它把传统视频制作的「写剧本 → 定角色 → 画分镜 → 生成视频 → 成片」全流程全部 AI 化，最长支持生成 **60 秒**的视频，并内置 **12 种主流视频生成模型**可切换使用。

## 为什么用它 / 适合什么场景
- 想做短剧 / 演示视频 / 概念片，但不想用剪映、PR、AE 这种「人工拼」软件。
- 想要从「一句故事大纲」一键到「可发布短视频」的最低摩擦链路。
- 已有 12 家视频模型（Runway / Pika / Kling / 可灵等）的 API key，想统一在一个面板里跑。
- 关心版权与代码可控：MIT 全栈开源，不被某个商业 SAAS 绑死。

## 关键能力
| 能力 | 说明 |
|------|------|
| 剧本 → 视频全流程 | 写剧本 → 定角色 → 画分镜 → 生成 → 成片一条龙 |
| 多模型支持 | 内置 12 种主流视频生成模型，可按场景切换 |
| 60 秒长片 | 一次最长 60 秒，比多数工具的单段上限更长 |
| 角色一致性 | 在分镜阶段先固定角色，再驱动镜头 |
| MIT 开源 | 前后端全部 MIT，自部署、可魔改 |
| 在线体验 | 提供 [magiviz.com](https://magiviz.com) 直接试用 |
