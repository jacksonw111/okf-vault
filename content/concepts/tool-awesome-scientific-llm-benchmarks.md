# Awesome Scientific LLM Benchmarks

## 它是什么

[subinium/Awesome-Scientific-LLM-Benchmarks](https://github.com/subinium/Awesome-Scientific-LLM-Benchmarks) 是一份**精选的科学大模型基准测试清单**（Awesome List 风格），覆盖数学、物理、化学、材料科学、生物和智能体科学，专门给需要评估 LLM 在「科学发现 / 推理」任务上表现的团队。

## 覆盖面

| 学科 | 示例任务方向 |
|------|------|
| 数学 | 形式化证明、定理发现、数论 |
| 物理 | 物理推理、模拟 / 仿真 |
| 化学 | 反应预测、分子生成 |
| 材料 | 新材料筛选、性质预测 |
| 生物 | 蛋白 / 基因 / 序列设计 |
| 智能体科学 | 长任务、多步实验设计 |
