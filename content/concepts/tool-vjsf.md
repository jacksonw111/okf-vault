# VJSF

## 它是什么

[VJSF](https://madewithvuejs.com/vjsf) 是一个**声明式 Vue 表单库**：用**带注解的 JSON schema** 就能为 **Vue / Vuetify** 应用生成完整表单。

## 为什么用它 / 适合什么场景

- 表单字段多且变动频繁（CRM / 后台 / 配置系统）。
- 想让前后端共享表单 schema（schema 即文档）。
- 已有 Vuetify 项目想加 schema 驱动表单。

## 关键能力

| 能力 | 说明 |
|------|------|
| JSON schema 驱动 | schema 即表单定义 |
| Vue 原生 | Vue 3 组件 |
| Vuetify 集成 | 主题与组件库统一 |
| 注解支持 | 用 JSON schema 注解控制 UI |
| 声明式 | 不写组件代码 |
