# 设计与组件灵感 Gallery 站合集

## 它是什么
社区里有一类「**按页面段落 / 组件维度拆解**」的设计灵感站点：每个站点专注一种元素（导航栏、页脚、404、CTA、Bento 网格……），把全球优秀案例集中展示，方便快速寻找参考。

## 主要站点
| 站点 | 关注点 |
|------|------|
| <https://navbar.gallery> | 导航栏 |
| <https://footer.design> | 页脚 |
| <https://404s.design> | 404 页面 |
| <https://cta.gallery> | CTA / 行动召唤 |
| <https://unsection.com> | 区段/分段版式 |
| <https://60fps.design> | 60fps 动效 |
| <https://bentogrids.com> | Bento 网格布局 |
| <https://designspells.com> | 微交互 / 细节 |
| <https://supahero.io> | 营销 hero 段 |

## 适合什么场景
- 设计/前端选型时快速找参考。
- 做 vibe coding 时让 AI 锁定某种版式/组件风格。
- 想系统学习某类页面段落的常见处理方式。
