# Lazymark（终端 Markdown 笔记 + 任务看板）

## 它是什么

[Lazymark](https://github.com/MathiasDrizzy/lazymark) 是 **MathiasDrizzy** 开源的 **Go 写的终端 TUI**：把 **笔记**（以纯 Markdown 文件存储）、**任务** 和 **Kanban 看板** 放在同一个界面里管理；笔记文件夹可直接作为 **Obsidian vault** 打开。

定位是「**一站式终端 PKM**」——既能在命令行里记笔记，又能做任务和看板，不离开终端。

## 为什么用它 / 适合什么场景

- **Obsidian 用户** 想用纯 Markdown 文件，不想被 GUI 锁死
- **终端党** 想 TUI 操作一切笔记 / 任务
- **极简工作流**：笔记、任务、Kanban 同界面
- **零依赖**：纯 Go 单二进制
