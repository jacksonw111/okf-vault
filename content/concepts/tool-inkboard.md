# InkBoard

[InkBoard](https://github.com/kuaner/inkBoard) 是**墨水屏平板专用的桌面 / HOME 应用**,把桌面做成纯黑白、少动画、大触控目标、手动翻页;常用应用钉在主页一按即开,解决手机式桌面在墨水屏上的残影、灰阶降级、全屏闪烁问题。

项目链接：<https://github.com/kuaner/inkBoard>

## 它是什么

墨水屏平板的**专属桌面启动器**:不沿用 Android 默认启动器的图标墙与滚动逻辑,而是为墨水屏特性重新设计 UI——黑白两色 / 大点击区 / 手动翻页 / 零动画。

## 为什么用它 / 适合什么场景

- **墨水屏 Android 平板**:文石 / 掌阅 / Boox / 大上等墨水屏设备当主力阅读 / 写作设备时,需要一个能用的 HOME。
- **省残影**:不闪屏、不刷动画,墨水屏寿命更长、阅读更专注。
- **大字触控**:图标与按钮放大,适合戴手套 / 老人家 / 视力受限用户。

## 关键能力

| 能力 | 说明 |
|------|------|
| 纯黑白配色 | 与墨水屏原生灰阶匹配 |
| 零动画 | 不闪屏,墨水屏寿命更久 |
| 大触控目标 | 按钮 / 图标放大,误触率低 |
| 手动翻页 | 不用滚动 / 滑动,墨水屏响应友好 |
| 应用钉主页 | 常用应用一按即开 |
| E-ink 专属 | 不再沿用手机桌面范式 |
