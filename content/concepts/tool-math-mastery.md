# math-mastery（纯前端数学练习应用）

## 它是什么

一个纯前端的数学练习小应用：**不用装、不用联网**，浏览器打开就能刷题。覆盖小学到高中的核心解题方法，每个方法都能随机出题，因此题题不重样。

## 为什么用它 / 适合什么场景

- 想给孩子 / 自己找个不带账号体系、不推送广告的刷题工具。
- 需要离线可用（平板离线、网络受限环境）。
- 想按方法专项训练，而不是按章节做整套试卷。

## 关键能力

| 能力 | 说明 |
|------|------|
| 覆盖范围 | 小学到高中核心解题方法 |
| 随机出题 | 每个方法可无限随机生成，题题不同 |
| 解析 | 带步骤解析与配图 |
| 学习路径 | 按顺序学、闯关式推进 |
| 薄弱本 | 做错的题自动进入薄弱本继续练 |
| 数据存储 | 进度存在浏览器本地 |
| 附加 | 站内整理了若干可视化数学工具 |
