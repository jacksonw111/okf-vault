# DESIGN.md 资源站合集

## 它是什么

`DESIGN.md` 是设计 / 前端社区近期流行的一种资源组织形式——把"设计系统 / 组件库 / UI 模板 / 配色 / 字体"等内容按 Markdown 方式汇总到一个站点，便于 LLM agent 与人类共同消费。下面是社区里广为流传的 9 个站点：

| 站点 | 定位 |
|------|------|
| <http://styles.refero.design> | 设计样式库 |
| <http://designmd.me> | 通用 DESIGN.md |
| <http://open-design.ai> | 开源设计资源 |
| <http://designmd.supply> | 设计素材补给站 |
| <http://getdesign.md> | DESIGN.md 检索 |
| <http://aura.build> | 视觉生成 |
| <http://neuform.ai> | 新形态设计 |
| <http://design-md.hyperbrowser.ai> | 浏览器内设计资源 |
| <http://typeui.sh> | 字体 / UI |
