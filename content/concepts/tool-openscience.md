# OpenScience

## 它是什么
`synthetic-sciences/openscience` —— 开源 **AI 科研工作台**，从「设定目标」开始自主完成 **文献调研 → 假设形成 → 代码编写 → 实验运行 → 结果分析 → 论文撰写** 全流程。**内置 290+ 项技能**，覆盖模型训练（DeepSpeed / PEFT / TRL）、分子生物学、化学信息学、论文排版等方向。

## 为什么用它 / 适合什么场景
- 把科研当成"流水线"，而不是每次跑实验都手工串工具。
- 想让 LLM 不仅生成文本，还可以 **实际执行训练 / 实验** 并闭环回来写论文。
- 不想为每个研究方向（NLP / 分子 / 化学）单独配 Agent 时，用现成的工作台 + 技能库。

## 关键能力
| 能力 | 说明 |
|------|------|
| 全流程自主 | 文献调研 → 假设 → 代码 → 实验 → 结果 → 论文撰写 |
| 290+ 内置技能 | 覆盖模型训练（DeepSpeed / PEFT / TRL）/ 分子生物学 / 化学信息学 / 论文排版 |
| 多学科 | 同一工作台支持 ML、AI4Science、化学、生物学 |
| 论文排版 | 自动产出可投稿 / 可编译的论文稿 |
| 开源 | 完全开源可本地部署 |
