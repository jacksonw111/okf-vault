# Spell UI

## 它是什么
Spell UI 是 tomm_ui 维护的**高质量 React 组件集合**：覆盖按钮、卡片、表单、导航、模态、菜单等常见 UI 元素，强调 **copy-and-paste**——选中代码贴进任意 React 项目即可使用，不强制安装整套依赖。

## 为什么用它 / 适合什么场景
- 想找"看一眼就能 copy 走"的 React 组件，而不是装一个巨大组件库。
- 项目结构各异，不想被 shadcn/MUI 这类框架"绑定"。
- 给 vibe coding / 一次性原型准备高质量 React 模板。

## 关键能力
| 能力 | 说明 |
|------|------|
| Copy-paste | 不强制依赖整套包 |
| 覆盖广 | 按钮 / 卡片 / 表单 / 导航 / 模态等 |
| 高质量 | 视觉与交互打磨过 |
| React | 适配 React 项目 |
