# OpenXplorer（原 Winspace：Linux 上的 Windows 资源管理器式文件管理器）

## 它是什么

[OpenXplorer](https://github.com/AKolenda/openxplorer)（原名 **Winspace**，2026-09 改名）是 AKolenda 出品的 **Linux 文件管理器**：用 **Python + GTK 3 / WebKitGTK** 写，**界面照 Windows 资源管理器复刻**，主打 **Zorin OS**。

关键能力是把**本地目录**与 **SMB 网络共享**放在**同一套标签页界面**里，习惯 Windows 资源管理器工作流的人在 Linux 上零成本迁移。

## 为什么用它 / 适合什么场景

- 从 Windows 切换到 Linux（尤其 Zorin OS），想**保留资源管理器式的导航 / 多标签 / 路径栏**习惯。
- 经常访问 **SMB 共享**（NAS / 公司服务器）——SMB 与本地目录在同一套标签页，无需单独窗口。
- 想要**轻量**文件管理器（GTK 3 / WebKitGTK 而非 Electron）。
- 想要**右键菜单 / 路径历史 / 树形侧栏**等 Windows 风格的细节。

## 关键能力

| 能力 | 说明 |
|------|------|
