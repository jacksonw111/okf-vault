# 3dviz-pro-max

## 它是什么

[viettranx/3dviz-pro-max](https://github.com/viettranx/3dviz-pro-max) 是一个**给 AI 编码 agent 用的 Three.js 3D 场景 Skill 包**：把一句话想法变成可探索、可交互的 Three.js 3D 场景，免去「从零选渲染器 / 写规范」的痛苦。

## 数据规模

| 资产 | 数量 |
|------|------|
| 配方（Recipes） | 223 |
| 知识记录 | 440 |
| Kit 蓝图（带实拍图） | 22 |
| 示例项目 | 37（pnpm 起服务直接打开看） |

## 为什么用它 / 适合什么场景

- 用 Claude Code / Codex 接 Three.js 3D 场景活儿，需要现成的「配方 / 蓝图 / 示例」。
- 想学 Three.js 但不想从空白项目搭起。
- 做产品 demo / 概念验证，需要快速出一个能跑的 3D 场景。

## 关键能力

| 能力 | 说明 |
|------|------|
| Skill 套件 | 装进 Claude Code / Codex 直接调用 |
| 配方丰富 | 223 个覆盖常见场景 |
| 蓝图带图 | 22 个 Kit 蓝图含实拍图 |
| 示例可跑 | 37 个示例 pnpm 起服务即看 |
| 知识库 | 440 条知识记录兜底 |
| Three.js 原生 | 直接接 Three.js 生态 |
