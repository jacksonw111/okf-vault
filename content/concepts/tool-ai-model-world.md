# ai-model-world（大模型像素小镇）

## 它是什么

[liyupi/ai-model-world](https://github.com/liyupi/ai-model-world) 是一个 **Next.js 静态站点**——把 **556 个大模型**拟人化成**像素小镇里的角色**，按国内外厂商分区展示。

首页「**今日格局**」用**八块领奖台**给出「最聪明 / 最会编程 / 最划算 等」的当日结论，每块领奖台只给一个名字、一个数字和一句理由。

## 为什么用它 / 适合什么场景

- 模型名字太多记不住，想**扫一眼**就知道「谁最强 / 谁最便宜 / 谁刚出生」。
- 给非技术同事 / 学生做「大模型生态科普」，像素拟人化比论文式列表好懂。
- 想自己 fork 一份做团队内部的「模型导航页」。
- 做**模型选型调研**时把 500+ 模型一次性摆出来对比。

## 关键能力

| 能力 | 说明 |
|------|------|
| 556 个模型收录 | 大体量模型目录 |
| 像素小镇拟人化 | 按厂商分屋站好，视觉化认知负担低 |
| 「今日格局」八块领奖台 | 强 / 编程 / 划算 等榜单 |
| 每个结论一句话 | 名字 + 数字 + 一句话理由 |
| Next.js 静态站 | 部署简单，可 Vercel / 自托管 |

## 与相关概念的关系

- [Free Model Radar](./tool-free-model-radar.md) — 同样是大模型发现 / 对比类工具，free-model-radar 偏「免费模型监控」，ai-model-world 偏「全模型生态导航站」
