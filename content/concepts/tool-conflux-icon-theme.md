# Conflux Icon Theme（Linux 桌面图标主题）

## 它是什么

[MoshiurRahmanAdib/Conflux-Icon-Theme](https://github.com/MoshiurRahmanAdib/Conflux-Icon-Theme) 是为 Linux 桌面设计的**图标主题**：风格上**顺眼、不抢戏**——任何形状的应用图标放进来都不会违和。

## 关键特征

- **风格统一**：图标之间视觉重量一致
- **不抢戏**：低调不抢应用图标本身注意力
- **形状宽容**：方形 / 圆形 / 异形应用图标都和谐
