# remocn

## 它是什么

[remocn.dev](https://remocn.dev) 是**「shadcn 风格的 Remotion 组件库」**——把 Layout / typo / block UI / transitions 等 motion 组件全部整好，**不用 After Effects 也能输出专业 demo 视频**。可以让 AI agent 直接调用或人工手动组合。

## 组件类别

| 类别 | 内容 |
|------|------|
| Layout | 网格 / 居中 / 分屏 / 卡片堆叠 |
| Typography | 标题 / 副标题 / 字幕样式 |
| Block UI | 按钮 / 卡片 / 模态 |
| Transitions | 淡入淡出 / 滑动 / 缩放 / 蒙版切换 |

## 为什么用它 / 适合什么场景

- 想做产品 demo / 短视频但不想学 After Effects。
- 想让 AI agent 直接用组件拼视频。
- 想统一团队的视频风格。

## 关键能力

| 能力 | 说明 |
|------|------|
| shadcn 风格 | 复制粘贴即用 |
| Remotion 渲染 | 代码绘制视频 |
| 全组件覆盖 | 布局 / 字体 / 交互 / 转场 |
| AI 友好 | agent 可直接调用 |
| 无 AE 依赖 | 浏览器出视频 |
