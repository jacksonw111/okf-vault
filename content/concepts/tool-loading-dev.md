# loading.dev

## 它是什么

[loading.dev](https://loading.dev/) 是一个**专门收录「决定版」加载动画的灵感集合站点**——按场景（按钮 / 表单 / 卡片 / 页面切换 / 数据加载等）分类展示 loading 动画、占位、骨架屏、进度条等生产可用的效果。

## 为什么用它 / 适合什么场景

- 产品需要补「加载等待」的视觉体验时——纯 CSS / SVG / Lottie 都行。
- 寻找「**决定版**」级别的加载动效——避免反复改稿。
- 想了解行业（Vercel / Linear / Stripe 等）当下用的加载态长什么样。

## 关键能力

| 能力 | 说明 |
|------|------|
| 分类浏览 | 按 UI 段落 / 触发场景分组 |
| 生产可用 | 收录的都是真在用的效果，不是纯设计稿 |
| 形式多样 | CSS 动画 / SVG / Lottie / 视频 / 骨架屏 |
| 行业参考 | 收录头部产品的实现 |
