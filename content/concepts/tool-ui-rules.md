# UI Rules

## 它是什么
UI Rules 是 hamishoneill（二十年设计系统与团队经验）创办的**设计系统即服务（公开 Beta）**：把品牌的样式与设计指南（Design Guidelines）**连接到 AI 工具**，让 agent 帮你"在品牌之上"产出界面，而不是默认跑出一套通用风。

## 为什么用它 / 适合什么场景
- vibe coding 时 AI 输出一致性差，老是"换种风格"。
- 团队品牌规范想直接喂给 AI 工具，不用每次写长 prompt。
- 想把"设计 token + 组件规则"作为一层被 agent 主动遵守的约束。

## 关键能力
| 能力 | 说明 |
|------|------|
| 品牌 → AI 通道 | 把设计 token / 规范喂给 agent |
| AI 工具集成 | 与主流 coding agent 工具联动 |
| 一致性 | 让 agent 跨页面/跨会话维持品牌风 |
| 二十年经验沉淀 | 来自资深设计系统 lead |
