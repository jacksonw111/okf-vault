# opensourceui.in

## 它是什么

[opensourceui.in](https://opensourceui.in) 是一个**开源 UI 案例合集站**——专门收录开源项目的实际界面截图，给 UI 设计师 / 产品经理 / 前端开发者做素材库。

## 价值

- 看真生产项目的界面怎么设计，比 Dribbble 那些 mock 更落地
- 同类项目横向对比，能看出同类场景的不同设计解法
- 给 AI 生成 UI 提供「真参考」而非「假精致」

## 适合场景

- 找某类功能（dashboard / 设置 / 列表 / 表单）的真实界面参考
- 横向对比同一场景不同产品的设计选择
- 给 LLM 提供「UI 参考素材库」做风格收敛
