# DeepSeekGUI

## 它是什么

[See-Sol-Lab/DeepSeekGUI](https://github.com/See-Sol-Lab/DeepSeekGUI) 是 **DeepSeek Harness 的桌面 GUI 套壳**：Harness 官方只有命令行和网页版，这个项目把改动 / Git / worktree / 记忆 / 网页浏览全塞进桌面窗口，省的是来回切终端查状态的功夫。

## 核心特性

| 特性 | 说明 |
|------|------|
| 桌面 GUI | 不用开终端也能用 DeepSeek Harness |
| Git 集成 | worktree 管理、diff、提交 |
| 改动查看 | 实时显示 Agent 改了哪些文件 |
| 协作记忆 | 跨会话保留上下文 |
| 网页浏览 | 内置浏览器给 Agent 看资料 |

## 为什么用它 / 适合什么场景
- 想用 DeepSeek Harness 但不熟命令行。
- 不想在终端、VSCode、Git 客户端、网页之间来回切。
- 想看 Agent 实时工作状态，又不想装各类增强 harness。

## 关键能力

| 能力 | 说明 |
|------|------|
| 改动实时查看 | 文件级 diff |
| Git 管理 | worktree / 提交 / 切换 |
| 记忆延续 | 跨会话上下文 |
| 内置浏览器 | Agent 看资料不必外部开窗 |
| 桌面原生 | 系统通知 / 任务栏 |
