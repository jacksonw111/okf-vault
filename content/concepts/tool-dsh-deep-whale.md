# dsh-deep-whale

## 它是什么
`Small-tailqwq/dsh-deep-whale` 是给 **DeepSeek Harness (DSH)** Web GUI 设计的「**鲸鱼娘**」主题皮肤。安装方式是**一条命令**，无需手动改 CSS / 替换资源文件，就能把 DSH 的整套界面（侧栏 / 对话区 / 卡片 / 按钮）切到鲸鱼娘视觉风格。

## 为什么用它 / 适合什么场景
- 想把工作用的 DeepSeek Harness 桌面化、个性化，加点视觉调味。
- 喜欢鲸鱼娘 IP，希望桌面与桌面壳图标 (`deepseek-whale-girl-icon`) 视觉一致。
- 团队 / 个人「主题日」：把 DSH 切到节日 / 角色主题。
- 给后续 DSH 主题开发者一份可参考的最小主题包样板。

## 关键能力
| 能力 | 说明 |
|------|------|
| 一行命令安装 | 复制粘贴到 DSH 终端或 Web 控制台即可生效 |
| 全局覆盖 | 侧栏 / 顶栏 / 消息气泡 / 按钮 / 弹窗一并换肤 |
| 鲸鱼娘 IP | 与鲸鱼娘桌宠、鲸鱼娘图标等系列主题视觉一致 |
| 可逆 | 不喜欢了再换回默认主题，不破坏原 DSH 数据 |
