# EvilCharts

## 它是什么

一个**专为 dashboard 设计的动效 React 图表库**：组件开箱即用，并自带数据变化时的过渡动画，让图表「看起来活着」。定位不是要替代 Recharts / Chart.js 这种通用图表库，而是给「**数据要动起来**」的场景（实时 dashboard、AI 输出可视化、指标看板）一个更省心的起点。

## 为什么用它 / 适合什么场景

- 实时数据 / 指标看板，希望变化过程丝滑而不是瞬间跳变。
- 做 AI / 数据产品的 demo / 落地页时希望图表"自己会动"。
- 不想为每个图表手写 GSAP / Framer Motion 时序。

## 关键能力

| 动效 | 内置过渡动画 |
