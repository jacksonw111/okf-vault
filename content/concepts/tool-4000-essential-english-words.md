# 4000-Essential-English-Words

[4000-Essential-English-Words](https://github.com/MohKardan/4000-Essential-English-Words) 是把经典词表书 **4000 Essential English Words**(1–6 册)全套资源一次性抓取并打包成 **Anki 牌组**的 Python 脚本。

## 关键能力

| 能力 | 说明 |
|------|------|
| 单词抓取 | 全 6 册 4000+ 词 |
| 配图 | 抓取每词对应插图(辅助记忆) |
| 音频 | 抓取每词发音音频 |
| Anki 牌组 | 输出 .apkg,直接导入 Anki |
| Python 脚本 | 可定制(改字段、改模板) |

## 适合什么场景

- 英语学习者想**系统过基础词表**,直接用 Anki 间隔重复刷 4000 词。
- 准备四六级 / 托福 / 雅思的考生追求**有图有音**的词表。
- Anki 重度用户:从静态 PDF / Word 词表升级到标准牌组。

## 与同类资源的差别

| 资源 | 定位 | 4000-Essential-English-Words |
|------|------|-------------------------------|
| AnkiWeb 共享牌组 | 词表 | 单一来源书,内容可控 |
| Quizlet | 在线词卡 | 不需要联网账号,本地牌组 |
| ExamPrep-AI | PDF → 闪卡 | 输入资料;本工具自带完整词表 |
