# Scriptya（脚本菜单化 / 桌面化工具）

## 它是什么

[filonux/Scriptya](https://github.com/filonux/Scriptya) 把**散落在文件夹里的各类脚本**组织成**可搜索菜单**，一键运行、装成桌面应用、换图标、接文件管理器右键——让 shell 脚本像普通应用一样被用起来。

## 关键能力

| 能力 | 说明 |
|------|------|
| 菜单化 | 脚本变成可搜索菜单项 |
| 一键运行 | 点一下就跑 |
| 桌面化 | 脚本可以装成桌面应用 |
| 换图标 | 菜单 / 桌面应用自定义图标 |
| 文件管理器右键 | 集成到系统右键菜单 |
| 多脚本管理 | 一个工具管全部脚本 |

## 适合谁

- 收藏了很多 .sh / .py 脚本但难找
- 想把常用脚本变成桌面应用 / 图标
- 想统一管理而不丢脚本的灵活性
