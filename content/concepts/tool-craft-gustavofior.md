# Craft by Gustavo Fior（UI 细节小技集）

## 它是什么

[Craft by Gustavo Fior](https://craft.gustavofior.com/) 是一个汇总 UI 细节层面「小技」的站点。核心理念是：当 AI 生成前端成为常态，光扩充组件库不够，「让 AI 真正吃进去的设计规则文档」才是真正的瓶颈——Craft 把这类规则与细节技沉淀在站点里。

## 关键能力

| 能力 | 说明 |
|------|------|
| 细节小技 | UI 视觉细节层面的具体做法 |
| AI 友好 | 文档形态便于喂给编码 AI |
| 设计规则沉淀 | 把「什么时候用 / 什么时候不用」写明 |
| 持续更新 | 收录具体可复用的细节决策 |

## 为什么相关

AI 编码时，「写得出」已经不难，「写得像样」靠的是把视觉规则沉淀成可消费的文档，Craft 提供了一组参考。
