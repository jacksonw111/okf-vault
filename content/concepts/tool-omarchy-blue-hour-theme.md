# omarchy-blue-hour-theme

## 它是什么
一个**Omarchy 桌面主题包**：深板岩蓝的冷调主题（"blue hour"），一条命令装完，壁纸 + shell 部件配色一起换掉。

## 为什么用它 / 适合什么场景
- 在用 Omarchy 桌面，想要一套冷调深色主题而不必一个个手动配。
- 喜欢「blue hour」（深蓝冷调）色调，希望整套桌面协调一致。

## 关键能力
| 能力 | 说明 |
|------|------|
| 适配 | Omarchy 4 桌面 |
| 色调 | 深板岩蓝冷调 |
| 安装 | 一条命令 |
| 覆盖 | 壁纸 + shell 部件配色 |
