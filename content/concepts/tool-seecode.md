# SeeCode

## 它是什么

[SeeCode](https://github.com/Aryanutkarsh/SeeCode) 是 Aryanutkarsh 开源的「**代码可视化**」工具：把代码库渲染成多种**交互式视图**——类图、依赖图、调用图、控制流图，让「代码长什么样、模块怎么连」一眼可读，并能在此基础上由 Agent 直接生成更多视图。

定位与「GraphViz / Mermaid + 脚本」类似，但目标是**专门为代码库定制**的可视化输出。

## 为什么用它 / 适合什么场景

- **接手老仓库**：先看依赖图 / 调用图，比读代码快得多
- **架构评审**：把模块依赖画出来给团队 review
- **重构规划**：看清耦合关系再动刀
- **教学 / 写文章**：把代码结构画成可发布的图
- **Agent 工作流**：让 Agent 也能输出可视化视图

## 关键能力

| 能力 | 说明 |
|------|------|
| 类图 | 类的字段 / 方法 / 继承关系 |
| 依赖图 | 模块 / 包之间的依赖 |
| 调用图 | 函数 / 方法之间的调用链 |
| 控制流图 | 函数体内的分支 / 循环结构 |
| 交互式 | 节点可点击、可缩放、可聚焦 |
| Agent 友好 | 可让 AI 直接生成视图 |
