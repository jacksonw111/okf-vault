# SICK（Yuri-NagaSaki/SICK）

## 它是什么

`Yuri-NagaSaki/SICK` 是一套 **Linux 服务器运维脚本**，**一行命令**就能跑完**硬件检测、网络测速和 CPU 跑分**：
- **SICK** 查硬件（CPU / 内存 / 磁盘 / NVMe / RAID / 网卡 / GPU / 主板）；
- **NETS** 用 iperf3 测全球 23 个节点网速；
- **CPUX** 自动跑 Geekbench 5/6/7 出分。

## 为什么用它 / 适合什么场景

- 新机器到手 / 新租 VPS / 二手服务器验机时，希望**一套脚本全跑一遍**；
- 想要**客观的 Geekbench 跑分**做横向对比（而不是单一软基准）；
- 想测**到全球节点的真实网速**（23 节点）而不只是 `speedtest` 单一目标。
