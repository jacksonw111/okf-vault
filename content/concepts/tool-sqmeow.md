# sqmeow.nvim

## 它是什么

[sqmeow.nvim](https://github.com/2giosangmitom/sqmeow.nvim) 是一个 **Neovim 数据库插件**：

> 让 Neovim 用户不切终端就能连数据库、写 SQL 查数据并直接改表。

## 为什么用它 / 适合什么场景

- 主要工作流在 Neovim，不想切换到独立 GUI 数据库客户端（DataGrip / DBeaver）。
- 在终端 / SSH 远程开发时仍需要查询 / 修改数据库。
- 想要「Vim 键位 + SQL」的连贯体验。

## 关键能力

| 能力 | 说明 |
|------|------|
| 数据库连接 | 在 Neovim 内直接连接 |
| SQL 查询 | 写 SQL 并查看结果 |
| 表修改 | 直接修改表（schema / 数据） |
| 形态 | Neovim 插件 |

## 与同类工具的差异

| 工具 | 形态 |
|------|------|
| sqmeow.nvim | Neovim 插件 |
| DataGrip / DBeaver | 独立 GUI 客户端 |
| psql / mysql CLI | 纯命令行 |
