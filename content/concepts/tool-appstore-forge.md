# appstore-forge（应用截图转商店展示素材）

## 它是什么

一个跑在本机的 Mac 应用（Electron + TypeScript），专做一件事：把开发者手上的**原始应用截图**加工成**能直接上传应用商店的展示素材**。选好目标商店、背景、设备外壳，把截图拖进去，逐屏写标题，导出即可交付。

![](https://video.twimg.com/tweet_video/HRQpScibYAAsxdk.mp4)

视频：<https://video.twimg.com/tweet_video/HRQpScibYAAsxdk.mp4>

## 为什么用它 / 适合什么场景

- 独立开发者上架前手工用 Figma 拼商店截图，费时且尺寸容易错。
- 截图里含未发布功能 / 用户数据，不希望上传到任何在线截图生成服务——它**没有任何网络调用**，图片不出机器。

## 关键能力

| 能力 | 说明 |
|------|------|
| 六步流程 | 选商店目标 → 挑背景与设备外壳 → 拖入截图 → 逐屏写标题 → 微调 → 导出 |
| 商店适配 | App Store 与 Google Play 两套尺寸规范 |
| 本地优先 | 无账号、无上传、无服务器，零网络调用 |
| 技术栈 | Electron + TypeScript，macOS 本地运行 |
