# FxEmbed（X / Twitter 无 API 检索）

## 它是什么

[FxEmbed](https://github.com/FxEmbed/FxEmbed) 是一个绕过 X 官方 API 的第三方方案，提供 X / Twitter 的检索、嵌入卡片渲染等能力。免去申请与维护 X Developer 账号、API Key 与配额，适合在产品中嵌入推文卡片或做轻量检索。

## 适用场景

- 想在博客 / 文档 / Notion 风格的页面里嵌入推文卡片，但不愿配 X API Key
- 只想做轻量的 X 内容检索 / 引用，不想承担付费 API 配额
- 已有 5k+ stars 的成熟开源方案

## 关键能力

| 能力 | 说明 |
|------|------|
| 无 API Key | 走第三方路径绕开 X 官方 API |
| 嵌入卡片 | 可在网页里渲染 X 风格的推文卡片 |
| 检索支持 | 提供 X / Twitter 内容的检索能力 |
| 开源 | GitHub 公开仓库，5k+ stars |

## 注意点

- 第三方路径可能受 X 前端策略变化影响，长期稳定性不如官方 API
- 高频 / 大规模场景仍建议走官方 API
