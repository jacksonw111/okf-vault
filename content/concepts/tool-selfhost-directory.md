# selfhost.directory（自托管开源应用目录）

## 它是什么
[selfhost.directory](https://github.com/turhobr/selfhost.directory) 是一款 **可搜索的自托管开源应用目录**：把 2,700+ 个能跑在自己服务器上的开源项目汇总到一起，每条都附 **安装指南、替代方案和实时版本跟踪**。比起 awesome-selfhosted 这种 GitHub README 列表，更像一个真正「能搜」的目录站。

## 为什么用它 / 适合什么场景
- 想找某个具体用途的自托管替代品（网盘 / 笔记 / 看板 / 聊天 …），但不想翻 awesome 列表。
- 关注自托管项目版本是否仍维护——目录提供实时版本跟踪。
- 想做技术选型时，比较「同一需求下有哪些可选项」。

## 关键能力
| 能力 | 说明 |
|------|------|
| 2,700+ 项目 | 覆盖广泛的自托管开源应用 |
| 搜索 | 不是平铺列表，是可搜索目录 |
| 安装指南 | 每条记录附部署要点 |
| 替代方案 | 列出同类产品横向对比 |
| 实时版本跟踪 | 项目版本变化可感知 |
