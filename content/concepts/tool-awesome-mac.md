# awesome-mac（patricksun1986）

## 它是什么

patricksun1986/awesome-mac 是一个**专注 macOS 高质量软件**的精选清单仓库：按类别系统化整理，每条都附简介、官网或下载链接、收费 / 免费 / 平台要求等元信息，方便用户按场景快速找到合适工具。

## 分类覆盖

| 类别 | 典型收录 |
|------|----------|
| 开发工具 | 编辑器 / IDE / 终端 / 版本控制 |
| 效率办公 | 笔记 / 任务管理 / 剪贴板 / 快捷键 |
| 设计创作 | 设计工具 / 截图 / 录屏 / 字体 |
| 网络代理 | VPN / 代理 / 下载工具 |
| 系统增强 | 菜单栏工具 / 窗口管理 / 文件管理 |
| 影音娱乐 | 播放器 / 录音 / 音乐制作 |

## 适合谁

- 新 Mac 用户不知道「这个需求该装什么」
- 老用户想发现替代品 / 同类工具里更优的选项
- 自媒体 / 博主写「macOS 软件推荐」类内容时的选题源
