# finding-unknowns-skills

## 它是什么

Neeeophytee/finding-unknowns-skills 是一个**8 个 Claude Skill 的合集**，点子取自 Anthropic 工程师 Thariq Shihipar 的《Finding Your Unknowns》一文——把「动手前该问什么 / 写时该盯什么 / 写完该复盘什么」拆成 8 个可装可单独用的 Skill，覆盖编码会话全生命周期。

## 八个 Skill

| Skill | 用途 | 阶段 |
|-------|------|------|
| `blindspot-pass` | 掀出未知未知 | 动手前 |
| `brainstorm-prototypes` | 做一次性原型定调性 | 动手前 |
| `interview-me` | 一次问一个问题，把模糊需求收敛 | 动手前 |
| `reference-hunt` | 拿现成源码当规格 | 着手时 |
| `implementation-plan` | 把最可能改的决策放最前 | 着手时 |
| `implementation-notes` | 记偏离原计划的地方 | 写时 |
| `pitch-packager` | 把成果打包成说服文档 | 写完 |
| `change-quiz` | 合并前先考过自己 | 写完 |

## 关键能力

| 能力 | 说明 |
|------|------|
| 全生命周期 | 从「还没动手」到「合并 PR」每个阶段都覆盖 |
| 可单独使用 | 8 个 Skill 互不依赖，按需装 |
| 协作友好 | Skill 提示词结构清晰，可在团队里分阶段强制流程 |

## 与已有 Skills 工具的差别

- [SkillsPlusPlus](./tool-skillsplusplus.md) — Tauri 2 桌面 Skills 管理工具（安装器）
- [OpenClaw Marketing Skills](./tool-openclaw-marketing-skills.md) — 37 个营销 Skill 集合（垂直领域）
- finding-unknowns-skills 的差异点：**针对编码工作流的全阶段元 Skill**，不是单一领域知识

## 适合谁

- Claude Code / Codex 等 Agent 用户希望把「好的编码习惯」固化为可强制流程
- 团队里想统一新人 / 老手在 PR 流程中的脑回路
- 个人开发者对抗「无脑写代码」惯性
