# iconcreator.dev

## 它是什么

`iconcreator.dev` 是一款**免费**的在线**动画 / 3D 图标设计器**：浏览器内即可生成带动画效果或 3D 立体感的图标素材，无需安装软件、可直接下载使用。

定位：填补「静态图标工具（Heroicons / Lucide）」与「完整 3D 建模工具（Blender）」之间的空白——**快速出可动 / 可立体的图标**。

## 为什么用它 / 适合什么场景

- 想要比 Heroicons / Lucide 更有视觉冲击的图标（动画 / 3D）。
- 不愿意打开 Blender 这种重工具做一个小图标。
- 想要**免费**方案——iconcreator.dev 直接白嫖。
- 落地页 / 启动页 / 营销页需要「会动的小图标」。

## 关键能力

| 能力 | 说明 |
|------|------|
| 动画图标 | 浏览器内生成可动图标 |
| 3D 图标 | 立体感图标设计 |
| 浏览器即用 | 无需安装 |
| 免费 | 直接使用 |
