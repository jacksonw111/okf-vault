# UNIGIT Ecosystem

## 它是什么

[adtexterry-lgtm/unigit-ecosystem](https://github.com/adtexterry-lgtm/unigit-ecosystem) 是 **UNIGIT 项目的公开门面仓库**——把产品要做什么、愿景是什么、哪些能公开讲清楚，沉淀为一份对外可读的资料；同时**向外界征集靠谱的模型、工具和能力**，邀请协作者对接。

定位：

- **对外「门面」型仓库**：相比核心实现仓库，这个仓库承担品牌 / 路线图 / 协作者对接的功能。
- **RFP 模式**：通过公开仓库声明需要哪些外部能力。

## 为什么用它 / 适合什么场景

- 研究「UNIGIT」是什么、想参与的协作者：先读这份仓库判断是否对位。
- 学习「产品公开门面仓库」应该包含哪些内容——愿景 / 路线图 / 协作入口。
- 想找同类「用 GitHub 仓库当产品主页 / RFP」的开源范式。

## 关键能力

| 能力 | 说明 |
|------|------|
| 产品愿景 | 写清楚要做什么 / 不做什么 |
| 对外叙事 | 哪些可公开讲 / 哪些是内部机密 |
| 能力征集 | 公开列出需要哪些外部模型 / 工具 / 能力 |
| 协作者入口 | 潜在的合作伙伴从这里进入 |
