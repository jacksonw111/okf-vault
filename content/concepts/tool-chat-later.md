# chat-later

[chat-later](https://github.com/jjyaoao/chat-later) 是一个把聊天记录"翻旧账"的工具：把时间线里**一年没人回看的约定、反馈、没下文的事**主动翻出来，每条结论都钉上原始消息编号，点一下就能回到化名后的原文。

## 它是什么

本地聊天记录的回顾助手。人在群里、跟人聊完事，最常发生的状况是"那天说要做的事后来呢？"——多数时候没人回看、没人追。chat-later 把这类"悬而未决的对话"显式捞出来，并把每条断言都钉到原始消息 ID，确保可追溯。

## 为什么用它 / 适合什么场景

- **约定 / 跟进防漏**：群里"我下周发给你"这类话永远要追。
- **反馈闭环**：约好"用完给你反馈"但忘了的事。
- **没下文的事**：别人提了但你一直没回的事。
- **原始消息溯源**：每条结论都钉到原始消息编号（化名后）。

## 关键能力

| 能力 | 说明 |
|------|------|
| 时间线回顾 | 把聊天按时间排好，自动捞"悬而未决"的内容 |
| 约定追踪 | 翻出未兑现的承诺 / 约定 |
| 反馈闭环 | 标记"约好用完反馈"等还没回的事 |
| 消息编号钉死 | 每条结论都钉回原始消息 ID |
| 化名原文 | 隐私优先：原文以化名形式展示，可点开回溯 |
