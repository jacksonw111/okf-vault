# Codex Work Starter（fanko1217/codex-work-starter）

## 它是什么

**Codex Work Starter** 是给「**不会写代码的人**」的 Codex 起步套件——给出一条**稳妥路线**：

1. **手动搞定一个真实任务**：不要一开始就「全 AI 自动」。
2. **确认没出岔子**：自己看一遍输出。
3. **沉淀成可复用的提示词 / skill / 定时任务**：成功路径转成可复用资产。

避免「一上来就把收发邮件、改日历全交给 AI 自动操作而后翻车」。

## 为什么用它 / 适合什么场景

- **新手 AI 编码 agent 用户**：避免过度授权翻车。
- **想用 Codex 自动化日常任务**（邮件、日历、文件整理），但**担心权限 / 误操作**。
- 想从「一次性 prompt」进化到「**可复用 skill + 定时任务**」。

## 关键能力

| 能力 | 说明 |
|------|------|
| 手动优先 | 先人肉跑通，再 AI 化 |
| 风险分级 | 明确「敏感操作」（邮件 / 日历）需人工 |
| 沉淀模板 | 把成功路径转 prompt / skill |
| 定时任务 | 可挂 cron / 定时器 |
| 适合非开发者 | 降低 Codex 使用门槛 |
