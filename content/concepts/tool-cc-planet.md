# cc-planet

## 它是什么

[cc-planet](https://github.com/gezihua123/cc-planet) 是一款**视觉化桌面通知工具**：用一架拖横幅的飞机飞过屏幕，把 CI/CD 构建结果与日常提醒变成一眼可见的动画通知。**抢眼度远超传统桌面通知 / 弹窗**——但也因此偏向极客玩具属性，请评估是否真需要这种程度的视觉打断。

## 为什么用它 / 适合什么场景

- 经常忽略 CI/CD 构建完成通知，希望「一眼就看见」。
- 副屏 / 显示器常驻多个工作区，希望通知能跨越工作区可见。
- 想给自动化任务（爬虫 / 备份 / 长时间跑批任务）做「完成提示」。
- 想把 macOS / Windows 桌面通知做得更有个性。

## 关键能力

| 能力 | 说明 |
|------|------|
| 飞机横幅动画 | 飞机拖横幅飞过屏幕，跨工作区可见 |
| CI/CD 集成 | 构建开始 / 成功 / 失败均可触发 |
| 自由文本通知 | 也支持自定义文本与触发方式 |
| 自托管 | 单机本地运行 |
