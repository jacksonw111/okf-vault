# EffectCraft（开源 AE 替代合成器）

## 它是什么

**EffectCraft** 是 storytold 出品的开源合成器——跑在 macOS / Windows / Linux / **浏览器**，用 Rust 写的合成引擎照着 **After Effects** 的面板布局与关键帧行为做；让动效师不交 Adobe 月费也能做图层 / 关键帧 / 渲染队列的活。

## 为什么用它 / 适合什么场景

- **替代 AE 月费**：开源、可商用、对个人 / 小团队极友好
- **跨平台**：macOS / Windows / Linux / 浏览器通吃
- **AE 兼容 API**：306 个效果覆盖 AE 298 个全部
- **可扩展**：JavaScript 表达式 + Puppet 工具

## 关键能力

| 能力 | 说明 |
|------|------|
| 图层类型 | solids / shapes / 文本 / 嵌套合成 / 摄像机 / 灯光 |
| 效果 | 306 个（AE 298 个全覆盖） |
| 图层样式 | 9 种（投影 / 描边 / 渐变叠加等） |
| JavaScript 表达式 | 像 AE 一样写表达式 |
| Puppet 工具 | 网格变形 / 骨骼绑定 |
| 渲染队列 | 输出 mp4 / mov / 序列帧 |
| 浏览器内运行 | Web 版无需安装 |
