# clay-safari

## 它是什么

[clay-safari](https://github.com/cclank/clay-safari) 是一个基于 **Three.js** 的 3D 互动动物认知项目，专为儿童早期双语启蒙设计：场景里的每只动物都用**黏土（clay）风格**建模，点一下就触发动作 + 双语名字 + 叫声，帮助孩子在「玩」的过程中建立动物 — 英文 / 中文 — 声音的三重映射。

## 为什么用它 / 适合什么场景

- 给 2–6 岁小朋友做动物 + 双语启蒙。
- 想给幼儿园 / 早教机构做一个本地或内网可跑的互动展项。
- 设计师 / Three.js 学习者参考「黏土质感 + 互动叙事」的实现套路。

## 关键能力

| 能力 | 说明 |
|------|------|
| Three.js 场景 | 浏览器原生 3D 渲染，无需安装客户端 |
| 黏土风格 | 软糯材质 + 圆润轮廓，对低龄用户视觉友好 |
| 点击互动 | 每只动物点一下就动 / 叫 / 显示双语名 |
| 双语发音 | 触发英文名 + 中文名 + 动物叫声 |
| 开源可改 | 代码结构清晰，方便替换动物、增加新场景 |
