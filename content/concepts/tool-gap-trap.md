# gap-trap（AI 编程代码库的 Gates / Contracts / 红测）

## 它是什么

[pliablepixels/gap-trap](https://github.com/pliablepixels/gap-trap) 是一套**给 AI 编程时代代码库加护栏**的工具：AI 写代码太快导致质量失控，gap-trap 通过「**Gates（门控）** + **Contracts（契约）** + **Proven red（已证红的失败测试）**」强制 AI 遵循规范，把 Vibe Coding 落地为可工程化的产出。

## 三大机制

| 机制 | 说明 |
|------|------|
| Gates | 提交 / 部署前必经的检查门 |
| Contracts | AI 输出必须满足的形式约束 |
| Proven red | 先证明失败的测试，再让 AI 实现 |

## 关键能力

- **全语言支持**：不绑定特定语言栈
- **契合 SDD**：与 Spec-Driven Development 开发流天然契合
- **AI 护栏**：把 AI 输出限制在工程化范围内
- **质量守门**：杜绝「AI 写完代码没人审」

## 适合谁

- 团队用 Vibe Coding 但担心质量失控
- 想给 AI 编程加门控而不是放任
- 已经写 Spec 但缺少工具强制执行
