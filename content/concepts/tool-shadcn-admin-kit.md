# Shadcn Admin Kit（Next.js 后台模板）

## 它是什么

一套构建在 **shadcn/ui + Tailwind** 上的付费后台管理模板，基于 **Next.js 16**，含 **139 个预制页面**。

## 覆盖场景

| 模块 | 内容 |
|------|------|
| 电商 | 商品 / 订单类页面 |
| 项目管理 | 任务与项目视图 |
| 支付 | 账单 / 交易页面 |
| 待办应用 | 完整的 todo 示例 |
| 数据展示 | 数据表格、图表、筛选器 |
