# vmlops AI 工程师实战代码库

## 它是什么

[vmlops 在 X 整理](https://x.com/_vmlops/status/2106270137339035930) 的**面向 AI 工程师的实战代码资源汇总**——按 5 大核心场景分类，每个场景收可端到端、生产就绪的代码。

## 五大分类

| 分类 | 代表内容 |
|------|---------|
| AI Agents | Multi-agent 研究、金融分析师、Web 自动化、SQL 搜索 |
| RAG 系统 | GraphRAG、Hybrid RAG、HyDE、Clinical RAG |
| OCR & Vision | 公式提取、报销单识别、处方数字化 |
| Audio & Voice | 实时语音 agent、多语言翻译 |
| Fine-Tuning | 本地模型、自定义 adapter |

## 模型支持

- OpenAI
- Anthropic
- Gemini
- Mistral
- 本地 Ollama pipeline

## 定位

适合作为「想从 prompt 调到 production code 之间」的过渡资料库——既有完整可跑代码，又覆盖多模型可移植。
