# PiTTy

基于 TypeScript 与 OpenTUI 的 Pi 终端界面，强化对话滚动、折叠信息、子代理控制与任务管理。

## 适用场景

- 需要输入区固定、对话独立滚动，长会话更易浏览的场景。

## 关键能力

| 能力 | 说明 |
|------|------|
| 对话布局 | 输入区固定、对话独立滚动，长会话更易浏览。 |
| 信息降噪 | 思考过程与工具输出可折叠。 |
| 子代理控制 | 可单独检视、暂停子代理并发送指令。 |
| 工作管理 | 提供 Todo 面板与 MCP 管理。 |
