# Openship（自托管部署平台）

## 它是什么

[oblien/openship](https://github.com/oblien/openship) 是**开源可自托管的部署平台**，定位类似 Vercel / Netlify 的「一体化部署面板」，但控制面整套都跑在用户自己的服务器 / 云账号上。它内置 CI/CD，三种前端交互形态都支持。

## 关键能力

| 能力 | 说明 |
|------|------|
| 三种前端形态 | 桌面应用 + Web 仪表盘 + CLI，随选 |
| 内置 CI/CD | 推代码即触发流水线 |
| 打容器 | Docker 容器化产物 |
| 基础设施管理 | 把代码 / 容器 / 服务全收口 |
| 自托管 | 控制面在自己手上，不依赖第三方 SaaS |
