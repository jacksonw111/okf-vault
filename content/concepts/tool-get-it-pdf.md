# Get It

## 它是什么

[beltromatti/get-it](https://github.com/beltromatti/get-it) 是一个**开源 PDF 学习助手**，专治「PDF 啃不透」：

## 核心能力

| 能力 | 说明 |
|------|------|
| 关键概念标记 | 自动从 PDF 提取关键概念 |
| 抽象可视化 | 转 3D 模型 / 动画演示 / 公式推导 |
| 知识图谱 | 自动生成概念关系图 |
| 四种学习模式 | 问答 / 闪卡记忆 / 选择题测验 / **费曼模式**（反过来教 AI） |
| 四维评分 | 记忆 / 理解 / 结构 / 应用 四个维度评估每个概念 |
| 数据本地 | 所有数据本地存储，不上传服务器 |
| 登录 | 用 ChatGPT 账号登录即可 |

## 为什么用它 / 适合什么场景

- 学生在啃难懂的论文 / 教材 PDF。
- 研究者读论文想快速建立知识图谱。
- 想用「**费曼模式**」自测理解深度。

## 关键能力

| 能力 | 说明 |
|------|------|
| 关键概念 | 自动标记 |
| 3D 转换 | 抽象内容可视化 |
| 知识图谱 | 概念关系自动构建 |
| 四模式 | 问答 / 闪卡 / 选择 / 费曼 |
| 四维评分 | 记忆 / 理解 / 结构 / 应用 |
| 数据本地 | 隐私优先 |
