# Logseq

## 定义

**Logseq** 是开源、**本地优先**的**块式（block-based）**个人知识库——以「**块（block）**」而非「整页」为最小单位，每个块可独立打 tag、引用、嵌入查询；同时支持双向链接、PDF 高亮与注释、日记流（journal）、查询 DSL（`{{query}}`）、Graph View。

## 要点

- **官网**：[logseq.com](https://logseq.com)
- **形态**：桌面 / 移动 App + 本地纯文本（Markdown / Org-mode 文件）
- **核心理念**：日记流（默认每天一页）+ 块级引用 + 查询 DSL（`{{query (and [[tag]])}}`）
- **与 Obsidian 对比**：
  - Logseq：**块级 + outliner + 日记流** 默认；查询 DSL 强；多端同步需自己接
  - Obsidian：整页笔记 + Markdown 链接为主 + 丰富插件生态
- **插件**：支持自定义 plugins / themes / flashcard
- **典型场景**：日记、阅读笔记（PDF highlight）、GTD、研究学习
