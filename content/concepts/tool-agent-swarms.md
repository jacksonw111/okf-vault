# Agent Swarms

可自托管的 Agent 与 BI 平台，支持多 Agent swarm、知识库和数据源连接以及完整执行追踪。

## 主要能力

- 作为可复用的软件或工作流组件，按项目文档进行部署和评估。
- 适合在对应场景中替代重复的手工流程。
