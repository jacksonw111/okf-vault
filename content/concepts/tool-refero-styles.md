# Refero Styles（面向 AI Agent 的 DESIGN.md 库）

## 它是什么

一个面向 AI Agent 的 **`DESIGN.md` 库**：把 Anthropic、Notion、Stripe 等 **2000 以上真实产品**的设计系统收集整理，以 Markdown 形式呈现，让编码 Agent 能直接读取某个产品的设计语言（配色、字体、间距、组件风格）。

## 为什么用它 / 适合什么场景

- 要给自己的项目写一份 `DESIGN.md` 交给编码 Agent，但不知道该写哪些维度、写到多细——照着真实产品的样本抄结构最快。
- 想让生成的界面「像某类成熟产品」，可直接引用对应条目作为风格锚点。
