# ESP32

## 定义

**ESP32** 是乐鑫（Espressif Systems）出品的**低成本、低功耗 SoC 微控制器系列**，集成 Wi-Fi + 双模蓝牙（经典蓝牙 + BLE）。自 2016 年发布以来，因价格低（单芯片几美元）、功耗低、Arduino / ESP-IDF / MicroPython / CircuitPython 多 SDK 友好、开源项目海量，被创客、工业 IoT、可穿戴、教育机器人等场景广泛采用，是当下硬件 Agent Skill 的主战场之一。

## 要点

- **官网**：[espressif.com/en/products/socs/esp32](https://www.espressif.com/en/products/socs/esp32)
- **代表型号**：ESP32 / ESP32-S2 / ESP32-S3 / ESP32-C3 / ESP32-C6 / ESP32-H2
- **SDK**：ESP-IDF（C 官方）/ Arduino / MicroPython / CircuitPython / PlatformIO
- **典型场景**：智能家居传感器、桌宠、显示项目、机器人控制、蓝牙 Mesh、教育
- **生态**：GitHub `topics/esp32` 下有数万项目；社区维护 ESPHome（与 Home Assistant 集成）、Tasmota 等固件
