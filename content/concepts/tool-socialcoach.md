# SocialCoach（AI 顶嘴压力沟通训练）

## 它是什么

[GeminiLight/SocialCoach](https://github.com/GeminiLight/SocialCoach) 是一个**沟通压力训练工具**。它用一组「会顶嘴、有自己底牌」的 AI 角色，把你放进固定回合的真实对话场景里练习沟通——例如面对老板叹气 / 客户甩脸色 / 同事阴阳怪气。

沟通技巧书籍教的是「**知道该怎么说**」，但真到压力那一刻往往怂了。SocialCoach 关注的是另一段差距：**知道但压力下使不出来**。

## 关键能力

| 能力 | 说明 |
|------|------|
| 高压 AI 角色 | 对手不配合、按自己利益 / 情绪出牌，模拟真实压力 |
| 固定回合 | 不是随便聊聊，每轮有明确目标与可观察结果 |
| 逐句复盘 | 用你**自己的原话**逐条点评，不替换成模板答案 |
| 能力二分 | 区分「**不知道这招**」和「**知道但压力下没使出来**」两类问题，给出不同改进路径 |
| 渐进难度 | 角色行为模式可调，从温和施压到强对抗 |

## 适合什么场景

- 工作中需要在压力下与上级 / 客户 / 同事做关键对话、又怕当场怂的人。
- 学完沟通书籍 / 课程，但发现自己「**懂道理做不到**」的职场人。
- 想在低风险环境里反复演练一次真实的难对话（加薪、拒绝、致歉、对质）。
