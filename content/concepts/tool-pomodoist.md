# Pomodoist（任务 + 番茄钟 + 生产力报告三合一）

## 它是什么

[Pomodoist](https://github.com/Kabanya/Pomodoist) 把**任务管理、番茄钟专注、生产力报告**合为一个开源应用，一套代码覆盖 macOS / iOS / iPadOS / Android / Linux / Windows 与 Web。

## 为什么用它 / 适合什么场景

- 想要一款把「任务 + 番茄钟 + 复盘报告」三件套打通的工具，而不是装三个 App；
- 多端同步（手机 + 电脑 + 平板 + Web）都要用同一套生产力数据；
- 偏好开源、生产力数据可导出；
- 想要自动统计每日 / 每周专注时长与任务完成率。

## 关键能力

| 能力 | 说明 |
|------|------|
| 三合一 | 任务 + 番茄钟 + 报告 |
| 多端 | macOS / iOS / iPadOS / Android / Linux / Windows / Web |
