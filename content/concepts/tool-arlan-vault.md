# arlan.me/vault

[arlan.me/vault](https://www.arlan.me/vault) 是一个**炫酷前端/AI 效果的合集网站**。每个效果不仅展示了成品,**还把驱动 AI 还原该效果的提示词(Markdown 格式)一并公开**——使用者把 MD 直接粘贴给 AI 即可复现。

## 它解决了什么

平时刷到好看的 Web 动效、组件、AI 生成效果,**复现需要反复猜 prompt**。arlan.me/vault 把「成品 + 驱动 prompt」打包成对,**省掉试错**——对 Agent 时代尤其有用,Agent 直接吃这份 prompt 就能产出接近的效果。

## 关键能力

| 能力 | 说明 |
|------|------|
| 效果合集 | 大量精选的炫酷前端/AI 效果 |
| 提示词公开 | 每个效果附 Markdown 提示词,直拷即用 |
| AI 一键还原 | 提示词设计成喂给 AI 即可 |
| 适合 Agent pipeline | Agent 可直接将该站列入 prompt 库 |
