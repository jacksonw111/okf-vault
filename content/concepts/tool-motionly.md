# Motionly（COPPSARY/Motionly）

## 它是什么

[`Motionly`](https://github.com/COPPSARY/Motionly) 是一个 **AI 驱动的动效编辑器**。流程是：

1. 用一句话描述想要的动画；
2. AI 生成 `.motion` 项目文件；
3. 用户把 `.motion` 文件拖到画布和时间轴里**手动调细节**。

核心是「AI 出初稿 → 人手工精修」，而不是「AI 一键成片」。

## 关键能力

| 能力 | 说明 |
|------|------|
| 元素支持 | 文字 / 图片 / SVG / 视频 |
| 变换 | 缩放、旋转、位置 |
| 时间轴 | 关键帧 + 缓动 |
| 剪辑 | 切、转场 |
| 音频 | 音轨集成 |
