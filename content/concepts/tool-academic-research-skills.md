# academic-research-skills（科研 Skill 主项目统称）

## 定义

Imbad0202 在 GitHub 上维护的**学术科研 Skill 主仓库**，把读文献 / 综述 / 写作 / 绘图 / 顶刊排版 / 答辩 / 复现等科研全流程中可被 Claude Code / Codex 等 Agent 加载的 Skill 集合起来。该项目本身是一个「统称 / 入口」，下挂多个子项目（笔记 [`note-academic-research-skills-list`](./note-academic-research-skills-list.md) 整理了按场景分类的精选清单）。

## 要点

- 主仓库：`https://github.com/Imbad0202/academic-research-skills`
- 是学术 Agent Skill 的代表项目，与 `tool-emdash`（AI Coding 后台任务运行器）等同属 Agent Skill 生态
- 通常以 Skill / Plugin 形式被加载到 Claude Code / Codex 等编码 Agent 里使用
