# TutorOS（SF-6655/TutorOS）

## 它是什么

[`TutorOS`](https://github.com/SF-6655/TutorOS) 是 SF-6655 开源的**白标 LMS 模板**：

- 目标用户：**tutoring 机构**（一对一辅导 / 小班课 / 培训工作室）；
- 卖点：clone 一次 → 改客户配置 → 几小时内上线一套**带自己品牌的教学平台**；
- 比起从零搭 Moodle / 自研 LMS，节省的不是「功能」，而是「**面向小机构的多租户 / 多品牌运营能力**」。

## 关键能力

| 能力 | 说明 |
|------|------|
| 白标 | 名称、Logo、主题、域名可改 |
| 模板化配置 | 改少量配置就能交付一个新客户 |
| 课程 / 学员管理 | LMS 核心模块开箱即用 |
| 快速上线 | 目标 SLA：几小时交付一套独立平台 |

## 适合什么场景

- 想给多家 tutoring 客户**分别部署自己品牌的教学平台**；
- 不愿直接用 SaaS LMS（怕客户数据 / 品牌被绑定）的机构；
- 想做「LMS 部署服务」副业的工程师 / 工作室。
