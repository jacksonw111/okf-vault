# DeskChan

## 它是什么

[DeskChan](https://github.com/Yumesaka13/DeskChan) 是 Windows 桌面上的「栅栏（Fences）」工具：把零散图标收进可拖拽、可调整大小、可隐藏的栅栏区域，按类别（工作 / 临时 / 游戏 / 文档……）整理桌面，省去反复手动归位。

## 为什么用它 / 适合什么场景

- 桌面图标超过两位数，每次找文件像考古。
- 想用 Stardock Fences 风格，但不愿意付订阅费 / 安装闭源软件。
- 想要开源、可定制、可脚本化的桌面整理方案。
- 想让桌面按「最近使用 / 文件类型 / 文件夹」自动归类。

## 关键能力

| 能力 | 说明 |
|------|------|
| 栅栏分组 | 桌面图标收进可拖拽栅栏 |
| 自动归类 | 按文件夹 / 类型 / 最近使用时间自动整理 |
| 隐藏栅栏 | 双击桌面隐藏所有图标，专注模式 |
| 透明 / 主题 | 自定义栅栏背景与边框 |
| 开源 | 可定制 / 可审计 / 免费 |
