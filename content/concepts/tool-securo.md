# securo

## 它是什么
[securo](https://github.com/securo-finance/securo) 是一个**开源的个人理财管理器**，定位「**自托管、隐私优先**」——所有财务数据都跑在自己的机器上，不依赖第三方 SaaS，不向云端同步。

面向想**管好个人 / 家庭财务**但**不愿把数据交给商业产品**的用户：账本、收支、分类、报表这些核心功能开源透明。

## 为什么用它 / 适合什么场景
- 想要**自托管**的个人理财工具——数据在自家机器或自建服务器上；
- 关注**隐私 / 数据主权**，不想让财务信息上 SaaS；
- 想要**开源**可审计的理财逻辑（而不是黑盒算法）；
- 想给家庭 / 小团队搭一个共享账本。

## 关键能力

| 能力 | 说明 |
|------|------|
| 自托管 | 数据跑在自家机器 / 服务器 |
| 隐私优先 | 不上传云端，不依赖第三方 SaaS |
| 开源 | 逻辑可审计 |
| 个人理财 | 适配个人 / 家庭财务场景 |
| 收支记账 | 收入 / 支出 / 转账记录 |
| 分类与报表 | 常见个人理财分析维度 |
| 多用户 / 共享 | 可拓展到家庭 / 小团队 |
