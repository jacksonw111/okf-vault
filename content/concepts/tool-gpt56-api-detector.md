# gpt56_api_detector

## 它是什么
一个本地运行的「中转 API 真伪检测器」。当一个 API 声称自己是 GPT-5.6（或类似新版本），实际跑的是哪个模型、是否混跑了老模型、是否改写了输出——这件事对调用方来说通常是黑盒。

该工具在本机向目标 API 发起**两层检测请求**，把结果归类为**七种结论**输出报告，告诉用户「到底是不是」所声称的模型。

## 为什么用它 / 适合什么场景
- **第三方 / 中转 API 用户**：你买的「GPT-5.6 转发」实际上是不是 GPT-5.6，靠它出报告。
- **模型对比 / 评测**：判断不同供应商返回的是不是同一档模型。
- **可审计性要求**：下游要把模型调用结果当证据，需要先验真。
- **避免被偷改输出**：中转可能在 prompt 之外改输出风格 / 截断 / 重写，检测器能间接暴露这点。

## 关键能力
| 能力 | 说明 |
|------|------|
| 运行位置 | 本机发起请求（不依赖云端） |
| 检测层数 | 两层（具体策略见仓库） |
| 结论数 | 七种可能结论 |
| 输出形式 | 报告（人读 + 可追溯） |
| 适配目标 | OpenAI 兼容 API（GPT-5.6 系列等） |
