# AutoShorts（长视频 / 音频自动转竖屏短视频）

## 它是什么

AutoShorts 是基于 **Tauri 2** 的开源工具：把**长视频或音频**作为输入，AI 自动挑出**「爆款段落」**并切成适合 YouTube Shorts / TikTok / 抖音等社交平台的**竖屏短视频**。

与 [easyedit](./tool-easyedit.md) 互补：easyedit 专注于「电影独白 + 卡点字幕混剪」，AutoShorts 则是更通用的「长视频 / 音频 → 竖屏短片」流水线。

## 为什么用它 / 适合什么场景

- 想把**播客 / 直播录像 / 长视频**批量转成竖屏短视频（YouTube Shorts / TikTok / 抖音）。
- 想用 AI 自动挑「爆款段落」，避免人工逐条剪辑。
- 想用 **Tauri 2** 桌面应用获得原生体验 + 低资源占用。

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | Tauri 2 桌面应用 |
| 输入 | 长视频 / 音频 |
| 输出 | 竖屏短视频（适合社交平台） |
| 选段 | AI 自动挑选爆款段落 |
| 适合 | 批量转短视频 / 播客切片 |
