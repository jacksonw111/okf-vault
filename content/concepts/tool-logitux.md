# LogiTux

面向 Linux 的原生 Logitech 外设配置工具，可管理 DPI、灯光、耳机均衡与摄像头参数。

## 适用场景

- 需要为不便使用 Logitech G HUB 的 Linux 环境提供图形界面的场景。

## 关键能力

| 能力 | 说明 |
|------|------|
| 原生 Linux | 为不便使用 Logitech G HUB 的 Linux 环境提供图形界面。 |
| 外设配置 | 覆盖鼠标 DPI 与灯光、耳机均衡器、摄像头参数。 |
