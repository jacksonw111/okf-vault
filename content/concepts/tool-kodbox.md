# kodbox（浏览器即云端 OS：Web 文件管理器）

## 它是什么
`kalcaddle/kodbox` 是一个 3k+ 星的开源 Web 文件管理器，但它远超文件管理：
- **万物皆可挂载**：本地盘 / WebDAV / S3 / 阿里 OSS / 其它云盘 全部捏在一起统一管理。
- **桌面级操作感**：全局拖拽 / 右键菜单 / Ctrl+C/V / 快捷键全套，丝滑得不像网页。
- **全能在线预览**：上百种格式直接打开，Office 文档、视频、压缩包都能在线解压查看。
- **行走的开发机**：内置代码编辑器，120 种语言高亮，随时随地敲代码。
- **极低配置门槛**：Windows / Mac / Linux 全平台通吃，吃灰旧电脑也能跑。

## 为什么用它 / 适合什么场景
- 想**把浏览器变成「我的电脑」**：去哪一台机器只要打开浏览器，就能接管所有云盘和本地文件。
- 想用一个**自托管 NAS 替代品**，不限速、不收费、数据在自己手里。
- 想给团队一个**统一文件接入面板**：成员打开浏览器即可访问共享盘 + 在线协作。
- 想偶尔**在线写代码建网站**：内置编辑器 + 在线预览。
- 对比：商业网盘（坚果云/OneDrive）隐私差，自建 Nextcloud 重，kodbox 是个轻但全的中间选项。

## 关键能力
| 能力 | 说明 |
|------|------|
| 多协议挂载 | WebDAV / S3 / OSS / Google Drive / OneDrive / 本地盘 |
| 桌面级操作 | 拖拽 / 右键 / 全套快捷键 / 多选 / 批处理 |
| 多格式预览 | Office / 视频 / 图片 / 压缩包 / PDF / 100+ 格式 |
| 内置代码编辑器 | 120 种语言高亮 |
| 跨平台 | Win / Mac / Linux 全平台 |
| 自托管 | 数据在自己手里，无外部依赖 |
