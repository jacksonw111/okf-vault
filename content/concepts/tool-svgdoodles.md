# svgdoodles.com

## 它是什么

[svgdoodles.com](https://svgdoodles.com) 是一个**手绘风格 SVG doodles 资源站**：提供大量可直接复制的 SVG 内联代码，覆盖商务、教育、医疗、节日、人物等多种主题。免费、个人 / 商用许可（依官方说明），目的是给网页 / PPT / 文档增加「手作温度」。

## 核心特性

| 特性 | 说明 |
|------|------|
| 内联 SVG | 直接复制 `<svg>` 代码到 HTML |
| 主题分类 | 商务 / 教育 / 医疗 / 节日等 |
| 手绘风 | 不像 icon font 那样冰冷 |
| 风格统一 | 多插画师保持手作一致感 |

## 为什么用它 / 适合什么场景
- 想要「不像 icon font 那么冷」的手作 UI 风格。
- 做品牌官网 / SaaS 着陆页 / 博客配图 / 教学 PPT。
- 不想花钱买插画、又不满意免费 icon 库的工业感。

## 关键能力

| 能力 | 说明 |
|------|------|
| 海量 SVG | 多主题持续扩充 |
| 内联使用 | 直接嵌 HTML，可改色 / 改尺寸 |
| 风格统一 | 同一批插画师出品 |
| 许可宽松 | 大部分可商用 |
