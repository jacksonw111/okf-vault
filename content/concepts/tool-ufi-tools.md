# UFI-TOOLS

## 它是什么

[UFI-TOOLS](https://github.com/kanoqwq/UFI-TOOLS) 是 **kanoqwq** 开源的 **中兴 T760 系列随身 WiFi 增强管理后台**——针对 F50、U30 Air 等机型，补一套**比原厂后台更完整**的管理界面。

把 **信号监控 / 锁频锁小区 / 短信转发 / 插件扩展 / 远程维护** 集中到一个统一后台。

## 为什么用它 / 适合什么场景

- **随身 WiFi 玩家** 嫌原厂后台简陋 / 隐藏功能多
- **锁频 / 锁小区需求**：把随身 WiFi 钉在特定基站 / 频段
- **短信转发**：把收到的短信自动转发到指定渠道
- **远程维护**：出门在外也能管随身 WiFi
- **可扩展**：插件机制允许加更多工具

## 关键能力

| 能力 | 说明 |
|------|------|
| 硬件支持 | 中兴 T760 系列（F50 / U30 Air 等） |
| 信号监控 | 实时信号强度 / 网络参数 |
| 锁频 | 锁定特定频段 |
| 锁小区 | 锁定特定基站小区 |
| 短信转发 | 自动把收到的短信转发出去 |
| 插件扩展 | 插件机制 |
| 远程维护 | 远程访问管理后台 |
