# study-desk

## 它是什么

[`miku1130/study-desk`](https://github.com/miku1130/study-desk) 是一款 Windows 桌面学习客户端，把**课表 / 番茄钟 / 备忘录 / 倒数日 / 学习资料库 / 健康提醒**这六类日常学习场景都收进同一个窗口里——典型「学生桌面 one-pager」，避免装六个工具切换。

## 它集成了什么

| 模块 | 作用 |
|------|------|
| 课表 | 上课 / 自习时间可视化 |
| 番茄钟 | 学习专注计时 |
| 备忘录 | 临时想法快速记 |
| 倒数日 | 距离考试 / 任务的剩余时间 |
| 学习资料库 | 文档 / 笔记归档 |
| 健康提醒 | 喝水 / 起身 / 休息 |

## 为什么用它

- **多合一**：不装六个 App，少占系统托盘和开机启动项
- **统一数据**：六个模块的数据同源，能跨模块联动（例：番茄钟结束 → 备忘录加一行回顾）
- **本地优先**：个人学习资料不出本机

## 适用人群

主要面向学生 / 自学者群体——这些用户桌面工具少而专，不喜欢装一堆 SaaS。
