# Cube Motion

## 它是什么

[Cube Motion](https://www.cube-motion.dev/) 是一个**零依赖的动效库**，主打「**给你四个动效，时机已经定好了，直接用**」。

它的理念是：**动画库不应该要求使用者先变成动效设计师**。传统动画库（Framer Motion、GSAP 等）功能强大，但缓动曲线、时长、节奏都要自己挑——挑不好就显得别扭。Cube Motion 把这些都预先配好，开箱即用。

## 关键能力

| 能力 | 说明 |
|------|------|
| 零依赖 | 不带任何运行时依赖 |
| 四种动效 | 预置四套时机已定的动效 |
| 跨框架 | React / Vue / Solid / Svelte / 纯 JS |
| 时机已选 | 用户不必再在缓动 / 时长上反复调 |
| 体积小 | 没有冗余功能 |
| 关注点分离 | 工程师不必成为 motion designer |

## 适合什么场景

- 想给组件加过渡动效、又不想研究缓动曲线 / 时长配比的工程师。
- React / Vue / Solid / Svelte 跨框架项目，需要一套统一动效。
- 「**有动效比没动效好、但别让用户等**」的常规 Web 应用。

## 与相关概念的关系

- [Ark UI](./tool-ark-ui.md) — Ark UI 是 headless 行为层；Cube Motion 在它的「过渡动效」一类上是更轻量的预制方案。
