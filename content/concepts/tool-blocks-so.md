# blocks.so

## 它是什么

[blocks.so](https://blocks.so) 是 **ephraimduncan** 推出的**免费 shadcn 风格 dashboard blocks 站**：把常用的 dashboard 组件（图表 / 卡片 / 数据展示 / 表格）做成一组组可直接复制的 blocks。

## 一行安装

```bash
npx shadcn add @blocks-so/dashboard-01
```

## 为什么用它 / 适合什么场景

- 想快速搭 SaaS / 后台仪表盘，不想自己写每个组件。
- 喜欢 shadcn 风格但想用现成的 blocks 而不是单组件。

## 关键能力

| 能力 | 说明 |
|------|------|
| shadcn 风格 | 与生态一致 |
| 一行安装 | `npx shadcn add @blocks-so/...` |
| 免费 | 开源 / 免费 |
| 模块化 | 按块安装 |
| Dashboard | 仪表盘专用 |
