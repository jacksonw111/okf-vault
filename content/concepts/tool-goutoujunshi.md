# goutoujunshi（狗头军师）

## 它是什么

[`goutoujunshi`](https://github.com/powerycy/goutoujunshi)（狗头军师）是一个面向**恋爱全周期**的 Codex AI 助手。**先接住情绪再分析关系**，拆开事实 / 猜测 / 未知，最后给出可执行的下一步策略——而不是绝大多数恋爱 AI 的「勇敢追」或「赶紧分」二选一。

## 与「套路式恋爱 AI」的差异

| 套路式 AI | goutoujunshi |
|----------|--------------|
| 给情绪化建议 | 先稳住情绪 |
| 二选一结论 | 拆开事实 / 猜测 / 未知三层 |
| 鼓励冒险 | 给真的能执行的下一步 |
| 泛泛之谈 | 内置跨学科知识库（心理学 / 沟通学 / 行为经济学） |

## 设计哲学

1. **先共情，再分析**：用户带着情绪来，先接住，再讲理；
2. **拆三层**：哪些是事实、哪些是用户的猜测、哪些其实是未知——分别对待；
3. **可执行**：输出「下一步做什么」，而不是「你应该……（鸡汤）」。
