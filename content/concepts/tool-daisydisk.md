# DaisyDisk

## 它是什么

[DaisyDisk](https://daisydiskapp.com) 是 macOS 上老牌**商业**磁盘空间分析工具——用 sunburst 图直观展示每个目录占多少空间，支持一键清扫可识别的大文件 / 缓存。

## 关键能力

| 能力 | 说明 |
|------|------|
| 可视化 | sunburst（多层环形）图 |
| 速度 | 扫描本地磁盘秒级出图 |
| 一键清扫 | 对系统能识别为「可安全删除」的部分提供快速入口 |
| 大文件定位 | 直接找出占空间最多的目录/文件 |
| 商业授权 | 单设备一次性买断，非开源 |

## 适合场景

- macOS 用户想最快速度搞清「磁盘都被什么占着」
- 不想折腾命令行 / 自部署工具
- 接受一次性付费换取省心体验

## 与同类开源工具的对比

- 开源替代：[petal](./tool-petal-disk.md) — 同样 sunburst + 安全等级清单，边扫描边画精确到字节
- 系统自带：[macOS 磁盘工具](./tool-macos-disk-cleanup.md) — 仅基础功能
