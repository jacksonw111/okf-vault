# personal-os-setup（AmineDjeghri/personal-os-setup）

## 它是什么

`AmineDjeghri/personal-os-setup` 是**一条命令**就能在 **Windows、Linux、macOS、WSL2** 甚至 **Google TV** 上搭出**一致开发环境**的工具。它集成各平台原生包管理器（**winget、apt/snap/yay、brew**），内置 WSL2 发行版管理工具，还能一键配置 **Windows Terminal 主题和字体**。

## 为什么用它 / 适合什么场景

- 在多平台之间切换（公司 Windows + 家里 macOS + 服务器 Linux）时，希望**同一套脚本搞定**；
- 新机器 / 重装系统时，希望**一行命令拉起**完整开发环境；
- 同时用 WSL2 + 原生 Linux，希望统一管理。

## 关键能力

| 能力 | 说明 |
|------|------|
| 跨平台 | Windows / Linux / macOS / WSL2 / Google TV |
| 平台原生包管理 | winget / apt / snap / yay / brew |
| WSL2 管理 | 内置发行版管理工具 |
| 终端配置 | Windows Terminal 主题字体一键 |
| 一行命令 | 整套环境一气呵成 |
