# AI-Portfolio-Compass

[AI-Portfolio-Compass](https://github.com/Elian-dan/AI-Portfolio-Compass-public) 是跑在本地的**投资组合工作台**,前端 React + Vite,后端 FastAPI。把 A 股基金、A 股股票、美股、港股这些**散在不同 App 里的资产并成一个总览**,统一不同币种和口径算清账,并接入 AI 帮你**诊断组合 + 复盘交易**。**AI 只诊断,绝不替你买卖。**

## 它解决了什么

散户最常见的痛:持仓散布在 N 个券商 / 银行 App,每个 App 一套统计口径(基金净值 vs 股票浮动盈亏 vs 美股盘后价),总账算不清。AI-Portfolio-Compass 把这些拼成一张表,再让 AI 看你历史买卖复盘做总结。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多市场合并 | A 股基金 / 股票 / 美股 / 港股同表 |
| 多币种统一 | 自动换算统一本位币 |
| AI 诊断 | 帮你分析组合结构、行业暴露、集中度风险 |
| 复盘助手 | 拉历史交易复盘对错 |
| 本地运行 | 数据 / 模型不出本机 |
