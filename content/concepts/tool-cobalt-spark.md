# cobalt-spark (azhuchuchkov)

## 它是什么

[cobalt-spark](https://github.com/azhuchkov/cobalt-spark) 是一个**配色克制、突出命令行的极简 Oh My Zsh 主题**。**用闪电符号分隔上下文与命令**——扫屏时容易定位。

![cobalt-spark 截图](https://pbs.twimg.com/media/HO1XQx-acAAE8Pk.jpg)

## 它显示什么

- 上级目录
- 当前分支
- 分离 HEAD 状态
- 工作区改动
- 未推送提交
- Python 虚拟环境（通过 virtualenv 插件）
- 嵌套 shell 提示
- 后台任务提示

## 为什么用它 / 适合什么场景

- **配色克制**：低饱和，不抢戏。
- **闪电分隔**：上下文 / 命令一眼分开。
- **信息密度可控**：必要信息全部上墙，不堆无关装饰。
- **Python 友好**：virtualenv 插件集成，Python 项目一眼可见当前环境。

## 关键能力

| 能力 | 说明 |
|------|------|
| 闪电分隔 | 上下文 ↔ 命令视觉断开 |
| Git 状态 | 上级目录 / 分支 / 分离 HEAD / 改动 / 未推送 |
| Python 环境 | virtualenv 插件集成 |
| 嵌套 shell | 检测并提示 |
| 后台任务 | 检测并提示 |
| 配色克制 | 不抢戏 |
