# keepIT

支持多人共享、实时同步、搜索和提醒的自托管笔记系统，配套 Android 应用、桌面小部件与离线能力。

## 适用场景

- 需要支持多人共享和实时同步的场景。

## 关键能力

| 能力 | 说明 |
|------|------|
| 协作与同步 | 支持多人共享和实时同步。 |
| 跨场景使用 | 提供 Android 应用、桌面小部件和离线访问。 |
| 信息管理 | 内置搜索与提醒。 |
