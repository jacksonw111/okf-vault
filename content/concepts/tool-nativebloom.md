# NativeBloom（1000+ React Native 组件区块）

## 它是什么

一个 React Native 的**区块（blocks）库**，站内已超过 1000 个可直接取用的组件区块，同时可当作真实实现的范例来读。

视频：<https://video.twimg.com/amplify_video/2095853908572925952/vid/avc1/1920x1080/R6n9H4lF7ThJ8we9.mp4?tag=29>

## 为什么用它 / 适合什么场景

- React Native 生态里成体系的 UI 区块资源比 Web 少，逐个页面从零写成本高。
- 拿现成 block 当参考实现，比对着文档猜手势 / 动画写法更快。
