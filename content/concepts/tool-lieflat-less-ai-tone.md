# lieflat-less-ai-tone

## 它是什么
[`larashero3-dotcom/lieflat-less-ai-tone`](https://github.com/larashero3-dotcom/lieflat-less-ai-tone) 用 **283 万字对照语料**做统计检验，找出真正能把「AI 生成文本」与「人类写作」区分开的特征，再把这些特征**工程化**为一份可执行的去 AI 味改写规则集——可作为 Skill 加载、可作为本地脚本跑、也可作为审稿时的核查清单。

## 为什么用它 / 适合什么场景
- 内容创作者：用 AI 起草后想真正去掉「一眼假」的 AI 味，但又怕「过度改写」丢掉信息。
- 编辑 / 审稿：想用客观指标判断「这段是不是 AI 写的」，而不是凭直觉。
- 教学：想给学员一份「AI 文本特征图谱」而非泛泛的「不要用 AI」说教。

## 关键能力
| 能力 | 说明 |
|------|------|
| 大语料验证 | 283 万字对照语料做统计检验 |
| 特征工程化 | 把高区分度特征抽象成可执行规则，不是「感觉像」 |
| 规则可加载 | 改写规则可作为 Skill / 脚本 / 审稿清单 |
| 多场景适用 | 适合营销文案、学术写作、社交媒体、自媒体多类文本 |
