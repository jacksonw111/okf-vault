# dsh-plugin-shop

## 它是什么
`dsh-plugin-shop` 是面向 [DeepSeek Harness](https://github.com) 用户的**插件目录/应用商店**：把所有可用 DSH 插件集中到一个可浏览、可审计的列表里，解决「插件散落各处、不知道装什么、不知道装没装最新版」的问题。

## 为什么用它 / 适合什么场景
- 想系统找 DSH 周边插件，但不想一个个翻 GitHub。
- 想知道哪些插件被社区广泛使用、有审计/安全记录。
- 想一条命令查 → 装 → 启用 → 更新一条龙。

## 关键能力
| 能力 | 说明 |
|------|------|
| 集中目录 | 一个页面浏览所有 DSH 插件 |
| 可审计 | 显式标注审计/安全状态 |
| 安装/启用/更新一站 | 不用跳到各 repo 自寻 |
| 解决发现性 | 不再"知道有插件存在才装得到" |
