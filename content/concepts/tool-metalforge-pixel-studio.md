# MetalForge Pixel Studio

## 它是什么

`metalforge.xyz` 上的 **Pixel Studio**：在线制作自定义**像素动画**。与同站的进度条、Orbs 系列属于不同主题的动效模块。

视频：<https://video.twimg.com/amplify_video/2095557022267625472/vid/avc1/2102x1400/i1DYFNdoPtT0m2fq.mp4?tag=29>

## 为什么用它 / 适合什么场景

- 做像素风的小游戏 / 复古界面，需要现成可自定义的像素动效。
- 不想为一段 loading / 装饰动画单独开 Aseprite 手工逐帧画。
