# Marea（Wayland 桌面合一外壳）

## 它是什么

[Marea](https://github.com/k4ditano/marea-plm) 是 k4ditano 开源的 Wayland 桌面合一外壳：把通知中心、搜索器、截图、锁屏这些本来要装好几个工具的功能合在一起，再加一只趴在屏幕顶上的「球」作点缀。

## 关键能力

| 能力 | 说明 |
|------|------|
| 通知中心 | 统一的系统通知中心 |
| 搜索器 | 应用 / 文件统一搜索入口 |
| 截图 | 集成截图能力 |
| 锁屏 | 锁屏界面 |
| 装饰小球 | 屏幕顶上一只可定制的球 |

## 适用场景

- Wayland 用户想要「类 macOS 一体化体验」
- 想用一个工具替代多个独立小工具
- 喜欢自定义桌面风格
