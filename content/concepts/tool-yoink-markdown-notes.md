# YOINK（Python 终端 Markdown 笔记工具 + 自我结算预测记录）

## 它是什么

[DefiLeoo/YOINK](https://github.com/DefiLeoo/YOINK) 是 Leo 开发的 **Python 终端笔记工具**：底层就是普通 Markdown 文件夹，可直接用 Obsidian 打开，**零第三方依赖**。

它还能把笔记变成**可自我结算的预测记录**——给一个预测条目 + 截止日期 + 数据源，到期自动对照数据源判定对错，算出**过度自信分数**。

## 关键能力

| 能力 | 说明 |
|------|------|
| 终端原生 | Python CLI，零第三方依赖 |
| Markdown 文件夹 | 笔记就是普通 .md，可直接被 Obsidian / Vim / VS Code 打开 |
| 预测记录 | 把笔记条目变成可结算的预测 |
| 数据源对照 | 到期自动拉数据源判定对错 |
| 过度自信评分 | 自动算出用户的过度自信程度 |

## 适合谁

- 想用终端写笔记、不想被 IDE / SaaS 绑架
- 想做**预测市场式的自我反思**——写下预测，到期结算
- 想用 Obsidian 打开但用终端快速写
