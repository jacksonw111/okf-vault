# Sleepwalker

## 它是什么
品牌"AI 搜索可见度"监测工具：扫描目标品牌在 ChatGPT、Perplexity、Grok、Gemini 等 AI 搜索回答中被提及与引用的频率，序列化被引用的网页，评分内容深度 / 新鲜度并给出 SEO/GEO 优化建议，结果统一落入一个工作区。

## 为什么用它 / 适合什么场景
- 想量化自家品牌在"AI 搜索时代"的曝光——传统 SEO 之外的新维度。
- 想找到内容里被 AI 频繁引用的"权威源"页面去做优化。
- 想把 AI 搜索可见度当作常规监控指标，跟排名一样看趋势。

## 关键能力
| 能力 | 说明 |
|------|------|
| 多平台覆盖 | 同时扫描 ChatGPT / Perplexity / Grok / Gemini 等 AI 搜索 |
| 网页序列化 | 把被引用的网页内容抓回来 |
| 深度 / 新鲜度评分 | 给"为什么被引用"打分 |
| 优化建议 | 输出针对性的 SEO / 内容优化动作 |
| 工作区聚合 | 所有结果沉淀到统一工作区方便回看 |
