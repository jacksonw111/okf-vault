# drawably

## 它是什么
`dwhitedesign/drawably`（站点 [drawably-site.pages.dev](https://drawably-site.pages.dev/)）是一个**手绘风 UI 控件库**：每个按钮、开关、滑块看上去都像「现场画出来」的。最大亮点是**每次组件挂载都重新画一次笔触**——同一个按钮，每次刷新页面都是「不同的画」，永远不重复。

## 为什么用它 / 适合什么场景
- 给产品 demo / 早期原型一个**有温度、不刻板**的视觉。
- 博客 / 个人主页 / 写作平台想要「手帐感 / 涂鸦感」UI。
- 教学场景：用「像被画出来」的按钮，让学习者感觉更轻松。
- 强调**每件作品唯一性**的产品（独立游戏、插画周边）。

## 关键能力
| 能力 | 说明 |
|------|------|
| 每次挂载重画 | 新笔触不重复，每个实例都是「独一无二的手绘」 |
| 4 KB 零依赖 | 不依赖 React / Vue / 任何框架，原生 DOM 可用 |
| 手绘风格控件 | 按钮 / 开关 / 输入框 / 复选框等常见组件 |
| 零构建集成 | 直接 `<script>` 引入或拷贝 CSS/JS |
