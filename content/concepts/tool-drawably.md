# drawably

## 它是什么

[Danilaa1/drawably](https://github.com/Danilaa1/drawably) 是**把 HTML 控件换成手绘钢笔风格的库**：表单 / 按钮 / 文本装饰等元素，每次挂载时都重新生成**独一无二的手绘钢笔线条**；原生键盘 / 表单 / 无障碍行为**全部保留**。

## 核心特性

| 特性 | 说明 |
|------|------|
| 手绘钢笔 | 每次挂载重新生成 |
| 原生兼容 | 键盘 / 表单 / a11y 全保留 |
| 独特外观 | 每次都不一样 |
| 轻量集成 | 标准 HTML 元素替换 |

## 为什么用它 / 适合什么场景
- 想要一种「手作、非工业感」的网页风格。
- 教学 / 文化 / 儿童网站。
- 不想牺牲可访问性又要个性外观。

## 关键能力

| 能力 | 说明 |
|------|------|
| 手绘 SVG | 钢笔线条风格 |
| 原生兼容 | 不破坏交互 |
| 无障碍 | a11y 全保留 |
| 每次独特 | 重新生成 |
