# StockPet

## 它是什么
[YellowPancake/StockPet](https://github.com/YellowPancake/StockPet) 是**桌面股票养宠物**——把分时行情养在桌面角落。痛点：上班想盯盘但又怕太显眼、想看又不想被看到、被弹窗打断工作。

StockPet 的解法：

- 桌面角落**静默显示**自选股的实时涨跌幅（不弹窗、不抢焦点）；
- 涨跌幅**触及设定阈值**时，用**小牛 / 小熊动画**提醒（牛 = 涨、熊 = 跌）；
- 动画温和不刺眼，不会被同事一眼看出「这人在盯盘」；
- 支持 **A 股、港股、美股**多市场。

## 为什么用它 / 适合什么场景
- 上班族 / 学生**想盯盘但怕被看到**——角落小动画比弹窗更隐蔽；
- 不想被高频通知打断，只在**关键阈值**被触发时才知道；
- 同时关注**多市场**自选股，需要一个统一展示；
- 给桌面加点趣味——牛熊动画本身就有「陪伴感」。

## 关键能力
| 能力 | 说明 |
|------|------|
| 多市场 | A 股 / 港股 / 美股 |
| 角落展示 | 静默显示，不弹窗抢焦点 |
| 阈值提醒 | 涨跌幅触及设定阈值才触发 |
| 牛熊动画 | 牛 = 涨 / 熊 = 跌，温和不刺眼 |
| 隐蔽性强 | 动画体积小、不易被察觉 |
| 自选股 | 用户自定义关注的标的列表 |
