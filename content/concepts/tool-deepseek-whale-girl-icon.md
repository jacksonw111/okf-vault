# deepseek-whale-girl-icon

## 它是什么
`fornarwhal/deepseek-whale-girl-icon` 是给 **DeepSeek Harness (DSH)** 桌面端生态准备的一套「**鲸鱼娘**」主题 **应用图标 + 高清原图素材包**。同一个 IP（鲸鱼娘 / DeepSeek V4 Pro 二创角色）可被多个 DSH 桌面壳项目复用，避免每个仓库各画一遍。

## 为什么用它 / 适合什么场景
- 想做一个 DSH 桌面壳应用但不想自己画图标。
- 已有桌面壳想换一套识别度高、风格统一的图标。
- 鲸鱼娘 IP 粉丝 / 二创者：手里多一份合规可用的原图。
- 给 DSH 桌面端 / 主题包项目引流：图标统一了，整个 DSH 桌面生态看起来更成体系。

## 关键能力
| 能力 | 说明 |
|------|------|
| 应用图标 | 各平台桌面端（macOS / Windows / Linux）所需尺寸的 PNG / ICO / ICNS 资源 |
| 高清原图 | 高分辨率角色立绘，方便二次裁切 |
| 与 DSH 桌面壳配套 | 直接套用到 `deepseek-harness-desktop` 等桌面壳 |
| 鲸鱼娘主题 | 与 `dafeiyu-pet`、`dsh-deep-whale` 等鲸鱼娘系列桌面主题视觉一致 |
