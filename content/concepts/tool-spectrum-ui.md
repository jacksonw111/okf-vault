# Spectrum UI

## 它是什么

[ui.spectrumhq.in](https://ui.spectrumhq.in) 是 arihantCodes 开源的 UI 组件合集站（**Spectrum UI**）：覆盖按钮 / 卡片 / 表单 / 数据表 / 弹窗等高频组件，采用 **shadcn** 风格 + Motion 动效，组件**可探索 / 可交互**。

## 代表组件

| 组件 | 说明 |
|------|------|
| Data Table | shadcn + motion 驱动，借鉴 Linear 设计语言 |
| 表单 | 输入 / 选择 / 校验全套 |
| 弹窗 / 模态 | 含动效与焦点管理 |
| 卡片 / 按钮 | 通用 UI 基础件 |
| 动效 | Motion 库加持 |

## 为什么用它 / 适合什么场景

- 想用 shadcn 风格但要更「现成」的整站组件合集。
- 想给项目找带动效的 UI 库参考。
- 设计师 / 前端工程师收集灵感 / 借鉴交互。

## 关键能力

| 能力 | 说明 |
|------|------|
| shadcn 风格 | 复制粘贴即用 |
| Motion 动效 | 自带动效细节 |
| Linear 借鉴 | Data Table 风格 |
| 开源 | 代码可见可改 |
| 高频组件 | 含 Data Table 等关键件 |
