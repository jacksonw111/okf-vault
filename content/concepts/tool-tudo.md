# tudo

## 它是什么

[tudo](https://github.com/jolleyDesign/tudo) 是一个**跑在终端里的「待办 + 笔记」二合一 TUI 工具**——

- **任务模块**：GTD 风格任务管理
- **笔记模块**：纯 Markdown 笔记本

在一个工具里同时管「做什么」和「知道什么」。

## 关键能力

| 模块 | 能力 |
|------|------|
| 任务 | 优先级、故事点、截止日期、标签、子任务、归档 |
| 笔记 | 纯 Markdown 编辑、渲染预览、Wiki 链接、标签、置顶 |
| 形态 | 终端 TUI，原生本地 |

## 任务模块细节

| 字段 | 说明 |
|------|------|
| 优先级 | 高 / 中 / 低 |
| 故事点 | 估算工作量（Fibonacci 风格） |
| 截止日期 | 到期提醒 |
| 标签 | 多标签分类 |
| 子任务 | 任务可拆分 |
| 归档 | 已完成任务归档 |

## 笔记模块细节

| 能力 | 说明 |
|------|------|
| 纯 Markdown 编辑 | 原生 .md 文件 |
| 渲染预览 | TUI 内预览渲染效果 |
| Wiki 链接 | `[[link]]` 风格双向链接 |
| 标签 | 多标签 |
| 置顶 | 重要笔记置顶 |
