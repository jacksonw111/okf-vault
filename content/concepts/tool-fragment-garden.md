# fragment-garden

[fragment-garden](https://github.com/Zev55555/fragment-garden) 是一款以**像素花园 / 庭院散步**为隐喻的碎片想法应用：你随手记的想法会自动归类进花园，过几天「在庭院里散步」时能再随机翻到，从而解决「收藏夹存了再也没翻过」的问题。

## 它是什么

不是传统的标签 / 文件夹笔记产品，而是把「想法」和「花园里的物品」挂钩——

- 碎片记下 → 自动归类（埋进花园某处）
- 隔几天去逛庭院 → 随机散步时撞见旧想法
- 隐喻替代手动整理：分类由系统完成，你只需要记

## 为什么用它 / 适合什么场景

| 痛点 | 这种设计怎么回应 |
|------|------------------|
| 收藏夹存了不翻 | 「庭院散步」让旧想法主动浮现 |
| 手动打标签太累 | 归类由「花园」自动决定 |
| 笔记软件长成列表 | 用像素庭院的视觉隐喻提升重访率 |
| 没法重温随机旧条目 | 散步式随机遭遇而不是按时间翻 |

## 关键能力

| 能力 | 说明 |
|------|------|
| 随手记 | 极简输入，零负担 |
| 自动归类 | 由系统把想法埋入像素花园 |
| 庭院散步 | 间隔一段时间以探索方式重访旧想法 |
| 像素美学 | 视觉隐喻替代列表，让人想回来 |
