# Kiroku

## 它是什么

[`DevysonSilva/kiroku`](https://github.com/DevysonSilva/kiroku) 是一个**全栈个人动漫 / 漫画 / 小说追番追读工具**，替代表格和零散的「我追过啥」列表，集中管理观看 / 阅读进度、评分、笔记。

## 核心能力

| 能力 | 说明 |
|------|------|
| 统一进度 | 一处记录动漫看到第几集、漫画看到第几话、小说读到第几章 |
| 评价系统 | 对每部作品打分、写短评 |
| 笔记 | 关联到具体集 / 话 / 章节，写下想法 |
| 三类作品 | 同时覆盖动画 / 漫画 / 小说（部分 tracker 只管其中一项） |
| 自托管 | 全栈项目，本地或自托管部署 |

## 解决什么痛点

- 既有表格（Notion / Excel）追番追到一半就弃了
- 第三方平台（Bangumi / AniList）功能受限、广告多、数据不在自己手里
- 同一时间追 20 部，想找回「上次看到哪儿了」

## 适合什么场景

- 重度二次元 / 轻小说读者，需要追踪大量作品进度
- 想自托管一份属于自己的观看历史 + 笔记，不依赖商业平台

## 与同类工具的差异

| 工具 | 范围 | 差异 |
|------|------|------|
| [Biliroaming](./tool-biliroaming.md) | B 站大会员 / 港澳台 | 解锁 B 站限制，不是 tracker |
| [TonKATSU Box](./tool-tonkatsu-box.md) | 番剧下载 / 整理 | 偏资源管理，不是进度笔记 |
| Kiroku | 进度 + 评价 + 笔记 | 自托管的全栈 tracker |
