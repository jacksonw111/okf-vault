# lcu

## 它是什么

[lcu](https://github.com/amontlabs/lcu) 是 **amontlabs** 开源的项目——把 Codex App 最强的 **Computer Use** 功能**直接迁移到 Pi Agent**：在 Pi 里面就能控制整台电脑，把桌面级 GUI 自动化接进 Pi 的 agent 工作流。

## 关键能力

| 能力 | 说明 |
|------|------|
| Computer Use | 模拟键鼠 / 截屏 / 操作任意 GUI 应用 |
| 宿主 | Pi Agent（而非 Codex App） |
| 跨平台 | 由 Pi 的执行环境决定 |
| 开源 | 仓库在 GitHub |

## 适合场景

- 想让 Pi Agent 操作 SaaS / 桌面软件（这些没有 API）
- 不想被绑死在 Codex App 的产品形态里
- 想把 Computer Use 拼到 Pi 自带的工具链里
