# Emeraldian

## 它是什么

[Emeraldian](https://github.com/iamrohithrnair/emeraldian) 是一个用 **Rust 写的 Obsidian 风格终端 UI**：在终端里呈现出 Obsidian 标志性的三栏布局（文件夹 / 文件列表 / 编辑 / 预览一侧）、**实时 Markdown 预览**、**反向链接**、**力导向关系图**和 **18 套主题**。整一个「Obsidian 的终端替身」。

## 为什么用它 / 适合什么场景

- 终端党 / VPS-only 用户：不想为了一个知识库切到 GUI 应用。
- 服务器或 SSH 工作流里写作：随时随地记笔记、维护反向链接网络。
- 想做完全本地、纯文本优先的「知识图谱」工具，又不想完全抛弃 Obsidian 那种结构感。

## 关键能力

| 能力 | 说明 |
|------|------|
| Rust TUI | 单一二进制，跨平台 |
| 三栏布局 | 文件树 / 列表 / 编辑预览类 Obsidian |
| 实时预览 | 编辑与渲染同步 |
| 反向链接 | Wiki-style `[[link]]` 引用追踪 |
| 力导向图 | 笔记关系可视化 |
| 18 套主题 | 不同风格切换 |
