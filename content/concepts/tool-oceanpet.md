# OceanPet

## 它是什么
`cpp285/OceanPet` 是一个 **macOS 桌面 AI 桌宠**：让一个**有角色设定的 AI 形象**（默认海洋 / 海生物 IP）常驻桌面。桌宠会**自己在屏幕上散步、跟用户的鼠标「互动」**，还能**用角色性格**陪用户聊天——不是「无情的 Q&A 框」，是「有脾气有设定的虚拟伙伴」。

## 为什么用它 / 适合什么场景
- 想要一个会动的、活的桌面陪伴，缓解一个人写代码时的孤独感。
- 给团队 demo / 视频录制加个可爱元素。
- 想体验「带角色」AI 对话（不像 ChatGPT 那么正），适合闲聊 / 减压。
- 桌宠路线（与桌宠生态 `dafeiyu-pet` 等）爱好者集邮。

## 关键能力
| 能力 | 说明 |
|------|------|
| 常驻桌面 | macOS 桌面宠物，应用层而非浏览器层 |
| 自动散步 | 桌宠会在屏幕空闲时自己走动，不打扰输入 |
| 鼠标互动 | 检测鼠标位置 / 点击，桌宠会「看向」或「追」鼠标 |
| 角色化对话 | 接入大模型，但用角色设定 + 性格 prompt 过滤输出 |
| 聊天窗口 | 双击桌宠可开对话气泡，跟普通聊天工具无异 |
