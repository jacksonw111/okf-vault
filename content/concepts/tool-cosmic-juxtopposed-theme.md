# COSMIC Juxtopposed 像素风蓝色主题包

## 它是什么

[juxtopposed/cosmic](https://github.com/juxtopposed/cosmic) 是一套给 [COSMIC 桌面](https://system76.com/cosmic) 用的**成套像素风蓝色主题**：配色方案、字体、光标、壁纸、终端配色都打包在一起，下载导入就能整套换皮，不用逐项设置。

![](https://pbs.twimg.com/media/HQdH2uKakAACQ4N.jpg)

## 为什么用它 / 适合什么场景

- **想用 COSMIC 但嫌默认主题单调**：直接换一套有「设计感」的主题。
- **像素风 / 复古蓝色爱好者**：整套协调的视觉风格。
- **不想自己一项一项配**：主题一次性给齐，避免配色与字体不搭。
- **Linux 桌面新鲜人**：COSMIC 还是新生态，能直接 ship 的成套主题不多。

## 关键能力

| 能力 | 说明 |
|------|------|
| 配色 | 一套协调的蓝色调色板 |
| 字体 | 配套字体（偏像素 / 等宽） |
| 光标 | 自定义光标样式 |
| 壁纸 | 与主题协调的桌面壁纸 |
| 终端配色 | 终端颜色方案与桌面同步 |
