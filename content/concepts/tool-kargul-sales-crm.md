# kargul/sales-crm

## 它是什么

[kargul/sales-crm](https://github.com/kargulstudio/sales-crm) 是 **kargulstudio** 开源出来的销售 CRM 模板作品——UI 风格现代、字段结构按「真实销售流程」预置好，可作为自托管销售系统起点。

## 关键能力

| 能力 | 说明 |
|------|------|
| 字段结构 | 按 B2B 销售管道（lead / opportunity / deal）预置 |
| 视觉风格 | 现代 SaaS 卡片 / 时间线 / 看板 |
| 起点定位 | 模板项目，二次开发友好 |
| 开源 | 可自托管 |

## 适合场景

- 想自建 CRM、又不想用 Salesforce / HubSpot 类订阅服务的小团队
- 需要把客户数据留在自己手里的合规 / 隐私场景
- 作为 AI 编码 agent 生成定制 CRM 的参考结构（字段已规划合理）
