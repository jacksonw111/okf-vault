# presenter-mode

[presenter-mode](https://github.com/jinnyjiinlee/presenter-mode) 把任意 HTML 幻灯片加上**演示者视图**(演讲者备注 + 计时器 + 黑屏等),**单 HTML 文件**实现,**无需安装、无需联网**。

## 它解决了什么

做技术分享时:Keynote / PowerPoint 又重又要装,但演示者视图(演讲者看下一张 / 计时 / 备注)是刚需。presenter-mode 只用一份 HTML 套在已有幻灯片外面,演讲者视图功能立刻有。

## 关键能力

| 能力 | 说明 |
|------|------|
| 单 HTML 文件 | 一个文件就是一个工具,U 盘拷走即用 |
| 离线运行 | 没有依赖,断网也能讲 |
| 通用代理 | 不绑定某个幻灯片框架,任何 HTML 都能套 |
| 演讲者视图 | 备注 / 计时 / 黑屏都到位 |
