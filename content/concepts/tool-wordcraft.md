# WordCraft

## 它是什么

[WordCraft](https://github.com/storytold/wordcraft) 是 storytold 团队用**纯 Rust** 从零写的**开源文字处理软件**：

- 兼容 **.docx** 编辑
- 排版、PDF 导出**不依赖微软 Office**
- 可由 **AI Agent 通过 CLI 与 MCP 驱动**

## 为什么用它 / 适合什么场景

- **不想给 Office 月费**：开源 + 商用友好
- **Linux / 跨平台**：.docx 在 Linux 上读 / 写 / 导 PDF
- **Agent 写文档**：让 AI 自动排版 / 出报告 / 批量生成文档
- **隐私**：本地处理，文档不上云

## 关键能力

| 能力 | 说明 |
| ------ | ------ |
| 引擎 | Rust 写 |
| 文件格式 | 兼容 .docx |
| PDF 导出 | 内置导出，无依赖 Office |
| CLI / MCP | Agent 可驱动 |
| 跨平台 | Rust 二进制 |
| 形态 | 开源文字处理软件 |
