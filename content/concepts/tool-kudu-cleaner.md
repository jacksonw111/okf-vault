# Kudu（跨平台开源系统清理工具）

## 它是什么

[`AdventDevInc/kudu`](https://github.com/AdventDevInc/kudu) 是一款**免费 + 开源 + 跨平台**的系统清理工具，一套 UI 同时覆盖 Windows / macOS / Linux 三系统。

## 关键能力

| 能力 | 说明 |
|------|------|
| 垃圾文件清理 | 临时文件 / 缓存 / 缩略图 / 系统日志 |
| 浏览器缓存清理 | Chrome / Firefox / Edge / Safari 等多浏览器 |
| 注册表清理 | Windows 端特有的死链 / 残留项清理 |
| 磁盘分析 | 可视化磁盘占用，找大文件 |
| 开机启动项管理 | 控制开机自启的应用 |
| 恶意软件扫描 | 内置 / 集成恶意软件识别 |
| 隐私保护 | 清浏览痕迹 / Cookie / 输入历史 |

## 为什么用它

- **跨平台一致体验**：一台电脑装 Win + macOS（开发机），UI 和操作一致
- **免费开源**：不像 CCleaner Pro 那样付费解锁
- **隐私友好**：数据完全在本机，不上传
- **一体化**：清理 + 磁盘分析 + 启动项管理 + 安全扫描全在一个 App

## 适用场景

- 经常装机 / 重装系统的开发者
- 关心个人隐私但不想用付费工具的用户
- 跨平台办公 / 学习的用户
- 系统盘越用越满想找出大文件的用户
