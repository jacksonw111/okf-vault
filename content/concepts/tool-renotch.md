# renotch（把 Mac 刘海变成开发状态栏）

## 它是什么

MacBook 屏幕上方的刘海区域平时是空的。renotch 把它变成一条**开发状态栏**：本地服务是否在跑、当前播放的音乐、番茄钟计时，都在刘海里搞定。

![](https://pbs.twimg.com/media/HRRaCnIaIAAa66d.jpg)

## 关键能力

| 能力 | 说明 |
|------|------|
| 服务状态 | 显示本地开发服务的运行状况 |
| 音乐 | 当前播放信息与控制 |
| 番茄钟 | 专注计时常驻可见 |
