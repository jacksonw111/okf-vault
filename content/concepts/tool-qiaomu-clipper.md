# Qiaomu Clipper（乔木剪藏）

## 它是什么

**Qiaomu Clipper（乔木剪藏）** 是 joeseesun 出品的开源浏览器剪藏工具——把「收藏了一堆文章和视频却没消化」的痛点，变成「**能读、能问、能记**」的工作流：选段直接问 AI，视频里点字幕回看，想法随手进 Obsidian 日记。

## 为什么用它 / 适合什么场景

- **文章剪藏**：划段 → 提问 → 把 AI 回答和原文段落一起存
- **视频剪藏**：看视频时点字幕，把片段时间戳 + 文字一并保存
- **Obsidian 集成**：剪藏结果直接落到 Obsidian 仓库的日记里
- **AI 内置**：不用切换工具就能问剪藏内容

## 关键能力

| 能力 | 说明 |
|------|------|
| 选段提问 | 划一段文字 / 一段视频字幕 → 调用 AI 提问 |
| 视频时间戳 | 点击字幕记录时间戳，方便回看 |
| Obsidian 同步 | 剪藏内容按日记日期落到本地 Markdown |
| AI 模型可选 | 自己配 API key，可换底层 LLM |
| 本地优先 | 剪藏数据保存到本地，不上云 |
