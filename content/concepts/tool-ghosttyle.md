# Ghosttyle（Ghostty 可视化配置工作台）

## 它是什么

[JoeyOnMars/ghosttyle](https://github.com/JoeyOnMars/ghosttyle) 给 **Ghostty 终端**套了个**中英双语的网页配置台**：从已安装的 Ghostty 发现主题与字体，提供深浅色实时预览、字体 / 背景 / 光标 / 窗口的可视化控件，外加**保留注释与快捷键的原始配置编辑器**。

## 关键能力

| 能力 | 说明 |
|------|------|
| 自动发现 | 扫描已安装的 Ghostty 主题与字体 |
| 深浅预览 | 实时切换预览 |
| 可视化控件 | 字体 / 背景 / 光标 / 窗口 |
| 原始配置编辑 | 保留注释与快捷键 |
| 中英双语 | 适合跨语言用户 |
| Web 形态 | 浏览器里配置 |

## 与同类对比

| 维度 | Ghosttyle | Sheets（tool-sheets-terminal-themes） | 手写 ghostty config |
|------|-----------|-------|---------------------|
| 终端覆盖 | 仅 Ghostty | Ghostty + Kitty + Alacritty | Ghostty |
| 形态 | 网页 | 桌面应用 | 文件 |
| 双语 | 中英 | 英文 | 英文 |
