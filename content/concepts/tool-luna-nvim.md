# luna.nvim

## 它是什么
luna.nvim 是给 Neovim 设计的一套「近乎纯黑」配色主题。底色全部走灰阶，只用 4 种冷暖强调色（关键字 / 函数 / 类型 / 字符串）做区分，夜间长时编程眼睛不累，语法仍清晰。

## 为什么用它 / 适合什么场景
- 不想用花哨配色的开发者，喜欢低饱和、低对比的「克制感」编辑环境。
- 暗光 / 夜间长时间编程，眼睛怕亮底色。
- 想要「像 Vim 默认配色一样克制、但语法识别更清楚」的主题。

## 关键能力
| 能力 | 说明 |
|------|------|
| 底色 | 全灰阶、几乎纯黑 |
| 强调色 | 4 种冷暖色（key / function / type / string） |
| 风格 | 夜间不刺眼、语法清晰 |
| 适用 | Neovim |
| 许可 | 开源 |
