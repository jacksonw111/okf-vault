# becoming-lab

## 它是什么

[becoming-lab](https://github.com/Jax-void02/becoming-lab) 是一份「对话式 AI 工作流」——不是心理测试，**一次只问一个问题**：先把「迷茫」拆成七种不同的「卡住」状态，再决定下一步是内省、查信息、缩减选项还是行动。方向判断靠三类证据：**愿意认领的动机 / 普通一天过得合不合身 / 现实条件走不走得动**，三类证据凑齐才形成一个方向假设，**默认只保留 2–3 个**。

## 为什么用它 / 适合什么场景

- 处于「想换 / 想试 / 想做点什么但说不清要什么」的阶段。
- 想用 AI 做一次结构化的方向探索，而非单纯的灵感收集。
- 想避免「一次列出 20 个方向」式 overload（默认保留 2–3 个）。
- 想把「迷茫 → 行动」的过程沉淀为可复用的 prompt 工作流。

## 关键能力

| 能力 | 说明 |
|------|------|
| 七种卡住状态 | 内省 / 信息缺失 / 选项过载 / 完美主义 / 身份错位 / 价值真空 / 行动瘫痪 |
| 三类证据 | 动机认领 / 日常合身度 / 现实条件 |
| 单问推进 | 一次只问一个问题，避免认知 overload |
| 方向假设收敛 | 默认只保留 2–3 个方向假设 |
| 工作流而非测试 | 强调行动导向而非人格化结论 |
