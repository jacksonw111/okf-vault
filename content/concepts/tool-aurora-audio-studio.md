# Aurora Audio Studio

## 它是什么

`swy2018/Aurora-Audio-Studio` 是一个**Windows 本地**的音频 AI 一体化工作台：把原本要分别启动的七类 AI 音频工具——**音乐生成 / AI 配音 / 声音克隆 / 歌声转换 / 音轨分离 / MIDI 扒谱 / 视频字幕**——统一收纳进一个 GUI，共用端口管理、结果目录与缓存。

特点：单一启动器、统一工作台，避免「装七套依赖、配七个 venv、盯七个端口」的零散局面。

## 为什么用它 / 适合什么场景

- 同时需要多种音频 AI 能力（创作歌曲、做有声书、扒谱、分离人声）。
- 想在 Windows 上「装一次、用全套」。
- 不想自己拼装 Muffe / RVC / Demucs / Spleeter / Basic Pitch 等多个工具。
- 想统一管理输入 / 输出 / 中间文件。

## 关键能力

| 能力 | 说明 |
|------|------|
| 音乐生成 | 文案 → 音频 |
| AI 配音 / TTS | 多角色配音 |
| 声音克隆 | 短样本 → 复刻声线 |
| 歌声转换 | 源音频 → 目标歌声音色 |
| 音轨分离 | 把歌曲拆成人声 / 鼓 / 贝斯 / 其他 |
| MIDI 扒谱 | 音频 → MIDI 音符 |
| 视频字幕 | 视频 → SRT / VTT |
| 统一工作台 | 一个 GUI 管所有任务，结果同目录输出 |
