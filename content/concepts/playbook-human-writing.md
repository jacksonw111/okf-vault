# Human Writing Skill（去掉 AI 味）

## 它是什么

Human Writing 是一套 Agent skill，专门解决「AI 写中文读起来顺畅却没有辨识度、不像谁在说话」的常见问题。它把「去掉 AI 味」沉淀成可复用的创作与改稿流程：先固化真实作者的判断、节奏、口吻，再让模型在受控条件下生成，最终产出会带有作者个人痕迹，而非通用的「AI 顺畅体」。

## 为什么用它 / 适合什么场景

- 用 LLM 写中文长文（公众号 / 知乎 / Newsletter）时，受不了「读起来都一个味」。
- 想给自己定制一份专属写作风格，而非用通用 prompt 调出千篇一律的输出。
- 希望模型既保留生成效率，又能体现真实作者立场 / 节奏 / 习惯用词。
- 想把「去 AI 味」沉淀成流程，而非每次临时改 prompt。

## 适用场景

- 中文长文写作（公众号、Newsletter、专栏）。
- 需要保留作者人设的内容（个人 IP、专栏作家、咨询顾问）。
- 团队多人共用一套写作流程，希望输出口径统一。

## 前置条件

- 已确定目标作者的人设 / 立场 / 受众。
- 已准备好若干篇该作者过往作品作为风格样本。
- 已把本 skill 装入目标 Agent。

## 步骤

1. **风格样本采集**：收集目标作者过往作品 5–20 篇，标注出核心立场、节奏、用词习惯。
2. **判断清单固化**：把「什么观点必说 / 什么观点不说」「开头 / 结尾偏好」「段落节奏」等写成可执行 checklist。
3. **口吻模板**：抽离若干高频句式 / 转场 / 收束的句法骨架。
4. **生成阶段**：让模型按 checklist + 模板生成初稿，禁止使用通用 AI 高频套话（「值得一提的是」「综上所述」「不仅……而且」）。
5. **改稿阶段**：按 checklist 反向检查，发现 AI 套话立刻替换为作者本人的表达。
6. **自检清单**：跑固定的「AI 味检测」prompt，对照规则打分。

## 验证 / 自检

- [ ] 通读全文，找出 ≥5 处「AI 套话」并替换成作者本人表达
- [ ] 关键立场 / 价值判断段落是作者本人的判断，不是中性陈述
- [ ] 段落节奏与样本作者一致（短段比例、长句断句位置）
- [ ] 受众读完能「认出来」是谁写的
