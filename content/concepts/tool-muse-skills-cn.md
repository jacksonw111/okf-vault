# Muse Skills 中文玩法 300 条

## 它是什么

[muse-skills](https://github.com/jasonbitsmith/muse-skills) 是 **jasonbitsmith** 出品的 **Muse 中文玩法清单**——给 Meta 的 **Muse 个人助理** 整理 **300 条中文玩法**，每条「**一句话痛点 + 三步说法**」，照着复制就能用。

定位是「**Muse 上手指南 + 玩法词典**」——把 Muse 的能力整理成可执行的最小剧本，避免用户「装了但不知道能干嘛」。

## 为什么用它 / 适合什么场景

- **Muse 新用户** 想快速上手：300 条玩法当 prompt 范例
- **中文场景** Muse 默认英文范例不好用，这套全是中文
- **复制即用**：每条都标了痛点（why）和步骤（how），照抄即可
- 与既有 `awesome-muse-skills`（社区技能目录）**互补**：本仓库是「玩法范例」而非「技能清单」
