# next16-calendar

## 它是什么
**Next.js 16 的「参考实现」项目**。新版 Next.js 的特性（缓存 / 预取 / 即时导航等）通常散落在文档、博客与 RFC 里——next16-calendar 把它们**串成一个完整应用**：日历 + 预约。

- 能跑（一个真实可用的日历 + 预约应用）
- 能测（配套测试）
- 能学（看实际代码怎么写这些新特性）

## 为什么用它 / 适合什么场景
- 想升级到 Next.js 16 但不知道新特性**怎么落地**——比翻文档更直观。
- 想用日历 / 预约作为脚手架快速搭新项目。
- 学习 Next.js 现代特性的「实战范本」，比官方示例更接近真实业务。
