# Fintech Advisor（开源净值与投资组合追踪）

## 它是什么

`KORAYTEACHER/fintech-advisor` 是一个**开源净值与投资组合追踪应用**。明确**不是**预算 / 支出记账 App，而是给「已经在自管资产」的人用：

- **交互式组合图表**——多资产组合的可视化。
- **多币种 + 自动汇率**——跨币种持仓合并展示。
- **AI 一键导入**——把券商 / 表格里的持仓自动结构化导入。
- **Yahoo Finance 日更行情**——美股 / 港股等日更报价。
- **AI 对话**——带着完整组合与历史的 AI 参谋（可以问「我应该怎么调仓」）。

## 为什么用它 / 适合什么场景

- 已有自管股票 / 基金 / 加密资产组合，想统一可视化。
- 想要一个「开源、不上传券商账户」的净值追踪工具。
- 想让 AI 带着完整组合上下文当投顾，而不是从零让它瞎答。

## 关键能力

| 能力 | 说明 |
|------|------|
| 交互式组合图表 | 多资产可视化 |
| 多币种 | 自动汇率换算 |
| AI 一键导入 | 从券商 / 表格智能识别持仓 |
| Yahoo Finance 日更 | 行情数据 |
| AI 对话 | 带着组合上下文的 AI 参谋 |
