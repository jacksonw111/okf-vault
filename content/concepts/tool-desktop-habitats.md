# Desktop Habitats

## 它是什么

[chaseleantj/desktop-habitats](https://github.com/chaseleantj/desktop-habitats) 把**实时渲染的水族箱**糊成 **macOS 动态壁纸**——鱼追着鼠标游、抢饲料，水草顺着水流晃。像极了 Windows 98 那个「情书水族馆」屏幕保护程序，跨平台精神续作。

## 为什么用它 / 适合什么场景

- 桌面想养一缸**会动的鱼**，但又不想真的养（投喂 / 换水 / 水温）。
- 想给 macOS 桌面找个「**长时间看不腻**」的动态壁纸。
- 想顺便怀旧 Windows 那个经典屏保。

## 关键能力

| 能力 | 说明 |
|------|------|
| 实时渲染 | 水族箱是 GPU 实时画出来的，不是循环视频 |
| 互动 | 鱼会**追鼠标游**、**抢饲料** |
| 流体 | 水草顺着水流晃 |
| 动态壁纸 | macOS 桌面 / 锁屏能直接当壁纸用 |
