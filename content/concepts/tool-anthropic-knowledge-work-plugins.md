# Anthropic knowledge-work-plugins

## 它是什么

[Anthropic knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins) 是 Anthropic 官方在 2026 年 10 月开源的「**岗位级 Claude 插件包**」：

- 覆盖 **销售 / 法务 / 财务 / 产品 / 市场 / 客服 / 数据** 等 11 个知识工作岗位
- 每个插件都是「这个岗位怎么干活」的完整知识库
- 附赠该岗位常用的**全套工具连接器**
- 开源、免费、Claude 装上即可

## 为什么重要

第一次让「岗位经验」变成可分发的开源制品：

- 之前：一个岗位 know-how = 这个人脑子里的经验，别人学要走师傅带
- 现在：Claude 装上插件 = 24 小时在线的「半个专家」

## 关键能力

| 能力 | 说明 |
|------|------|
| 11 个岗位插件 | 销售 / 法务 / 财务 / 产品 / 市场 / 客服 / 数据 等 |
| 完整知识库 | 每个岗位的工作流、模板、规范 |
| 工具连接器 | 岗位常用 SaaS / 数据库 / 内部系统的对接 |
| Claude 原生 | 作为 Claude Code 插件直接装 |
| 开源免费 | Apache 之类许可 |

## 适合谁

- 想给团队 Claude 装上「行规」的企业 IT
- 个人想系统补某个岗位的 know-how
- 知识工作者想知道「我的活儿有多少能被 Claude 替」
