# post-investment-platform（VC/PE 投后管理平台）

## 它是什么

[Oliveluo666/post-investment-platform](https://github.com/Oliveluo666/post-investment-platform) 是面向 **VC / PE 投后管理**场景的开源平台：**项目台账**（portfolio ledger）、**财务数据**（financials）、**合规待办**（compliance TODOs）、**报告导出** 集成进同一个界面，替代"项目信息散在 Excel 和各种表里"的现状。

## 为什么用它 / 适合什么场景

- 投后经理 / 基金 IR 想统一追踪被投企业的关键指标、文件、合规节点。
- 中小基金没有预算上 Bloomberg / Carta 等专业系统，需要一个能自托管的轻量替代。
- 想给 LP 出统一格式的投后报告，避免手工拼 Excel。

## 关键能力

| 能力 | 说明 |
|------|------|
| 项目台账 | 被投企业的关键字段、阶段、行业、负责人 |
| 财务数据 | 财报录入 / 三表 / 关键比率 |
| 合规待办 | 监管 / 内部合规事项的提醒与追踪 |
| 报告导出 | 给 LP / 内部用的标准化报告 |
