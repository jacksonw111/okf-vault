# SwiftPieces（SwiftUI 组件库）

## 它是什么

[SwiftPieces](https://swiftpieces.com) 是 saivion 在做的 **SwiftUI 组件库**：把 SwiftUI 开发中常用的 UI 模式封装成可复用的控件，让 SwiftUI 在 iOS App 开发中**更好用、更易表达**。

## 为什么用它 / 适合什么场景

- 在做 iOS / iPadOS App，需要一组高于原生 SwiftUI、低于重组件库的「**中间层控件**」。
- 想少写重复的 layout / state 代码，让 SwiftUI 更像「声明式乐高」。
- 想参考社区实践的 SwiftUI 封装思路。
