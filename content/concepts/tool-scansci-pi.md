# ScanSci Pi (Rimagination/scansci-pi)

## 它是什么
`Rimagination/scansci-pi` 是一套**科研引用 / 证据核对**工作流：把「找论文 → 读文献 → 写笔记 → 做幻灯片」每一步都**钉在原文上**——任何引用 / 论断都必须能追溯到具体文献页码或段落；当证据不足时**明确说明证据缺口**，绝不编造出处或糊弄读者。

## 为什么用它 / 适合什么场景
- LLM 写学术内容时最爱「编一段看似合理的引用」，ScanSci Pi 强制每条引用都能追原文。
- 写综述 / 答辩 / 组会幻灯片时需要可靠引用链，不怕答辩被问出处。
- 想让 AI 科研助手有「证据门槛」，遇到不确定就明确说「这里证据不足」。

## 关键能力
| 能力 | 说明 |
|------|------|
| 引用钉原文 | 每条引用都可追溯到具体文献位置 |
| 证据不足即声明 | 缺证据时明确标记，不糊弄 |
| 端到端工作流 | 检索 → 阅读 → 笔记 → 幻灯片一条龙 |
| 抗幻觉 | 不编造出处，对 LLM 学术引用通病做硬约束 |
