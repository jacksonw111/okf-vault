# Sheets（Ghostty / Kitty / Alacritty 主题管理器）

## 它是什么

[tylersuits1/Sheets](https://github.com/tylersuits1/Sheets) 是一个**专门管三款终端（Ghostty / Kitty / Alacritty）外观**的小型桌面应用：用 Tauri 写的 macOS 原生工具，把三套终端的主题、字体、透明度统一放进一个设置面板。

## 关键能力

| 能力 | 说明 |
|------|------|
| 三终端统一管理 | Ghostty / Kitty / Alacritty 一处切换 |
| 400+ Ghostty 主题 | 自带 400+ 主题库，搜到就能换 |
| 实时预览 | 旁边直接看到代码高亮效果 |
| 色轮 / HEX 输入 | 颜色可以用色轮挑或手输 |
| 场景标签 | 每个主题可标白天 / 晚上 / 都用 |

## 适合谁

- 在 macOS 上同时用 Ghostty / Kitty / Alacritty 三款终端
- 想快速切换主题而不想手写配置文件
- 想给不同主题打「白天用 / 晚上用 / 都用」标签
