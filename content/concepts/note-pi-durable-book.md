# pi-durable-book

## 它是什么

[pi-durable-book](https://github.com/robotbird/pi-durable-book) 是 **robotbird** 翻译整理的《**pi-durable：持久化智能体运行时**》中文手册——把 [earendil-works/pi-durable](https://earendil.com/posts/pi-durable) 的全部文档与示例翻译为中文。

## 内容结构

| 篇章 | 内容 |
|------|------|
| 第一篇 | 快速上手（看做什么） |
| 第二篇 | 规范说明书（看设计原理） |
| 第三篇 | 实现计划（看实现思路） |
| 第四篇 · 00-13 | 底层机制：会话、文档、分叉、监听、Harness |
| 第四篇 · 14-19 | 完整用法：聊天、流式、打印模式、JSON 模式 |
| 第四篇 · 14-31 | 完整用法：子代理、压缩、编码智能体、计划模式 |

## 学习路径

- **想快速了解能做什么**：读第一篇 + 浏览示例 14-19
- **想理解设计原理**：读第二篇 + 第三篇
- **想动手实践**：按第四篇示例教程逐个运行
