# Holosticker

## 它是什么

[Holosticker](https://github.com/jal-co/holosticker) 把「做出镭射 / 全息效果的贴纸」这件事**搬到浏览器里**做成一个工作室：丢进 SVG 或 PNG 图稿，就能在网页里**实时调箔面效果**（闪烁角度 / 颜色光谱 / 高光强度等），**当场预览**，最后导出**带透明通道的 PNG**。

## 为什么用它 / 适合什么场景

- 想做贴纸 / 包装 / 装饰图，先在浏览器里快速试几种镭射参数看效果，省得上 Illustrator / Photoshop 折腾。
- 独立设计师 / 自媒体作者偶发需要全息素材但不想付费买现成。
- 想把一个开源的「镭射材质生成器」嵌入自己的网页 / 工作流。

## 关键能力

| 能力 | 说明 |
|------|------|
| 浏览器内运行 | 不装软件，打开网页即用 |
| SVG / PNG 输入 | 矢量和位点图都接受 |
| 箔面参数可调 | 颜色光谱 / 高光 / 角度都现场试 |
| 透明通道导出 | 输出的 PNG 自带 alpha 通道 |
| 实时预览 | 参数改动即时刷新 |
