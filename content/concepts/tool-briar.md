# Briar

## 它是什么

Briar 是一款去中心化加密消息应用，专为高风险环境（抗议人群、战地记者、维权活动）设计。它通过 Tor / Wi-Fi Direct / 蓝牙三种模式互联，无需手机号、无中心服务器，消息端到端加密。

## 为什么用它 / 适合什么场景

- 关心隐私 / 反对审查的通讯。
- 在网络受限或断网环境（断电 / 关闭基站）下仍能传消息。
- 不想被任何中心服务器掌握通讯录。

## 关键能力

| 能力 | 说明 |
|------|------|
| Tor / Wi-Fi / 蓝牙 | 三种互联模式，适应不同网络环境 |
| 无手机号 | 不需要实名手机号 |
| 无中心服务器 | 消息不流过第三方 |
| 端到端加密 | 消息全程加密 |
| 群组 / 论坛 | 支持私聊、群聊、论坛 |
| 仅 Android | 当前仅 Android 平台 |
