# pi-agent-desktop

## 它是什么
[Chasen-Liao/pi-agent-desktop](https://github.com/Chasen-Liao/pi-agent-desktop) 是 Pi 编程 Agent 的**独立桌面客户端**。如果你想在桌面上跑 Pi 编码 Agent 但又不想挂着浏览器标签页 / IDE 窗口，这个项目把 Pi 装进一个独立 GUI 进程里。

## 为什么用它 / 适合什么场景
- 习惯桌面应用工作流，不喜欢切来切去的网页 / 终端；
- 想用 Pi 编码 Agent 但希望有更接近 IDE 的交互形态；
- 想在多桌面环境（macOS / Windows / Linux）下用同一套 Pi 入口。

## 关键能力
| 能力 | 说明 |
|------|------|
| 独立窗口 | 不依赖浏览器 / IDE |
| 桌面体验 | 桌面级 GUI 包装 |
| 跨平台 | 桌面应用形态 |
| 引擎来源 | 复用 Pi 编码 Agent 引擎 |
| 形态 | 开源桌面客户端 |

## 相关概念

- [Claude Code](tool-claude-code.md) — 终端原生 AI 编码 agent；pi-agent-desktop / ThinkRail 是 Pi 这条路线的桌面入口
