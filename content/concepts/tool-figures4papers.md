# figures4papers（顶刊论文绘图脚本）

## 它是什么

[figures4papers](https://github.com/ChenLiu-1996/figures4papers) 是 Chen Liu（耶鲁大学 CS 博士生）把自己发表在 Nature Machine Intelligence、ICML、NeurIPS、ECCV 等顶刊顶会上的 Python 绘图脚本整理开源的仓库，并把绘图经验打包成 AI 编程助手可调用的 Skill。

## 解决什么问题

- 写论文 / 技术报告时，「凑一张能上 NeurIPS 风格的图」常常要从 matplotlib / seaborn 参数重新拼
- 直接复用顶刊论文里「已经打磨过」的绘图风格，能省去反复调样式的时间
- 把绘图经验写成 Skill，让 AI Agent 也能按顶刊标准出图

## 关键能力

| 能力 | 说明 |
|------|------|
| 顶刊脚本沉淀 | 来自 Nature MI / ICML / NeurIPS / ECCV 等顶刊 / 顶会 |
| Skill 化 | 同一套经验打包为 AI Agent 可调用 Skill |
| Python 生态 | 基于 matplotlib / seaborn 等通用库 |
| 开源 | GitHub 公开 |

## 适用场景

- 写论文 / 报告时想直接复用顶刊级别的绘图风格
- 想给 AI Agent 配置「按顶刊标准出图」的绘图 Skill
- 想系统学习「顶刊绘图参数怎么调」
