# AI System Design（amitshekhariitbhu 的 AI 系统设计学习仓库）

## 它是什么

[ai-system-design](https://github.com/amitshekhariitbhu/ai-system-design) 是 amitshekhariitbhu 开源的 **AI 系统设计学习仓库**——把「**构建 AI 系统**」相关的核心模块（LLM 推理 / Agent 系统 / RAG / 向量检索 / 推理优化 / 评估等）的设计要点整理在一处，作为面试 / 实战的速查清单。

## 主题覆盖

| 主题 | 内容 |
|------|------|
| LLM 推理架构 | 推理服务、KV cache、推测解码 |
| Agent 系统 | 工具调用 / 状态管理 / 多 Agent |
| RAG 系统 | 索引 / 检索 / 重排 / 评估 |
| 向量检索 | embedding / ANN / hybrid |
| 推理优化 | 量化 / batching / 调度 |
| 评估 | benchmark / 评测管线 |

## 为什么读 / 适合什么场景

- 想从「**会用 LangChain**」跨到「**懂 AI 系统的设计权衡**」——和传统系统设计一样，AI 系统也有自己的「**坑 / 选型 / 权衡**」。
- 准备 AI / ML 工程师面试时，需要一份**结构化**的 AI 系统清单。
- 在落地一个 AI 产品前，先**对照清单**看看哪些模块没考虑。
- 和经典的 [Top 10 系统设计资源清单](./note-system-design-resources.md) 互补——一份是通用系统设计，一份专攻 AI 系统。
