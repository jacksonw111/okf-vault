# Design Spells

## 它是什么

[Design Spells](https://designspells.com/) 是一个**专注微交互与彩蛋细节的灵感库**：

> 不收那些大而全的套路界面，专门扒各种产品里让人眼前一亮的微交互和彩蛋细节——比如一个极其顺手的按钮动效、一段藏在角落的趣味反馈。

## 为什么用它 / 适合什么场景

- 做产品审美卡壳时去翻翻，找回「**好产品的灵气全在这些克制又迷人的小细节里**」。
- 与 useLayouts / Rewamp UI 等「结构级」灵感站点互补——本库专注**微观交互层**。
- 想给产品加入「让人记住的小动作」时参考。

## 与同类资源站的差异

| 站点 | 侧重 |
|------|------|

| useLayouts | 页面段落级版式 |
