# neonplan3d

## 它是什么

[neonplan3d](https://github.com/Mastershort/neonplan3d) 是 **Mastershort** 开源的 **Home Assistant 集成**——在 HA 里直接画户型图并生成可交互的**霓虹风 3D 视图**：用这套 3D 模型当挂墙平板的控制界面，不用另装外部建模工具。

## 关键能力

| 能力 | 说明 |
|------|------|
| 编辑器 | 画楼层 / 房间 / 墙 / 门 / 窗 / 车库门 / 楼梯 / 楼层开口 / 室外区域 / 屋顶，边画边看 3D |
| 设备操作 | 3D 视图直接点灯开关、滑动调光、长按改色 |
| 物理动效 | 窗帘按位置动 / 窗户倾斜或打开 / 门会转 |
| 摄像头 | 挂墙或吊顶，地面投出视野；看到移动变红，点开是快照 |
| 风格 | 霓虹（neon） |

## 适合场景

- 家里已经在用 Home Assistant
- 想给挂墙平板一个「科幻风」控制界面
- 不想学 SketchUp / Blender 也能搭出可交互 3D 户型
