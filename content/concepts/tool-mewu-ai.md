# mewu_ai

## 它是什么
mewu_ai 是一套**截图 + AI 配套工作流工具**：截屏后立刻在截图旁边直接给出翻译、OCR 文本、表格提取结果与 AI 讲解，不再需要在截图工具、OCR 工具、翻译工具、笔记工具之间反复跳。

## 为什么用它 / 适合什么场景
- 读外文论文/网页时，截一段图就要拿到中英对照。
- 把截图里的表格快速转可编辑结构。
- 想让截图自带"上下文解释"再贴进笔记/聊天。

## 关键能力
| 能力 | 说明 |
|------|------|
| 截屏 + OCR | 一并识别图中文字 |
| 翻译 | 截图旁生成译稿 |
| 表格提取 | 把图中表格直接结构化 |
| AI 讲解 | 给截图加上下文解释/总结 |
| 一体化 | 少装 N 个单点工具 |
