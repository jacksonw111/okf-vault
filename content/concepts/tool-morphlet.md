# Morphlet（React Native 形变浮层托盘）

## 它是什么

[Morphlet](https://github.com/rit3zh/morphlet) 是 **rit3zh** 开源的 **React Native 形变浮层托盘组件**——给 React Native 提供一个原生实现的 **形变浮层托盘**：**触发按钮可以直接长成卡片再收回**，形变动画由原生层驱动。

定位是「**原生级 UX 细节**」的 RN 实现——告别 RN 默认的「弹个 Modal」风格，做出 iOS / Android 系统级「按钮变卡片」交互。

## 为什么用它 / 适合什么场景

- **React Native App** 想要原生级 UX 细节
- **节省 Modal 跳转**：把详情 / 操作直接做成「按钮变卡片」
- **形变流畅**：原生层动画，60 fps 稳定
- **跨平台**：iOS / Android 一致行为

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | 原生层形变浮层 |
| 触发 | 按钮 → 卡片（长成） |
| 收回 | 卡片 → 按钮（收回） |
| 平台 | React Native（iOS + Android） |
| 实现 | 原生层 |
| 性能 | 60 fps 流畅 |
