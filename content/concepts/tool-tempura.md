# Tempura（Vadim Costin 的桌面专注计时器）

## 它是什么

[vcostin/tempura](https://github.com/vcostin/tempura) 是 Vadim Costin 开发的**桌面专注计时应用**：前端 React + TypeScript，后端用 Rust 写的 Tauri 2，倒计时逻辑放在 Rust 引擎里——即便窗口隐藏或系统睡眠，依然能跑准。

## 关键能力

| 能力 | 说明 |
|------|------|
| 前后端分离 | React + TS 前端 / Rust 后端 |
| 准确计时 | 倒计时由 Rust 掌管，窗口隐藏 / 睡眠不受影响 |
| 多种节奏 | 25/5、50/10、90/20、52/17、Flowtime 等七八种 |
| 自定义 | 自己加节奏 |
| 本地 SQLite | 历史记录 / 设置存在本地 |

## 关键节奏

| 节奏 | 用途 |
|------|------|
| 25/5 | 经典番茄工作法 |
| 50/10 | 长专注 + 长休息 |
| 90/20 | 90 分钟深度工作周期 |
| 52/17 | DeskTime 数据统计的最佳节奏 |
| Flowtime | 按完成度自定休息 |
