# feral-ui / gradients（高质量 CSS 渐变资源站）

## 它是什么

[feralui.dev/gradients](https://feralui.dev/gradients) 是一个**专门做 CSS 渐变资源**的站点，集合了大量可直接复制的渐变配色，被广泛认为是「the best gradient site ever」。

## 关键特征

- **高质量筛选**：每个渐变都是审美过的，不是网上随手抓的
- **可直接复制**：给 CSS / Tailwind / shadcn theme 直接用
- **设计友好**：配色 + 命名 + 预览齐全
- **Web 形态**：浏览器里看，不需要装东西

## 适合谁

- 前端 / 设计在做配色，想快速找渐变
- 想给 SaaS 落地页 / Dashboard 加背景渐变
- 觉得传统 CSS gradient 工具不够用
