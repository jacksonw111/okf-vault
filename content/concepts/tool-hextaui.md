# HextaUI

## 它是什么

[HextaUI](https://hextaui.com) 是 **preetsuthar17** 维护的开源组件库——v3 版本提供 **60+ 组件**，全部基于 **shadcn 生态**，附带 ready-to-use blocks。

## 版本演进

| 版本 | 状态 |
|------|------|
| 首发 | 60+ 精心制作的组件 |
| v3 | 60+ 组件 + blocks 即将发布 |

## 关键能力

| 能力 | 说明 |
|------|------|
| 数量 | 60+ 组件 |
| 形态 | 完全 free & open-source |
| 栈 | 基于 shadcn 生态（React） |
| Blocks | v3 引入 ready-to-use blocks |
| 风格 | shadcn 默认 clean 风 |

## 适合场景

- 想要「shadcn 风格但更现成」的整站组件库
- 不想每个组件从头拼装
- 偏好 MIT / Apache 类宽松协议
