# Jumper（22 自由度开源螃蟹机器人 + AI 工具包）

## 它是什么

[Jumper](https://github.com/KingKongRobotics/jumper) 是 **KingKongRobotics** 开源的 **22 自由度螃蟹机器人**——又萌又灵活，能搬东西还能跳跃，整套项目（硬件 + 软件 + AI 工具包）都开源。

仓库除了硬件本身，还带 **AI 工具包**：管 **外观 / 运动 / 场景**。跟 AI 助手说一句话，就能：
- 设计外观 → 导出 `.skin`
- 训练步态策略 → 回放评估后打包成 `.app`
- 搭场景 → 导出 `.map`

定位是「**硬件 + AI 工具包**」一体化——既给仿真环境，又给训练流水线。

## 为什么用它 / 适合什么场景

- **机器人学习 / 教学**：22 自由度形态丰富，仿真 + 真机一体化
- **强化学习研究**：螃蟹形态的步态策略训练有独特价值
- **桌面级实验**：尺寸适合实验室 / 桌面
- **AI 工具包**：自然语言驱动设计 → 训练 → 部署流水线
