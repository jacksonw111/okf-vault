# Sylvester

## 它是什么

[chang-07/sylvester](https://github.com/chang-07/sylvester) 是一个 **macOS 菜单栏**应用，把**多家经纪账户的净资产与持仓明细**聚到一个面板里看。分红、交易、存款等事件触发 **macOS 原生通知**——不用挨个登录各家门户。

## 为什么用它 / 适合什么场景

- 资产分散在**多家券商**，每天看净资产要切来切去。
- 想在**菜单栏一眼看到**总持仓 / 当日盈亏，而不是开网页。
- 需要**被动接收事件通知**——分红入账、有交易发生自动弹通知。

## 关键能力

| 能力 | 说明 |
|------|------|
| 菜单栏面板 | macOS 状态栏一个图标，点开看净资产与持仓 |
| 多经纪账户 | 一处聚合多家券商的数据 |
| 原生通知 | 分红 / 交易 / 存款等事件触发系统级通知 |
| 免去切来切去 | 一个面板看完所有账户 |
