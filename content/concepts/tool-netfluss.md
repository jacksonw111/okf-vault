# NetFluss（macOS 菜单栏实时网速 + 网络管理）

## 它是什么

[rana-gmbh/NetFluss](https://github.com/rana-gmbh/NetFluss) 是一款 **macOS 菜单栏网络监控与管理工具**：菜单栏实时显示**上下行网速**，点击弹窗里管**网卡 / DNS / Wi-Fi / 路由器 / VPN**。

## 关键能力

| 能力 | 说明 |
|------|------|
| 菜单栏实时网速 | 上下行流量常驻菜单栏 |
| 网卡管理 | 查看 / 切换网卡 |
| DNS 管理 | 配置 DNS 服务器 |
| Wi-Fi 管理 | 查看 / 切换 Wi-Fi |
| 路由器信息 | 查看路由器状态 |
| VPN 管理 | 启停 / 切换 VPN |

## 适合谁

- 想要极简网络监控，不需要 iStat Menus 那么重
- 想一个弹窗里管完所有网络相关
- 主要在 macOS 上开发 / 调网络
