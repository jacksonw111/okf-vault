# awesome-engineering-articles

## 它是什么

[awesome-engineering-articles](https://github.com/ashishps1/awesome-engineering-articles) 收录的**不是「教程」，而是真上线后百万到千万用户体量的工程实战文章**——书最多告诉你一句「应该怎么做」，但生产环境的具体权衡和踩坑细节，只有团队自己写过。

## 收录范围

| 维度 | 覆盖 |
|------|------|
| 公司 | Airbnb、Amazon、Netflix、Meta、Stripe、Uber、GitHub 等 |
| 主题 | 数据库、分布式系统、基础设施、搜索、性能优化 |
| 延伸 | AI/ML、数据工程、安全 |
| 数量 | 300+ 篇 |
| 组织方式 | 按公司、年份、技术方向分类 |

## 用法

最舒服的用法不是「从第一篇读到最后一篇」，而是遇到技术难题时**进去翻翻**——看有没有团队已经在生产环境趟过同一个坑。

## 适合人群

- 后端工程师
- 架构 / 基础设施方向开发者
- 想知道「大厂线上真实问题长什么样」的所有人
