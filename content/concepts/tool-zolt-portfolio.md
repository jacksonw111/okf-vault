# Zolt（Shadcn UI 设计师作品集 Landing Page）

## 它是什么

[ShadcnStudio/zolt](https://github.com/ShadcnStudio/zolt) 是一份基于 **Shadcn UI** 构建的**免费设计师作品集 Landing Page 模板**。定位是「为设计师与创意人提供的干净起点」——可直接展示作品、项目、经历、个人品牌。

视频：<https://video.twimg.com/amplify_video/2092251608017190912/vid/avc1/1280x720/6M38WkanJxVNINny.mp4?tag=14>

## 为什么用它 / 适合什么场景

- **设计师 / 创意人需要作品集站点**：不想从零开始，Zolt 给现成骨架。
- **Shadcn UI 粉丝**：直接用熟悉的 UI 组件库，定制成本低。
- **想找一个干净的「起步模板」**：Zolt 强调「clean starting point」，不是花哨成品。
- **作为 fork 起点**：把页面 fork 下来按自己作品 / 配色改一改就能上线。

## 关键能力

| 能力 | 说明 |
|------|------|
| Shadcn UI 内核 | 沿用 Shadcn UI 组件与设计 token |
| 作品集结构 | 作品 / 项目 / 经历 / 个人品牌展示位 |
| 干净起点 | 不是花哨成品，留足定制空间 |
| 免费 | 直接 fork / clone 使用 |
| 设计师导向 | 模板结构贴合作品集常见需求 |
