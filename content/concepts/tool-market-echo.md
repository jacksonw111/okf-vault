# market-echo（本地行情形态相似度检索工具）

## 它是什么

[market-echo](https://github.com/pruettlazaro143-a11y/market-echo) 是一个**本地运行的开源行情研究工具**——核心问题是：

> 「**最近的 N 根 K 线**（默认 96 根、已收盘）」在历史上**和哪些区间最像**？

比对维度：

- 价格形态（标准化后）
- 价格结构
- 波动率
- 成交量

返回最多 **30 / 60 / 100 个互不重叠的历史案例**（避免「同一段历史被多次命中」）。

## 为什么用它 / 适合什么场景

- 个人 / 量化研究想快速回答：「**最近一周 / 一月**的形态，历史上发生过几次？后续怎么走？」
- 不想把数据 / 行情传到云端——**本地**跑，数据本地存。
- 比起「**人眼看图找相似**」，想要**结构化的可比对特征**（形态 / 结构 / 波动 / 量能），不靠主观。
- 适合做**复盘 / 案例研究**：历史案例可以直接拿来对照当前。

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | 本地开源 CLI |
| 查询窗口 | 默认最近 96 根已收盘 K 线 |
| 比对维度 | 价格形态 / 结构 / 波动率 / 成交量 |
| 返回数量 | 30 / 60 / 100 个（互不重叠） |
| 数据来源 | 本地行情数据 |
| 隐私 | 完全本地，不上传云端 |
