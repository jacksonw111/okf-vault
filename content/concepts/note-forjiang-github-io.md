# ForJiang 个人主页（5 个静态工具 + AI 插画合集）

## 它是什么

[ForJiang/ForJiang.github.io](https://github.com/ForJiang/ForJiang.github.io) 是 ForJiang 维护的**个人主页**：把 **5 个纯静态、可离线的网页工具**和**AI 插画作品**收进同一个站点，**Next.js 静态导出**后部署到 **GitHub Pages**。

## 关键特征

- **5 个静态工具** —— 全部纯前端、可离线运行
- **AI 插画作品** —— 集中展示
- **Next.js 静态导出** —— `next export` 生成纯静态文件
- **GitHub Pages 部署** —— 零成本托管

## 为什么用它 / 适合什么场景

- 想参考「**个人作品 + 工具集**」一站式的轻量架构（静态 + GitHub Pages）。
- 想要**纯静态、可离线**的网页工具集——不需要后端。
- 想用 **Next.js 静态导出** 做个人主页，又想保留 React 生态的便利。
- 想了解**AI 插画 + 工具集**的个人作品站怎么组织。
