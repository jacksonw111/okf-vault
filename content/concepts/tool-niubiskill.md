# niubiskill

## 它是什么

[`niubiskill`](https://github.com/nathanskill/niubiskill) 是一个装到 AI Agent 里的 Skill，专门解决「做项目总是迟迟收不到钱」的痛点。核心思路是**先叫停无收入循环**，再从后台获利模式库中选最可行的路径。

## 触发逻辑

1. 判断你手上在做的事离「收钱」有多远；
2. 如果还在开发新功能、重做网站、追加投入但**没有收入**——叫停；
3. 从后台的获利模式库里挑出**最多 3 个**做比较；
4. 最终只推荐 **1 个**路径。

## 排序标准（5 条硬规则）

- 有权限做
- 有买方证据
- 离收钱近
- 七天能验证
- 能交付且经济上可能成立

## 输出格式

- 本周先停什么
- 走「引流 / 成交 / 暂停」哪条
- 一个入口 + 一个目标角色
- 一个七天内能完成的收钱事件
- 可以直接用的材料（文案、落地页骨架、邮件等）
