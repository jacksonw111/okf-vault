# WorkBuddyGuide

[WorkBuddyGuide](https://github.com/AlephAITech/WorkBuddyGuide) 是一份**面向 WorkBuddy 的开源蓝皮书教程**,用真实任务当主线,把安装、实操案例、Skill/MCP/自动化到多智能体协作一条龙讲清楚。

## 它是什么

非「文档翻译 / API 罗列」式的教程,而是**任务驱动**的手册——从「我要做 XX」出发,把 WorkBuddy 该怎么用才合算讲出来,避免读文档只会堆 API。

## 关键能力

| 能力 | 说明 |
|------|------|
| 真实任务线索 | 每章围绕一个具体业务场景展开 |
| 全链路覆盖 | 安装 → 实操 → Skill → MCP → 自动化 → 多 agent |
| 蓝皮书形式 | 系统性整理,可当 reference 反复翻 |

## 适合什么场景

- 已经选 / 准备选 WorkBuddy 作为 agent runtime 的团队,需要 onboarding 资料。
- 想了解 agent 工具链如何围绕一个产品做分层(协议 / skill / 自动化 / 编排)。
