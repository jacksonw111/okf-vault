# mamf

## 它是什么

mamf 是 macOS 上**极简、自管**的截图 + OCR + 标注工具 —— 把日常「截一张图 → 提取文字 → 简单标注」三件事压进最小工作流，文件留本机、不依赖云服务。功能上比 [kiri](./tool-kiri.md) 收敛：不做录屏、不做多平台分发，专注 macOS + 单帧截图/OCR/标注。

## 为什么用它 / 适合什么场景

- 只想要 macOS 上的「截图 + OCR + 标注」三件套，不录屏、不想要全家桶；
- 偏好**极简 + 自管**——产出落本机、不上传云端；
- 作为 [kiri](./tool-kiri.md) 的轻量替代：功能更窄但启动更快、干扰更少。

## 关键能力

| 能力 | 说明 |
|------|------|
| 截图 | macOS 本地截图（框选 / 窗口 / 全屏） |
| OCR | 截图文字一键识别为可编辑文本 |
| 标注 | 在截图上画箭头 / 圈 / 涂改 / 打码 |
| 本地优先 | 截图与 OCR 结果全部落本机 |
| 极简 | 不含录屏、不含多平台支持，专注单帧截图流 |

## 相关概念

- [kiri](./tool-kiri.md) — 多平台 / 多功能扩展版（截图 + 标注 + OCR + 录屏四合一），mamf 是其 macOS 极简源头
