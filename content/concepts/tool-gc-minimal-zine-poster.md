# gc-minimal-zine-poster

## 它是什么

[`gc-minimal-zine-poster`](https://github.com/LiamGvchi/gc-minimal-zine-poster) 是一个开源的视觉生成 Skill，给它一句话、一个主题、一种情绪或一张参考图，它会直接生成一张**安静、克制、带纸张与印刷质感**的独立杂志风海报。

## 设计风格

- 独立杂志（zine）风
- 安静、克制
- 纸张 / 印刷质感
- 非「AI 满屏」噪点

## 输入形态

| 输入 | 说明 |
|------|------|
| 一句话 | 描述海报想表达什么 |
| 一个主题 | 关键词 |
| 一种情绪 | 形容词 |
| 一张参考图 | 风格参考 |
