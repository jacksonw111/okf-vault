# threejs-3d-portfolio-viewer

## 它是什么
`Piercies3sc/threejs-3d-portfolio-viewer` 是一个**在浏览器内直接展示与交互 GLTF/GLB 三维模型的作品集组件**：访客可旋转 / 缩放查看模型，并一键切换三种渲染模式，适合用作个人 3D 作品集页面底层。

## 为什么用它 / 适合什么场景
- 想做一份 3D 作品集，但不想从零搭 three.js 场景。
- 已有 GLTF / GLB 资产（Blender / Sketchfab 导出），需要即开即用的浏览器查看器。
- 想要比静态截图更有「现场感」的呈现方式（旋转 / 缩放 / 多种渲染模式）。

## 关键能力
| 能力 | 说明 |
|------|------|
| 浏览器内交互 | 无需插件，原生 three.js 渲染 |
| GLTF / GLB 支持 | 加载主流 glTF 格式资产 |
| 旋转 / 缩放 | 标准轨道相机控制 |
| 三种渲染模式 | 一键切换（如线框 / 实色 / PBR 等） |
| 作品集承载 | 作者用它承载个人 3D 作品集页面 |
