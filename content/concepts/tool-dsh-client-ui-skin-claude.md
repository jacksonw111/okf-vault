# dsh-client-ui-skin-claude (PAKIKNOWLEDGE/dsh-client-ui-skin-claude)

## 它是什么
[`PAKIKNOWLEDGE/dsh-client-ui-skin-claude`](https://github.com/PAKIKNOWLEDGE/dsh-client-ui-skin-claude) 是 **DeepSeek Harness (DSH)** 客户端的一个**皮肤**扩展：官方 DSH Web UI 视觉比较朴素，这个插件直接把页面**换皮**为 Claude 风格，省去自己写样式的功夫。

## 为什么用它 / 适合什么场景
- 喜欢 Claude 那种偏暖、低饱和的视觉调调，又要用 DSH 后端。
- 不愿意为 DSH 单独维护一套 CSS / 主题。
- 想要即装即用的"皮肤升级"，而不去读官方主题文档。

## 关键能力
| 能力 | 说明 |
|------|------|
| 主题皮肤 | 把 DSH Web UI 换成 Claude 风 |
| 即装即用 | 不必改源码，装上就生效 |
| 同生态插件 | 与 DSH 其他插件共存 |
