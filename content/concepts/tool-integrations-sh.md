# integrations.sh

## 它是什么
**开源的第三方集成目录（catalog）**——收录每个 SaaS / 开源产品的 **MCP 服务器 / REST API / CLI / GraphQL 服务**及其**认证方式**。

突出特点：
- **Deep link 一键生成 API key**：跳过厂商后台的多步导航
- **1 键复制 spec URL**：直接贴到 AI 代理 / 客户端配置里
- **早期项目**但收录量已经很大

由 RhysSullivan 推出。

## 为什么用它 / 适合什么场景
- 给 AI 代理接第三方服务时，不知道有没有官方 MCP / GraphQL / CLI——先来这里查。
- 拿到新 API key 后不知道 base URL / spec 在哪——这里直接复制。
- 想统一发现「哪些产品有 MCP 服务器」——这是 MCP 生态最重要的目录之一。
- 想给自家 SaaS 产品贡献一个 MCP 服务器条目。

## 关键能力
| 能力 | 说明 |
|------|------|
| 收录范围 | 每个产品的 MCP / API / CLI / GraphQL 服务器 |
| 认证信息 | 每条目录含认证方式 |
| Deep link | 直接生成 API key（跳厂商后台） |
| Spec URL | 1 键复制 |
| 形态 | 开源 catalog（网站 + 数据可下载） |
| 阶段 | 早期但已有大量条目 |
