# tsuzuri

## 它是什么

[tsuzuri](https://github.com/jaisuriya-11/tsuzuri) 是 **jaisuriya-11** 开源的**终端块式笔记工具**——把块式笔记搬进终端；笔记以**纯 Markdown 文件**存在本地目录，**不依赖数据库**。

## 关键能力

| 能力 | 说明 |
|------|------|
| 实现 | Go 单二进制，零运行时依赖 |
| 存储 | 纯 Markdown 文件，可放任意位置 |
| 文件树 | TUI 内浏览 |
| 标签页 | 多文档并行编辑 |
| 状态栏 | 字符 / 字数 / 状态展示 |
| 主题 | 96 套内置主题 |
| 形态 | Block-based（块式），每块独立 |

## 适合场景

- 不想装 GUI 笔记工具但想要「块式」体验
- 笔记需要纯文本可移植 / 可 grep
- 在 SSH 远程盒子里也想随手记
