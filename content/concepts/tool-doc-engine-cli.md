# Doc Engine CLI

零配置把 Markdown 转为学术质量 PDF 的 CLI，基于 Typst 且无需安装 LaTeX 或 Pandoc。

## 主要能力

- 作为可复用的软件或工作流组件，按项目文档进行部署和评估。
- 适合在对应场景中替代重复的手工流程。
