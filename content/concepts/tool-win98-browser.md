# Windows 98 in Browser

## 它是什么

Windows 98 in Browser 是一款在浏览器里复刻 Windows 98 桌面体验的开源项目。打开网页就能看到经典的「蓝天白云」桌面、图标、任务栏、我的电脑 / 回收站，以及扫雷等小游戏，纯属怀旧氛围的复刻工程。

## 为什么用它 / 适合什么场景

- 怀旧：体验 90 年代末桌面 UI。
- 设计参考：研究极早期桌面 OS 的视觉语言。
- 演示 / 教学：用熟悉的桌面隐喻解释 UI 概念。

## 关键能力

| 能力 | 说明 |
|------|------|
| 桌面复刻 | 图标、桌面右键菜单、任务栏 |
| 经典窗口 | 我的电脑、记事本、计算器等 |
| 内置游戏 | 扫雷等经典小游戏 |
| 纯前端 | 无需后端，静态部署即可 |
