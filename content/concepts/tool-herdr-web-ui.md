# Herdr Web UI

## 它是什么

[Herdr Web UI](https://github.com/devswha/herdr-web-ui) 是为 **Herdr 多 Agent 管理器** 提供 **浏览器 + PWA 手机客户端** 的配套工具：

- 在网页里**查看 Agent 会话**
- **回应审批**请求
- **SSH 连远程机器**
- 接收**推送提醒**（PWA）

## 为什么用它 / 适合什么场景

- **跨设备操作 Herdr Agent**：手机端 PWA 让审批不必等回到电脑前。
- **远程 SSH 入口**：不必每个远程机器都配客户端，从一个 Web UI 统管。
- **多 Agent 集中监控**：Herdr 本身管多 Agent，Web UI 把会话视图化。

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | 浏览器 + PWA |
| 集成对象 | Herdr 多 Agent 管理器 |
| 操作 | 查看会话 / 审批 / SSH / 推送提醒 |
| 推送 | PWA 推送通知 |
