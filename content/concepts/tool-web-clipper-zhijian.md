# zhijian WebClipper Skill

## 它是什么

[zjp1997720/zhijian-skills](https://github.com/zjp1997720/zhijian-skills) 里的 `web-clipper` skill 是一个**全能网页抓取**：集成市面所有抓取方案，**多层兜底**保证一次成功；开新对话就能用。

## 核心特性

| 特性 | 说明 |
|------|------|
| 多方案集成 | 主流抓取方案都打包 |
| 多层兜底 | 单方案失败自动 fallback |
| 一键安装 | `npx skills add` |
| 兼容 | Claude Code / Codex 等 |

## 为什么用它 / 适合什么场景
- Agent 需要抓网页时不想挨个试方案。
- 想「开新对话就能用」不要胶水代码。
- 复杂页面（登录墙 / JS 渲染）也想一次成功。

## 关键能力

| 能力 | 说明 |
|------|------|
| 全能抓取 | 静态 / 动态 / 登录 |
| 多层兜底 | 失败自动切方案 |
| Skill 形态 | 一键安装调用 |
| 一次成功 | 默认策略即优 |
