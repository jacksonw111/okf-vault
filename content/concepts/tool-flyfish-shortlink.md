# shortlink

一个**能自己托管**的**短链接 + 活码**（动态二维码）平台——核心卖点是**资源归你所有、发布前要审核、品牌二维码、访问统计**，并预留了"以后接不接 AI 辅助"的可审计扩展点。

## 它是什么

- 一套**自托管**的短链接服务（不是 SaaS，URL 与数据都在自己手上）；
- 同时支持**活码**：同一个二维码背后可切换跳转目标，方便运营活动 / AB 测试；
- 内置**发布前审核**流程，避免误链 / 错链直接对外生效；
- 提供**品牌二维码**生成能力（带 logo / 颜色 / 装饰），不是单调的黑白方块；
- 自带**访问统计**（点击量、来源、设备、地区等常规维度）；
- 架构上为"**未来接入 AI 辅助**"留了**可审计**的扩展点（不默认开启）。

## 关键能力

| 能力 | 说明 |
|------|------|
| 自托管 | 一台服务器 / 一个容器即可跑，资源与日志都本地化 |
| 短链接生成 | 长链 → 短链，可自定义短码 |
| 活码（动态二维码） | 一个二维码可切换跳转目标，无需重印物料 |
| 发布前审核 | 改动先入待审，人工 / 流程通过后才生效 |
| 品牌二维码 | 加 logo、配色、装饰，输出更体面的二维码 |
| 访问统计 | 点击、来源、设备、地区等基础访问分析 |
| AI 扩展留口 | 架构上预留"是否接 AI 辅助"的开关，便于审计 |

## 为什么用它 / 适合什么场景

- 公司 / 个人**不想把营销短链 / 二维码交给第三方 SaaS**（担心链接被封、统计被砍、服务商跑路）；
- 印刷物料 / 线下活动需要**可换链的二维码**：活动期间多次换目的地，但物料不能重印；
- 团队需要**发布前有人审**的合规流程：营销文案、短链目标都得先批后发；
- 想要"**真品牌二维码**"而不是 QQ 群风格的黑白格；
- 计划未来加入 AI 自动生成短码 / 自动建议目标 / 自动风控，但**想保持可审计、可关停**——这个工具把扩展口暴露了出来。

## 设计哲学

1. **资源归你**——短链、统计、二维码素材全部自托管；
2. **审过再发**——发布链路里强制审核一环；
3. **品牌不是黑方块**——二维码也能讲究；
4. **AI 留口不留债**——能不能接 AI 是一个**显式开关**，不是悄悄塞进来。
