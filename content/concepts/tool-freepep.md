# FreePEP

## 它是什么
FreePEP 是 siknet 写的 MIT 协议开源工具：**批量下载人教版中小学教材**为本地 PDF。它盯着人民教育出版社官方教材平台，自带 780+ 本教材目录（截至 2026 年 8 月底），已实现解密与阿里云滑块验证码绕过；提供 Web 和命令行两种入口，可按学段 / 学科 / 年级勾选后批量下载。

## 为什么用它 / 适合什么场景
- 想在本地/人教电子书包之外保存一份人教版 PDF 教材做备份或离线使用。
- 教育研究/出题/翻译场景需要批量抓取课本。
- 喜欢命令行批处理 + 可编程筛选条件（年级/学科/版本）。

## 关键能力
| 能力 | 说明 |
|------|------|
| 全套人教版 | 780+ 目录覆盖中小学主要学科 |
| 条件批量 | 学段 / 学科 / 年级任意勾选 |
| 双入口 | Web UI + 命令行 |
| 反爬绕过 | 含阿里云滑块验证码处理 |
| 自动解密 | 抓下来的内容已解密成 PDF |
