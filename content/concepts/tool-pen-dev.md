# Pen.dev（设计 + AI 协作 canvas）

## 它是什么

[Pen.dev](https://pen.dev) 是一个**设计与 AI 协作的 canvas**。它能：

1. 导入现成的 Figma 文件、网页截图、HTML 源码
2. 让 Claude 或 Codex 这样的 LLM agent **直接在画布上改稿**
3. 把最终成果**导出为代码**

定位：「**一个人做的设计，看起来像团队做的**」——Figma 里繁琐的 layer / frame 调整交给 AI 操作，设计师只关心判断。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多源导入 | Figma / 站点 / HTML 都能进 canvas |
| AI 改稿 | Claude / Codex 等 agent 直接操作画布 |
| 导出代码 | 把最终视觉稿导出为前端代码 |
| 协作形态 | 设计师管判断、AI 管操作 |
| 跨工具 | 把 Figma 与代码两端打通 |

## 适合什么场景

- 设计师或独立开发者，想让 AI 帮自己改稿 / 出代码、但又不想在 Figma + Cursor / Claude Code 之间反复切。
- 需要把 Figma 稿 / 网站截图快速转成可运行代码的团队。
- 个人 / 小团队想做「**一人即团队**」的设计到落地流程。

## 与相关概念的关系

- [Claude Code](./tool-claude-code.md) — Claude Code 是终端里的编码 agent；Pen.dev 让它能直接动 Figma / 设计稿。
- [Computer Use（计算机使用）](./term-computer-use.md) — Pen.dev 是「AI 直接看 / 改视觉稿」的更精准实现，比通用 Computer Use 聚焦在设计领域。
