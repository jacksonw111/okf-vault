# AntV Infographic（信息图生成框架）

## 它是什么

[AntV Infographic](https://github.com/antvis/Infographic) 是蚂蚁集团 AntV 出品的开源 SVG 信息图生成框架：甩一句描述进去，就能产出专业的 SVG 信息图，覆盖 PPT / 报告 / 文档可视化场景。

## 关键能力

| 能力 | 说明 |
|------|------|
| 模板库 | 约 200 个模板：流程 / 结构 / 数据故事 |
| 声明式语法 | AI 流式输出也能实时渲染 |
| 主题系统 | 手绘 / 渐变 / 图案等主题都支持，可接着编辑 |
| 多端集成 | npm 可直接集成 |
| Agent Skill | 可给 Claude Code / Codex 装 Skills |

## 它解决的问题

不会画信息图、又需要给 PPT / 报告 / 文档加专业可视化？传统方案要么用 Figma / Canva（重），要么自己写 SVG（重）。AntV Infographic 用声明式语法 + 模板库把门槛降到「一句话描述」。

## 适合谁

- 做 PPT / 报告 / 文档可视化
- 给 AI 编码工具装「自动生成信息图」的 Skill
- 想要批量产出的信息图保持风格一致
