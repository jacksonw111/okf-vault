# ca-72

## 它是什么

[ca-72](https://github.com/idlefoundry/ca-72) 是 idlefoundry 用 **Rust** 复刻 1972–73 年 **Minimoog Model D**（CA3046 老振荡器板）电路的合成器插件：

- **形态**：VST3 / CLAP / AU 三格式插件
- **平台**：macOS / Windows / Linux
- **引擎**：Rust 写

## 为什么用它 / 适合什么场景

- **复古合成器爱好者**：想要 Model D 的味道又买不起原版 / 不愿买
- **音频工程师**：要在 DAW 里挂插件
- **开源音频**：希望复刻电路细节而不只是「听起来像」
