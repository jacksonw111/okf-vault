# Invidious

## 它是什么

[Invidious](https://github.com/iv-org/invidious) 是 **iv-org** 维护的**开源 YouTube 替代前端**——由志愿者社区在 GitHub 上开发，浏览器直接用，提供 YouTube Premium 那些付费功能（无广告 / 后台播放 / 不登录 / 无 Google 追踪）。

## 关键能力

| 能力 | 说明 |
|------|------|
| 无广告 | 去掉 YouTube 的全部广告位 |
| 移动后台播放 | 让手机锁屏后继续听 |
| 不登录 | 无需 Google 账号即可订阅频道 |
| 零追踪 | 不发请求给 Google 的追踪像素 |
| 订阅迁移 | 一键导入 YouTube 全部订阅 |
| 浏览器扩展 | YouTube 链接自动跳转 Invidious |
| 自部署 | 可自行部署私有实例 |

## 注意事项

- Google 自 2024 年起持续封锁第三方实例；公共站点时好时坏
- 想稳定用，建议自部署或挑稳定的社区镜像

## 适合场景

- 想退订 YouTube Premium 但还想用核心功能
- 重视隐私 / 不想被 YouTube 算法「勾着刷」几小时
- 有服务器 / NAS 可跑自托管
