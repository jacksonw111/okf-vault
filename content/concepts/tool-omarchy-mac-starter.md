# Omarchy Mac Starter

## 它是什么

[Omarchy Mac Starter](https://github.com/johnloringpollard/omarchy-mac-starter) 是给 **Omarchy 桌面（Arch + Hyprland）** 套一层「macOS 操作手感」的开源配置合集：

- Mac 风格快捷键
- 圆角窗口
- 毛玻璃面板
- 透明顶栏
- 可选的苹果外设集成

## 为什么用它 / 适合什么场景

- **想用 Arch + Hyprland 的灵活，又怀念 macOS 的细腻交互**：这套合集让你两者兼得。
- **Mac 切换过来的过渡**：不必为了 Linux 完全改操作习惯。
- **苹果外设用户**：Magic Mouse / Magic Keyboard 在 Linux 桌面下也能体验一致手感。

## 关键能力

| 能力 | 说明 |
|------|------|
| 目标系统 | Omarchy（Arch + Hyprland） |
| Mac 风格 | 快捷键 / 圆角 / 毛玻璃 / 透明顶栏 |
| 外设集成 | 苹果外设（可选） |
| 形态 | dotfiles / 配置合集 |
