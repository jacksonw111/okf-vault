# Helius Finance Tracker（本地优先 Rust TUI 记账）

## 它是什么
Helius Finance Tracker 是一个**本地优先**的个人财务追踪工具：用 Rust 写的终端界面（TUI）+ SQLite 数据库，涵盖日常记账、预算管理、循环账单、对账、现金流预测等功能。所有数据存在本地，无云同步、无账号。

## 为什么用它 / 适合什么场景
- 不想把个人财务数据交给任何第三方平台 / 云服务。
- 想要一款「终端党也能用」的记账工具，与 htop / lazygit 一致的工作流。
- 重隐私 + 重效率：本地优先 + 终端原生 + 键盘操作。

## 关键能力
| 能力 | 说明 |
|------|------|
| 本地优先 | SQLite 数据库，无云同步 |
| Rust TUI | 终端原生界面，键盘操作高效 |
| 记账 | 日常收支录入与查询 |
| 预算 | 月度 / 周度预算管理 |
| 循环账单 | 自动识别重复账单 |
| 对账 | 与银行 / 信用卡账单对账 |
| 现金流预测 | 基于历史数据预测未来现金流 |

## 一句话总结
**「Rust TUI + SQLite」的本地优先记账工具——账目、预算、循环账单、对账、现金流预测都在终端里。**
