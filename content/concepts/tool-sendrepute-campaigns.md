# SendRepute Campaigns

## 它是什么

[SendRepute Campaigns](https://github.com/sendrepute/sendrepute-campaigns) 是 **sendrepute** 开源的自托管邮件营销系统。装在自有服务器上就能管 **受众 / 活动 / 模板 / 自动化 / 投递**，所有数据留本地，不依赖任何 SaaS 服务。

定位是「**隐私 + 数据可控**」的自托管替代——既能给团队内部用，也适合对外做独立 newsletter / 产品发布邮件。

## 为什么用它 / 适合什么场景

- **数据本地**：受众邮箱、活动统计、模板都不出本地
- **完整功能链**：受众 → 活动 → 模板 → 自动化 → 投递一站到底
- **自托管**：避免 Mailchimp / ConvertKit 等按规模涨价的 SaaS 收费陷阱
- **隐私 / 合规**：适合对数据流向有严格要求的场景（GDPR / 国内合规）

## 关键能力

| 能力 | 说明 |
|------|------|
| 受众管理 | 自有数据库，不传第三方 |
| 活动 | 单发 / 群发 / 定时 |
| 模板 | 邮件模板设计 |
| 自动化 | 触发序列、drip |
| 投递 | SMTP / 自有邮件服务器对接 |
| 自托管 | 装到自己的服务器 |
