# build-your-own-x

## 它是什么

[build-your-own-x](https://github.com/codecrafters-io/build-your-own-x) 是 **codecrafters-io** 维护的**「从零实现 X」教程合集**——一个 ≈55.1 万 ⭐ 的 GitHub 仓库，**按技术分类收录 step-by-step 教程**，教读者亲手重建日常使用的技术栈：从 **数据库 / Docker / Git / 操作系统** 到 **正则表达式引擎 / 3D 渲染器 / 神经网络** 等数十种。

## 核心理念

> "What I cannot create, I do not understand." —— Richard Feynman

把工具从零实现一遍，才能真正理解它的每一层。

## 收录的典型主题

- 数据库（SQLite、Redis-like KV）
- 容器 / Docker
- Git
- 操作系统
- 正则表达式引擎
- 编程语言解释器
- 神经网络 / ML 框架
- 3D 渲染器

每个主题都给出多个语言实现的教程链接（Python / C / Rust / Go / JS 等），部分教程可短到「40 行 JS 写完一个正则引擎」。

## 为什么用它 / 适合谁

- **面试前临时加深理解**：光看八股不够，自己写一遍印象深得多。
- **想转方向 / 自学底层**：从零做一遍比读十篇综述更快建立直觉。
- **教学场景**：给计算机系学生 / 自学者当「从理论到代码」的桥梁。
