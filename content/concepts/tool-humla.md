# Humla (michaelwilhelmsen/humla)

## 它是什么
[`michaelwilhelmsen/humla`](https://github.com/michaelwilhelmsen/humla) 是一个面向 macOS 的**本地优先**会议助手：**录制、转写、按说话人分离、总结**整套流程全压在 Mac 本地跑，录音与笔记不必上传到任何第三方服务器。

## 为什么用它 / 适合什么场景
- 想在会后再翻重点，但不愿"雇一个语言机器人"进会议把录音送到云端。
- 涉及合规 / 客户机密 / 内部战略讨论，对数据出境有顾虑。
- 想要一个比 Otter / 飞书会议记录更"离线"的工具，万一断网也能跑。
- 总结 / 待办可与本地的 Markdown / Obsidian / 笔记库打通。

## 关键能力
| 能力 | 说明 |
|------|------|
| 本地处理 | 全流程在 Mac 本地完成，无需联网 |
| 自动转写 | 录音 → 文本 |
| 说话人分离 | 多说话人场景自动分段、归类 |
| 会议总结 | 输出要点 + 待办 + 关键讨论 |
| 隐私优先 | 录音与笔记不出本机 |
