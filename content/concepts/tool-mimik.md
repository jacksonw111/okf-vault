# Mimik

## 它是什么
[westpoint-io/mimik](https://github.com/westpoint-io/mimik) 是一个**浏览器扩展**：点「开始录制」，按真实操作走一遍流程，它就把**每一步变成带截图和标注的图文指南**——自动产出可发布的「怎么做 X」教程。

定位是 **「本地优先 + 隐私优先」** 的操作录制工具：

- **不需要账号**：打开就用；
- **不上云**：所有截图 / 操作记录都在本地；
- **不追踪**：无遥测、无分析；
- **导出自包含**：输出是可分享的 HTML / Markdown 指南。

## 为什么用它 / 适合什么场景
- 写**产品文档 / 用户操作手册**（录一遍流程，导出就是图文指南）；
- 给客户做**培训材料**（不暴露内部账号 / 数据）；
- **Onboarding** 新员工——把内部工具操作录成教程；
- 隐私敏感场景（医疗 / 法律 / 金融）——不能把截图传到云端；
- 写博客文章里的「**操作演示**」段落（自动截图比手动截图稳定）。

## 关键能力

| 能力 | 说明 |
|------|------|
| 操作录制 | 浏览器内点击 / 输入 / 滚动全程记录 |
| 自动截图 | 每步自动截屏并叠加标注 |
| 导出自包含 | 输出 HTML / Markdown 教程 |
| 本地优先 | 数据全程不出浏览器 |
| 零账号 | 无注册、无云端依赖 |
| 零追踪 | 无遥测、无分析 |
