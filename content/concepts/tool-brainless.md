# Brainless（theswerd/brainless）

## 它是什么

**Brainless** 把 **Claude Code / Codex / Grok 三种编码 Agent 的终端界面**做成了 **shadcn/ui 组件**——文档 / 演示页 / 产品 UI 里要放一个「**以假乱真**」的终端画面，**复制粘贴组件就行，不截图、不嵌 iframe**。

## 为什么用它 / 适合什么场景

- 写产品文档 / Landing page 时，要给客户演示「**Claude Code 长什么样**」，又不想放真截图（截图会过期 / 显得假）。
- 营销页 / 落地页要放「终端风格」的视觉。
- 教学 / 博客要演示 prompt 效果，又不想录视频。

## 关键能力

| 能力 | 说明 |
|------|------|
| shadcn 组件 | 可复制粘贴进任何 React 项目 |
| 三种 Agent 终端 | Claude Code / Codex / Grok |
| 不截图 | 真实 React 组件，可改可定制 |
| 不 iframe | 纯 DOM，不嵌第三方 |
| 演示效果持久 | 不会因真实工具 UI 升级而失真 |
