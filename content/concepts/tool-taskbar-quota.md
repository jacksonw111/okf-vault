# TaskbarQuota

## 它是什么

[zioder/TaskbarQuota](https://github.com/zioder/TaskbarQuota) 是 **Windows 任务栏 AI 编程额度监控器**：装了多个 AI 编程工具（Codex、Claude Code、Cursor、Kimi、Grok 等），切换工具时不用挨个去查额度——直接看任务栏当前用量、剩余百分比、重置时间、积分余额。

## 核心特性

| 特性 | 说明 |
|------|------|
| 自动识别 | 看当前聚焦的编辑器 / 终端 |
| 13 家厂商 | Codex / Copilot / Claude / Kimi / Grok 等 |
| 实时显示 | 剩余额度 / 百分比 / 重置时间 |
| 余额 / 积分 | 各家计费体系都覆盖 |
| Windows 原生 | 任务栏图标 |

## 为什么用它 / 适合什么场景
- 同时用多个 AI 编程工具，怕额度用爆。
- 经常在不同 AI 工具之间切换。
- 想一眼看清「现在还能跑多少任务」。

## 关键能力

| 能力 | 说明 |
|------|------|
| 自动对应厂商 | 看焦点应用推断在用谁 |
| 任务栏常驻 | 不占窗口空间 |
| 多指标展示 | 额度 / 百分比 / 重置 / 余额 / 积分 |
| 13 家支持 | 主流 AI 编程工具全覆盖 |
