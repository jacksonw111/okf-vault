# awesome-dsh-plugin（DeepSeek Harness 插件审核清单）

## 它是什么

[`awesome-dsh-plugin`](https://github.com/bruc3van/awesome-dsh-plugin) 是 bruc3van 维护的 **DeepSeek Harness (DSH) 插件精选清单**。

背景：DSH 生态扩展找插件很折腾，**GitHub 上挂 dsh-plugin 标签的仓库一大半在蹭流量**。本清单的差异化做法：

- **每天跑脚本**把新挂 dsh-plugin 标签的仓库抓进**待审核队列**
- **人工逐一审阅**才收录
- **不达标的踢掉并留档理由**（避免「靠删除再重新挂标签」绕过）

## 为什么用它 / 适合什么场景

- 想给 DSH 找靠谱插件但不想被营销贴仓库淹
- 想了解「被严格审核收下」的 DSH 插件有哪些
- 想跟 DSH 生态的资源方向

## 关键能力

| 能力 | 说明 |
|------|------|
| 自动抓取 | 每天拉新挂 dsh-plugin 标签的仓库 |
| 人工审核 | 逐一审阅后才收录 |
| 踢除留档 | 被踢的仍记录理由，供追溯 |
| 质量阈值 | 避免蹭流量贴扰乱清单 |
| 与 DSH 生态对齐 | 与原 DSH 团队节奏协同 |
