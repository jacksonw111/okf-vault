# Spun (yappologistic)

## 它是什么
Spun 是 yappologistic 开源的 Linux 音乐播放器：把**本地曲库直播**与通过 [Cider](https://cider.sh/) 接入的 **Apple Music** 统一到一个 UI 里，封面摆成 CD 形态，播放体验整体干净。

## 为什么用它 / 适合什么场景
- Linux 用户想统一管本地 + Apple Music 曲库，不愿多装几个 App。
- 喜欢 CD 风格的视觉呈现。
- Cider 用户希望在 Linux 上继续用 Apple Music 体验。

## 关键能力
| 能力 | 说明 |
|------|------|
| 本地直播 | 直接播本地曲库 |
| Apple Music 整合 | 借 Cider 接 Apple Music |
| CD 风格 UI | 封面以 CD 形态呈现 |
| Linux 桌面 | 为 Linux 设计 |
