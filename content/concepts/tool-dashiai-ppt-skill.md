# dashiai-ppt-skill

[dashiai-ppt-skill](https://github.com/mujingquan835/dashiai-ppt-skill) 是一个**网页版 PPT 编辑器 Skill**，把"AI 出 PPT 只能得渲染结果、事后想改只能重来"的痛点彻底解决：成品是网页版 PPT，每页配一个编辑控制台，改完一键导出可继续编辑的 PPTX。

## 它是什么

Agent Skill 形态的 PPT 工具：拿文档喂给 Agent，输出网页版 PPT；网页里**每一页都是可编辑的**（滑杆调模块数量、点文字就地改字、拖图换图），改完导出 PPTX / PDF / 离线 HTML。

## 为什么用它 / 适合什么场景

- **AI 出 PPT 后还要改**：传统 Agent 出 PPT 只出渲染图，本工具支持"改完再出 PPTX"。
- **不锁定格式**：导出 PPTX 可继续在 PowerPoint / Keynote 编辑。
- **多种分析模型**：雷达图、瀑布图、桑基图、甘特图 + SWOT / 波特五力 / PEST / 商业模式画布。
- **网页 / PDF / PPTX 多输出**：一份素材多份产出。

## 关键能力

| 能力 | 说明 |
|------|------|
| 文档 → PPT | Agent 拿文档直接出成品 |
| 网页版编辑器 | 每页可点可改，滑杆调模块 |
| 可编辑 PPTX 导出 | 改完导出可在 PowerPoint / Keynote 继续编辑 |
| 多输出格式 | PPTX / PDF / 离线 HTML |
| 12 套主题 | 风格可选 |
| 1020 个版式页面 | 几乎覆盖常见内容场景 |
| 丰富图表 | 雷达图 / 瀑布图 / 桑基图 / 甘特图 |
| 分析模型 | SWOT / 波特五力 / PEST / 商业模式画布 |
