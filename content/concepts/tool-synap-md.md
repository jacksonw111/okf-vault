# synap.md (BungeeDEV/synap.md)

## 它是什么
[`BungeeDEV/synap.md`](https://github.com/BungeeDEV/synap.md) 是一款**自托管**、**Obsidian 风格**的 Markdown 笔记应用：**笔记以磁盘上的纯 `.md` 文件为准**（不被锁进私有数据库），配上一套原生桌面客户端既能离线编辑，又能与自己部署的服务器同步。

## 为什么用它 / 适合什么场景
- 喜欢 Obsidian 的「本地 `.md` + 双链」工作流，但希望**自己的数据由自己的服务器同步**，不依赖 Obsidian Sync 订阅。
- 团队共享一个笔记库，希望有服务端、权限、版本控制。
- 跨设备（Mac / Windows / Linux）需要同时支持，离线编辑、上线后再同步。
- 想保留「纯文本就是真相」的原则，未来可随便换工具。

## 关键能力
| 能力 | 说明 |
|------|------|
| 纯 `.md` 文件 | 笔记存在磁盘上，不被锁库 |
| 自托管同步 | 自建服务器，跨设备同步 |
| 原生桌面客户端 | Mac / Windows / Linux 离线可用 |
| Obsidian 风格 | 双链 / 反向链接 / 本地浏览体验对齐 Obsidian |
