# flyingmouse-format

## 它是什么
flyingmouse-format 是一款完全离线运行的文件格式转换工具（支持 Windows / macOS），内置 FFmpeg / LibreOffice / Poppler / Tesseract 等成熟开源引擎，覆盖图片、文档、表格、PPT、PDF、音视频与 WPS 格式互转；并附带 OCR、批量转换、网易云 / QQ 音乐音频解密等额外能力。

## 为什么用它 / 适合什么场景
- 不想把敏感文档 / 音视频上云转换。
- 想用一个 GUI 工具覆盖日常 80% 格式互转需求，不必再去对应专门工具。
- 适合普通办公用户、老师、设计助理、内容创作者。

## 关键能力
| 能力 | 说明 |
|------|------|
| 内置引擎 | FFmpeg / LibreOffice / Poppler / Tesseract |
| 覆盖格式 | 图片 / 文档 / 表格 / PPT / PDF / 音视频 / WPS 互转 |
| 特色能力 | OCR、批量转换、网易云 / QQ 音乐音频解密 |
| 运行模式 | 完全离线 |
| 平台 | Windows / macOS |
