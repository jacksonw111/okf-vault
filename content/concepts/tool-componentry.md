# Componentry

## 它是什么

Componentry(`componentry.dev`)是一个面向「前端工程师 + 设计师」的组件目录。它把分散在开源项目里的高质量 UI 组件(动画按钮 / 404 页 / 表单状态 / 模态框 / 卡片 hover / 进度条等)按视觉类别聚到一个站,每个组件都有可交互 demo、源项目链接、关键实现说明。

项目链接：<https://componentry.dev/>

## 为什么用它 / 适合什么场景

- **找灵感**:不停在 GitHub 上挖组件效率低,目录站按分类浏览更快。
- **找现成方案**:每个组件都给「源码在哪」「npm 包名」「复制按钮」三件套,看完直接拿。
- **横向比较**:同一类需求下能同时看到 4-5 种实现风格,挑最合适那个。

## 站点结构(典型)

| 区域 | 内容 |
|------|------|
| 分类导航 | Button / Form / Modal / Toast / Layout / Empty State / 404 / Pricing 等 |
| 组件详情 | 动图 demo + 源码片段 + 项目地址 + 维护者信息 |
| 筛选 | 按框架(React / Vue / Solid / Svelte)、按主题、按许可证 |

## 适合谁

- 给自己的 SaaS / 工具项目找差异化 UI 元素
- 学习「别人怎么实现 X 动效」,比翻 Dribbble 更落地
- 写技术博客 / 教程时引用例子
