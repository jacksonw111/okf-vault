# UI SFX

## 它是什么
UI SFX 是一个专门给应用 / 游戏 UI 准备的免费开源音效包，覆盖 936 个短促反馈音（点击、弹窗、切换、通知、错误等），分 12 个语义包整理。开发者可直接挑包内取用，不再到处搜零散的 UI 音效。

## 为什么用它 / 适合什么场景
- 找「合适的 UI 反馈音」成本高：散在 Freesound、各类个人 Sounds Pack 里，质量参差、命名混乱。
- UI SFX 把同一类反馈音收成 12 个包，整组拿即可让 UI 听感一致。
- 适合 indie 开发者、设计师、Agent 写 demo / 原型时统一配 UI 音效。

## 关键能力
| 能力 | 说明 |
|------|------|
