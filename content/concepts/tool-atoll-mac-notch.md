# Atoll (MacBook notch 交互面板)

## 它是什么

MacBook 的刘海（notch）在 14 / 16 寸机型上长期闲置。`Atoll` 把刘海区域扩成一块可交互的命令面板：悬停展开、点击进入；面板内置媒体播放控制、系统指标（CPU / 内存 / 风扇 / 电量）、可自定义的小组件和快捷工具；锁屏时还能把媒体信息、计时器、电量等显示在刘海两侧，让刘海区域"全天都有事做"。

## 关键能力

| 能力 | 说明 |
|------|------|
| 刘海悬停展开 | 鼠标移到刘海即下拉出命令面板，离开自动收 |
| 媒体 / 系统控制 | 一面板管媒体播放、CPU / 内存 / 电量 / 风扇等系统指标 |
| 锁屏显示 | 锁屏态也能在刘海区域显示媒体、计时器、电量 |
