# Game UI Database

## 它是什么
一个游戏界面截图聚合参考库，按界面类型（主菜单、HUD、库存、设置、过场）、布局、材质（赛博朋克、像素、扁平、写实）、平台等维度筛选。

## 设计借鉴的视角
| 维度 | App 设计师能借什么 |
|------|------------------|
| 任务 / 进度 | 游戏怎么让用户知道"接下来做什么 / 我做到哪了" |
| 升级 / 奖励 | 升级前后怎么把变化讲清楚、让奖励"爽" |
| 信息密度 | 信息挤在一起时怎么分主次 |
| 反馈机制 | 完成任务时的爽点设计 |

## 关键能力
| 能力 | 说明 |
|------|------|
| 多维筛选 | 类型 / 布局 / 材质 / 平台 |
| 大量截图 | 上万张游戏 UI 参考 |
| 设计视角 | 不是为了抄，而是为了"看游戏怎么解决同类问题" |

## 适用场景
- App / SaaS 设计师想找差异化反馈机制
- 想学"游戏化设计"的产品团队
- 不想再让记账软件"塞个龙头、加圈金边"的同质化
