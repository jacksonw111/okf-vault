# FolderSizeExplorer

## 它是什么
FolderSizeExplorer（`ribeirogustav/FolderSizeExplorer-Releases`）是一个 Windows x64 便携版文件管理器，**能在浏览文件的同时递归统计文件夹大小**，直观看出哪些目录最占磁盘空间。

![FolderSizeExplorer 界面](https://pbs.twimg.com/media/HOnHBnPaAAAJSSm.jpg)

## 为什么用它 / 适合什么场景
- **便携免安装**：单一可执行文件，扔进 U 盘就能用。
- **边浏览边统计**：不需要先跑 TreeSize 再切回文件管理器。
- **Windows 桌面生态补缺**：OpenDisk 是 macOS 等价方案，本工具补 Windows 端。

## 关键能力

| 能力 | 说明 |
|------|------|
| 递归统计 | 浏览时同步显示每个目录的总大小 |
| 便携可执行 | Windows x64 单文件，免安装 |
| 直观对比 | 目录大小一眼可见，便于识别「占空间却又没用的」目录 |
