# Dotmatrix

## 它是什么
[dotmatrix.zzzzshawn.cloud](https://dotmatrix.zzzzshawn.cloud) 是一个**点阵 / 字符微动画站点**：所有内容都是浏览器里跑的小动效，**微动画（micro animations）观感极致顺滑**。定位是「**前端微动效的灵感 / 玩法参考**」——既可以欣赏，也可以照着复刻思路。

与一般「动画 demo 集合」相比，Dotmatrix 强调的是**字符 / 点阵**这个具体载体：动效粒度细、节奏紧凑、视觉统一。

## 为什么用它 / 适合什么场景
- 找**前端微动效**（micro animation）的灵感——尤其是字符 / 点阵这类「克制即美」的风格；
- 想要一个**在线玩得到**的微动画沙盒，可以直接浏览器体验；
- 设计 / 前端工程想看看「**纯 CSS / JS 微动画**」能玩到什么程度；
- 把 Dotmatrix 当**教学样本**：读源码看微动画的实现技巧（timing、easing、stagger）。

## 关键能力

| 能力 | 说明 |
|------|------|
| 点阵 / 字符载体 | 所有动效统一在点阵 / 字符层面 |
| 微动画 | 短促、顺滑、有节奏感 |
| 浏览器原生 | 直接打开即玩，无需安装 |
| 玩法丰富 | 多种交互 / 动效变体 |
| 灵感参考 | 适合前端动效设计借鉴 |
| 在线访问 | 无需登录、无需安装 |
