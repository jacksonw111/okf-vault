# FerrumPix

## 它是什么

[Bitpainter75/FerrumPix](https://github.com/Bitpainter75/FerrumPix) 是一个**三合一桌面照片工具**：库管理 + RAW 显影 + 图层精修塞进同一个应用里，**不用在 Lightroom / Bridge / Photoshop / RAW 处理器之间来回切**。可对接自己的 **Immich** 或 **Nextcloud** 自托管相册。

## 三合一的意义

传统工作流：

```
Bridge 浏览 → Lightroom 打分 → RAW 处理器显影 → Photoshop 精修
```

FerrumPix：

```
FerrumPix 一个窗口全搞定
```

## 为什么用它 / 适合什么场景

- 摄影师不想为浏览 / RAW / 图层各装一个软件。
- 用 Immich / Nextcloud 做自托管相册，想在桌面端直接连过去。
- 喜欢 Avalonia 跨平台桌面（Windows / macOS / Linux）体验。

## 关键能力

| 能力 | 说明 |
|------|------|
| 库管理 | 浏览 + 打分 + 标签 |
| RAW 显影 | 内置 RAW 处理 |
| 图层精修 | 类 Photoshop 图层 |
| 自托管对接 | Immich / Nextcloud |
| 跨平台 | Avalonia 多端 |
| 单窗口 | 不切软件 |
