# wfdash

## 它是什么

[wfdash](https://github.com/mingrath/wfdash) 是 wayfinder `/wayfinder` 命令输出的**本地浏览器仪表盘**：把 wayfinder 生成的任务地图转成可视化看板，一眼区分「现在需要你」与「可以放着跑」的事项，省去在终端逐个翻 issue 的时间。

## 为什么用它 / 适合什么场景

- 用 [wayfinder](https://github.com/) 风格的 task-map 工具管理多任务，希望可视化总览。
- 想看「现在该不该动手 / 哪件事可以后台挂着」，而非线性列表。
- 想在副屏 / 浏览器标签里常驻任务总览。

## 关键能力

| 能力 | 说明 |
|------|------|
| 任务地图可视化 | 把 wayfinder 输出转看板 |
| 状态分组 | 当前需要 / 可以放着 / 已完成 |
| 本地浏览器 | 跑在本地，零云依赖 |
| 实时刷新 | 跟随 task-map 文件更新 |
