# OpenPost（开源社媒内容一站式工具）

## 它是什么

[getopenpost/openpost](https://github.com/getopenpost/openpost) 是一个**自托管的社媒内容工作台**，定位是「Buffer + Canva + CapCut 的开源合体」：写文、做图、剪视频、定时发布都在同一个应用里完成。

## 为什么用它 / 适合什么场景

- 团队用 SaaS 社媒工具年费太高，想换自托管。
- 想把写文 / 设计 / 剪辑 / 发布收口到一个工具，避免在不同 SaaS 之间复制粘贴。
- 注重内容数据自有、可以内部使用敏感素材。

## 关键能力

| 能力 | 说明 |
|------|------|
| 帖子写作 | 文案编辑与多平台格式适配 |
| 图与轮播设计 | Canva 替代品 |
| 视频剪辑 | CapCut 替代品 |
| 定时发布 | 多平台 scheduler |
| 自托管 | 数据自有 |
| Buffer / Canva / CapCut 三合一 | 不再切工具 |
