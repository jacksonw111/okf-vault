# Dreeve（自托管 Strava 数据面板）

## 它是什么
Dreeve（前身 Statistics for Strava）是一个面向骑行 / 跑步 / 越野等户外运动的自托管开源数据面板。活动数据既可以拿原始 `.fit` / `.tcx` / `.gpx` 文件直接导入，也可以连接 Strava 账号自动同步；面板里把概览、活动列表、交互月历、装备使用次数与保养进度、热量地图、里程碑时间线、路段分段成绩、Rewind 年度回顾、挑战与活动照片都收进同一个界面。

## 为什么用它 / 适合什么场景
- 想完全掌控自己的运动数据、又不想被 Strava 的订阅墙或隐私策略绑架。
- 想统一管理多设备 / 多平台（Garmin / Wahoo / Apple Watch / 手表 + 手机 app）的活动数据。
- 想要一份「年终回顾」级别的可视化，但 Strava 默认 Rewind 不够定制。

## 关键能力
| 能力 | 说明 |
|------|------|
| RAW 文件导入 | `.fit` / `.tcx` / `.gpx` 直接拖进，跨厂商数据通吃 |
| Strava 同步 | 连账号自动同步活动数据 |
| 概览 + 月历 | 一眼看训练量与频次分布 |
| 装备追踪 | 鞋子 / 心率带 / 自行车按使用次数和保养周期管理 |
| 热量地图 | 在地图上累积展示常去路段与训练热区 |
| 路段分段 | Strava 路段 PB 进度可视化 |
| Rewind 年度回顾 | 自动生成年度数据回顾 |

## 一句话总结
**「自托管版 Strava」——把运动数据从云端迁回本地，全功能仪表盘。**
