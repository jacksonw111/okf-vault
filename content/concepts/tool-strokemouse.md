# StrokeMouse

## 它是什么

Licoy/StrokeMouse 是一个 macOS 鼠标手势工具。按住**触发键**（默认可选 ⌃ / ⌥ / ⌘），鼠标在屏幕上画出轨迹，匹配预设后**自动执行对应动作**——键盘快捷键、打开应用、窗口管理、媒体控制键、Shell 脚本或 AppleScript。

## 关键能力

| 能力 | 说明 |
|------|------|
| 自定义手势 | 任意方向 / 形状的手势都可绑定动作 |
| 多类动作 | 键盘快捷键 / 应用启动 / 窗口操作 / 媒体键 / Shell / AppleScript |
| 多触发键 | 支持 ⌃ / ⌥ / ⌘ 等组合触发，避免与系统手势冲突 |
| 可视配置 | 手势编辑界面，所见即所得 |

## 适合谁

- macOS 重度用户希望减少「右手摸键盘」次数
- 触控板 / Magic Mouse 用户希望在键鼠之间无缝切换
- 习惯 Windows 上的「StrokeIt / MouseGestureLiker」想平替到 macOS

## 与已有 macOS 工具的差别

- [MacTools](./tool-mac-tools.md) — 免费开源 macOS 菜单栏工具集（30+ 小工具，但无鼠标手势）
- [OmniWM](./tool-omniwm-macos.md) — 水平滚动平铺 WM（窗口管理方向不同）
- StrokeMouse 的差异点：**专做「鼠标手势 → 任意动作」的绑定**，是市面上少有的 macOS 鼠标手势工具
