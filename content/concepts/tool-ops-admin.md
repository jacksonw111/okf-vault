# Ops Admin

## 它是什么
[ops-admin](https://github.com/qishu321/ops-admin) 是一个**基于 Go + Vue 3 构建的一体化运维管理平台**。它把**服务器监控、资产、命令执行、告警**等常见运维场景统一进一个 Web 控制台，让运维工作不必在「SSH + 跳板机 + zabbix + 各类脚本」之间来回切换。

技术栈：**后端 Go、前端 Vue 3**——典型的「**Go 提供并发与系统调用能力、Vue 提供现代化交互**」组合，适合做中后台系统。

## 为什么用它 / 适合什么场景
- 想要一个**开箱即用**的运维管理平台，不想从零搭；
- 喜欢 **Go 后端 + Vue 3 前端** 的中后台技术栈（并发稳、上手快）；
- 想统一**服务器资产 + 监控 + 命令执行 + 告警**四个常见场景；
- 想要**自托管**的运维平台（数据自己掌控）。

## 关键能力

| 能力 | 说明 |
|------|------|
| 服务器监控 | CPU / 内存 / 磁盘 / 网络等基础指标 |
| 资产管理 | 服务器列表、分组、标签 |
| 命令执行 | Web 端下发命令到目标机器 |
| 告警 | 异常阈值告警通道 |
| Go 后端 | 高并发、稳定的服务端 |
| Vue 3 前端 | 现代化的交互界面 |
| 自托管 | 数据自己掌控，可私有化部署 |
| 一体化 | 多场景统一进同一控制台 |
