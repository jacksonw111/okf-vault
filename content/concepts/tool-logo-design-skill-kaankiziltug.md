# logo-design-skill（kaankiziltug：logo 设计 Skill）

## 它是什么

[logo-design-skill](https://github.com/kaankiziltug/logo-design-skill) 是 kaankiziltug 出品的 **Agent Skill**：给 **Claude / Codex / Gemini CLI** 等编码 Agent 装一套**做 logo 的手艺**。

流水线：接 **brief → 出概念 → 跑测试 → 交 SVG + 品牌手册**。

## 为什么用它 / 适合什么场景

- 想让 AI 编码 Agent 帮忙做 logo / 品牌物料，而不是单纯生成单张图。
- 团队 / 个人项目需要快速出一套**可生产**的 logo——产出是 SVG（矢量、可继续编辑）+ 品牌手册（颜色 / 字体 / 使用规范）。
- 已在用 Claude / Codex / Gemini CLI，添加 Skill 后直接接管 logo 流程。
