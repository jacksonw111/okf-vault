# vibe-wise

## 它是什么

[vibe-wise](https://github.com/nykooi1/vibe-wise) 是 **nykooi1** 出品的 Claude Code Skill——在 Build / Design / Implementation 三道确认关卡逼用户**先想清方案再让 AI 落代码**。

## 解决什么问题

Vibe Coding 常见问题：用户没想清楚就一路让 Agent 跑下去，最后产出一堆「能跑但不是自己想要的」代码——「全程旁观式 vibe coding」。

## 三道关卡

| 关卡 | 作用 |
|------|------|
| Build | 先确认「要构建什么」— 需求 / 目标 |
| Design | 再确认「怎么构建」— 架构 / 关键选择 |
| Implementation | 最后确认「具体实现路径」— 再让 Agent 落代码 |

## 适合场景

- 团队想系统化用 Vibe Coding 但又怕乱来
- 个人想从「想到就开干」升级为「想清楚再干」
- 想给 Vibe Coding 流程加质量门禁

## 与同类 Skill 的差异

| Skill | 侧重点 |
|-------|--------|
| vibe-coding-cn | 教程型：从零到能做产品 |
| vibe-wise | 流程型：三道关卡防失控 |
