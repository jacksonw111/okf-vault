# NEO

## 它是什么
[neo](https://github.com/hughhowey/neo) 是《羊毛战记》（*Silo*）作者休·豪伊（Hugh Howey）开发的本地写作工具，主打**「只写书、别无他物」**——把整个 UI 收束到「书」这一个心智模型上：左侧是可视化书架，中间是手稿，右侧是写作者最在意的成书排版预览。

与一般 Markdown 编辑器相比，NEO 的差异化在于**写作时就让你看到书的样子**：自动章节编号、首字下沉、智能标点、引号转换、封面拖放、进度条、系列归类这些「出版级排版细节」默认就是输出形态，而不是手稿完成后另排。

## 为什么用它 / 适合什么场景
- 长篇 / 系列小说作者想要一个**以书为单位**的工作台，而不是一份份散落的 Markdown；
- 想要本地优先 / 文件可移植（不绑定云端、不绑定专有格式）的写作工具；
- 喜欢「写作时就能看到最终印刷效果」的工作流，省一遍排版；
- 想要一个**写书的人**写给**写书的人**的工具：默认参数都是小说家审过的。

## 关键能力

| 能力 | 说明 |
|------|------|
| 可视化书架 | 整本书就是一个可拖动封面的对象，多本组系列 |
| 系列归类 | 多卷本自动归到一个系列视图 |
| 封面拖放 | 直接把图片拖到书脊上换封面 |
| 进度条 | 每本书的写作进度可视化（字数 / 章节完成度） |
| 自动章节编号 | 写作时自动按顺序编号章节 |
| 首字下沉 | 章节起始字符按印刷书默认下沉 |
| 智能标点 | 引号 / 破折号 / 省略号按出版规范自动替换 |
| 进度条 | 整本书写作完成度可视化 |
