# ASCILINE

## 它是什么

`ASCILINE` 把视频流实时转成 ASCII 字符再渲染：浏览器内基于 HTML5 Canvas，约 30FPS 实时转换；同时支持 WebSocket 低带宽传输（推 ASCII 流到远程），甚至能在 Terminal 里播放。适合做极客风格的实时画面预览、低带宽场景（远程看监控 / 直播画面）、或纯 ASCII 美学的项目展示。

## 关键能力

| 能力 | 说明 |
|------|------|
| 实时视频转 ASCII | HTML5 Canvas，约 30FPS |
| WebSocket 低带宽流 | 推 ASCII 文本而非视频帧 |
| 终端播放支持 | 直接在 Terminal 里看 ASCII 视频 |
