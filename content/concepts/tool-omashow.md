# Omashow

## 它是什么

**Omashow** 是 [28allday](https://github.com/28allday) 维护的演示文稿工具，专门为 **Omarchy 桌面**打造。它的特点：

- **完全离线**：不依赖云服务。
- **全键盘驱动**：演示场景下无需频繁摸鼠标。
- **能打开 PowerPoint / Keynote 文件**并**回存为 pptx**——也就是说，即便本机没装 PowerPoint / Keynote 也能处理 .pptx / .key 文件。

## 为什么用它 / 适合什么场景

- 用 Omarchy 桌面、需要一款**原生离线**的编辑 / 放映工具，不希望装 Microsoft Office / Keynote。
- 在演讲场景下偏好键盘流（翻页、跳转、注释）而非鼠标点。
- 经常需要把别人的 Keynote 转成 pptx 留档。
