# LaunchCorner

[LaunchCorner](https://github.com/wenujacodes/LaunchCorner) 是免费开源的 macOS 工具。新版 macOS 把 Launchpad 的热角入口删了,想靠热角拉起应用的第三方工具大多要付费解锁,LaunchCorner 用**原生 SwiftUI**把屏幕四个角落变成应用启动开关,触发 LaunchOS / Launchpad 替身类应用,不用再花钱订阅。

项目链接：<https://github.com/wenujacodes/LaunchCorner>

## 它是什么

一个**macOS 热角应用启动器**——把"鼠标移到屏幕某角"映射到"启动指定应用",SwiftUI 原生实现,轻量且系统集成度高。

## 为什么用它 / 适合什么场景

- **免费**:替代 Hot Corner 类付费工具。
- **原生 SwiftUI**:低系统开销,不依赖 Electron / 第三方 runtime。
- **触发 LaunchOS 类应用**:可作为 Launchpad 替代品的启动开关。

## 关键能力

| 能力 | 说明 |
|------|------|
| 四角映射 | 屏幕四个角可分别映射应用启动动作 |
| 原生 SwiftUI | macOS 原生 UI,资源占用低 |
| 触发 LaunchOS 类应用 | 与 Launchpad 替代品协同 |
| 免费开源 | 替代付费 hot-corner 工具 |
| 系统集成 | 与 macOS 触发机制深度结合 |
