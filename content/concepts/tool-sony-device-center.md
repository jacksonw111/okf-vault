# sony-device-center

## 它是什么

[marconvcm/sony-device-center](https://github.com/marconvcm/sony-device-center) 是**电脑端的索尼耳机控制工具**：以前调降噪、均衡器等都得掏手机开 App，这个项目让你直接在电脑上完成同样的设置。

## 核心特性

| 特性 | 说明 |
|------|------|
| 电脑端 | 不需要掏手机 |
| 降噪控制 | ANC 模式切换 |
| 均衡器 | EQ 调节 |
| 桌面友好 | 集成到工作流 |

## 为什么用它 / 适合什么场景
- 经常在电脑前戴着索尼耳机。
- 不想为调节设置打断工作掏手机。
- 视频会议 / 直播时快速调降噪。

## 关键能力

| 能力 | 说明 |
|------|------|
| 降噪控制 | 多档 ANC |
| 均衡器 | EQ 调节 |
| 电脑端 | 跨平台桌面 |
| 蓝牙直连 | 无需手机 |
