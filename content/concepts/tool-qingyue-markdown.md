# 轻阅 qingyue（Windows 本地 Markdown 阅读编辑器）

## 它是什么

Windows 上一个「打开就能看 / 就能写」的本地 Markdown 工具：**免安装、免登录、离线可用**。想写作就切分栏，想专心读就切阅读模式。另有一个功能精简的 Lite 版。

![](https://pbs.twimg.com/media/HRRUQmAaUAARnm9.jpg)

## 为什么用它 / 适合什么场景

- Windows 上临时打开一份 `.md`，不想为此装 Obsidian / Typora 或起 VS Code。
- 需要把 Markdown 交付成 PDF / DOCX，但不想走 Pandoc 命令行。
- 内网 / 离线环境，工具不能联网也不能登录账号。

## 关键能力

| 能力 | 说明 |
|------|------|
| 三种布局 | 分栏编辑 / 纯阅读（收起编辑区）/ 随手切换 |
| 阅读体验 | 目录、缩放、翻页、书签、多套主题 |
| 渲染支持 | 表格、代码高亮、公式、Mermaid 图 |
| 导出 | PDF、HTML、DOCX |
| 完整版附加 | Word / Excel 轻量编辑、白板、思维导图 |
| 版本 | 完整版 + 功能精简的 Lite 版 |
