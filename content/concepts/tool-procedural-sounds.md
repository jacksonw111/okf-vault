# procedural-sounds

## 它是什么
`m1ckc3s/procedural-sounds` 是一个**程序化（procedural）音效生成工具 / 站点**：[procedural-sounds.vercel.app](https://procedural-sounds.vercel.app/)。它把常见 UI / 游戏 / 应用所需的声音（点击、确认、错误、过渡…）**用代码现场合成**，**无需音频素材文件**——所有音效都是**算法生成**的，可以按需微调。

## 为什么用它 / 适合什么场景
- 想给 demo / 原型加音效，但不想买 / 录素材。
- 想要「**永远不重复**」的音效（每次播放都有微妙差异），适合游戏 / 沉浸式 UI。
- Web 项目：用 JS Web Audio 现场合成，避免下载 mp3 / wav 资源。
- 教学 / 玩「声音合成」：用参数直观理解波形 / 包络 / 滤波。

## 关键能力
| 能力 | 说明 |
|------|------|
| 程序化合成 | 不用音频素材，参数化现场生成 |
| Web 端 | 站点 [procedural-sounds.vercel.app](https://procedural-sounds.vercel.app/) 直接试听 |
| 多种音效 | UI 反馈 / 游戏 / 过渡 / 通知等场景全覆盖 |
| 可调参数 | 频率 / 持续时间 / 包络 / 滤波等参数可调 |
