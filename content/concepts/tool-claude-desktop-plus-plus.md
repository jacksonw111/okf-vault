# ClaudeDesktopPlusPlus

## 它是什么

把官方 **Claude Desktop** 增强为一站式工作站的扩展套件：

- **cc-switch 管理**：Claude Code 切换器
- **第三方 API 直连**：用任意 OpenAI 兼容 API 替代官方
- **插件管理**：装 / 卸 / 启停插件
- **汉化**：本地化界面
- **历史修复**：补官方功能遗留的小问题

![截图示例](https://pbs.twimg.com/media/HOSQAcWbcAAGDX8.jpg)

## 它填补了官方 Claude Desktop 的什么空白

| 官方缺失 | ClaudeDesktopPlusPlus |
|----------|---------------------|
| API 固定官方 | 接任意第三方 API |
| 没有插件机制 | 插件管理 |
| 英文界面 | 汉化 |
| 没有 cc-switch | 内置 cc-switch |
| 历史 bug | 修复补丁 |

## 关键能力

| 能力 | 说明 |
|------|------|
| cc-switch 集成 | 一键切 Claude Code provider |
| 第三方 API | 摆脱官方锁定 |
| 插件系统 | 扩展官方功能 |
| 汉化 | 中文用户友好 |
| 历史修复 | 官方遗留 bug 的补丁 |
