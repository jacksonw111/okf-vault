# kubernetes3d.com

## 它是什么

[kubernetes3d.com](https://kubernetes3d.com/) 提供 **Kubernetes 集群的 3D 可视化**：把集群节点 / Pod / 网络流量画成 3D 场景，配左侧白板 + rack 视角。

## 核心能力

| 能力 | 说明 |
|------|------|
| 3D 可视化 | 集群节点、Pod 立体呈现 |
| Server Room 视角 | 整体机房视角 |
| Rack 视角 | 更细致的机柜视角 |
| apply / delete | 同套控件管 K8s 资源 |
| 扩缩 replica | 调副本数 |
| 滚镜像 | 滚动升级 |
| 打流量 | 流量注入 / 模拟 |
| kubectl get pods | 命令面板 |

## 看请求链路

> 可以看请求从外网进集群，落到哪台机器。

## 为什么用它 / 适合什么场景

- K8s 教学 / 培训场景，把抽象的调度变直观。
- 复杂集群故障排查（看流量分布）。
- 想给团队 / 客户做 K8s 演示。
- 工程师的「**设计品味**」练习项目。

## 关键能力

| 能力 | 说明 |
|------|------|
| 3D 渲染 | 立体直观 |
| 多视角 | 白板 / Rack / Server Room |
| 同套控件 | apply / delete / scale / 滚镜像 |
| 命令面板 | kubectl 集成 |
| 流量可视化 | 请求链路 |
| 美学 | 经验作品 |
