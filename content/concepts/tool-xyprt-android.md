# xyprt_android

## 它是什么
一个 **Android 应用**，与**学科网错题小印 X1 便携热敏打印机**通过蓝牙配对，打印：

- 文字
- 图片
- PDF

并提供：

- **拍照裁剪**：拍一张错题照片直接裁剪后打印
- **自由排版**：自定义版式输出

## 为什么用它 / 适合什么场景
- 学生 / 教师：把错题照片 / PDF / 笔记文字直接打到热敏纸上做错题本。
- 现场场景：无打印机驱动也能从 Android 设备打印。
- 需要比系统自带打印服务更细的排版 / 裁剪控制。
- 学科网 X1 这类特定热敏打印机的「官方之外」开源客户端选项。

## 关键能力
| 能力 | 说明 |
|------|------|
| 平台 | Android |
