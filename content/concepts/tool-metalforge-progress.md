# MetalForge Progress Bar

## 它是什么

`metalforge.xyz` 是一个动效资源站，主打"save it now"系列的进度条 / loading 动画合集。每条动效都附实现方式 / 可直接 copy 的代码片段，适合做 App / Web 项目时挑一个"看着还行"的 loading 动画直接用。与同站出品的 [MetalForge Orbs](./tool-metalforge-orbs.md) 属同一站点不同主题。

## 关键能力

| 能力 | 说明 |
|------|------|
| 进度条专精 | 集中收纳 progress / loading 类动效 |
| 可复制实现 | 每条动效附源码或提示 |
| 适合做 UI 减法 | App 等待态不再用通用菊花 |
