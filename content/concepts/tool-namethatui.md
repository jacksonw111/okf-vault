# namethatui

[namethatui](https://www.namethatui.com/) 是一个 **UI 词典** ——「看得见但叫不出来的 UI 事物」都能在这里查到名字。

> a dictionary for ui things you can see but can't name
> it learns as people use it: every search teaches the site new words, and the built-in pocket dictionary grows with it

## 关键能力

| 能力 | 说明 |
|------|------|
| 视觉 → 名称 | 上传截图 / 描述界面元素,反查 UI 标准命名 |
| 口袋词典 | 内嵌便携版,随用随查 |
| 众包学习 | 每次检索都会教词典学新词,词库随使用增长 |
| 设计师自维护 | 作者是设计师,知道 prompt 工程师最缺的术语 |

## 适合什么场景

- 设计师 / prompt 工程师给 AI 写「我要 **Breadcrumb** 而不是上面那一排小箭头」时,先查准术语。
- 与 AI 设计协作(尤其 AppLovin 风格 / Material / iOS HIG 的细颗粒度控件)卡壳时快速参考。
- 设计 review 时统一团队用词,避免「那个上面的下面一坨」式低效沟通。
