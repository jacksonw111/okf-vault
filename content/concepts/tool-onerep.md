# OneRep

## 它是什么

[an2tha/onerep](https://github.com/an2tha/onerep) 是一个**自托管**的健身 / 健康一体化系统，把训练、饮食、恢复、AI 教练这些原本散落在各家付费应用里的功能整合在一起，并**允许用户把整套系统跑在自己的服务器上**——数据由用户掌握，不必每个功能各买一份订阅。

![](https://pbs.twimg.com/media/HQeRLDwbEAEr3oC.png)

## 为什么用它 / 适合什么场景

- **订阅疲劳**：健身类应用普遍「一个订阅一个功能」，数据互不相通，OneRep 想把它们合一。
- **数据主权**：训练记录 / 饮食 / 身体指标不愿交给第三方云。
- **AI 教练想自定义**：模型可换、提示词可调，不被厂商绑定。
- **家里有 NAS / 小服务器**：想 7×24 跑一套个人健康仪表板。

## 关键能力

| 能力 | 说明 |
|------|------|
| 训练模块 | 力量 / 有氧 / 周期化训练记录 |
| 饮食模块 | 摄入记录 + 营养素拆解 |
| 恢复模块 | 睡眠 / HRV / 主观疲劳度追踪 |
| AI 教练 | 基于本地数据的问答 / 计划生成 |
| 自托管 | 数据留在自己的服务器 |
| 模块互联 | 训练强度 ↔ 恢复状态 ↔ 饮食建议可以打通 |
