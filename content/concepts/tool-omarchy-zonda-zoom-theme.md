# Omarchy Zonda Zoom Theme

## 它是什么

[dhh/omarchy-zonda-zoom-theme](https://github.com/dhh/omarchy-zonda-zoom-theme) 是 DHH（Ruby on Rails 作者、Omarchy Linux 项目发起人）发布的一款 Omarchy 桌面主题，灵感来自帕加尼（Paganí）Zonda 跑车的碳黑配色 + 强烈对比的细节色，把整套桌面（终端 / GTK 应用 / 状态栏 / 启动器）刷成「碳纤维 + 金属银边」的气质。

## 为什么用它 / 适合什么场景

- 想给 Omarchy / Hyprland 桌面换一身低调奢华的皮肤。
- 喜欢纯黑底 + 强对比点缀色，避免白底刺眼。
- 想要一个由知名 maintainer 直接发布的、可信度高的主题。

## 关键能力

| 能力 | 说明 |
|------|------|
| 全栈主题 | 同时覆盖终端 / GTK / Qt / Hyprland 配色 |
| 碳黑底色 | 接近 #000 的纯黑底，长时间使用不易疲劳 |
| 强对比强调色 | 帕加尼 Zonda 的金属银 / 红点缀 |
| 一键安装 | 提供 install 脚本，跑一次完成所有应用替换 |
