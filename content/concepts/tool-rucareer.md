# rucareer

## 它是什么

[bydtesla1609/rucareer](https://github.com/bydtesla1609/rucareer) 是**面向大学生的 Windows 本地经历管理与 AI 简历生成工具**：

- **Python** 编写，**WebView2** 承载界面。
- 当前**桌面版 1.0.0**。
- 资料保存在用户自选的**本地「包装盒」文件夹**中，**不注册不联网**。

## 五个档案页签

| 页签 | 内容 |
|------|------|
| 基础信息 | 个人信息 |
| 科创经历 | 科研 / 项目 / 竞赛 |
| 社会实践 | 实习 / 志愿服务 / 国际校际交流 |
| 兴趣爱好 | 软性展示 |
| 简历生成 | 按岗位 / 研究生项目挑材料出 DOCX/PDF |

## 12 类经历归置

每条经历**独立文件夹**，可挂 TXT / Markdown / CSV / JSON / DOCX / PDF 附件。归类包含：

- 科研 / 项目 / 竞赛
- 实习 / 社会实践 / 志愿服务
- 国际校际交流 / 实践项目
- 等共 12 类

## 为什么用它 / 适合什么场景

- 大学生 / 研究生想让**简历随经历沉淀**——每做一件事就归档一份材料。
- 不愿把简历 / 个人信息交给**云端 SaaS**，本地是唯一副本。
- 想**一份材料服务多个岗位**——针对不同 JD 自动挑素材、改写。

## 关键能力

| 能力 | 说明 |
|------|------|
| 本地优先 | 资料全在用户自选文件夹，无云端 |
| 经历模块化 | 每条经历独立文件夹 + 多格式附件 |
| AI 简历生成 | 对照岗位要求挑素材 + 出 DOCX/PDF |
| 不注册不联网 | 全过程本地完成 |
