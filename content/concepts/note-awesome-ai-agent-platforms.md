# awesome-ai-agent-platforms

## 它是什么

[Agenta-AI/awesome-ai-agent-platforms](https://github.com/Agenta-AI/awesome-ai-agent-platforms) 是一份**开源 AI Agent 平台导航**清单，按五个维度分类：

1. **AI 协作者** — 多 Agent 协作 / 对话框架
2. **开发框架** — 自建 Agent 用的 SDK / 库
3. **工作流自动化** — Agent + 触发器 + 集成的流程类平台
4. **浏览器 Agent** — 操控浏览器的 Agent
5. **代码 Agent** — 编码 / 仓库操作的 Agent

每个项目**一句话讲清干什么**，顺带标**许可证、部署方式**，并提供能筛选对比的网站。

## 关键属性

| 维度 | 说明 |
|------|------|
| 收录门槛 | 真实可用、有人维护 |
| 许可证 | 清单本身 **CC0**，随便用随便改 |
| 分组 | 五大类（见上） |
| 元信息 | 项目一句话 + 许可证 + 部署方式 |
| 配套站点 | 可筛选 / 对比的展示页 |

## 为什么用它

- 想从零找一个 Agent 平台时，按分类 + 维护状态快速过一遍。
- 比 awesome-* 列表多了「许可证 + 部署方式」字段，更便于公司 / 团队选型。
- CC0 协议意味着可以二次分发做内部知识库或培训资料。
