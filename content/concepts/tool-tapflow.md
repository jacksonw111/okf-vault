# tapflow（自托管浏览器版 iOS / Android 模拟器）

## 它是什么

[tapflow](https://github.com/jo-duchan/tapflow) 是 jo-duchan 出品的开源工具：把 **iOS / Android 模拟器**直接搬进浏览器，团队打开网页就能用。

定位于 **Appetize / BrowserStack 这类云服务的「自托管替代品」**：不再依赖第三方云跑 App 模拟器，所有数据留在自家服务器。

## 为什么用它 / 适合什么场景

- 团队**不想给 App 上传到外部云**做测试（合规 / 隐私 / 知识产权）。
- **不想在每台开发机上装 Xcode / Android Studio**——浏览器开箱即用。
- 想要**自托管、MIT 协议**的轻量替代：两行命令部署。
- 应用文件、设备画面、操作记录都要留在自己手里。

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | 浏览器内的 iOS / Android 模拟器 |
| 部署 | 自托管，两行命令 |
| 数据 | 应用 / 设备画面 / 操作记录全留自家服务器 |
| 协议 | MIT 开源 |
| 对标 | Appetize / BrowserStack 的自托管替代 |
| 出品 | jo-duchan |
