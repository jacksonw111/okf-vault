# joi-codex-pet

[joi-codex-pet](https://github.com/tpmoonchefryan/joi-channel-codex-hatch-pet) 是一个**非官方、非商业的 ChatGPT Codex 像素桌宠资源包**——把 B 站虚拟主播轴伊 Joi 做成 Codex Pet v2 桌宠。它给的是一套像素精灵素材:

- **图集规格**:一张 1536×2288 的 WebP 图集,按 8 列 × 11 行、每格 192×208 切分
- **动作**:9 种标准动作(待机、左右走动、挥手、跳跃、失败、等待、执行任务、审阅结果)
- **视线**:16 个视线方向(覆盖 360°)

## 它解决了什么

OpenAI 在 Codex 里开放了 Codex Pet v2 接口,允许第三方接入桌宠精灵;但开发者需要自己画像素动画。joi-codex-pet 直接给一套以 VirtuaReal 旗下 VTB 轴伊 Joi 为形象的可用素材,爱好者可在此基础上二次修改或直接装来养。

## 关键能力

| 能力 | 说明 |
|------|------|
| Codex Pet v2 兼容 | 完全符合 ChatGPT Codex Pet v2 桌宠协议 |
| 像素图集 | 1536×2288 WebP 大图集,程序切片省传输 |
| 9 种动作 | 涵盖 Agent 工作流的关键状态语义 |
| 16 视线方向 | 支持 360° 转向,角色随时「看」用户 |
| MIT/类开源 | 非商用,允许爱好者改造 |
