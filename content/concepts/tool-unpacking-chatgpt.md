# Unpacking ChatGPT（aa1143/unpacking-chatgpt）

## 它是什么

**《拆开 GPT》** 是一套**中文科普系列**，作者以后端工程师视角讲 ChatGPT 的**模型原理**与**工程实现**，目标读者是「**没学过机器学习的人**」。

结构：

- 共 **20 期**
- 分**三阶段**：
  1. **ChatGPT 怎么回答问题**（模型原理基础）
  2. **怎么获得能力**（训练 / 微调 / 提示工程）
  3. **如何变成产品**（工程化 / 应用 / 部署）

## 为什么用它 / 适合什么场景

- 后端工程师想**系统理解 LLM 原理**，不想读论文。
- 教学场景：**没 ML 背景的人**也能跟上。
- 中文社区：「原理 → 工程」的清晰讲解比英文资料少。

## 关键能力

| 能力 | 说明 |
|------|------|
| 中文讲原理 | 不依赖英文论文 / 文档 |
| 后端工程师视角 | 从工程实践反推模型原理 |
| 三阶段递进 | 怎么回答 → 怎么获得能力 → 怎么变产品 |
| 20 期结构 | 节奏稳定、可预期 |
