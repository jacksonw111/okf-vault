# God's Eye View

## 它是什么

[bilawalsidhu/gods-eye-view](https://github.com/bilawalsidhu/gods-eye-view) 是**浏览器里跑的开源地理情报客户端**（前身 WorldView）——用 [CesiumJS](https://cesium.com/) 把 **15 个图层叠在一个写实 3D 地球上**。

## 15 个图层

| 图层 | 内容 |
|------|------|
| 航班 | 11,000+ 架实时 |
| 军机 | 实时 |
| 船舶 | 实时 |
| 卫星 | 838 颗 |
| 地震 | 实时 |
| 交通 | 路况 |
| 公交 / 地铁 | 实时 |
| 共享单车 | 实时 |
| 山火 | 实时 |
| 火箭发射 | 排期 |
| 公开摄像头 | 约 3,600 路 |
| 全球电台 | 实时 |
| 其他 3 个 | 见项目 |

**13 个图层不需要任何密钥**即可打开。

## 为什么用它 / 适合什么场景

- 想把分散的**公开数据源**汇到一个 3D 地球上**看 / 查 / 标注**——不搭 GIS。
- 关心**态势感知**（航班、军机、地震、船舶同屏对照）。
- 想做**公开摄像头路网**复盘 / 验证。
- 不想被 SaaS GIS 绑死，希望数据可下载 / 自托管。

## 关键能力

| 能力 | 说明 |
|------|------|
| 写实 3D 地球 | CesiumJS 渲染 |
| 15 个图层 | 航班 / 军机 / 船舶 / 卫星 / 地震 / 交通 / 公交 / 单车 / 山火 / 火箭 / 摄像头 / 电台 / … |

| 浏览器内运行 | 装好打开页面就能用 |
