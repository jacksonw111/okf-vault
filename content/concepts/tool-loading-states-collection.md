# loading.daniasyrofi.com

## 它是什么
`loading.daniasyrofi.com` 是 **dani asyrofi** 维护的一份**加载状态合集站点**：作者长期「逐个记录」遇到的 loading 状态（skeleton / spinner / progress bar / 占位符…），最终把分散的整理合并到这一个站点集中展示，供设计与前端参考。

## 为什么用它 / 适合什么场景
- 找「loading 怎么做得不无聊」的灵感。
- UI 动效参考库：想看别人怎么处理等待 / 占位场景。
- 设计师 / 前端做产品时不想每次从零想 loading 方案。

## 关键能力
| 能力 | 说明 |
|------|------|
| 集中合集 | 把分散记录的 loading 状态汇总到一处 |
| 持续累积 | 作者长期记录，不断扩充 |
| 视觉灵感 | 给设计与前端做产品时提供动效参考 |
| 在线展示 | 站点直接打开就能浏览 |
