# texpile

## 它是什么
`texpile/texpile` 是一个**完全离线、免注册**的桌面级编辑器，把 LaTeX、Typst、Markdown 三种语法整合在同一应用内，并提供**可视化编辑**与**源代码编辑**两种模式，可无缝切换。

## 为什么用它 / 适合什么场景
- 写学术论文（LaTeX）、现代排版文档（Typst）、博客 / 笔记（Markdown），不愿在多个编辑器间切换。
- 需要「所见即所得」与「源代码」并存：初稿用可视模式细调，复杂公式回源码手写。
- 网络受限或涉密场景：完全离线、不上传、不注册。

## 关键能力
| 能力 | 说明 |
|------|------|
| 三栈合一 | LaTeX / Typst / Markdown 一处编辑 |
| 双模式切换 | 可视化编辑 ↔ 源代码编辑 |
| 完全离线 | 不需要联网即可使用全部功能 |
| 免注册 | 无账号、无登录门槛 |
| 桌面级 | 原生桌面体验，不依赖浏览器 |
