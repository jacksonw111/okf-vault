# Pigma

Rust + Ratatui 构建的终端音乐播放器，支持网易云与本地音乐，并提供歌词高亮和 YouTube 音源回退。

## 适用场景

- 需要Ratatui 界面，适合键盘驱动的音乐浏览与播放的场景。

## 关键能力

| 能力 | 说明 |
|------|------|
| 终端体验 | Ratatui 界面，适合键盘驱动的音乐浏览与播放。 |
| 多来源播放 | 支持网易云音乐与本地文件，并可在音源不可用时回退到 YouTube。 |
| 歌词呈现 | 支持逐字渐变高亮歌词。 |
