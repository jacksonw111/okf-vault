# Motion Movement Reference

## 它是什么

[Motion Movement Reference](https://motion-reference.takayustudio.jp/index.html) 是一个面向动效设计师的辞典站，按「动作类型、缓动曲线、速度」等维度收录 UI 动效样例。设计师在写 motion design brief 或挑缓动曲线时，可以按维度浏览参考实现。

## 适合谁用

- 动效设计师想找特定节奏 / 曲线 / 速度的现成参考
- 前端 / 全栈工程师在落地 motion design 时需要快速对照「类似参考」
- 给设计评审提供「同类动效命名 / 节奏」词典

## 关键能力

| 能力 | 说明 |
|------|------|
| 多维分类 | 按动作类型 / 缓动 / 速度等维度检索 |
| 真实样例 | 收录真实 UI 中的动效片段 |
| 命名参考 | 给动效提供通用命名，便于跨团队沟通 |
