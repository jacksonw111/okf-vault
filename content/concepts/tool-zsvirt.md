# ZSvirt（ZStack ZSphere 虚拟化引擎开源版）

## 它是什么

[`ZSvirt`](https://github.com/Kid-G0629/zsvirt) 是 Kid-G0629 把 **ZStack 久经验证的 ZSphere 虚拟化引擎**开源化的产物。

- **背景**：企业级虚拟化平台长期被 VMware vSphere / Microsoft Hyper-V 等商业厂商锁定，授权昂贵
- **目标**：从**家庭实验室**到**超大规模机房**的统一可自托管替代
- **继承**：基于 ZStack 商用版反复打磨过的 ZSphere 引擎

## 为什么用它 / 适合什么场景

- 想摆脱 VMware / Hyper-V 等商业授权锁定
- 自托管机房 / 内网部署场景
- 想用开源的国产化虚拟化栈
- 已有 ZStack 经验想延续

## 关键能力

| 能力 | 说明 |
|------|------|
| 企业级特性 | 继承 ZStack 商用 ZSphere 引擎 |
| 自托管 | 数据全在自己手里 |
| 规模可伸缩 | 家庭实验室 → 超大规模机房 |
| 开源 | 不被授权锁定 |
| 国产化 | 国内生态 / 合规友好 |
