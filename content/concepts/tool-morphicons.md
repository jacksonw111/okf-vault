# Morphicons

## 它是什么
一组图标切换形变动画（morphing icons）。当用户在 UI 里切换两个图标时（比如菜单开/关态、播放/暂停、收藏/已收藏），Morphicons 让两个图标之间按曲线平滑变形，而不是直接替换。

## 三种动画策略
| 策略 | 视觉感受 |
|------|---------|
| 形变（morph） | 边 / 点一一对应逐渐过渡 |
| 翻转（flip） | 3D 翻转换面 |
| 拉伸（stretch） | 路径沿轴拉伸 |

## 关键能力
| 能力 | 说明 |
|------|------|
| 多种策略 | morph / flip / stretch 等 |
| 丝滑过渡 | 曲线 + 缓动函数 |
| 通用 | 任何 SVG 图标都可套 |

## 适用场景
- 网站 / App 里需要"有质感"的微交互
- 强调"精致 / 优雅"调性的产品落地页
- 给静态图标加上微动画
