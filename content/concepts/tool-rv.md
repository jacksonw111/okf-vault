# rv (madeye)

## 它是什么
`madeye/rv` 是一款**RealVNC Viewer 的开源替代**：作者 m0d8ye 因公司网络里 RealVNC Viewer 的 License 问题不便使用，于是自己写了一个 VNC Viewer；目前主要实测 macOS，Win / Linux 版本欢迎社区试用。

## 为什么用它 / 适合什么场景
- 公司 / 组织禁止 RealVNC Viewer 的 License，需要一个开源 VNC 客户端跑同款协议。
- 不想被 RealVNC 的闭源追踪 / 上报策略绑住。
- macOS 主力使用，Win / Linux 偶尔用。

## 关键能力
| 能力 | 说明 |
|------|------|
| 开源 VNC 客户端 | 可自审 / 自托管 |
| License 友好 | 避开 RealVNC Viewer 的企业 License 限制 |
| 多平台 | macOS 实测，Win / Linux 可用 |
| VNC 协议 | 标准 VNC 协议，可连 RealVNC Server 等任意 VNC 服务端 |
