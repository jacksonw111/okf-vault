# 狗头军师 Jev Chat（goutoujunshi-jev-chat）

## 它是什么

[狗头军师 Jev Chat](https://github.com/shengjidaguai-china/goutoujunshi-jev-chat) 是「狗头军师」项目的延伸：在 Mac 微信会话旁挂一个悬浮窗，读屏抓聊天原文、分析对方可能的意图，再排出一组候选回复。

## 它解决的问题

微信聊天时经常需要：
- 揣摩对方意图（真实意思 / 字面意思）
- 准备多个候选回复，挑一个最合适的
- 不希望用「勇敢追 / 赶紧分」二选一的简单 AI

Jev Chat 把这种「狗头军师」式辅助带到 Mac 微信会话旁。

## 与「狗头军师」主项目的关系

| 项目 | 形态 |
|------|------|
| 狗头军师（goutoujunshi） | Codex AI 助手，偏方法论 + 跨学科知识库 |
| 狗头军师 Jev Chat | Mac 桌面延伸工具，读屏 + 意图分析 + 候选回复 |

## 关键能力

| 能力 | 说明 |
|------|------|
| 读屏抓原文 | 在 Mac 微信会话旁挂悬浮窗读取聊天内容 |
| 意图分析 | 分析对方可能意图（区别字面 / 真实意思） |
| 候选回复 | 排出一组候选回复，由用户挑选 |
