# qingming-riverside（清明上河图网页交互版）

## 它是什么

[qingming-riverside](https://github.com/xianxie6/qingming-riverside) 是一个把《清明上河图》做成网页交互长卷的项目。用户可以在岸边唤船渡河，按住方向键把货船牵过虹桥，也能让清明时雨下起来。

## 体验要点

| 要素 | 说明 |
|------|------|
| 街市长卷 | 还原宋代市井街市长卷 |
| 互动唤船 | 在岸边可触发渡船动作 |
| 牵船过桥 | 方向键控制货船牵过虹桥 |
| 实时天气 | 可以让清明时雨下起来 |

## 适用场景

- 文化 / 历史主题的互动体验
- 网页交互与动画的样例参考
- 想把中国古典绘画做成可玩体验的开发者
