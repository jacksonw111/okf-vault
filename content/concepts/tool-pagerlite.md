# Pagerlite（Pagerlite/pagerlite-laravel）

## 它是什么

`Pagerlite/pagerlite-laravel` 是一个**轻量、自托管的 Laravel 值班（on-call）与告警分派系统**，体验类似 **Horizon / Telescope**——**即装即用**。

## 为什么用它 / 适合什么场景

- 中小团队 / 个人项目**不想用 PagerDuty / OpsGenie** 那种 SaaS，又想要标准 on-call 流程；
- 已有 Laravel 应用，希望**告警系统就嵌在同一个项目里**；
- 想要像 Horizon / Telescope 那样「装上就用」的开箱体验。

## 关键能力

| 能力 | 说明 |
|------|------|
| 值班分派 | on-call 排班与告警路由 |
| Laravel 集成 | 与现有 Laravel 应用同源 |
| 自托管 | 数据在自己手里 |
| 轻量 | 比 PagerDuty / OpsGenie 简单 |
