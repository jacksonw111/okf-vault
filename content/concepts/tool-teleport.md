# Teleport（Windows 右键「发送到」批量移动工具）

## 它是什么
[Teleport](https://github.com/GlifBoss/Teleport) 是一款 Windows 桌面小工具：把自己注册进资源管理器的右键 **「发送到（Send to）」** 菜单后，你在文件管理器里多选若干个文件 / 文件夹 → 右键 → 「发送到」→ 选 Teleport → 选目标位置，即可一次性把所有选中项目移过去。比拖拽 / 多次「剪切-粘贴」省事，又不强制装一个常驻进程。

## 为什么用它 / 适合什么场景
- 在 `下载`、`桌面`、`临时目录` 之间反复转移文件，每次都拖一摞。
- 想给某些高频目标（比如 `D:\Work`、`E:\Archive`）做「一键分发」，不必复制完整路径。
- 喜欢 Send to 这种 **Windows 原生范式**，不想为这点小事装大软件。

## 关键能力
| 能力 | 说明 |
|------|------|
| 右键集成 | 通过注册 Send to 菜单挂入资源管理器 |
| 批量移动 | 多选文件 / 文件夹一次性搬走 |
| 目标预置 | 把常用目标位置先配好，「发送时」只选不输 |
| 原生范式 | 不抢焦点、不开窗口、不驻留后台 |
| 跨盘 / 跨目录 | Windows 资源管理器可触达的所有路径 |
