# SlopMonster

## 它是什么

[ItsssssJack/SlopMonster](https://github.com/ItsssssJack/SlopMonster) 是一款**反 AI 腔工具**：把 AI 生成的「机器味」文案改写成**人类会发布的版本**。流程带**打分门禁**（5 分制）——没过线就继续改；并支持**换模型家族**清洗同源异味（同一模型改两遍往往改不干净，换家族更有效）。

## 为什么用它 / 适合什么场景

- 内容运营需要批量把 AI 草稿变成「像人写」的版本。
- 自媒体 / 公众号 / 邮件外发，不想因 AI 痕迹被读者识别。
- 已有评分标准但缺自动化门禁的工作流。
- 单模型改写效果不佳时，希望自动切到另一家族再改一遍。

## 关键能力

| 能力 | 说明 |
|------|------|
| 反 AI 腔改写 | 把机器味文案润色成人类语气 |
| 5 分制门禁 | 改到过线才放行 |
| 模型家族切换 | 同一改写任务可换家族清洗 |
| 可嵌入流水线 | 适合放进内容运营 / 邮件外发批处理 |
| 异味评分 | 量化「还剩多少机器味」 |
