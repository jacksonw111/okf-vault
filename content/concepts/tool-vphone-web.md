# vphone-web

## 它是什么
`34306/vphone-web` 是一款把**虚拟 iPhone 调试搬到浏览器里**的工具：vphone 是开发者用的虚拟 iPhone 运行环境，本工具提供 Web 端调试界面，让你在浏览器里就能远程看 / 控 / 排 vphone 上的 App。

## 为什么用它 / 适合什么场景
- 想远程调试 vphone 上的 App，而不必坐在本机屏幕前。
- 团队里多人都要复用同一台 vphone，Web UI 便于共享访问。
- 在受限设备上也想「看一眼跑得怎么样」，Web 端最轻。

## 关键能力
| 能力 | 说明 |
|------|------|
| Web 调试界面 | 浏览器内直接看 / 控 vphone |
| 远程调试 | 不必物理接触 vphone 主机 |
| 共享访问 | 团队成员可同时通过 Web 调试同一台 vphone |
| vphone 配套 | 与 vphone 虚拟 iPhone 运行环境配套使用 |
