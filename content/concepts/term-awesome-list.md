# Awesome Lists（精选清单）

## 定义

GitHub 生态里以 **`awesome-<topic>`** 命名的资源精选清单——通常以单一 README 维护、按子分类切分、定期接收 PR 增删。其原型是 [`sindresorhus/awesome`](https://github.com/sindresorhus/awesome) 的「机器学习」清单，后来被复制到几乎所有技术领域。

## 要点

- **典型格式**：分类标题 + 简短条目 + 链接（必要时一行注释）
- **维护方式**：社区 PR + 维护者 review，质量靠准入门槛（star / 活跃度 / 实用性）
- **价值**：对人是「一份清单入门一个领域」；对 Agent 是「带语义的元数据」便于按需检索
- **同形异构**：很多「非 awesome」的精选清单（`xxx-resources`、`xxx-collection`、`xxx-stars`）在结构与目的上等同于 awesome list
