# Pindo（拼豆图纸自动生成器）

## 它是什么

[`Pindo`](https://github.com/LunarXuan/Pindo) 是 LunarXuan 写的拼豆助手工具——**把图片直接转成可照着拼的拼豆图纸**：

- **网格**：自动出像素网格图，方便逐格对照
- **每颗豆子的色号**：标在对应格子上
- **用量统计**：每色用多少颗，采购一目了然
- **旧图纸识别**：已有的拼豆图纸（照片）也能识别，对**缺色号**的格子自动补上候选色
- **全程浏览器内**——图片不传服务器，隐私友好

## 为什么用它 / 适合什么场景

- 想自己把图片 / 角色 / LOGO 转成拼豆作品（不必手动数格子）
- 现成图纸没标色号，要快速补料采购
- 不想让图纸图上传到第三方图像识别服务

## 关键能力

| 能力 | 说明 |
|------|------|
| 图片 → 拼豆图纸 | 自动网格 + 色号标注 |
| 色号用量统计 | 每色用多少颗 |
| 旧图纸补色 | 识别时自动补缺色号 |
| 浏览器本地 | 无服务器上传 |
| 隐私友好 | 图不离开本地 |
