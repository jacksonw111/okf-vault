# Expenso

## 它是什么
离线优先的 Android 端记账 / 理财应用，用 Jetpack Compose + Material 3 写成，数据落本地 Room 数据库——不依赖任何云后端，开机即用。

## 为什么用它 / 适合什么场景
- 不想把个人财务数据交给第三方云，又想要现代 Material 3 体验。
- 离线 / 信号差的环境（出差 / 海外）下继续记账。
- 学习 Jetpack Compose + Room 离线架构的实战参考项目。

## 关键能力
| 能力 | 说明 |
|------|------|
| 离线优先 | 无需网络即可完整使用，数据全部本地 |
| 现代 UI | Jetpack Compose + Material 3，跟上 Android 设计语言 |
| 本地存储 | Room 数据库，单设备持久化，隐私可控 |
