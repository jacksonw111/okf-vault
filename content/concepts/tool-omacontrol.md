# OmaControl

## 它是什么

[OmaControl](https://github.com/Davedes83/OmaControl) 是 **Davedes83** 开源的 **Omarchy 顶栏任务管理器**——把 Omarchy 顶栏的一个图标变成完整的系统监控面板：**实时曲线**、**单应用历史用量**、**进程管理**、**摄像头麦克风调用提醒**都塞在一个顶栏入口里。

定位是「**Omarchy 桌面专用**」的一站式顶栏监控组件，省去单独开终端跑 `htop` / 写脚本来监控摄像头被调用的麻烦。

## 为什么用它 / 适合什么场景

- **Omarchy 用户** 想给顶栏加一个统一监控入口
- **隐私敏感** 用户要随时知道哪个 app 在偷偷调摄像头 / 麦克风
- **多任务场景** 想知道每个 app 的 CPU / 内存历史曲线
- 极简 / Linux 美学爱好者——所有功能在一个图标里

## 关键能力

| 能力 | 说明 |
|------|------|
| 实时曲线 | 系统资源实时图 |
| 单应用历史用量 | 按应用维度看历史 |
| 进程管理 | 在顶栏里直接结束 / 调整进程 |
| 摄像头提醒 | 哪个进程调用了摄像头立即告警 |
| 麦克风提醒 | 同上 |
| 形态 | Omarchy 顶栏一个图标 |
