# vibe-coding-cn

## 它是什么

[vibe-coding-cn](https://github.com/tradecatlabs/vibe-coding-cn) 是 **tradecatlabs** 维护的**中文 Vibe Coding 系统教程**——不是简单整理几个 Prompt，而是从零开始教怎么用 Codex / Claude Code / Cursor / Gemini CLI 把一个想法真正做成产品。

## 覆盖的完整流程

| 阶段 | 内容 |
|------|------|
| 起步 | 环境配置、需求拆解 |
| 表达 | Prompt 工程、Skill 设计、Context 组织 |
| 执行 | Workflow 编排、质量门禁 |
| 收尾 | Git 工作流、测试方法、复盘模板 |

## 与同类教程的差异

- **不只 Prompt 模板**：把整个 AI 编程的工作流讲清楚
- **多 Agent 兼容**：Codex / Claude Code / Cursor / Gemini CLI 一份内容通吃
- **中文写就**：术语和思考方式更贴中文开发者习惯

## 适合人群

- 第一次接触 AI 编程工具的工程师
- 想把 AI 编程流程「系统化」的团队
- 中文为主工作环境的开发者
