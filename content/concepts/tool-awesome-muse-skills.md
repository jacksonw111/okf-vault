# awesome-muse-skills（Meta Muse 助理技能目录）

## 它是什么

[awesome-muse-skills](https://github.com/aicodedecode/awesome-muse-skills) 是 aicodedecode 维护的社区资源库：给 Meta 的 Muse 个人助理收集可复用的 agent 技能，每个技能就是一个 SKILL.md 文件，用户从目录里挑一个粘进对话就能用。

## 关键能力

| 能力 | 说明 |
|------|------|
| 2365 个技能 | 899 个原创 + 1466 个带署名的第三方精选导入 |
| 单文件形态 | 每个技能一份 SKILL.md |
| 选 / 粘即用 | 从目录挑一个粘进 Muse 对话 |
| 社区维护 | 持续更新，含第三方导入 |

## 适用场景

- 想给 Muse 个人助理加新技能
- 想找现成的 agent skill 模板
- 想要 SKILL.md 格式的技能合集
