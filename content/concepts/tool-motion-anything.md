# motion-anything

## 它是什么
开源动效生成工具，主打「**自然语言 → 可上线的网页动效**」：把"温柔地飘过来""果冻般弹一下"这样的感觉描述直接编译成可嵌入页面的代码片段（关键帧 + 弹簧曲线 + 自定义轨迹），Apache 2.0 协议，由 Open Design 团队原班人马打造。

## 为什么用它 / 适合什么场景
- 设计小白零门槛：不用懂 transition timing function，**说 "感觉" 就能出顶尖动效**。
- 专业设计师 / AE 老手够用：关键帧、弹簧曲线、自定义轨迹可精调。
- 产物可直接上线：输出基于 CSS / Framer Motion / Lottie 可直接嵌入生产页面。
- 开源可控：可二次定制或接入企业级动效系统。

## 关键能力
| 能力 | 说明 |
|------|------|
| 感觉描述编译 | 自然语言（"果冻弹" / "温柔飘" / "猛烈撞"）→ 工程化动效 |
| 关键帧编辑器 | 可逐帧调位置 / 缓动 / 旋转 / 透明度 |
| 弹簧曲线 | 物理感（质量 / 张力 / 阻尼）而不是简单 cubic-bezier |
| 自定义轨迹 | 任意路径动画（鼠标轨迹 / 物体运动轨迹） |
| 多端输出 | CSS / JS / Framer Motion / Lottie |
