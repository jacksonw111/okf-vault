# ThinkingOrbs（SwiftUI 3D 点阵加载指示器）

## 它是什么

[ThinkingOrbs](https://github.com/haplollc/ThinkingOrbs) 是一个给 SwiftUI 的 AI / agent 界面设计的 3D 点阵加载指示器组件库。**一行代码替换系统转圈**，就能让等待状态显得更专业。

## 适合谁用

- SwiftUI 开发者做 AI / Agent 类应用
- 想用「思考中」的视觉表达替代默认菊花转圈
- 想给 macOS / iOS 应用加 3D 风格的加载指示器

## 关键能力

| 能力 | 说明 |
|------|------|
| 一行接入 | 单行代码替换系统加载指示器 |
| 3D 风格 | 点阵的 3D 视觉效果 |
| SwiftUI 原生 | 直接接入 SwiftUI 项目 |
| AI 场景 | 为「思考 / 推理中」状态量身定做 |

## 适用场景

- 任何 SwiftUI 应用想替换默认 loading spinner
- AI 聊天 / agent 应用的「thinking」状态指示
- macOS / iOS 上的 3D 风格 UI 装饰
