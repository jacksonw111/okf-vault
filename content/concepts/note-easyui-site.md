# easyui.site

## 它是什么

[easyui.site](https://easyui.site) 是一个面向**极简风格 UI**的灵感站——收录大量极简风界面作品，给追求「少即是多」视觉风格的项目做参考。

## 风格定位

- 大量留白
- 元素少而精
- 视觉重心单一
- 排版 / 间距克制

## 适合场景

- 产品 Landing Page 想做极简高端感
- AI 生成 UI 出来后想往「专业感」方向再推一档
- 个人作品集 / 工具型 Web App 的视觉参考
