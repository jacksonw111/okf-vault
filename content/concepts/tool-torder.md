# Torder 今序（Tauri 2 本地待办）

## 它是什么
[Torder 今序](https://github.com/kelongyan/Torder) 是一款 Windows 上的本地待办工具：技术栈 **Tauri 2 + React + Rust**，数据存到 **本机 SQLite**，记录 / 整理 / 提醒完全在本地完成，不上传任何服务器。中文名「今序」，强调「以今日为序、按时序推进」的本地生活流。

## 为什么用它 / 适合什么场景
- 想要一款轻量、隐私优先、不开会员就不让用的待办工具。
- 喜欢 Tauri 系「Web 前端 + 原生壳 + Rust 后端」的栈，体积小、启动快。
- 待办内容敏感（个人事务 / 副业规划），不想丢给云端。

## 关键能力
| 能力 | 说明 |
|------|------|
| Tauri 2 壳 | Web 前端体验 + 原生性能 + 小体积 |
| 本地 SQLite | 数据完全在本机 |
| 记录 / 整理 | 任务清单、分类、优先级（按工具界面） |
| 提醒 | 本地通知，不依赖任何云服务 |
| 离线可用 | 完全离线运行 |
