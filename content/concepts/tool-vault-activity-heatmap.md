# Vault Activity Heatmap（AndrewRao114/vault-activity-heatmap）

## 它是什么

`AndrewRao114/vault-activity-heatmap` 为 **Obsidian 笔记库**生成 **GitHub 风格的写作贡献热力图**：统计每日写作活动（修改、新增等），形成可视化仪表盘，跨设备同步。

## 为什么用它 / 适合什么场景

- 长期使用 Obsidian 写笔记，想看到**每日产出分布**、识别规律 / 倦怠；
- 喜欢 GitHub 贡献图的样式，希望把写作行为**量化 + 视觉化**；
- 多设备同步笔记库，需要**跨设备聚合**活动统计。

## 关键能力

| 能力 | 说明 |
|------|------|
| 写作热力图 | 类 GitHub contribution graph 的年历视图 |
| 每日统计 | 自动汇总每日笔记新增 / 修改次数 |
| 跨设备同步 | 多端 Obsidian 笔记库聚合 |
| Obsidian 集成 | 作为 Obsidian 增强工具 |
