# easy-stock (jundizhou/easy-stock)

## 它是什么
`jundizhou/easy-stock` 是面向 **A 股** 的 AI 原生行情分析与智能投研**桌面工作台**：把盘中观察、盘后复盘、长期认知三段沉淀为持续进化的本地研究系统，并由 Agent 自动收集「大 V 文章 / 公开观点」提炼要点喂给工作台。

## 为什么用它 / 适合什么场景
- 做 A 股个人投研，但不想把数据 / 笔记全托管给券商 App。
- 想把「盘中 / 盘后 / 长期」三段时间尺度的认知都沉淀在同一处。
- 关心大 V 公开观点但没空逐篇读完：交给 Agent 提炼要点后再精读。

## 关键能力
| 能力 | 说明 |
|------|------|
| 三段时间尺度 | 盘中观察 / 盘后复盘 / 长期认知 |
| 本地研究系统 | 数据沉淀在本地，可长期积累 |
| 大 V 文章自动收集 | Agent 持续抓公开文章 / 帖子 |
| 观点提炼 | 自动抽取要点，减少阅读负担 |
| 桌面工作台 | 一体化 GUI，不依赖浏览器 |
