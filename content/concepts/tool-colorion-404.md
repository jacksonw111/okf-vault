# colorion 404

## 它是什么

`404.colorion.co` 是 colorion 站推出的免费 404 页面组件集合：动画 / 插画 / 排版多种风格可选，每条都可自定义后直接放进自家落地页 / Web 应用。同站另有 [text-effects.colorion](./tool-text-effects-colorion.md) 系列（文字效果），构成 colorion 的 UI 资源矩阵。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多种风格 | 动画 / 插画 / 排版风格一应俱全 |
| 可自定义 | 颜色 / 文案 / 跳转目标均可改 |
| 直接落地 | 复制粘贴即用 |
