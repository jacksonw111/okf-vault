# craftUI

## 它是什么
交互式 SVG 图标库（craftui.space），每个图标都自带微交互（鼠标悬停 / 点击时产生动画反馈），让静态图标不再是"死的 png"。

## 关键能力
| 能力 | 说明 |
|------|------|
| 交互式图标 | 悬停 / 点击触发微动画 |
| 浏览器内试用 | 不用下载即可看效果 |
| SVG 格式 | 矢量、可改色 |
| 可复制源码 | 与同类 SVG 库一致风格 |

## 适用场景
- 想给产品落地页 / 卡片增加"活起来"的图标
- 想要差异化图标风格的产品
- 给静态图标加微交互的设计师
