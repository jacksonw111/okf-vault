# Mobius（自进化开源 Agent OS）

## 它是什么
`nutshellai-tech/mobius` 自称是"**全球首个自进化开源 Agent OS**"：

- 把**项目 / 团队 / AI agent / 设备 / 算力**连进同一个**可追踪**工作区
- 通过**变更请求 / 截图 / 链接**三种入口，agent 自动改写**自身代码、UI 与插件**
- "自进化"：agent 不仅是工具，**能改自己**，且每次改动都被追踪、回滚、再进化

## 为什么用它 / 适合什么场景
- 想要一个**统一工作台**：项目、agent、设备、算力都看得见摸得着。
- 想让 agent **自己修自己**——不是 prompt 改、而是真的写 PR 改自己代码。
- 适合：AI 公司工作流 / 中小企业自托管 SaaS / 想要"程序开发自动化"的产品团队。
- 对比：传统 Agent OS 是「agent 帮你做事」，Mobius 是「agent 也能被改」。适合长跑型、可迭代型系统。

## 关键能力
| 能力 | 说明 |
|------|------|
| 跨实体工作区 | 项目 / 团队 / agent / 设备 / 算力同台 |
| 三种入口 | 变更请求 / 截图 / 链接 |
| 自进化 | agent 自动改自己代码 + UI + 插件 |
| 全程可追踪 | 每次改动有迹可查 |
| 开源 | 私有部署可用 |
