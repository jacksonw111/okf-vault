# MarkdownReader（Windows 轻量 Markdown 编辑器）

## 它是什么
Windows 平台上的轻量级 Markdown 编辑器，主打「打开即写、边写边预览、一键导出 PDF」。定位是比 Typora / Obsidian 更轻、比 VS Code Markdown 插件更专注的写作工具。

## 为什么用它 / 适合什么场景
- 只想专注写 Markdown，不需要知识图谱 / 双向链接 / 插件生态。
- 写完直接要 PDF 交付（投稿、汇报、合同），不想走 Markdown → Word → PDF 这种长链。
- Windows 用户，希望装一个小体积工具就能跑，不要 WSL / Docker。

## 关键能力
| 能力 | 说明 |
|------|------|
| 实时预览 | 边写边渲染，所见即所得 |
| PDF 导出 | 一键导出 PDF，适合交付 |
| 轻量 | 体积小、启动快、不臃肿 |
