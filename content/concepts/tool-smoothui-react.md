# smoothui

## 它是什么
smoothui 是 educlopez 开源的 React 组件库，专门提供「产品级流体动画」。每个组件都已把弹簧 / 阻尼 / 时序等动效参数调好，开发者直接 copy-paste 进项目即可获得顺滑交互，避免从零配 Framer Motion。

## 为什么用它 / 适合什么场景
- 自己写动画经常「调试半天动效不如设计师演示」。
- 想要 Figma / shadcn 那种「装上就漂亮」的体验，smoothui 类似定位，但只覆盖动效维度。
- 适合做 SaaS Dashboard、登录页、营销站、产品落地页等需要给「专业感加分」的 React 项目。

## 关键能力
| 能力 | 说明 |
|------|------|
| 组件形态 | 可复制粘贴的 React 片段 |
| 动效范围 | 过渡、悬浮反馈、列表入场、模态、菜单等 |
| 底层 | 基于 Framer Motion |
| 风格 | 流体（fluid）、产品级、不花哨 |
| 许可 | 开源 |
