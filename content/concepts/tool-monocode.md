# monocode（编码 agent 多客户端统一桌面 UI）

## 它是什么

[monocode](https://github.com/hardbeat920/monocode) 是一个**桌面 UI**，把多种编码 agent（Claude Code、Codex、Cursor 等）统一收进同一个窗口：每个 agent 装好、登录好之后，在 monocode 里就像在 IDE 里切换标签页那样跑，会话就是标签页，**一个输入框指挥所有 agent**。

## 为什么用它 / 适合什么场景

- 同时用 Claude Code / Codex / Cursor，厌倦了在多个终端 / 应用间来回切换；
- 想要一个统一的入口看每个 agent 当前在做什么、过去做过什么；
- 想用一个 UI 同时调度多种编码 agent，比对它们的回答；
- 不喜欢每家工具各自一套独立 UI 与命令。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多 agent 统一 | Claude Code / Codex / Cursor 同窗运行 |
| 标签页式会话 | 每个 agent 会话当标签页 |
| 单输入框 | 一个输入框指挥所有 agent |
| 桌面端 | 独立桌面应用 |
