# 100 Themes

## 它是什么

**100 Themes** 是 [bjarneo](https://github.com/bjarneo) 维护的 **Omarchy 桌面主题合集**——把 **100 套现成的深色主题**打包好，每套都配齐 **ANSI 配色 + 壁纸**，省去自己手动调主题的繁琐。

Omarchy 是基于 **Arch + Hyprland** 的「一键桌面」发行版，100 Themes 直接补足了它的**视觉起点**——拿到一台新装的 Omarchy 不用从空白配色开始，挑一套开箱即用。

## 为什么用它 / 适合什么场景

- 刚装好 Omarchy，希望直接挑一套顺眼主题不踩坑。
- 想给 Arch / Hyprland / Waybar / Kitty / Ghostty 等做**视觉一致性**。
- 喜欢每隔一段时间就换主题，但不想每次都自己抠 ANSI 配色。
- 想要从别人调好的方案里**反向学习**：看现成主题学配色规律。
