# watermark-removal

## 它是什么
基于 **Inpainting（图像修复）** 技术的开源库，处理目标不是粗暴涂抹，而是用 AI 自动「理解」并填补被水印遮挡的底层像素，从而把打了水印的图片还原到肉眼真假难辨的程度。GitHub 已获 4600+ Star，代码纯开源本地可跑。

## 为什么用它 / 适合什么场景
- 无痕还原：去水印后与原图视觉差异极小。
- AI 智能脑补：底层算法直接生成被遮挡区域，而非简单覆盖。
- 免费白嫖：开源本地运行，零成本无限次使用。
- 适合需要批量清洗素材 / 二次创作原图的研究或设计工作流。

## 关键能力
| 能力 | 说明 |
|------|------|
| AI Inpainting 修复 | 不止涂抹，**重绘被遮挡的像素**使其与周围纹理一致 |
| 高质量复原 | 输出与原图肉眼难以分辨 |
| 批量处理 | 可对一批图片统一去水印 |
| 本地运行 | 完全离线不依赖云服务 |
