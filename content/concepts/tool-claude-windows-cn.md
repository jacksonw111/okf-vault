# claude-windows-cn（Windows 上 Claude Desktop 一键安装 / 更新 / 汉化工具）

## 它是什么

[claude-windows-cn](https://github.com/chrichuang218/claude-windows-cn) 是 chrichuang218 出品的 **Claude Desktop Windows 辅助工具**——把「**手动下载 Claude Desktop / 查更新 / 找替换包汉化**」这套繁琐流程收进一个**统一界面**：

| 操作 | 说明 |
|------|------|
| 装应用 | 自动下载并安装 Claude Desktop |
| 查更新 | 检测当前版本与最新版本 |
| 开汉化 | 一键应用中文本地化 |
| 恢复原样 | 一键还原回英文界面 |

## 为什么用它 / 适合什么场景

- Windows 上想用 **Claude Desktop** 但下载 / 安装 / 汉化流程繁琐。
- 团队成员不是技术背景——希望**点几下**就能用上中文 Claude Desktop。
- 担心**手动替换汉化包**出错导致 Claude Desktop 异常——需要一键恢复。

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | Windows GUI 工具 |
| 安装 | Claude Desktop 自动下载 / 安装 |
| 更新 | 检测新版本 |
| 汉化 | 一键应用 |
| 还原 | 一键恢复英文 |
