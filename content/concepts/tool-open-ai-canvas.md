# Open AI Canvas / 影策

## 它是什么

**AI 影视制作的无限画布工作台**——传统 AI 影视创作要在 5+ 个工具间来回切：

- 编剧工具（文本）
- AI 生图工具（角色 / 场景）
- AI 生视频工具（分镜）
- 角色卡 / 设定表（一致性管理）
- 素材库（图片 / 视频片段）
- 音频工具

Open AI Canvas / 影策把这些塞进一张无限画布：

- **画布上**摆着各种节点：文本块、角色卡、分镜、素材、3D 镜头预览
- **节点之间**可以相互引用（角色卡 → 所有相关分镜）
- **统一生成**：文字 / 图片 / 视频 / 音频一站完成
- **统一浏览**：跑在浏览器里

![截图](https://pbs.twimg.com/media/HOXi1tAbwAAUXIm.jpg)

## 关键能力

| 能力 | 说明 |
|------|------|
| 无限画布 | 节点化排版 |
| 多模态生成 | 文 / 图 / 视频 / 音频 |
| 分镜编辑器 | 剧本 → 分镜自动拆解 |
| 角色卡管理 | 一致性参考 |
| 3D 导演台 | 镜头预览 |
| 素材库 | 集中管理生成产物 |
| 浏览器跑 | 不装客户端 |

## 适合谁

- AI 影视 / 短剧 / 广告片创作者
- 想统一 AI 创作工作流的团队
- 重视角色一致性 / 资产管理的项目
