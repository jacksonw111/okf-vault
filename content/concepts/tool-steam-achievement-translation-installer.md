# Steam 成就中文翻译安装工具

## 它是什么

[GaBoron/steam-achievement-translation-installer](https://github.com/GaBoron/steam-achievement-translation-installer) 是给 Windows 玩家做的一键 Steam 成就中文化工具，自动解决「要中文化某游戏的成就，得手动对照社区翻译、自己写 / 改 BIN 文件、易翻车」这几个痛点。

## 关键能力

| 能力 | 说明 |
|------|------|
| 自动扫本机游戏 | 不用手动挑游戏列表 |
| 翻译库版本匹配 | 自动从社区翻译库挑匹配的版本 |
| 安全写入 | 对 .BIN 等二进制做安全改写，避免破坏游戏 |
| 备份 / 恢复 | 失败可回滚，不破坏原文件 |
