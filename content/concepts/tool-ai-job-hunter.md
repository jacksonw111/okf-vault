# AI Job Hunter

## 它是什么
面向 AI 行业求职者的 Claude Code 技能：先采你的个人画像，再抓 BOSS 直聘真实招聘数据，做技能差距分析，最后产出 30 / 60 / 90 天的定制化学习计划。

## 为什么用它 / 适合什么场景
- 想转行 / 进阶 AI 工程但不知道"目标岗位到底要什么"，需要真实招聘数据驱动规划。
- 简历与岗位 JD 长期脱节，需要自动做差距分析。
- 想把"自学计划"结构化到 30 / 60 / 90 天这种可执行节奏。

## 关键能力
| 能力 | 说明 |
|------|------|
| 个人画像 | 自动汇总你的技能 / 经验 / 项目 |
| 招聘数据 | 抓 BOSS 直聘真实岗位 JD |
| 差距分析 | 个人画像 vs 目标岗位技能矩阵 |
| 30/60/90 天计划 | 阶段化学习路线 |
| Claude Code 技能 | 直接在 Claude Code 里调用 |
