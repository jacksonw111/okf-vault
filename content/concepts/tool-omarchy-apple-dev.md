# omarchy-apple-dev

## 它是什么

[omarchy-apple-dev](https://github.com/joshuaswarren/omarchy-apple-dev) 是 joshuaswarren 开源的「**Linux 上做 Apple 开发**」工具：

- 在 **Omarchy Linux**（Apple Silicon 或 x86_64）上**编译 SwiftUI 应用**
- 通过 **USB 装进 iPhone**
- 直接上传 **App Store / TestFlight**
- 全程不需要 **macOS** 和 **Xcode**

## 为什么用它 / 适合什么场景

- **不想绑死在 Mac**：把开发环境迁到 Linux 上
- **跑 iOS 老项目**：被「一定要 Mac」的硬约束卡住的开发者
- **节省硬件成本**：Mac mini / MacBook 不用买第二台
