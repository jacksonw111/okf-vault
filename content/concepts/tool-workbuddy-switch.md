# WorkBuddy Switch

## 它是什么

[changexbc/workbuddy-switch](https://github.com/changexbc/workbuddy-switch) 是面向 **WorkBuddy / CodeBuddy CLI / CodeBuddy CN IDE** 多账号场景的辅助工具。它把「多账号切换、积分到期管理、自动签到、Token 保活、用量统计」这一整套日常管理工作集中到一处。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多账号切换 | 在 WorkBuddy / CodeBuddy CLI / CodeBuddy CN IDE 之间一键切账号 |
| 积分到期管理 | 集中查看各账号积分余额与到期时间 |
| 自动签到 | 每日签到任务自动化 |
| Token 保活 | 防止 Token 因长期未活动而失效 |
| 用量统计 | 集中展示各账号调用量 |

## 适合什么场景

- 同时持有多个 WorkBuddy / CodeBuddy 订阅账号需要轮换使用的开发者。
- 需要按时管理订阅积分到期日、避免突然断供的个人 / 团队。
- 想把「每天 5 分钟手动签到 / 检查状态」这件事自动化的用户。
