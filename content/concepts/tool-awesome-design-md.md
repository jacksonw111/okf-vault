# awesome-design-md（73 个网站 DESIGN.md 集合）

## 它是什么

[awesome-design-md](https://github.com/VoltAgent/awesome-design-md) 收录了 73 个网站（Vercel、Notion、Figma、Linear 等）的 DESIGN.md 设计规范。把其中一份拷进项目根目录后，让 Claude / Cursor 等编码 AI 遵循其中的视觉规则写代码，保证字体 / 配色 / 间距 / 组件风格一致。

## 它要解决的问题

AI 能快速生成页面，但 UI 风格容易「字体、配色、间距各自发挥」导致最终页面像拼出来的。DESIGN.md 提供了一种轻量解：把设计规范写成 Markdown，让 AI 跟着走。

## 使用流程

1. 选一份 DESIGN.md 放进项目根目录
2. 要求 AI 遵循其中的视觉规则写代码
3. 让字体、颜色、间距和组件风格保持一致

## 对比传统做法

- 不需要先画 Figma
- 不需要维护复杂 JSON 配置
- 一个 Markdown 文件就能给编码 Agent 提供清晰设计参照

## 关键能力

| 能力 | 说明 |
|------|------|
| 73 个样本 | Vercel / Notion / Figma / Linear 等主流产品 |
| 单文件配置 | 每个网站一个 Markdown，拷进项目即可 |
| AI 友好 | 文本格式，便于 LLM 摄入并遵循 |
| 开源 | GitHub 公开仓库 |
