# dictionary-of-ai-coding（AI 编程术语词典）

## 它是什么

[mattpocock/dictionary-of-ai-coding](https://github.com/mattpocock/dictionary-of-ai-coding) 是 TypeScript educator **Matt Pocock** 开源的 **AI 编程术语词典**：把 evals / inference / fine-tuning / RAG / embeddings 等高频词条，用**简单英文 + 一段示例**讲清楚。给「在 AI 讨论里一直点头但其实没听懂一半」的工程师当速查。

## 为什么用它 / 适合什么场景

- 想 60 分钟内把 AI 编程黑话全部「听懂」。
- 给团队新人发的入门 cheat sheet。
- 写技术文档时反复核对某个术语的精确含义。

## 适合的读者

- **半路转 AI 的传统工程师**——会写代码但 evals / RAG / agents 都在赶时髦听不太懂。
- **技术管理者**——想看懂 AI 同事在讨论什么。
