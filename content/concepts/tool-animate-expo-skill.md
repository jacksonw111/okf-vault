# animate-expo（emilkowalski/skills /animate-expo）

## 它是什么
[`emilkowalski/skills`](https://github.com/emilkowalski/skills) 仓库里挂载的 `/animate-expo` 技能，由动画设计师 Emil Kowalski 与 Expo 团队合作产出。它把「动效知识」从 Web 端移植到 React Native / Expo 原生应用，覆盖手势交互、底部面板、触感反馈、屏幕过渡等场景，作为 Agent Skill 直接安装到编码代理里即可触发。

## 为什么用它 / 适合什么场景
- 给 React Native / Expo 应用写动效，但团队没有专门的动效设计师。
- 想要「工业级但带分寸」的过渡，而不是堆库乱配曲线。
- 已有 Web 端 `/animate` 知识（同一作者），想把风格延续到原生端。

## 关键能力
| 能力 | 说明 |
|------|------|
| 手势 | 拖拽 / 滑动 / 长按等手势的视觉反馈 |
| 面板 | 底部 sheet / drawer 的进出动画 |
| 触感反馈 | 与动画绑定的物理触感（haptics） |
| 屏幕过渡 | Stack / Modal 路由切换的过渡效果 |
| 与 Expo 合作 | 与 Expo 团队联合出品，对齐官方动效范式 |
