# Grayslate（轻量桌面便签本）

## 它是什么
[Grayslate](https://github.com/shriram-ethiraj/grayslate) 是一款轻量桌面便签本：写代码或处理数据时，经常要临时格式化 JSON、转 CSV、加解密、写一行笔记——开浏览器在线工具有隐私风险，开 IDE 又太重。Grayslate **自动识别你贴的是什么内容**，本地提供对应转换工具，自动保存，能搜索找回，数据完全在本地。

## 为什么用它 / 适合什么场景
- 写代码时频繁处理 JSON / 格式化 / 加解密 / 临时笔记。
- 不愿意把临时数据贴到云端在线工具上。
- 想用一个比 IDE 轻、比浏览器安全、又快能搜的「开发杂事面板」。

## 关键能力
| 能力 | 说明 |
|------|------|
| 内容自动识别 | 贴入即判断类型（JSON / CSV / 加密文本 / 普通笔记） |
| 本地转换工具 | 配套本地格式化 / 转码 / 加解密 |
| 自动保存 | 内容本地持久化，无需手动存 |
| 可搜索 | 历史便签能找回 |
| 数据不出本机 | 完全离线运行 |
