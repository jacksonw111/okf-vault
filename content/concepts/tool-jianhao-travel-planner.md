# 见好·旅行规划器

## 它是什么

[见好·旅行规划器](https://github.com/awangwang123/jianhao-travel-planner) 是 **awangwang123** 出品的 Claude Code Skill——把「做旅行攻略」这件要自己搜信息、交叉核对的活接过去，用一句出行需求换一份**联网实查、断网可开**的单文件 HTML 路书。

## 工作流

| 阶段 | 内容 |
|------|------|
| 1. 需求采集 | 用户说出行需求 |
| 2. 联网实查 | 实时搜资料 |
| 3. 三源交叉 | 大众点评 + 高德 + 小红书 |
| 4. 产出 | 本地完整版单文件 HTML（断网可开）+ 可一键部署的瘦身在线版 |

## 关键能力

| 能力 | 说明 |
|------|------|
| 触发词 | 「去哪玩」「做攻略」 |
| 输入 | 一句出行需求 |
| 验证 | 三源交叉（点评 + 高德 + 小红书） |
| 输出格式 | 单文件 HTML（断网可用） |
| 部署 | 瘦身版可一键部署到自有服务器 |

## 适合场景

- 出差 / 旅行前自动出攻略
- 想把攻略做成「可分享的网页」给同伴
- 信息源不愿只信一个平台时，自动做交叉验证
