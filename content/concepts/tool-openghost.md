# OpenGhost

## 它是什么

**OpenGhost** 是 [ANDRETRIPOL](https://github.com/ANDRETRIPOL) 维护的桌面 Agent，覆盖 Windows / Linux / macOS 三端。它把"自己写的引擎 + 自己写的绘图"作为差异化卖点——能做以下事情并把结果**直接画成图**：

- 执行命令
- 改文件
- 管 git
- 操作网页
- 输出图表、流程图等可视化结果

## 为什么用它 / 适合什么场景

- 希望 Agent 在本地桌面跑、不依赖云端执行环境。
- 跑结果时希望 Agent **直接把图画出来**，而不是吐一堆文本让你自己 Excel / draw.io 处理。
- 在三平台（Windows / Linux / macOS）都希望有同一个桌面 Agent 体验。

## 关键能力

| 能力 | 说明 |
|------|------|
| 平台 | Windows / Linux / macOS |
| 形态 | 桌面 Agent |

| 绘图 | 自研，把结果画成图表 / 流程图 |
