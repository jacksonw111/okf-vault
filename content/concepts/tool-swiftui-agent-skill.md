# SwiftUI Agent Skill（v5）

## 它是什么

[SwiftUI Agent Skill v5](https://www.avanderlee.com/ai-development/swiftui-agent-skill-build-better-views-with-ai/) 是一套专为 SwiftUI 视图开发设计的 Agent Skill，已经迭代到第 5 版。

## 关键更新（v5）

| 项 | 说明 |
|----|----|
| SDK 适配 | 更新到 27 SDK |
| Xcode 集成 | 利用 Xcode 27 内置的 agent skills |
| 平台能力 | 支持可调整大小的应用（如 iPhone Duo） |
| Token 效率 | 优化上下文占用，降低成本 |
| 视图质量 | 让 AI 更稳定地写出更好的 SwiftUI 视图 |

## 为什么用它

- SwiftUI 视图层的「**小细节**」很多（modifier 顺序、State 绑定、动画），AI 写 SwiftUI 通常会漏。
- v5 借助 Xcode 27 内置 agent skills——相当于**双层 skill 叠加**：Xcode 系统级 + 社区 SwiftUI 专用。
- 优化 token 效率这点对长期协作很关键——不至于每个会话都从零讲 SwiftUI 规则。

## 关键能力

| 能力 | 说明 |
|------|------|
| SwiftUI 专用 | 针对视图开发优化 |
| 27 SDK 适配 | 跟上最新 SDK |
| Xcode 集成 | 调用 Xcode 27 内置能力 |
| Token 优化 | 减少每会话上下文消耗 |
| 多视图场景 | 列表 / 表单 / 弹窗 / 自适应布局 |
