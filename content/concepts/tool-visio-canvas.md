# Visio-canvas

## 它是什么

[didohm/Visio-canvas](https://github.com/didohm/Visio-canvas) 是给设计师做的**灵感聚合画布**：把分散在 Pinterest、Figma、Notion、截图、浏览器书签里的视觉素材统一收进一块可无限缩放的画布。它解决的问题是「**素材到处堆，找的时候想不起来在哪**」——所有视觉参考平铺在一张大画布上，按主题分区、按色块归类或自由排布。

![](https://pbs.twimg.com/media/HQdGA6abkAATozk.jpg)

## 为什么用它 / 适合什么场景

- **多个平台收藏夹来回切**：Pinterest 找氛围、Notion 找组件参考、截图找配色……Visio-canvas 把它们拉到同一平面。
- **项目立项前做 mood board**：在一块画布上把所有相关视觉拼起来，整体审视风格走向。
- **团队共享灵感库**：设计师把画布导出 / 共享，避免「我收藏的素材别人看不到」。
- **想脱离某个生态**：从 Pinterest / Figma 导出困难，索性统一放到本地画布。

## 关键能力

| 能力 | 说明 |
|------|------|
| 无限画布 | 平移 / 缩放无边界，参考图自由摆位 |
| 多源聚合 | 支持从 Pinterest / Figma / Notion / 截图 / 书签拉素材 |
| 视觉归类 | 按主题 / 色块 / 排版自定义分区 |
| 共享 | 画布可导出或共享给团队 |
| 本地优先 | 不强制云端同步，数据留本地 |
