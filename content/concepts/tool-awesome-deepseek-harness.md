# awesome-deepseek-harness

## 它是什么

[Dominic789654/awesome-deepseek-harness](https://github.com/Dominic789654/awesome-deepseek-harness) 是给 [DeepSeek Harness（DSH）](./note-deepseek-harness-handbook.md) 生态做的 **awesome 列表**：插件、技能（skill）、MCP 服务器、桌面壳、主题、提示词包等社区产物集中收录并分类。DSH 的用户量起来之后，社区产物分散在 GitHub / Discord / 文档站各处，找起来很费劲，这个索引就是「一站式导航」。

![](https://pbs.twimg.com/media/HQdFQSvakAAeFY4.png)

## 为什么用它 / 适合什么场景

- **新手入门**：想知道 DSH 上能装什么、有哪些玩法，先扫一遍这个列表。
- **找特定能力**：比如「DSH 能不能直接生图」「有没有人做了桌面壳」——按目录查。
- **想贡献**：知道同类项目已经有哪些，避免重复造轮子。
- **生态调研**：研究者 / 投资人看 DSH 周边健康程度。

## 关键能力

| 能力 | 说明 |
|------|------|
| 分类索引 | 插件 / 技能 / MCP / 桌面壳 / 主题等分门别类 |
