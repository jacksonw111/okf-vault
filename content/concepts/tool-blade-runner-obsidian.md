# Blade Runner Obsidian 主题

## 它是什么

[DuckTapeKiller/blade-runner](https://github.com/DuckTapeKiller/blade-runner) 是一套 **Obsidian 主题**，设计思路很有「边界感」：

- **霓虹色 / 发光只出现在界面部件**——标签页、侧栏、callout、状态栏。
- **正文保持无彩色**，方便长时间阅读不被高饱和度干扰。
- **深 / 浅双模式**都满足 WCAG AA 对比度要求。

## 为什么用它 / 适合什么场景

- 喜欢霓虹 / 赛博朋克氛围，但**不想让正文被高饱和颜色灼烧眼睛**。
- 每天在 Obsidian 里读 / 写几个小时，对**正文可读性**的优先级高于装饰。
- 在意可访问性——主题色**不能影响可读性**。

## 关键能力

| 能力 | 说明 |
|------|------|
| 霓虹只染 UI 部件 | 标签页 / 侧栏 / callout / 状态栏享受配色 |
| 正文无彩色 | 主体内容保持中性色，长时间阅读不疲劳 |
| 双模式 | 深色 / 浅色都满足 WCAG AA 对比度 |
| Obsidian 原生 | 安装即用，不依赖 CSS 片段手动配置 |
