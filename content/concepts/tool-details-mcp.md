# details.so/mcp

## 它是什么

[details.so/mcp](https://details.so/mcp) 是 [details.so](https://details.so) 提供的 **MCP server**：让 AI agent 直接接入**设计细节与「审美」数据库**，让生成的 UI「**更有 taste**」。

## 卖点

> Your AI has now access to taste.

## 为什么用它 / 适合什么场景

- 用 Claude Code / Cursor / Codex 写前端，生成的 UI 总是「**没味道**」。
- 想让 agent 接入设计细节参考库。
- 想给团队成员统一审美标准（让 AI 跟人类审美对齐）。

## 关键能力

| 能力 | 说明 |
|------|------|
| MCP 协议 | 标准 MCP server |
| 审美数据库 | details.so 沉淀的设计细节 |
| AI 友好 | 直接被 agent 调用 |
| 持续更新 | 站点持续补充细节 |
