# UI 微交互细节站点合集

## 它是什么

一份「小 UI 细节 → 大视觉体感」的**站点清单**——收录 **9 个**专注做「局部动效 / 视觉细节」的开源站点 / 工具，覆盖 WebGL、光线、动效、AI 界面、过渡、液态金属、UI 注解、思考态、抛光积木等典型场景。

## 9 个站点速查

| 站点 | 主题 |
|------|------|
| [canvasui.dev](https://canvasui.dev) | 在活动 HTML 上叠 WebGL 效果 |
| [beam.jakubantalik.com](http://beam.jakubantalik.com) | 给边框添加移动光束 |
| [originkit.dev](http://originkit.dev) | 免费动效组件，可直接用到下一个项目 |
| [aicss.dev](http://aicss.dev) | AI 聊天界面专用组件 |
| [transitions.dev](http://transitions.dev) | 给 Web App 更顺滑的过渡 |
| [metal.jakubantalik.com](http://metal.jakubantalik.com) | 给按钮液态金属收尾 |
| [beautiful-ui-five.vercel.app](http://beautiful-ui-five.vercel.app) | AI 界面抛光积木 |
| [agentation.com](http://agentation.com) | 给 UI 加注释指引编码 Agent |
| [orbs.jakubantalik.com](http://orbs.jakubantalik.com) | AI 思考态动效球 |

## 为什么用它 / 适合谁

- **AI 写前端时代越来越重要**：当 99% 布局 AI 都能写完时，「细节 + 体感」成了人与人 / AI 与人之间拉开差距的关键。
- **快速找灵感**：不必每个细节都重想一遍，看一眼现成效果再让 AI 实现。
- **与 Agent 协同**：像 agentation 这种「UI 注解工具」直接把注释传给编码 Agent。
