# Computational Neuroscience（计算神经科学）

## 它是什么

**计算神经科学（Computational Neuroscience）** 是用**数学模型**和**计算机仿真**研究神经系统的学科。从单神经元的 Hodgkin-Huxley 模型，到大规模皮层微回路、再到**全脑连接组（connectome）**仿真，都属于它的研究范畴。

它是 connectome（连接组学）、类脑计算、神经形态硬件（Neuromorphic）、脑机接口等方向的**理论基础**。

## 关键子领域

| 子领域 | 研究对象 |
|--------|----------|
| 单神经元建模 | Hodgkin-Huxley / Izhikevich 模型 |
| 神经微回路 | 皮层柱 / 海马回路仿真 |
| 全脑连接组 | 果蝇 / 斑马鱼 / 鼠脑完整接线图 |
| 神经动力学 | 同步振荡 / 神经编码 |
| 学习与可塑性 | STDP / Hebbian / 三因素学习规则 |
| 类脑计算 | 神经形态芯片（SpiNNaker / Loihi） |

## 代表项目

- **BlueBrain** — 鼠脑皮层柱微回路仿真
- **SpiNNaker / SpiNNcloud** — 神经形态硬件
- **fly-wirehead** — 果蝇全脑连接组仿真（浏览器跑）
- **Allen Brain Atlas** — 鼠脑基因表达 / 神经元形态数据库
- **Human Brain Project** — 欧洲人脑计划

## 与 AI 的关系

- **结构借鉴**：CNN / Attention 机制有神经科学原型
- **学习规则借鉴**：Hebbian / STDP 影响脉冲神经网络
- **可解释性**：神经科学模型帮助理解 LLM 表征
- **反向**：AI 工具（ML 拟合 / 强化学习）反过来用于分析神经数据
