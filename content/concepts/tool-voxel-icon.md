# Voxel Icon

[Voxel Icon](https://github.com/BIAsia/voxel-icon) 是 **voxel-obj 的免费档**，以自包含 Codex Skill 的形式交付：把任意实物或 emoji 变成**干净、俏皮、低密度的等距体素图标**，需要动起来时还能额外输出 4 帧物理循环。

## 它是什么

一个装好即用的 Codex Skill（agent skill 开放格式），跑在 Codex 终端里直接调用：给一个物体描述 / emoji，输出等距体素 PNG；需要动效，再加 4 帧动画帧。

## 为什么用它 / 适合什么场景

- **图标库构建**：批量产低密度等距图标。
- **UI 装饰 / 占位**：网站 / 应用 / 文档里要"有质感"的占位图。
- **动画图标**：4 帧物理循环直接出动画 GIF / APNG。
- **免手工建模**：不必开 Blender / MagicaVoxel。

## 关键能力

| 能力 | 说明 |
|------|------|
| 等距体素生成 | 干净、俏皮、低密度风格的等距视角体素图 |
| Codex Skill 形态 | 直接装到 Codex 跑 |
| 实物 / emoji 输入 | 用自然语言或 emoji 作 prompt |
| 4 帧动画 | 需要时输出物理循环动画帧 |
| 自包含 | 单 Skill 一键装好即用 |
