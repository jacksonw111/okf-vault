# marketing-studio

一个**为 Claude Code 设计的智能体驱动营销工作室**——在产品仓库里跑 **`/marketing`** 指令，自动完成**品牌接入、应用录屏**，并**渲染整套营销素材**（Logo 动画 / 产品演示 / 发布视频 / 配音配乐 / 社媒短片 / OG 图）。

## 它是什么

- 一套**装到 Claude Code 里**的营销自动化"工作室"——把原本需要设计师 / 视频剪辑 / 文案的活**合并成一条指令**；
- 通过 `/marketing` 一条 slash command 触发，**在产品仓库内执行**（自动读代码、读 README、跑应用）；
- 自动产出**可发布的全套素材**，从静态 OG 图到带配音配乐的发布视频。

## 关键能力

| 能力 | 说明 |
|------|------|
| `/marketing` 指令 | Claude Code slash command，一行触发整套流水线 |
| 品牌接入 | 读项目里的 brand 配置，自动套到所有素材 |
| 应用录屏 | 启动应用并按剧情录屏，作为演示 / 短片素材 |
| Logo 动画 | 自动生成品牌 Logo 动效 |
| 产品演示 | 把录屏拼成产品演示视频 |
| 发布视频 | 含镜头切换 + 字幕 + 配音配乐的发布级成片 |
| 配音配乐 | 自动配 TTS 旁白与背景音乐（具体后端视实现而定） |
| 社媒短片 | 适配 X / 抖音 / 小红书等不同比例的短版 |
| OG 图 | 站点分享卡片 / Open Graph 图自动出图 |

## 为什么用它 / 适合什么场景

- **个人开发者 / 独立创业者**发版前不再为"做营销物料"头疼——一条指令跑完整套；
- 想让 **Claude Code 直接接管**"品牌一致性"这件事：素材自动套品牌色 / 字体 / Logo；
- 在多个**社交平台**同步发版，OG 图 + 短片 + 发布视频是刚需；
- 把"**录屏 → 剪辑 → 配字幕 → 配乐 → 出片**"串成**一条流水线**而不是多个工具拼；
- 给开源项目做"**发布日物料包**"——README、release notes、视频、海报一站出。

## 典型流水线

```
   /marketing
       │
       ▼

 │  品牌接入    │ →  │  应用录屏    │ →  │  素材渲染    │
 │  读 brand    │    │  跑 + 录制   │    │  模板套用    │
 └─────────────┘    └─────────────┘    └─────────────┘
                                            │
                ┌────────────┬──────────────┼──────────────┐
                ▼            ▼              ▼              ▼
           Logo 动画     产品演示       发布视频        社媒短片
              │            │              │              │
              └────────────┴──────────────┴──────────────┘
                                            │
                                            ▼
                                       OG 图 / 海报
```

## 设计哲学

1. **指令即发布**——`/marketing` 一行 = 一份发布物料包；
2. **品牌一致性自动化**——所有素材自动套用同一套品牌元素；
3. **录屏而非摆拍**——直接启动真实应用录屏，比手摆分镜更"真"；
4. **一站出多版**——横版 / 竖版 / 静态图一并出，覆盖各平台。
