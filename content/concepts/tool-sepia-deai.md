# Sepia

## 它是什么
[Nanako0129/sepia](https://github.com/Nanako0129/sepia) 是一个**跨平台的 De-AI 写作技能**——不是改词改句表面，而是从**叙事架构**层面（节拍 / 视角 / 节奏 / 主观偏差 / 信息取舍）消除 AI 生成文字里那种「**教科书味 / 无立场味 / 平均分布味**」。

普通 De-AI 工具的思路是「换词」——把「**delve into**」换成「**explore**」、把「**in conclusion**」删掉。Sepia 的思路更进一步：**改变结构**。

- 让段落有**主观节奏**（不是平均字数 / 平均句长）；
- 让叙述有**信息取舍**（不是把所有角度都说一遍）；
- 让观点有**立场**（不是安全的中立堆砌）；
- 让衔接有**跳跃 / 留白**（不是平滑过渡）。

## 为什么用它 / 适合什么场景
- AI 写的营销文案 / 博客 / 邮件太「**一股 AI 味**」，想读起来像人写的；
- 需要**有立场 / 有取舍**的内容（评论、专栏、深度文章）；
- 想把 LLM 输出**改造成可发表的内容**，而不是「明显 AI 写的」；
- 想要一个**可复用**的写作工作流，而不是每次 prompt 工程一次。

## 关键能力

| 能力 | 说明 |
|------|------|
| 叙事架构层介入 | 不是换词，是改节拍 / 视角 / 节奏 |
| 跨平台 | 作为 Skill / 模板 / 工作流都可嵌入 |
| 立场植入 | 引导模型做有取舍的表达 |
| 主观节奏 | 让句子有「**人写**」的长短不齐 |
| 信息密度 | 打破平均分布，留下作者视角 |
