# ln-dev7/logos（15000+ 应用与公司 Logo 合集）

## 它是什么
[ln-dev7/logos-apps](https://github.com/ln-dev7/logos-apps) 是一个**开源 logo 合集**——15000+ 个应用与公司的矢量 logo 按公司 / 应用名组织在仓库里，可直接复制 SVG / PNG 用到自家项目。

典型用例：

- 落地页的「**我们的客户**」 / 「**支持的工具**」区块；
- Dashboard / SaaS 集成列表（每个第三方挂一张对应 logo）；
- README 里的「**技术栈**」图标条；
- 博客 / 文档里展示「本文用到了 X、Y、Z」。

## 为什么用它 / 适合什么场景
- 不想自己挨家挨户找 logo（每家品牌指南里翻）；
- 不想用付费素材站（许多 logo 商用需要单独授权）；
- 想要**统一格式 + 可搜索目录**，方便集成到项目；
- 适合**集成展示页**、落地页、技术文档。

## 关键能力

| 能力 | 说明 |
|------|------|
| 海量覆盖 | 15000+ 应用与公司 logo |
| 矢量优先 | 多为 SVG，可任意缩放 |
| 目录化 | 按公司 / 应用名组织，便于搜索 |
| 开源 | 不依赖付费授权，可商用需自查每家品牌条款 |
| 复制即用 | 直接 fork / 引用 SVG / PNG |
