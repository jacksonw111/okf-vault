# Valutio

## 它是什么

Valutio 是一款免费开源、本地优先的个人理财浏览器 PWA，让用户在无需注册账户、不连接任何银行 API 的前提下，集中追踪净资产、投资、账户、现金流、税务、退休规划与历史记录。数据默认只存在浏览器本地（IndexedDB），支持多账户、多币种手动录入。

## 为什么用它 / 适合什么场景

- 想管理个人财务但不愿把数据交给第三方平台。
- 不愿意做银行 API 集成 / Plaid 类授权。
- 想要 PWA 形式的轻量理财工具，手机 + 桌面均可装。
- 关心隐私：所有财务数据不出本地。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多维度财务追踪 | 净资产 / 投资 / 账户 / 现金流 / 税务 / 退休 |
| 本地优先 | 数据默认存浏览器 IndexedDB |
| 无需账户 | 不注册、不连接银行 |
| PWA 形态 | 浏览器即开，支持装到桌面 / 手机 |
| 多账户 / 多币种 | 手动录入支持多账户、多币种 |
| 历史记录 | 长期追踪净资产 / 现金流变化 |
