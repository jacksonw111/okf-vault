# UIArc

## 它是什么

[UIArc](https://uiarc.dev) 是一个**偏 clean / polished 风格的 UI 组件库**——主打「干净但有细节」的视觉：组件圆角、阴影、间距都做过打磨，可直接拿来用，不必再花大量时间调样式。

## 关键能力

| 能力 | 说明 |
|------|------|
| 风格 | clean + polished，圆角 / 阴影 / 间距都「正」 |
| 组件覆盖 | 通用组件齐全（按钮 / 表单 / 卡片 / 弹窗 等） |
| 集成方式 | 组件直接引入项目使用 |
| 定位 | 「看到就用」型资源，节省样式调试时间 |

## 适合场景

- 想要「不丑」基线又想保留自己品牌色 / 排版的中小型项目
- AI 生成 UI 的「中等感」想往上推一档
- 内部工具 / Dashboard 想快速搭出干净版本
