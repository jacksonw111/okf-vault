# OpenNews MCP（6551Team/opennews-mcp）

## 它是什么

[OpenNews MCP](http://github.com/6551Team/opennews-mcp) 是 6551Team 开源的 MCP 服务器，把 85+ 个实时市场资讯数据源（新闻 / 上币 / 链上巨鲸 / Meme 情绪 / 市场异动等）统一接进 AI 客户端（Claude / Cursor / Codex 等），让 AI 直接消费实时市场信号。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多源覆盖 | 85+ 数据源：新闻 / 上币 / 链上巨鲸 / Meme 情绪 / 市场异动 |
| 影响分 | 每条资讯带 0–100 影响分，方便快速筛选 |
| 多空信号 | AI 自动生成多空倾向信号，作为分析参考 |
| 双语摘要 | 中英双语摘要，不用自己逐条看原文 |
| MCP 协议 | 标准 MCP 接口，任何支持 MCP 的 AI 客户端都能直连 |

## 它解决的问题

加密 / 链上市场信号散落在 X / CoinGecko / 巨鲸钱包 / DEX 监控 / 项目公告等多处，靠人工追踪不可能。OpenNews MCP 把这些信号聚合成统一、可被 AI 消费的数据流。

## 适合谁

- 给 Claude / Cursor 等装「实时市场数据」能力
- 做链上 / 加密策略的 AI agent 需要最新数据源
- 想要中英双语市场摘要
