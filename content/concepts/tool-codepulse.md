# CodePulse（joewolly/codepulse）

## 它是什么
[`joewolly/codepulse`](https://github.com/joewolly/codepulse) 是一个跑在 **macOS 菜单栏**里的原生编码计时器：单击开始 / 暂停计一次编码时段，自动在本地把「什么时候开始编码、什么时候停下、当天累计多少分钟」记成日志，再基于本机数据算出简单的统计（每日 / 每周分布、活跃时段等）。

## 为什么用它 / 适合什么场景
- 自由职业 / 远程工作需要按小时记账，但不想开 Toggl / Clockify 那种重型 SaaS。
- 想用 macOS 菜单栏小工具「随手按一下」就开始 / 结束计时。
- 想要本地化、不联网的隐私友好编码时段统计。

## 关键能力
| 能力 | 说明 |
|------|------|
| 菜单栏原生 | 单击即开始 / 暂停，不占桌面 |
| 本地日志 | 所有记录落在本机，不上云 |
| 自动统计 | 按日 / 周聚合活跃时段 |
| 隐私友好 | 无账号、无网络请求 |
