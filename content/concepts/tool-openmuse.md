# OpenMuse（自托管任务执行台）

## 它是什么

[OpenMuse](https://github.com/CopilotKit/openmuse) 把「开网页、敲命令、翻文件、读邮件」这类零碎活收进同一个**自托管应用**——任务丢进去后它自己往下跑，事后能在应用里翻到每一步留下的记录。

## 它解决的问题

- 这些零碎活以前要在浏览器、终端、邮件几个地方来回切换
- 想统一一处发任务、统一一处看进度
- 想自托管：数据可控、不依赖第三方云

## 关键能力

| 能力 | 说明 |
|------|------|
| 任务编排 | 把多个动作编排成一个任务 |
| 自托管 | 数据本地化 |
| 执行轨迹 | 每一步留痕，事后可回放 |
| 多动作 | 网页、命令、文件、邮件统一入口 |

## 适用场景

- 个人 / 小团队需要一个自托管的「任务执行面板」
- 想把日常零碎活统一管理起来
- 想把分散在不同工具的工作流聚合到一处
