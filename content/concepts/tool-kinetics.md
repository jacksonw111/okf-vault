# Kinetics

## 它是什么
**开源的运动效果（motion effects）动画库**，已收录 **99 个动画**。同时提供 **三种形态**：
- **CSS 版本**：直接复制 CSS 用
- **React 版本**：封装好的 React 组件
- **Prompt 版本**：把每个动画的运动描述写成给 AI 编程代理的 prompt，让代理自己生成对应代码

由 csaba_kissi 在 colorion.co 上维护。

## 为什么用它 / 适合什么场景
- 想给网站 / App 加细节动画，但不会自己写——直接复制 CSS / React 组件。
- 用 Claude Code / Cursor / Codex 等 AI 代理写代码——给它 Prompt 版本，让它知道「这个动画怎么描述」并自动生成。
- 想找高质量 motion 库——99 个动画覆盖常见微交互、过渡、按钮反馈、加载效果。
- 设计 / 前端团队希望沉淀 motion 设计语言——可作为内部标准库。

## 关键能力
| 能力 | 说明 |
