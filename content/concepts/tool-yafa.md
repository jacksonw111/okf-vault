# YAFA

## 它是什么

bmccalmon 开源的 .NET 间隔重复（SRS）闪卡应用。明确目标受众是「想学习 Clean Architecture 的新手开源贡献者」——代码组织讲究到可以作为该架构的范例阅读。

## 为什么用它 / 适合什么场景

- 想找一份体量适中、代码结构典范的 .NET Clean Architecture 范例项目。
- 同时需要 SRS 闪卡功能（记外语单词 / 知识点 / 面试题等），又希望底层架构清晰以便扩展。
- 愿意参与开源贡献，从代码 review 中学习分层、解耦、依赖倒置。

## 关键能力

| 能力 | 说明 |
|------|------|
| SRS 间隔重复 | 经典遗忘曲线算法，按记忆强度动态调度复习间隔 |
| Clean Architecture 范式 | Domain / Application / Infrastructure / Presentation 分层清晰 |
| 可读性优先 | 注释、命名、目录结构都面向「新手贡献者」友好 |
| .NET 栈 | C# / ASP.NET / EF Core 等主流 .NET 技术 |
