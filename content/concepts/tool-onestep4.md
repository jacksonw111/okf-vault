# OneStep4

## 它是什么

[`SangLuoCN/OneStep4`](https://github.com/SangLuoCN/OneStep4) 是一款跑在**已 Root 的 Android 手机**上的多窗口 / 侧边小窗工具。延续 Smartisan 锤子手机「One Step」的交互逻辑——在主屏边缘**挂多个侧边小窗**，可以快速调出、切换应用，比 Android 原生分屏更灵活。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多应用窗口 | 同时在屏幕上跑多个应用实例 |
| 侧边小窗 | 边缘抽屉式呼出，不占主屏核心区 |
| 延续 One Step | 锤子「One Step」多窗口操作逻辑复刻 |
| 需要 Root | 利用 Root 权限做浮窗 / 跨应用窗口 |

## 解决什么痛点

- Android 原生分屏只能二分屏，且很多应用不支持
- 想在手机上同时挂着聊天 + 浏览器 + 笔记（边看边写）
- 想复刻 Smartisan「One Step」在普通 Android 上的体验

## 适合什么场景

- 已有 Root 的 Android 用户，重度多任务
- 怀念 Smartisan One Step 的老用户
- 想在手机上做**类桌面级多任务**

## 与同类工具的差异

| 工具 | 形态 | 差异 |
|------|------|------|
| Android 原生分屏 | 系统 | 只支持二分屏 |
| Samsung Good Lock | 厂商模块 | 部分设备能用，OneStep4 跨厂商 |
| OneStep4 | Root App | 复刻 One Step 跨应用浮窗 |
