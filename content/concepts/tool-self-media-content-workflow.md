# Self-Media Content Workflow

## 它是什么

自媒体内容生产**从需求到发布**的全流程管理套件：

- **9 个 Skill** —— 从总控路由到交付归档各司其职
- **不绑特定工具 / 模型** —— Claude Code / Codex / Cursor 都可接
- **同一素材为每个平台单独写**标题和结构
- **5 个强制确认点** —— 防未授权发布
- **关键数字要求来源** —— 防编数据
- **默认只出草稿不发** —— 人最终审核
- **内置 8 套配图风格**

![示意图](https://pbs.twimg.com/media/HOSRXZvaYAAclGQ.jpg)

## 解决的痛点

| 痛点 | 9 Skill 解法 |
|------|-------------|
| 漏步骤 | 全流程覆盖 |
| 编数据 | 数字必须带来源 |
| 跨平台重复劳动 | 一源多版本 |
| 未授权发布 | 5 个强制确认点 |
| 工具绑定 | 跨 Claude Code / Codex / Cursor |

## 关键能力

| 能力 | 说明 |
|------|------|
| 9 Skill 完整链路 | 路由 → 撰写 → 配图 → 审核 → 归档 |
| 跨平台输出 | 一源多版本 |
| 5 强制确认点 | 防未授权 |
| 数字带源 | 防编数据 |
| 草稿默认 | 人最终把关 |
| 8 套配图风格 | 视觉自动化 |
