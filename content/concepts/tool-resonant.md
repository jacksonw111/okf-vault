# Resonant（calesthio/Resonant）

## 它是什么
[`calesthio/Resonant`](https://github.com/calesthio/Resonant) 是一款在 **Windows 本地离线**运行的免费 AI 音乐工作室：用户不必联网、不必订阅，即可写词、生成歌曲、拆轨换声、编曲、混音并导出 WAV。它把 Suno / Udio 类云端 AI 音乐服务的能力「搬回」本地。

## 为什么用它 / 适合什么场景
- 想要 AI 音乐能力，但不愿把半成品上传到云端。
- 离线 / 内网环境也能产出音乐素材。
- 写歌 demo、播客片头、短视频 BGM 等轻量场景。

## 关键能力
| 能力 | 说明 |
|------|------|
| 本地离线 | 完全无网络、无云依赖 |
| 全流程 | 写词 → 生成 → 拆轨 → 换声 → 编曲 → 混音 → 导出 |
| WAV 导出 | 输出无损，适合后续二次编辑 |
| 免费 | 不订阅、无功能解锁付费墙 |
