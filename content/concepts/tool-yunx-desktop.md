# YunX Desktop（六大网盘聚合下载器）

## 它是什么

**YunX Desktop** 是 tidain 出品的 Windows 桌面程序——把 6 个常见网盘（百度网盘 / 阿里云盘 / 夸克网盘 / 迅雷 / 蓝奏云 / 微云 等）的**分享链接粘进同一个窗口**，自动匹配提取码并分片并发下载，省去逐家装客户端、跨平台找链接的麻烦。

## 为什么用它 / 适合什么场景

- **统一入口**：一个窗口管理多个网盘
- **自动提码**：分享链接里带提取码时自动识别
- **分片并发**：多线程分片下载，提速明显
- **省客户端**：不必为每个网盘单独装 App

## 关键能力

| 能力 | 说明 |
|------|------|
| 多网盘支持 | 百度 / 阿里 / 夸克 / 迅雷 / 蓝奏 / 微云等 |
| 自动提取码 | 链接里含提取码自动匹配 |
| 分片并发 | 多线程下载 |
| Windows 桌面 | 一键安装的可执行程序 |
| 任务管理 | 批量粘链接，排队下载 |
