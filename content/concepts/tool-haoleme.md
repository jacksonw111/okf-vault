# Haoleme（手机上监控电脑 / 服务器命令）

## 它是什么

[`HaolemeApp/Haoleme`](https://github.com/HaolemeApp/Haoleme) 是一款**命令运行监控工具**——用 `hao` 在电脑或服务器上启动命令，手机端 App 即可看到：

- 运行状态
- 终端输出
- 设备在线状态
- 运行结束通知

## 关键能力

| 能力 | 说明 |
|------|------|
| 命令启动 | `hao <command>` 包装任意命令 |
| 手机查看 | 配套 App 实时查看输出 |
| 运行状态 | 显示运行中 / 完成 / 失败 |
| 设备在线 | 检测电脑 / 服务器是否在线 |
| 结束通知 | 命令完成后推送通知 |

## 为什么用它

- **「盯着终端」变成「看手机」**：出门也能盯长任务
- **避免 SSH 卡死**：长任务不必一直连 SSH
- **多机统一面板**：手机端一个 App 看多台机器
- **失败即时通知**：失败了立刻知道

## 适用场景

- 模型训练 / 长任务
- 远程脚本 / 批处理
- 爬虫 / 数据采集
- 长 SSH 任务
- 任何「不想一直盯着终端」的命令
