# Soap (GhifariArsa)

## 它是什么
Soap（`GhifariArsa/soap`）是一个**纯终端用的文献管理工具**——管理论文、书籍和 PDF，自动补元数据，键盘操作完成浏览、审查和归档。

视频：
- <https://video.twimg.com/tweet_video/HOocsX2bgAAzykk.mp4>

## 为什么用它 / 适合什么场景
- **终端流研究**：写论文 / 综述时不开 GUI、TUI 流程不断。
- **自动补元数据**：DOI / 标题 / 作者 / 期刊等自动拉取。
- **键盘全操作**：浏览 → 审查 → 归档不依赖鼠标。

## 关键能力

| 能力 | 说明 |
|------|------|
| 论文 / 书籍 / PDF | 统一文献管理 |
| 自动补元数据 | DOI 等常见字段自动拉取 |
| 键盘浏览 | TUI 列表筛选 / 翻页 |
| 审查 | 标待读 / 已读 / 引用 |
| 归档 | 文件与元数据一并入库 |
