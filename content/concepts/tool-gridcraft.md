# GridCraft（展示 Logo 内部结构的工具）

## 它是什么

[GridCraft](https://designminis.com/tools/gridcraft) 是 [designminis](https://designminis.com/) 出品的 **Logo 内部结构展示工具**——把 Logo 透明叠加到不同网格 / 比例尺 / 尺寸上，方便**讲解 Logo 的形状构成、留白和比例**。

## 为什么用它 / 适合什么场景

- 设计交付时，把 Logo 拆开说明「为什么是这个间距 / 这个比例」，光看成品图讲不清楚。
- 教学 / 公开讲解「**Logo 是怎么搭出来的**」时，需要把内部网格露出来。
- 评审 Logo 时，把 Logo 套进统一网格能看出不同方案的**结构一致性**。
- 想快速分享一个 Logo 的**几何构造**截图给同事或客户。

## 关键能力

| 能力 | 说明 |
|------|------|
| Logo 叠加 | 透明叠加到任意网格 / 比例尺 |
| 网格切换 | 多套参考网格 |
| 尺寸对比 | 同时看多个尺寸下的辨识度 |
| 输出 | 截图导出，便于设计交付与讲解 |
