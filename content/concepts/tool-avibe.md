# avibe（合盖笔记本后 AI 编码代理继续运行 + 手机访问）

## 它是什么

[avibe](https://github.com/avibe-bot/avibe) 是 avibe-bot 出品的工具：让 **AI 编码代理即使在笔记本电脑合盖后也能继续运行**，并且**通过手机就能访问**。

解决的核心痛点：编码 Agent 跑长任务时，**合上笔记本盖 → 系统休眠 → Agent 进程被中断**。avibe 让 Agent 在后台继续跑，并提供**手机端访问界面**，随时看进度、给指令。

## 为什么用它 / 适合什么场景

- 想**跑长任务**（数小时甚至跨天）而不被合盖打断。
- 想**通勤 / 出差时**用手机监控代理状态、给指令。
- 想把编码 Agent 当成**持续运行的同事**，而不是「开盖才能用」的工具。
- 团队 / 个人项目希望 AI 代理 24/7 在线。
