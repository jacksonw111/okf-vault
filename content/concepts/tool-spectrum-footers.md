# Spectrum UI Footers（开源 Footer 组件库）

## 它是什么

[ui.spectrumhq.in/blocks/footers](https://ui.spectrumhq.in/blocks/footers) 是 arihantCodes 出品的**开源 Footer 组件库**：基于 **shadcn + motion** 构建，是「It's finally here — the footers.」系列的成品 Footers 集合。

## 关键能力

| 能力 | 说明 |
|------|------|
| shadcn 风格 | 跟 shadcn 体系完全一致 |
| motion 动效 | 用 motion 加交互动画 |
| 开源 | 完全开源、代码可用 |
| 一键复制 | 复制即可用 |

## 适合谁

- 前端做 SaaS / Dashboard，footer 永远是麻烦事
- 想要动效 + 设计感的 footer 不想自己调
- 已经在用 shadcn-ui 体系
