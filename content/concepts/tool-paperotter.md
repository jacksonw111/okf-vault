# PaperOtter（本机离线 PDF / 图片 / 文档工具集）

## 它是什么

[shyhunter/PaperOtter](https://github.com/shyhunter/PaperOtter) 是为 **PDF / 图片 / 文档** 提供 **19 个本机离线工具**的桌面应用：压缩、合并、拆分、水印、签名、涂黑、格式转换全部在本地完成，**文件不上传**。

## 19 个工具涵盖

| 类别 | 工具 |
|------|------|
| PDF | 压缩 / 合并 / 拆分 / 水印 / 签名 / 涂黑 / 格式转换 |
| 图片 | 压缩 / 格式转换 / 尺寸调整 |
| 文档 | 转换 / 编辑 |

## 关键能力

| 能力 | 说明 |
|------|------|
| 完全本机 | 所有处理在本地，不上传 |
| 多格式 | PDF / 图片 / 文档 |
| 19 个工具 | 一个应用搞定常见操作 |
| 隐私优先 | 不离开电脑的数据流 |

## 适合谁

- 处理敏感文件，不能上传第三方
- 想用一个工具替代 iLovePDF / Smallpdf 等 SaaS
- 需要离线场景下处理 PDF
