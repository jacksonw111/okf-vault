# libraries.dev（5 个 UI 特效库合集）

## 它是什么

一个把此前分散发布的 UI 特效库收拢到一处的站点，共 **5 个库、20+ 变体**，全部免费、可直接取用。

| 库 | 效果类型 |
|----|----------|
| Border beam | 边框流光 |
| Orbs | 光球 / 渐变球体 |
| Metal | 金属质感 |
| Gooey | 黏液 / 融合效果 |
| Image | 图像类特效 |

视频：<https://video.twimg.com/amplify_video/2095546456795217920/vid/avc1/1700x1280/mM-9Z2DjAyy9K8_w.mp4?tag=29>

## 为什么用它 / 适合什么场景

- 落地页 / 作品集需要一两处「看起来花了心思」的视觉点缀，但不想自己写 shader 或调 CSS 滤镜。
