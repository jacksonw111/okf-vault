# dot-motion-builder

## 它是什么

[LerSent001/dot-motion-builder](https://github.com/LerSent001/dot-motion-builder) 是一个**点动效（dot motion）的可视化 / 交互式编辑工具**——可以在这里体验。

## 为什么用它 / 适合什么场景

- 设计 / 前端需要做**点运动**类视觉表达。
- 想要一个**轻量的可视化编辑界面**而不是从零写代码。

|------|------|
