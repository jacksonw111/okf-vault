# openheard

## 它是什么

[openheard](https://github.com/Heilonng23/openheard) 是一个**自托管的轻量级用户反馈板**，目标是 **Canny 等收费产品的开源替代**：

> 把 Canny 这类收费用户反馈板换成自托管的开源版本，一个 Cloudflare Worker 加一个 D1 数据库就能跑起来。

## 为什么用它 / 适合什么场景

- 想用反馈板但**不想订阅 Canny 等付费服务**。
- 想**完全掌控用户数据**（自托管）。
- 想用 Cloudflare 生态——**Worker + D1** 几乎零运维。

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | 自托管 Web 应用 |
| 部署 | Cloudflare Worker + D1 数据库 |
| 目标 | 替代 Canny 类付费反馈板 |
| 维护 | 几乎零基础设施维护 |

## 与 Canny 等产品的差异

| 维度 | openheard | Canny |
|------|-----------|-------|
| 费用 | 开源自托管（仅 Cloudflare 费用） | 订阅制 |
| 数据 | 自有 | 第三方 |
| 部署 | Worker + D1 | SaaS |
