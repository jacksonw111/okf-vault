# mpvRx

## 它是什么

[Riteshp2001/mpvRx](https://github.com/Riteshp2001/mpvRx) 是 **Android 端基于 libmpv 的开源播放器**。在 [mpv-android](https://github.com/mpv-android/mpv-android) 基础上叠加了大量「用起来顺手」的细节：

- **无广告 / 无追踪**
- 多种主题
- 完整手势支持
- **HDR** 渲染
- **省电优化**

## 为什么用它 / 适合什么场景

- 想在 Android 上拿到 mpv 桌面端的解码能力（**几乎通吃所有格式**）。
- 不想用任何带广告 / 追踪的播放器。
- 想自己调外观 / 手势、HDR / 省电策略。

## 关键能力

| 能力 | 说明 |
|------|------|
| 解码后端 | **libmpv**（桌面 mpv 的核心引擎） |
| 隐私 | **零广告 / 零追踪** |
| 主题 | 内置多种主题切换 |
| 手势 | 完整触摸手势（亮度 / 音量 / 进度 / 双击等） |
| HDR | 支持 HDR 内容渲染 |
| 省电 | 对移动设备做了续航优化 |
| 开源 | GitHub 仓库可自行 build / 修改 |
