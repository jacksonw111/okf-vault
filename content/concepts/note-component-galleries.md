# Component Gallery 资源合集

## 它是什么
按**通用 UI 组件**维度组织的灵感和示例库站点合集：把按钮、卡片、表单、导航……按组件类型集中展示；并附上若干与组件搭配使用的辅助站点（App 截图、agent 工作台、终端）。

## 主要站点
| 站点 | 关注点 |
|------|------|
| <https://component.gallery> | 60 个组件 × 2670 个示例，覆盖主流 UI 元素 |
| <https://microkit.co> | 面向开发者的微交互 UI 组件库 |
| <https://appshot.gallery> | App 截图画廊（iOS / Android / macOS） |
| <https://superset.sh> | Claude / Codex / 任何编码 agent 的统一工作台 |
| <https://sw.kovidgoyal.net/kitty/> | GPU 加速、功能丰富的终端模拟器（kitty） |

## 适合什么场景
- 设计/前端在选型时按组件粒度找参考，而不是按整站看。
- 想找"微交互"参考而非完整页面。
- App 截图集合参考，便于学习各平台原生 UI 范式。
