# Hammer

## 它是什么

**Kotlin 写的本地优先跨平台故事编辑器**——核心设计：

- **本地优先**：数据纯文件、透明可读
- **跨平台**：一份代码多处跑
- **同步可选**：自托管同步 OR 走官方服务
- **离线可用**：断网照常编辑

![截图示例](https://pbs.twimg.com/media/HOWbxB8b0AA9v--.jpg)

## 与「在线 SaaS 编辑器」的差异

| SaaS 编辑器 | Hammer |
|-------------|--------|
| 数据在云 | 数据在本机 |
| 锁定格式 | 纯文件透明可读 |
| 需联网 | 离线可用 |
| 平台特定 | 跨平台 |
| 厂商风险 | 可自托管同步 |

## 关键能力

| 能力 | 说明 |
|------|------|
| 本地优先 | 纯文件存储 |
| 跨平台 | Kotlin Multiplatform |
| 透明数据 | 不锁格式，可手工编辑 |
| 同步可选 | 自托管 OR 官方 |
| 离线可用 | 网络不是前提 |
| 开源 | 仓库可审 |
