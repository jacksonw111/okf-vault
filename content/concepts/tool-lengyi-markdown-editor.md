# lengyi-markdown-editor

## 它是什么
`woyin2024/lengyi-markdown-editor` —— **纯前端 Markdown 编辑器**：所有功能（编辑器、预览、导入、导出）封装在一个 HTML 文件里，**双击即可使用**，不依赖任何后端或外部服务。

## 为什么用它 / 适合什么场景
- 临时想写一段 Markdown 又不想开 IDE / VS Code？
- 想分享一个无需安装的 Markdown 工具给同事 / 学生？
- 适合放在 U 盘 / 静态托管上随时取用。

## 关键能力
| 能力 | 说明 |
|------|------|
| 单文件 | 一个 .html 包含全部功能 |
| 实时预览 | 左写右看，所见即所得 |
| 拖拽导入 | 直接把 .md 拖进窗口 |
| 自动保存 | 防止意外丢失 |
| 多格式导出 | Markdown / HTML / Word / PDF / 长图 |
