# Wallpaper Machine

## 它是什么

[Wallpaper Machine](https://github.com/WallpaperMachine/WallpaperMachine) 是为 **macOS** 而生的工具——让 macOS 能直接播放 **Wallpaper Engine** 的场景、视频和网页壁纸，并可在应用里浏览和下载 Steam 创意工坊内容。

## 为什么用它 / 适合什么场景

- **Wallpaper Engine 没有 macOS 客户端**：Steam 上只有 Windows 版本，Mac 用户一直「馋」。
- **应用内浏览创意工坊**：不必切换 Steam / 网页。
- **场景 / 视频 / 网页三种壁纸**：覆盖 Wallpaper Engine 主要形态。

## 关键能力

| 能力 | 说明 |
|------|------|
| 平台 | macOS |
| 兼容内容 | Wallpaper Engine 场景 / 视频 / 网页壁纸 |
| 创意工坊 | 应用内浏览 / 下载 |
| Steam 依赖 | 不必启动 Steam |
