# pixel2motion（开源 Logo 动效生成工具）

## 它是什么
`nolanzg/pixel2motion` 是一个**免费开源 Logo 动效生成工具**：把静态 Logo / 图标 / 线条图转成能跑在网页 / 视频片头 / App 启动画面的品牌级动效。

## 为什么用它 / 适合什么场景

**适合做副业**（贴士来自原始介绍页面，本条目仅描述工具能力不做归属）：
- 💰 电商平台（淘宝/闲鱼）接 Logo 动效单。
- 💰 帮小公司做官网品牌动画。
- 💰 帮自媒体做视频片头 Logo。
- 💰 帮 App 开发者做启动画面动效。
- 💰 帮电商做产品品牌动态图。

**也适合自用**：
- → 独立开发者给产品做品牌动效。
- → 内容创作者做账号视觉升级。
- → 前端开发放官网/落地页。

> ⚠️ **更适合简洁 Logo / 图标 / 线条图。复杂照片效果一般。**

## 关键能力
| 能力 | 说明 |
|------|------|
| 一键动效 | 静态图 → 品牌级动画 |
