# Toolknit Desktop

Windows 本地桌面工具箱，集中处理文档、图片、音视频和文本任务且不上传文件。

## 主要能力

- 作为可复用的软件或工作流组件，按项目文档进行部署和评估。
- 适合在对应场景中替代重复的手工流程。
