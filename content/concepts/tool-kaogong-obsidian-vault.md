# kaogongzhentizhengliu（行测真题 Obsidian 知识库）

## 它是什么

[ERRRC/kaogongzhentizhengliu](https://github.com/ERRRC/kaogongzhentizhengliu) 把 **2016–2026 年国考、省考、联考行测真题** 按**考点**重新组织成可在 **Obsidian** 里直接浏览的双向链接知识库，目前覆盖**资料分析**与**判断推理**两个模块。

## 为什么用它 / 适合什么场景

- 备考行测又偏好 Obsidian 做笔记的考生，能直接获得一份已结构化的真题知识库。
- 想研究「按考点聚类」的真题数据可视化（哪些考点高频、哪类题型最常翻车）。
- 想把自己的错题本接入同一份知识图谱，复用双向链接。

## 关键能力

| 能力 | 说明 |
|------|------|
| 考点重组 | 不按年份、按考点聚类真题 |
| 双向链接 | Obsidian 原生体验，题目 ↔ 考点可来回跳转 |
| 时间跨度 | 2016–2026 年国考 / 省考 / 联考 |
| 模块覆盖 | 资料分析 + 判断推理 |
| 可二次编辑 | 仓库内容即 Markdown，可在 Obsidian 里继续补 |
