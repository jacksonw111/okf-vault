# 100 Days 100 IoT Projects

## 它是什么
kritishmohapatra 开源的 **IoT 学习项目集**：100 天 100 个项目，覆盖 ESP32 / ESP8266 / 树莓派 Pico 全系列，每个项目都附**代码、电路图、详细说明**。从最基础的传感器数据读取，到搭一个能看的 Web 仪表盘，嵌入式开发常见方向基本都走了一遍。

## 为什么用它 / 适合什么场景
- 想系统入门 IoT/嵌入式但不想满网找散落示例。
- 会 Python 就能上手（项目基于 MicroPython，绕过 C 阶段）。
- 没买硬件也想先跑通——支持 Wokwi 浏览器仿真。

## 关键能力
| 能力 | 说明 |
|------|------|
| 100 个项目 | 100 天渐进，结构化覆盖 IoT 主流方向 |
| 多硬件 | ESP32 / ESP8266 / 树莓派 Pico |
| MicroPython | 会 Python 即可，避开 C 复杂度 |
| 主流通用传感器 | DHT11、PIR、超声波、气体模块等 |
| 核心概念 | ADC、PWM、Wi-Fi、WebSocket、蓝牙均带 |
| 场景实用 | Web 服务器、Blynk IoT、Telegram 通知等现成方案 |
| Wokwi 仿真 | 无硬件也能在浏览器里跑 |
