# RTEcn

## 它是什么

[RTEcn（rtecn.space）](https://www.rtecn.space/) 把 **shadcn/ui 的「源码即组件」** 模式复刻到**富文本编辑器（Rich Text Editor）** 领域——把 RTE 拆成组件 / 工具栏 / 插件，按 shadcn 的「复制即可用 / 可改可持」流程装到 React 项目。

## 为什么用它 / 适合什么场景

- **现成 RTE 都不顺手**：TipTap / Lexical / Slate 都不错但都有学习成本和样式定制的坑。
- **想要 shadcn 的「源码即组件」体验**：装到项目里就是自己的文件，不锁版本、不追 changelog。
- **典型场景**：博客 / 文档站 / 评论 / 任务描述 / 富文本表单。

## 关键能力

| 能力 | 说明 |
|------|------|
| 交付方式 | 源码复制（shadcn 风格） |
| 适用栈 | React |
| 覆盖范围 | RTE 组件 + 工具栏 + 插件 |
| 自由度 | 与 shadcn 一样，组件不满意直接改 |
