# Television（Agent 可视化屏幕）

## 它是什么

**Television** 是 telepath-computer 开源的 Agent 协作工具——把「个人 Agent 与用户的交互停留在文字聊天」的局限打破，给 Agent **一块可视化屏幕**，让它把文档、图表、网页等 artifact 放上去持续修改和保存。

## 为什么用它 / 适合什么场景

- **超越文字聊天**：Agent 不再只能输出文字，可以直接渲染图表 / 网页 / 文档
- **持续修改**：Agent 可以持续在同一块「屏幕」上迭代 artifact
- **可保存**：artifact 可存盘 / 分享 / 二次编辑
- **本地优先**：可视化屏幕与 Agent 都在本地

## 关键能力

| 能力 | 说明 |
|------|------|
| 可视化屏幕 | 给 Agent 一块可画布 / 画板的输出空间 |
| 多 artifact | 文档 / 图表 / 网页 / SVG 都能放上去 |
| 持续修改 | Agent 可在 artifact 上反复迭代 |
| 本地保存 | artifact 存到本地文件 |
| 自带渲染器 | 内置 Markdown / HTML / SVG / Chart 渲染 |
