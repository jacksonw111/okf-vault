# zia

## 它是什么

[zia](https://github.com/z1n-k/zia) 是 **z1n-k** 出品的 **Zen Browser Sine 模组**——把 Zen 的工具栏 / 侧栏 / 地址栏 / 分屏 / 画中画 / PDF 阅读器整套界面改成 **Dia 风格**。

## 改造范围

- 工具栏
- 侧栏
- 地址栏
- 分屏布局
- 画中画模式
- PDF 阅读器

## 适合场景

- 在用 Zen 又想换 Dia 视觉风格的用户
- 想做浏览器外观主题改动的开发者
- 浏览器主题作者可参考的 Sine 模组开发范例
