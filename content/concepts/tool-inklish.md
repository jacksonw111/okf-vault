# Inklish

## 它是什么

英语练习工具，但**不是抽认卡、也不是通用聊天窗口**——它模拟你**真实会写的场景**：

- 邮件
- Slack
- GitHub Issues
- WhatsApp
- Telegram
- Discord
- …（共 10 种真实写作格式）

**流程**：选好场景 → AI 模拟对方角色和你对话 → 你每发一条消息都拿到语法、语气、改写建议 → 边聊边学。

![截图示例](https://pbs.twimg.com/media/HOSQEkRa8AAI8re.jpg)

## 它和「背单词 App」有什么不同

| 传统方式 | Inklish |
|----------|---------|
| 抽认卡 | 在真实场景里用 |
| 通用 chatbot | 模拟对方角色 |
| 写完没人批 | 每条消息都反馈 |
| 学完不会用 | 学完就能用 |

## 适用人群

- 工作中必须用英语写邮件 / Slack / PR 但担心语气不对的工程师
- 程序员想练 GitHub Issue / PR 描述
- 任何想在「真实场景」而不是「教科书场景」学英语的人

## 关键能力

| 能力 | 说明 |
|------|------|
| 10 种真实写作场景 | 不止聊天，还有邮件 / Issue / 群聊 |
| AI 模拟对方角色 | 对话有上下文、有人设 |
| 每条消息反馈 | 语法 / 语气 / 改写建议 |
| 边用边学 | 不必专门抽时间 |
| 开源 | GitHub 仓库可自部署 |
