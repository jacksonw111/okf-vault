# Dental Scope

## 它是什么

[Dental Scope](https://github.com/Yoosseph/dental-scope) 是 **Yoosseph** 出品的**牙齿 / 颌骨解剖 3D 教学工具**——把解剖结构做成**可在浏览器里交互查看的 3D 模型**，方便牙科教学、医学生参考与科普可视化。

## 为什么用它 / 适合什么场景

- **教科书图平铺难记**：3D 可旋转 / 拆解 / 标注，理解快得多。
- **Web 即可访问**：不必装客户端，浏览器打开即用。
- **典型场景**：牙科学院教学、患者教育、医学生自习、科普内容。

|------|------|
