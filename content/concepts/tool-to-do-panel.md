# TO-DO Panel（macOS 顶部本地工作台）

## 它是什么

[TO-DO Panel](https://github.com/xiaopu-ai/TO-DO-Panel) 是一个常驻 macOS 屏幕顶部的**本地工作台**，默认折叠成与 MacBook 刘海（Notch）同样大小、藏在状态栏后面；点击后从顶部平滑展开出一个聚合面板。首页汇集 7 个组件：

| 组件 | 用途 |
|------|------|
| 当前窗口 | 当前活跃窗口的快速切换 / 关闭 |
| 镜子 | 屏幕镜像 / 镜面显示 |
| 快速录音 | 一键开启本地音频录制 |
| 随笔记 | 弹出的快速 Markdown 笔记输入 |
| 常用指令 | 自定义的快捷 shell 命令面板 |
| 汽水音乐 | 内嵌的轻量音乐播放 |
| 番茄钟 | 25 分钟专注计时 |

## 为什么用它 / 适合什么场景

- 想要一个不像 Notion / Obsidian 那么重、但能在刘海里随手抓出来的本地小工具箱；
- 不想为每件事都打开单独 App（录音 / 笔记 / 计时器 / 音乐）；
- 偏 macOS 原生审美与刘海美学；
- 所有数据本地、不上云。

## 关键能力

| 能力 | 说明 |
|------|------|
| 常驻刘海 | 默认折叠成物理刘海大小 |
| 七组件首页 | 窗口 / 镜子 / 录音 / 笔记 / 指令 / 音乐 / 番茄钟 |
| 本地优先 | 数据全在本机 |
| macOS 风格 | 与系统视觉一致 |
