# RoamRadar

部署在 Cloudflare Workers 上的个人旅行 PWA，可自动导入行程并集中提供目的地实用信息。

## 适用场景

- 需要可从 Google Calendar 与 Gmail 导入，并解析预订邮件的场景。

## 关键能力

| 能力 | 说明 |
|------|------|
| 行程导入 | 可从 Google Calendar 与 Gmail 导入，并解析预订邮件。 |
| 目的地信息 | 整合天气、汇率、插头规格与急救电话。 |
| 轻量自托管 | 使用 Workers 与 KV，并支持每周备份。 |
