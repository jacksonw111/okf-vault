# xiaoyun-translator（Xiaoyun-0922/xiaoyun-translator）

## 它是什么

`Xiaoyun-0922/xiaoyun-translator` 是一款 Windows 桌面工具，把**划词翻译、公式 OCR、本地 AI 文献阅读**整合在一起：看论文时随手翻译，不用反复切窗口。

## 为什么用它 / 适合什么场景

- 读英文 / 跨语言论文时，希望**选中即译**而不是切到浏览器；
- 论文里大量**公式**，希望能 OCR 出来而不是手敲 LaTeX；
- 希望**本地 AI** 完成翻译/阅读，数据不上传。

## 关键能力

| 能力 | 说明 |
|------|------|
| 划词翻译 | 选中即译，沉浸阅读 |
| 公式 OCR | 论文公式直接识别成 LaTeX |
| 本地 AI 阅读 | 文献智能辅助 |
| 整合桌面工具 | 一个 App 替代多个切换 |
