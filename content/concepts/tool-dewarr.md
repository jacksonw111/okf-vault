# Dewarr

## 它是什么

[Dewarr](https://github.com/logabell/dewarr) 是一个**自托管的图书 / 有声书管理工作流 Web 应用**：

> 清单同步、搜书、挑版本、入库这四件事本来要在 Goodreads、Hardcover、下载站和 Audiobookshelf 之间来回切——Dewarr 把它们搬进一个自托管的 Web 应用，点完就能走完。

## 为什么用它 / 适合什么场景

- 同时使用 Goodreads 标记 + Hardcover 评分 + Audiobookshelf 收听，跨平台手动同步很烦。
- 想自托管一套统一入口，集中管理清单与下载。
- 想把「想读 → 找到资源 → 加入 Audiobookshelf」串成一条龙。

## 关键能力

| 能力 | 说明 |
|------|------|
| 清单同步 | 跨 Goodreads / Hardcover 等平台同步阅读清单 |
| 搜书 | 站内统一搜索（聚合多源） |
| 挑版本 | 比对多个来源的版本与格式 |
| 入库 | 直接对接 Audiobookshelf 等本地库 |
| 部署 | 自托管 Web 应用 |
