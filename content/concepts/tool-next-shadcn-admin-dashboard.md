# next-shadcn-admin-dashboard（Next.js 16 + shadcn 仪表盘模板）

## 它是什么
`arhamkhnz/next-shadcn-admin-dashboard` 是一个**面向 admin 仪表盘的 Next.js 16 + shadcn UI 起点模板**，省掉从零搭一套后台管理的样板时间：常用页面（登录、表格、表单、列表、详情）、shadcn 组件、Next.js App Router 结构都内置。

## 为什么用它 / 适合什么场景
- 想**快速搭一套后台 / 内部工具**，不想从零写 ListView / Form / 详情页 / 路由壳。
- 已用 / 想用 Next.js + shadcn 体系，希望在统一生态里起步。
- 适合：内部门户、数据仪表盘、客户管理系统、订单后台、CRM。

## 关键能力
| 能力 | 说明 |
|------|------|
| Next.js 16 起步 | React 19 / RSC / App Router 默认配置 |
| shadcn UI | 组件完整接入，直接 `npx shadcn add` 加新组件 |
| Dashboard 骨架 | 侧边栏 / 顶栏 / 路由 / 空状态齐全 |
| 数据展示 | 内置 TanStack / Recharts 等数据展示工具（按模板版本而定） |
