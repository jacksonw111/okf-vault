# openmouse（snekxs/openmouse）

## 它是什么

**openmouse** 是一款**统一游戏鼠标配置工具**：把罗技、雷蛇、卓威等各品牌的设置集中到**同一个网页**，插上鼠标就能：

- 看设备信息
- 调 DPI
- 调回报率（polling rate）
- 省掉每个牌子各装一个驱动软件

## 为什么用它 / 适合什么场景

- 多个鼠标切换的玩家（不同游戏用不同 DPI）。
- 不想装一堆**闭源、臃肿、带遥测**的品牌驱动。
- 跨平台使用同一份配置体验。

## 关键能力

| 能力 | 说明 |
|------|------|
| 跨品牌统一 | 一份网页搞定多个品牌 |
| 设备信息 | 插上即显示型号 / 当前 DPI / 回报率 |
| DPI 调节 | 可视化调档 |
| 回报率调节 | 125 / 500 / 1000 Hz 等 |
| 免驱动 | 不依赖各品牌原生驱动 |
| 网页交付 | 浏览器即用，无需安装 |
