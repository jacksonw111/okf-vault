# 微信 AI 记忆库 wechat-ai-memory

## 它是什么

项目讨论、口头承诺、事件进展常常散在微信私聊和群聊里，事后翻不到也喂不给模型。这个工具是**本地优先的 Windows 桌面应用**，直接读取 Windows 微信 4.x 的账户数据，把这些散落信息筛出来、归档，并导出成大模型可消费的**可追溯记忆档案**。

![](https://pbs.twimg.com/media/HRRWYV5a0AE2k1h.png)

## 为什么用它 / 适合什么场景

- 项目沟通在微信里发生，复盘时需要按人 / 按时间把上下文捞回来。
- 想给自己的 AI 助手补上「微信里发生过什么」这块记忆，同时不希望聊天记录离开本机。

## 关键能力

| 能力 | 说明 |
|------|------|
| 数据来源 | 直接读取本机 Windows 微信 4.x 账户数据 |
| 筛选维度 | 按联系人或群聊、日期范围、关键词 |
| 产物 | 可归档、可导出给大模型使用的记忆档案 |
| 可追溯 | 归档条目保留出处，便于回查原始对话 |
| 部署形态 | 本地优先，Windows 桌面工具 |
