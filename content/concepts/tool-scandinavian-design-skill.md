# Scandinavian Design Skill

## 它是什么
[scandinavian-design.vercel.app](https://scandinavian-design.vercel.app/) 把 IKEA 那种「北欧极简、性冷淡、黑白中性色基础」的设计语言沉淀成一份可加载的 Skill 文件，让 Claude / Cursor / Codex 等 AI 编码代理在生成页面时直接套用斯堪的纳维亚风格，而不是每次都要把风格描述写进 prompt。

## 为什么用它 / 适合什么场景
- 想让 AI 一次性输出整套「北欧系」UI（落地页、SaaS 控制台、营销站），不用反复修正风格细节。
- 喜欢 minimal design：黑白中性色、低饱和、大量留白、几何对比。
- 想给团队 / 设计系统沉淀一份「设计 Skill」而不是只写一段 prompt 描述。

## 关键能力
| 能力 | 说明 |
|------|------|
| 风格聚焦 | 单一锁定「北欧 / 性冷淡」一类风格，避免 AI 自由发挥 |
| 视觉对比示例 | 网站里直接列出改版前后的 GitHub 等案例，让 Skill 自带风格参考 |
| 适用多模型 | 通过 Skill 文件协议，可挂到支持 Skills 的 AI 编码代理 |
| 学习曲线低 | 改色 / 改版心 / 改对齐，靠常规 token 即可调节 |
