# pwnagotchi-neuromancer

## 它是什么

[pwnagotchi-neuromancer](https://github.com/wackojice/pwnagotchi-neuromancer) 是 pwnagotchi 的**主题插件**：把默认的 19 张 ASCII 表情换成 5 张《Neuromancer》风的 1-bit 像素肖像，并把全部 104 条状态文案改成 Gibson 式赛博朋克语感。

## 为什么用它 / 适合什么场景

- 玩 pwnagotchi 但审美疲劳了，想换种「赛博朋克黑客」味。
- 改装 e-ink 屏设备做桌搭 / 拍照 / 展览。
- 想学习「如何给小工具做主题包」（资源 / 文案 / 切换逻辑三件套）。

## 关键能力

| 能力 | 说明 |
|------|------|
| 5 张像素肖像 | 1-bit 风格适配 e-ink 屏 |
| 104 条文案 | 全部 Gibson 化（「the matrix has you」等） |
| 即装即用 | 作为 pwnagotchi 插件启用即可 |
| 可叠加 | 与其它 pwnagotchi 插件共存 |
