# elements-release

基于 Unlayer Elements 的更新日志邮件模板，可从一个数据文件生成邮件、网页、纯文本和编辑器 JSON。

## 适用场景

- 需要更新内容只维护一次，减少多渠道版本漂移的场景。

## 关键能力

| 能力 | 说明 |
|------|------|
| 单一数据源 | 更新内容只维护一次，减少多渠道版本漂移。 |
| 多格式输出 | 同时生成邮件 HTML、网页版、纯文本与编辑器 JSON。 |
