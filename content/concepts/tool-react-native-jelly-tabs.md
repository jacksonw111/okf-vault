# react-native-jelly-tabs

## 它是什么

[felipe-software/react-native-jelly-tabs](https://github.com/felipe-software/react-native-jelly-tabs) 是一个 React Native 动画标签栏组件：切 Tab 时图标与指示器带「果冻」回弹效果，过渡手感接近液态。实现走**原生端**而非 Reanimated / JS 驱动，避免大型应用里的帧率抖动。

## 为什么用它 / 适合什么场景

- 想要一个看起来「活」的底部 Tab，但不想自己写 Reanimated worklet。
- 同时使用 Expo Router 和 React Navigation，希望同一组件在两边都能用。
- 想做「差异化」的应用首屏交互（默认底部 Tab 太千篇一律）。
- 学习「React Native 原生组件 + Animated」的实践参考。

## 关键能力

| 能力 | 说明 |
|------|------|
| 果冻动画 | Tab 切换时图标与指示器带弹性回弹 |
| 原生实现 | 不依赖 Reanimated，跨平台性能稳定 |
| Expo Router 兼容 | Expo 项目开箱即用 |
| React Navigation 兼容 | 经典 React Navigation 项目也能直接挂 |
| 可定制颜色 | 自定义主题色匹配应用风格 |
