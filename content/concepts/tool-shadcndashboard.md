# shadcndashboard

## 它是什么
`shadcndashboard`（来源：[TheTechDiggest 转推](https://x.com/TheTechDiggest/status/2088671230685528441)）是一个**完整、可直接拿来做管理后台的开源 UI kit**，技术栈是 **shadcn/ui + Base UI + Next.js + React + Tailwind CSS v4**。目标是从零起步，**几分钟**搭出一个**生产可用的 admin dashboard**，而不是重新发明 boilerplate、路由、组件样式。

## 为什么用它 / 适合什么场景
- 公司内部管理后台 / SaaS 控制台 / 运营 dashboard 急需起步样板。
- 想在 shadcn/ui + Base UI 体系上做深，而不是临时拼凑组件。
- 给客户 demo：开箱即用，体验比纯 mockup 高出一截。
- 学习现代 Next.js + Tailwind v4 + shadcn 整合方式的范本。

## 关键能力
| 能力 | 说明 |
|------|------|
| shadcn/ui + Base UI | 直接享用社区主流组件库 + 可访问性原语 |
| Next.js + React | App Router / Server Components 全套现代 Next 范式 |
| Tailwind CSS v4 | 最新版 Tailwind，主题变量、性能优化全跟上 |
| 完整 admin 模板 | 路由 / 布局 / 表格 / 表单 / 图表 / 抽屉 / Modal 全部预置 |
| 开源 | 任意项目可改可商用 |
