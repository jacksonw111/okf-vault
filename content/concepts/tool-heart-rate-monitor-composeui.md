# HeartRateMonitor-composeui（XiaochangXu/HeartRateMonitor-composeui）

## 它是什么

`XiaochangXu/HeartRateMonitor-composeui` 是一款**基于 BLE 蓝牙**的 **Android 心率监测应用**，采用 **Material 3** 设计语言，支持**心率数据记录、图表分析与外部数据接口**。可作为**通用 BLE 心率设备**的 Android 端开源客户端。

## 为什么用它 / 适合什么场景

- 已有 BLE 心率带 / 心率手表，想找**开源 Android 客户端**做二次开发；
- 偏好 **Jetpack Compose + Material 3** 的现代 Android UI 写法；
- 需要把心率数据导出到**外部系统**（健身应用 / 科研采集）；
- 想做 BLE 心率设备的**协议解析参考实现**。

## 关键能力

| 能力 | 说明 |
|------|------|
| BLE 连接 | 标准蓝牙低功耗心率协议 |
| Material 3 UI | 现代 Android 设计语言 + Compose |
| 数据记录 | 心率样本本地持久化 |
| 图表分析 | 心率趋势可视化 |
| 外部数据接口 | 把数据导出到其他应用 / 服务 |
| 开源 App | 完整 Android Studio 工程 |
