# Reverse UI

## 它是什么

一个面向前端的**动效 UI 组件集合**——68+ 已完成的动效组件，可以直接搬进下一个 React 项目。每个组件都把"入场 / 出场 / hover / 状态切换"这类动效封装好，避免开发者从零写 GSAP / Framer Motion 时序。

## 为什么用它 / 适合什么场景

- 想给落地页 / 产品页加上"现代感"动效但不想自己调时序 / 缓动函数。
- 需要一组开箱即用的页面切换、卡片展开、菜单弹出等动效模板。
- 想用一致的动效语言贯穿整个产品界面，避免每个组件动效风格割裂。

## 关键能力

| 能力 | 说明 |
|------|------|
| 组件数量 | 68+ |
| 形态 | 直接 drop-in 的组件，不是 CSS 片段 |
| 侧重点 | 入场 / 出场 / hover / 状态切换等动效 |
| 定位 | 给 React 项目省去"动效地基"工作时间 |
