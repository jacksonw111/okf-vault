# Dapr Dev Dashboard

面向 Dapr 本地开发的仪表盘，可实时查看运行状态并交互式生成组件与弹性策略。

## 适用场景

- 需要实时查看 sidecar、workflow、actor 与 component的场景。

## 关键能力

| 能力 | 说明 |
|------|------|
| 运行态观察 | 实时查看 sidecar、workflow、actor 与 component。 |
| 配置向导 | 交互式生成 Dapr 组件和弹性策略，减少手写配置成本。 |
