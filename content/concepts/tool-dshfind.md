# dshfind

## 它是什么
`hikariming/dshfind` 是面向 **DeepSeek Harness (DSH)** 生态的**学习 + 分享社区站点**：把原理课程、插件市场、最佳实践与社区动态集中到一处，帮助开发者**理解、扩展、传播 DSH**。

## 为什么用它 / 适合什么场景
- 第一次接触 DSH，想找一份体系化教程而不是翻散乱的 release notes。
- 想看别人做了哪些插件 / 主题 / 桌面壳，决定要不要装。
- 想发布自己的 DSH 插件 / 皮肤，让社区找得到。
- 想跟进 DSH 的版本变化与最佳实践讨论。

## 关键能力
| 能力 | 说明 |
|------|------|
| 原理课程 | 系统讲 DSH 内部结构、工具协议、模型路由 |
| 插件市场 | 集中展示 DSH 插件（视觉 / 自动化 / 主题 / 桌面壳…） |
| 最佳实践 | 真实用户分享的部署、调优、避坑记录 |
| 社区动态 | 集合博客、推特、论坛关于 DSH 的最新讨论 |
