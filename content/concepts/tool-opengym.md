# openGym

## 它是什么

[openGym](https://github.com/DuarteSantos8/openGym) 是 **DuarteSantos8** 开源的**自托管健身与体重追踪应用**——把训练计划 / 体重记录从商业 App 的服务器搬回自己的机器，**免订阅 / 免账号 / 数据自持**。

## 关键能力

| 能力 | 说明 |
|------|------|
| 部署 | Docker Compose 一条命令起 |
| 存储 | 数据全部存本地 `./data` 目录 |
| 动作库 | 1324 个动作（带动画演示） |
| 入门计划 | 四种 |
| 高级训练 | 超级组 / 热身组 / 递减组 / 计时动作 / 有氧 |
| 杠铃配重 | 自动计算 |
| 训练辅助 | 自动填充上次重量 + 组间休息计时 |

## 适合场景

- 想从 MyFitnessPal / Strong / Hevy 类应用迁出
- 数据敏感不愿上云
- 家里有 NAS / 旧笔记本可长期跑 Docker
