# Storage UI（hahahumble/storageui）

## 它是什么

`hahahumble/storageui` 是一个**开源云存储文件浏览器**，支持 **S3、Cloudflare R2** 等后端，**可自部署**。**图标、列表、列、画廊**四种视图模式，支持搜索、筛选、排序，文件夹懒加载，用起来像**本地文件管理器**。

## 为什么用它 / 适合什么场景

- S3 / R2 桶里的对象浏览器太简陋，希望有更接近 macOS Finder 的体验；
- 团队**自托管一个统一网盘**（基于 R2 / S3）又不想被商业 SaaS 绑死；
- 需要在**四种视图**间快速切换（缩略图 / 列表 / 列 / 画廊）。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多后端 | S3、Cloudflare R2 等 |
| 四视图 | 图标 / 列表 / 列 / 画廊 |
| 搜索/筛选/排序 | 完整文件管理操作 |
| 懒加载 | 文件夹按需加载 |
| 自部署 | 自己的桶自己管 |
