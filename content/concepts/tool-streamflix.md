# Streamflix

## 它是什么

**Android TV + Android 手机流媒体聚合器**——把多个流媒体网站的内容集中到一个客户端里：

- 统一浏览界面（节目列表 / 搜索）
- 统一播放器（不用为每个站装一个 App）
- Android TV 遥控器适配
- 手机端同步

![截图](https://pbs.twimg.com/media/HOXZAC1aYAAt-ck.jpg)

## 关键能力

| 能力 | 说明 |
|------|------|
| 多源聚合 | 一个 App 看多个流媒体网站 |
| Android TV 支持 | 适配电视遥控器 / 大屏 |
| 手机端 | 同账号同步 |
| 统一播放器 | 内置，不依赖外部 |
| 开源 | 自部署 / 自定义数据源 |

## 适合谁

- 不想为每个流媒体站装独立 App 的用户
- Android TV 用户（电视端体验统一）
- 想自托管聚合规则的家庭 / 个人
