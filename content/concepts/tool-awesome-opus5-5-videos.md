# awesome-opus5-5-videos（Claude Opus 5.5 代码短视频合集）

## 它是什么

[awesome-opus5-5-videos](https://github.com/yihui-dev/awesome-opus5-5-videos) 是 yihui-dev 维护的 awesome 列表：**收集网友用 Claude Opus 5.5 写代码做出来的爆款短视频**，并把每条对应的**原始 prompt 一起整理出来**——方便复制复刻。

## 为什么用它 / 适合什么场景

- 想参考「**Claude Opus 5.5 写代码能做出什么短视频**」的优秀样本。
- 想直接**复用 prompt**——把 prompt 喂给 Claude / coding agent 自己出片。
- 关注模型能力边界——想知道前沿模型在「代码 → 多媒体」上的现状。
- 做 awesome-list 类内容 / 写技术周报。
