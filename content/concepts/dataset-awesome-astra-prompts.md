# awesome-astra-prompts

## 它是什么

[TripoGrowthLab/awesome-astra-prompts](https://github.com/TripoGrowthLab/awesome-astra-prompts) 是一个**awesome-list 风格的 prompt 数据集**：收录 GPT-6 Astra 模型在生成 3D 游戏 / 场景 / 资产时**可复用**的提示词与配套案例，按场景类型、视觉风格、任务类型（建模 / 材质 / 动画 / 场景）分组。

## 为什么用它 / 适合什么场景

- 想用 GPT-6 Astra 生成 3D 内容但 prompt 词穷。
- 想给团队沉淀一套「Astra 提示词库」作为工作标准。
- 想对比同一模型在不同 prompt 下的生成差异，研究 prompt 工程。

## 数据集内容

| 维度 | 说明 |
|------|------|
| 场景类型 | 室内 / 室外 / 幻想 / 科幻 / 卡通 等 |
| 视觉风格 | 写实 / 二次元 / low-poly / voxel / 等距 等 |
| 任务类型 | 静态建模 / 材质 / 绑定动画 / 完整场景 等 |
| 配套案例 | 每个 prompt 通常附带生成结果截图 / 链接 |
| 许可证 | 开源（具体见仓库） |
