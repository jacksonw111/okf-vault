# Prompt-Motion（动效画廊 + 原始 Prompt 索引）

## 它是什么

**prompt-motion.com** 是 p4nthera_ 维护的**动效画廊**——把用 Claude Opus 5.5 生成的 motion graphics 集中展示，每条动效旁边**附上生成它的 prompt 或 skill**，并标注原作者来源。截至发布时已收录 226 条。

## 为什么用它 / 适合什么场景

- **复刻参考**：看一段动效 + 看生成它的 prompt，方便学习「prompt → 成品」的对应关系
- **风格索引**：按作者 / 风格 / 主题聚类，便于找灵感
- **AI 动效入门**：Opus 5.5 的生成能力 + 配套 prompt 工程示例，对做「AI 动效 / 信息图 / 滚动幻灯」的团队是高质量数据集

## 关键能力

| 能力 | 说明 |
|------|------|
| 动效 + Prompt 配对 | 一段动效旁边附完整 prompt / skill |
| 作者溯源 | 每条都标注原作者与出处 |
| 持续增长 | 跟随 X 上 Opus 5.5 帖子持续增补 |
| 公开浏览 | 网页直接看，无需注册 |
