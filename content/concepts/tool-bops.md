# Bops

## 它是什么

[Bops](https://github.com/nickvasilescu/bops) 是 nickvasilescu 开源的「**AI 员工 bot**」：

- 给 AI agent 配**云电脑 + 邮箱 + 电话号码**
- 派活渠道：**聊天 / 短信 / 电话 / 邮件 / Slack**
- 业务操作范围：**收件箱、pipeline、发票、报表**等

定位是「一个能多渠道接收任务并完成业务操作的数字员工」。

## 为什么用它 / 适合什么场景

- **小团队 / 个人**：买不起整套 SaaS，用 bot 顶业务操作
- **多渠道响应**：客户从聊天 / 邮件 / 电话来都能接
- **重复劳动外包**：发票 / 报表 / 收件箱的枯燥活
- **数字员工实验场**：想用 AI 替一个完整岗位的人

## 关键能力

| 能力 | 说明 |
| ------ | ------ |
| 云电脑 | 每个 bot 自带沙箱运行环境 |
| 邮箱 | bot 可收发邮件 |
| 电话 | bot 可接打电话 |
| 派活渠道 | 聊天 / 短信 / 电话 / 邮件 / Slack |
| 业务范围 | 收件箱、pipeline、发票、报表 等 |
| 形态 | 一个 bot = 一个数字员工 |
