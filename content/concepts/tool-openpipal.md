# OpenPipal（macOS 可视化 Agent 应用）

## 它是什么

一个用 TypeScript 与 Electron 构建的 **macOS 可视化 Agent 应用**：不会用终端的用户也能连上自己配置的模型，用图形界面创建专职 Agent，并给任务排期自动运行。免费开源（Apache-2.0），当前仅支持 macOS。

![](https://pbs.twimg.com/media/HRRZUKRa0AAyzcs.jpg)

## 为什么用它 / 适合什么场景

- 团队里有非工程角色想用 Agent，但命令行门槛挡住了。
- 有重复性任务需要定时跑（每日汇总、周期巡检），希望排期而非手动触发。

## 关键能力

| 能力 | 说明 |
|------|------|
| 可视化建 Agent | 图形界面创建专职 Agent，无需终端 |
| 任务排期 | 给 Agent 排期，到点自动执行 |
| 模型接入 | 自身不带模型，请求**从本机直连**用户配置的 OpenAI 兼容接口 |
| 技术栈 | TypeScript + Electron |
| 许可 / 平台 | Apache-2.0；暂仅 macOS |
