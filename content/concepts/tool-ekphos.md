# ekphos

## 它是什么

[ekphos](https://github.com/nostacks/ekphos) 是一款**终端 TUI Markdown 笔记工具**：把 Obsidian 体验里的核心能力搬进命令行界面，单二进制运行。

> 在终端里维护 markdown 笔记库，把 Obsidian 的双链、图谱、任务汇总、Bases 属性视图和 Canvas 白板搬进 TUI。

## 为什么用它 / 适合什么场景

- 不想离开终端 / SSH 工作流，但需要管理 Obsidian 风格的笔记库。
- 跑在远端开发机或纯命令行环境（服务器 / 容器）又想用 Markdown 笔记。
- 喜欢 TUI 工具的轻量与键盘流操作。

## 关键能力

| 能力 | 说明 |
|------|------|
| 双链 | `[[wikilink]]` 与反向链接 |
| 图谱 | 笔记关系图可视化 |
| 任务汇总 | 跨笔记任务聚合视图 |
| Bases 属性视图 | 类似 Obsidian Bases 的结构化属性筛选 |
| Canvas 白板 | 节点关系自由排布 |
| 形态 | 终端 TUI，单二进制 |

## 与同类工具的差异

| 工具 | 形态 | 定位 |
|------|------|------|
| ekphos | TUI | 命令行维护 markdown 笔记库，兼容 Obsidian 体验 |
| Obsidian | 桌面 GUI | 同款体验的图形端 |
| YOINK | Python CLI | Markdown 笔记 + 预测结算 |
