# Logo First, IP Second（IP 即 Logo 设计原则）

## 适用场景
当你给一个新产品做品牌标识时，希望「Logo 一眼能识 → 缩成 16×16 也清楚 → 顺带还是个小 IP」时使用这套原则。它适合 App 图标、独立产品 Logo、小品牌主标识，也可用作 agent Skill 让 AI 一次性按规则出图。

## 前置条件
- 已确定品牌主调（一两种主色 + 纯色背景）。
- 已有「这个产品大概的气质」一句话描述（例如：友好 / 稳定 / 安静）。

## 步骤（设计四件硬性约束）
1. **简短化剪影**：先保证它是一个简洁、清晰、易识别的 Logo，其次才是一个可爱 IP 形象；剪影要能 16×16 也清楚。
2. **圆润几何形态**：避免尖角、细线和锐利结构；用尽量少的形状完成，缩小后依然清楚。
3. **复杂度上限**：平面为主，只加入非常微妙的阴影、压痕和明暗层次；绝不变成厚重 3D。
4. **超轻新拟物光影**：支持单色或双色 IP，整张 Logo 最多控制在**三种主色以内**。

## 附加构图建议
- **高占比人格化构图**：IP 从左下角或右下角探出，占据较大的画面比例；通过简单的眼睛、嘴巴和姿态建立性格与记忆点。
- **主体偏好**：默认挑大众熟悉的动物；物件、机器、奇幻生物、冷门动物要走默认路线必须给出明确的产品理由。
- **工作流**：默认先给三种设计方向；用户确认后每个方向再出 6 个独立候选。

## 适用 Agent 平台
遵循开放 Agent Skills 格式，兼容 Codex、Coze、Doubao、YouMind、Manus、Gemini Apps、Replit Agent 等支持内置图像生成的智能体，不绑定某个具体产品。

## 验证 / 自检
- [ ] 缩到 32×32 像素仍能看清主体形状？
- [ ] 整个画面用色 ≤ 3 种？
- [ ] 主体只用圆润弧线、无尖角？
- [ ] 截图替换成黑白后识别度仍在？（剥离颜色看骨架）
- [ ] 把 Logo 名字盖住、给陌生人看 3 秒，能否说出"大概是什么感觉"？

## 一句话总结
**把一个可爱的小 IP，压缩成一个精致的产品 Logo。**
