# Logo First, IP Second（IP 即 Logo 设计原则）

## 适用场景
当你给一个新产品做品牌标识时，希望「Logo 一眼能识 → 缩成 16×16 也清楚 → 顺带还是个小 IP」时使用这套原则。它适合 App 图标、独立产品 Logo、小品牌主标识，也可用作 agent Skill 让 AI 一次性按规则出图。

## 前置条件
- 已确定品牌主调（一两种主色 + 纯色背景）。
- 已有「这个产品大概的气质」一句话描述（例如：友好 / 稳定 / 安静）。

## 步骤（设计六原则）
1. **Logo First, IP Second**：先保证它是一个简洁、清晰、易识别的 Logo，其次才是一个可爱 IP 形象，避免复杂插画感。
2. **极简构成**：只保留最有辨识度的轮廓与五官，用尽可能少的形状完成设计，缩小后依然清楚。
3. **圆润、浑厚的线条**：避免尖角、细线和锐利结构，让形象更加友好、稳定，也更适合作为 App Icon。
4. **Flat-first 超轻拟物**：整体仍以平面为主，只加入非常微妙的阴影、压痕和明暗层次；绝不变成厚重的 3D 图标。
5. **克制的色彩系统**：支持单色或双色 IP；通常 IP 内不超过两种颜色，加上纯色背景，整张 Logo 最多控制在**三种主色以内**。
6. **高占比人格化构图**：IP 从左下角或右下角探出，占据较大的画面比例；通过简单的眼睛、嘴巴和姿态建立性格与记忆点。

## 验证 / 自检
- [ ] 缩到 32×32 像素仍能看清主体形状？
- [ ] 整个画面用色 ≤ 3 种？
- [ ] 主体只用圆润弧线、无尖角？
- [ ] 截图替换成黑白后识别度仍在？（剥离颜色看骨架）
- [ ] 把 Logo 名字盖住、给陌生人看 3 秒，能否说出"大概是什么感觉"？

## 一句话总结
**把一个可爱的小 IP，压缩成一个精致的产品 Logo。**
