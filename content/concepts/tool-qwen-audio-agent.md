# Qwen Audio Agent

全双工语音 Agent 运行时，可边听边答边执行，并把后台任务结果回流到同一会话。

## 主要能力

- 作为可复用的软件或工作流组件，按项目文档进行部署和评估。
- 适合在对应场景中替代重复的手工流程。
