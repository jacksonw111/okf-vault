# ackem

## 它是什么
**本地优先的 Windows 桌面 AI 伙伴**，Electron 写的，聊天记录、长期记忆、配置全存在本地硬盘上。模型兼容所有 OpenAI 协议接口（DeepSeek / OpenAI / Ollama / LM Studio 等），自己带模型就能跑，不依赖云服务。

由 JasonLiu0826 个人开发。

## 为什么用它 / 适合什么场景
- 想要**数据完全留在本地**的 AI 陪伴 / 数字伙伴——聊天内容、私人记忆、关系状态不进任何云端。
- 已经跑着 Ollama / LM Studio 等本地模型，想接个桌面 GUI 直接对话。
- 想让 AI 真的「记事情」——能导入 `.txt` / `.md` 历史、感知情绪、跟踪关系阶段（陌生人 → 熟人 → 亲密）。
- 想在桌面养个 AI 宠物、语音对话、桥接微信等轻量集成。

## 关键能力
| 能力 | 说明 |
|------|------|
| 平台 | Windows 桌面（Electron） |
| 存储 | 聊天 / 记忆 / 配置全在本地硬盘 |
