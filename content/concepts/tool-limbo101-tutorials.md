# Limbo101 教程站（dev.limbo101.win）

## 它是什么

[Limbo101 教程站](https://dev.limbo101.win) 是 limbopeng 维护的**可视化交互式教程合集**——每篇教程都有**详细文字说明 + 可视化可交互的图示**，把晦涩概念讲透。

主题覆盖范围很广，重点聚焦于：
- **Pi**（本地 AI 编程代理）
- **JEV**（类型化判定模型）
- **DSH**（DeepSeek Harness）
- **GPU**（硬件 / 算子 / 显存）
- **LLM**（模型 / 参数 / 推理）

## 为什么用它 / 适合什么场景

- 想**系统理解 LLM 推理参数**：权重 / 精度 / KV Cache / 并发 / 上下文长度 / 带宽 / Prefill / Decode / TTFT / 输出 token 速度等「模糊概念」通过交互图示变得具象。
- 想**手算推理配置**：看完教程能自己估算「给定显存与吞吐预算该选哪档模型」。
- 想**找本地部署参考**：覆盖 Pi、JEV、DSH 等本地优先工具的工程实践。
- 偏好「**文字 + 图示 + 可交互**」三重讲解（不只是纯文字或纯视频）。
