# github-profile-achievements

## 它是什么
`christianalberto/github-profile-achievements` 是一份**对 GitHub Profile Achievements（个人主页成就徽章）的系统整理**。GitHub 官方从未一次性公布过完整的徽章清单、等级阈值、历史版本与变动记录，这个项目把这些「散落在 release notes / docs / 社区帖」里的信息**集中成一份可查询的参考目录**。

## 为什么用它 / 适合什么场景
- 想点亮某个徽章却不知道当前等级门槛是多少。
- 写 README / 个人主页，想了解哪些徽章能挂上。
- 教学 / 写书 / 写博客：引用具体徽章含义和获取条件。
- 跟踪 GitHub 历史变动：哪些徽章被加 / 被改名 / 被取消。

## 关键能力 / 目录覆盖维度
| 维度 | 说明 |
|------|------|
| 徽章全集 | 列出每一个 profile 徽章（Mars 2020 / Pull Shark / Arctic Code Vault…） |
| 等级门槛 | 解锁条件、达到更高等级的具体数字（PR 数 / 贡献年数…） |
| 历史版本 | 徽章的引入年份、改名 / 重新设计时间线 |
| 官方动态 | 整理 GitHub 官方 blog / changelog 里的相关公告 |
| 可查询 | 单页参考目录 + 链接跳转，无需爬多个来源 |
