# GitGrimoire（GitHub 黑色五叶草 3D 魔法书）

## 它是什么

`tosxin-456/gitgrimoire` 是一个**面向 GitHub 用户的趣味可视化项目**：输入任意 GitHub 用户名，把这个用户的**公开活跃数据**（commits / repos / stars / languages 等）转成《**黑色五叶草**》（Black Clover）风格的「3D 魔法书」：

- **魔法书档案**——把用户的 GitHub 履历渲染成一本 3D 翻页魔法书。
- **对决（duels）**——两位 GitHub 用户的「魔法对决」动画。
- **排行榜**——按某种指标排魔法骑士团榜。
- **无需登录 / 无需授权**——只用公开数据。

## 为什么用它 / 适合什么场景

- 想用「宅文化 + 动漫 + 3D 视觉」的方式把 GitHub 个人页包装得有故事感。
- 团队 / 社群搞活动做「魔法骑士团排名」。
- 想要一份「不落俗套」的 GitHub 个人作品集页面。

## 关键能力

| 能力 | 说明 |
|------|------|
| 风格化 | 《黑色五叶草》IP 视觉 |
| 3D 魔法书 | 翻页 3D 渲染 |
| 对决 | 两位用户对比动画 |
| 排行榜 | 多用户聚合排名 |
| 免授权 | 只用 GitHub 公开数据，无 OAuth |
