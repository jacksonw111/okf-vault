# dsh-claude-style

## 它是什么

[dsh-claude-style](https://github.com/Nwflower/dsh-claude-style) 是 **Nwflower** 出品的**主题包**——给 **DeepSeek Harness 网页 GUI** 套上 **Claude Code Desktop** 的**配色、字体和交互**，同时保留 DeepSeek 品牌配色可切换。

## 为什么用它 / 适合什么场景

- **跨工具视觉一致性**：用户已经在 Claude Code 里建立视觉习惯，切到 DSH 时不必重新适应。
- **品牌灵活切换**：要演示 / 截图 DeepSeek 自家品牌时一键换回。
- **典型场景**：想试 DeepSeek Harness 但又怕 UI 不顺手的开发者。

## 关键能力

| 能力 | 说明 |
|------|------|
| 目标 | DeepSeek Harness 网页 GUI |
| 主题 1 | Claude Code Desktop 配色 / 字体 / 交互 |
| 主题 2 | DeepSeek 品牌配色（可切换） |
| 形态 | 主题 / 样式覆盖 |
