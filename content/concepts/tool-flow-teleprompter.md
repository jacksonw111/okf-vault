# Flow（Windows 置顶悬浮窗提词器）

## 它是什么

[LumoRez07/Flow](https://github.com/LumoRez07/Flow) 是 Windows 上的开源提词器：把讲稿 / 脚本 / 教学文案放进一个**置顶悬浮窗**，始终盖在摄像头画面之上，使用者看着屏幕念、不用低头看稿。

## 为什么用它 / 适合什么场景

- 主播 / 录课 / 答辩 / 讲演场景：保持**眼神对镜头**而不是看稿；
- 老师 / 培训师：照屏幕读讲义不用低头，缓解颈部疲劳；
- 面试 / 远程会议：把要讲的要点放上去，避免遗忘；
- 任何需要「**对着屏幕**、**连续讲一段话**」的内容生产者。

## 关键能力

| 能力 | 说明 |
|------|------|
| 置顶悬浮窗 | 脚本窗口常驻顶层，盖在所有应用之上 |
| 视线不离屏 | 文字贴在摄像头旁，避免低头 |
| 跟随讲话节奏 | 支持滚动 / 自动翻页 / 调速（看具体版本） |
| 本地运行 | Windows 本机软件，无云依赖 |
