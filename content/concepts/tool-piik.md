# Piik（开源屏幕共享工具）

## 它是什么

[Piik](https://github.com/TNTcraftHIM/Piik) 是一款**免费开源**的屏幕共享工具，主打「**好友无需安装客户端**」：通过桌面或移动浏览器打开邀请链接即可观看。捕获粒度支持**整屏 / 单个窗口 / 单个浏览器标签页**。

## 典型场景

- **游戏直播**：跟好友一起看游戏过程
- **电影之夜**：异地同步观影
- **绘画展示**：实时同步创作过程
- **照片分享**：批量滚动照片墙

## 为什么用它

- 「**零客户端**」门槛是关键优势：以往屏幕共享都要求对方装客户端 / 加好友 / 注册账号，Piik 把这一切简化成「**打开链接就看**」。
- 同时覆盖桌面与移动浏览器，覆盖面比同类只做桌面的方案更宽。
- 三档捕获粒度（屏 / 窗口 / 标签页）让共享范围可控——只共享单个标签页比共享整屏更安全。

## 关键能力

| 能力 | 说明 |
|------|------|
| 浏览器观看 | 好友无需装客户端 |
| 三档捕获 | 整屏 / 窗口 / 标签页 |
| 桌面 + 移动浏览器 | 双端兼容 |
| 邀请链接 | 一条 URL 进入共享 |
| 开源免费 | 无需订阅、无水印 |
