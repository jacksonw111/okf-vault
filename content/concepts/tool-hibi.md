# hibi

## 它是什么
一个**本地 Markdown 桌面编辑器**，差异点是：

- Markdown 与源码两种视图可并排对照
- 单个文件或整个文件夹都能当 workspace
- 写完可以导出 HTML 或用 Typst 出 PDF
- addon 扩展体系

## 为什么用它 / 适合什么场景
- 需要 Markdown 与源码并排对照视图（实时看渲染与源码差异）。
- 想要一个本地 Markdown 编辑器，对「把笔记 / 文档变成 PDF」有强需求（Typst 出 PDF）。
- 接受 176 MB 安装包体积（差异点之一就是 Typst 内嵌）。

## 关键能力
| 能力 | 说明 |
|------|------|
| 形态 | 桌面编辑器 |
| 视图 | Markdown 与源码并排 |
| Workspace | 单文件 / 整文件夹 |
| 导出 | HTML / Typst → PDF |
| 扩展 | addon |
| 安装包 | ~176 MB（内嵌 Typst） |
