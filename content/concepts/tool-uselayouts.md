# useLayouts

## 它是什么

[useLayouts](https://uselayouts.com/) 是一个**现代网站布局灵感集合**：按页面段落（hero / 导航 / 表单 / 卡片 / 团队 / 定价 / CTA / footer 等）分类，**收录真实生产级网站的截图**，用于做产品落地页、官网设计时「按图索骥」。

## 为什么用它 / 适合什么场景

- 准备做新项目官网 / 落地页，需要快速找到**当下流行的版式**。
- 想了解某个具体段落（pricing / testimonials / feature grid）的**行业惯用做法**。
- 想从生产级站点而非纯设计稿中找灵感——更接近真实工程约束。

## 关键能力

| 能力 | 说明 |
|------|------|
| 按段落分类 | hero / navbar / form / feature / pricing / footer 等 |
| 真实生产站点 | 收录的都是在用的产品官网，不是静态设计稿 |
| 筛选形态 | SaaS / 落地页 / 工具类 / 内容站等多种风格 |
| 视觉参考 | 每条配截图，可直接对比版式与视觉 |
