# neat-annotations

## 它是什么

[neat-annotations.syabro.com](https://neat-annotations.syabro.com/) 是 Maxim Syabro 写的**纯 CSS 注释库**：在网页上加「**设计师风格**」的注释气泡 / 标签 / 箭头，**全部 CSS 实现，零 JS**。

## 为什么用它 / 适合什么场景

- 做设计稿展示 / 案例分享页面想加标注气泡。
- 想给团队内部演示页加引导注释。
- 追求轻量（无 JS / 无构建）。

## 关键能力

| 能力 | 说明 |
|------|------|
| 纯 CSS | 零 JS |
| 注释气泡 | 设计师风格标签 |
| 箭头 | 标注连线 |
| 标签 | 信息提示 |
| 易集成 | 加 class 即可 |
