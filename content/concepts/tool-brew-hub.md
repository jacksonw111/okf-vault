# Brew Hub（Homebrew 图形界面）

## 它是什么

**Brew Hub** 是 cuongdc03 出品的 **macOS Homebrew 图形界面**——把「已装应用（casks）/ 命令行包（formulae）/ 后台服务（services）/ 磁盘缓存」四类管理操作从 `brew` 命令行搬到图形窗口里点，让不熟命令行的用户也能用 Homebrew。

## 为什么用它 / 适合什么场景

- **新人友好**：图形界面降低 Homebrew 学习成本
- **可视化**：已装包数量、占用空间、服务状态一图看清
- **批量管理**：勾选 / 卸载 / 升级多项
- **保留 Homebrew 能力**：底层仍是 `brew`，不损失灵活性

## 关键能力

| 能力 | 说明 |
|------|------|
| Formulae 管理 | 已装 / 可装 / 升级命令行包 |
| Casks 管理 | 已装 / 可装 GUI 应用 |
| Services | 后台服务启动 / 停止 |
| 磁盘缓存清理 | 旧下载包清理，腾出空间 |
| 搜索 | 按名 / 描述搜包 |
