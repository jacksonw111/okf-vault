# KPanel (kejilion)

## 它是什么

[KPanel](https://github.com/kejilion/KPanel)（**科技lion** 出品的开源免费 Linux 服务器管理面板）把**脚本运维能力带到 Web 端**：脚本、SSH、Compose 和面板创建的真实资源**可以互相发现、修改并继续管理**——不会换入口就丢掉对现有网站、容器和配置的控制。

![KPanel 截图](https://pbs.twimg.com/media/HOw0kQja0AAZmhg.jpg)
![KPanel 截图](https://pbs.twimg.com/media/HOw0k1aaAAAS1LO.jpg)

## 为什么用它 / 适合什么场景

- **统一入口**：脚本 + SSH + Compose + 面板共用一份视图，不切来切去。
- **资源不丢**：面板创建的真实资源能被脚本和 SSH 看见、修改、管理。
- **不重写已有**：不丢对现有网站、容器和配置的控制。

## 关键能力

| 能力 | 说明 |
|------|------|
| 脚本运维 | 把 shell 脚本能力暴露成 Web 界面 |
| SSH 集成 | 在面板里直接连 SSH |
| Compose 管理 | 管理 docker-compose 创建的容器 |
| 资源互通 | 脚本 / SSH / Compose / 面板创建的资源互相可见 |
