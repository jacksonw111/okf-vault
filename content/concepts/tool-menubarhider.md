# MenuBarHider

## 它是什么

[MenuBarHider](https://github.com/happy666End/MenuBarHider) 是一个轻量级 macOS 菜单栏隐藏工具，应对**系统大版本变更**的兼容性场景：

> macOS 27 重写菜单栏后，Hidden Bar、Ice 等隐藏工具集体失效，MenuBarHider 用两个分隔符加一次点击重新隐藏菜单栏图标。

## 为什么用它 / 适合什么场景

- macOS 27 系统升级后，原本用的 Hidden Bar / Ice 等工具失效。
- 想要「**两个分隔符 + 一次点击**」这种极简交互的菜单栏整理方案。
- 临时系统级 bug 修复工具，绕过 API 变化直接实现隐藏。

## 关键能力

| 能力 | 说明 |
|------|------|
| 极简交互 | 两个分隔符 + 一次点击 |
| 系统适配 | 应对 macOS 27 菜单栏重写后的 API 变化 |
| 隐藏图标 | 把不常用的菜单栏图标收纳进分隔符之后 |
| 开源 | 仓库公开，可自签 |
