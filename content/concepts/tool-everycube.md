# everycube

## 它是什么
everycube 把魔方全部 43,252,003,274,489,856,000（4.3 × 10¹⁸）种可达排列做成一个可滚动索引。每一格对应一个特定的魔方状态，滚动到该格时即用 3D 渲染呈现这个状态。

## 为什么用它 / 适合什么场景
- 组合数学 / 群论教学：直观展示魔方群的大小与可达状态分布。
- 魔方爱好者 / 算法研究者：从中发现有意思的特殊排列或从中随机取样练习。
- 想做一个「数据可视化奇观」案例——极简交互（滚动）+ 极复杂数据（4.3 × 10¹⁸）。

## 关键能力
| 能力 | 说明 |
|------|------|
| 数据规模 | 43,252,003,274,489,856,000（4.3 × 10¹⁸）种状态 |
| 交互 | 可滚动索引 |
| 渲染 | 滚动到任意一格即时渲染 3D 状态 |
| 性质 | 教学 / 数学 / 玩具 |
