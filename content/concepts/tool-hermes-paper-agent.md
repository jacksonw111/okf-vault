# hermes-paper-agent

## 它是什么

[vaelkeep/hermes-paper-agent](https://github.com/vaelkeep/hermes-paper-agent) 把「一天的数据」自动**排版成一份个人报纸**：日历、账本、步数、天气、行情、笔记……每晚跑一次，输出有头版、有版块、有结尾的成品，用来替代无止境的信息流刷取。

定位：

- **个人日报 Agent**：把分散在不同 App 的数据汇总到一份可阅读的产物。
- **结构化输出**：报纸形态（头版 / 版块 / 结尾）比纯 Markdown 摘要更适合晨间阅读。

## 为什么用它 / 适合什么场景

- 想从「刷信息流」切换到「定时收报纸」，降低每日决策疲劳。
- 已经在用多个数据源（日历 / 记账 / 手环 / 天气 / 投资笔记），希望有个统一的每日摘要。
- 喜欢纸质 / 报纸形态的阅读节奏，而不是冷冰冰的纯文本。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多源汇总 | 日历、账本、步数、天气、行情、笔记 |
| 报纸版式 | 头版头条 + 多个版块 + 收尾 |
| 定时触发 | 每晚自动跑一次 |
| 替代信息流 | 把被动刷取变成主动阅读 |
