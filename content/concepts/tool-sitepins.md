# Sitepins

连接 GitHub 或 GitLab 仓库的可视化 Markdown 编辑器，每次保存自动创建 Git commit。

## 主要能力

- 作为可复用的软件或工作流组件，按项目文档进行部署和评估。
- 适合在对应场景中替代重复的手工流程。
