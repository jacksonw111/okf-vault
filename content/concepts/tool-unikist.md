# Unikist（696+ 设计资源合集）

## 它是什么

[Unikist](https://unikist.com) 是一个把 696+ 个设计相关资源汇总到一处的导航站，覆盖图标、字体、样机、UI 套件、灵感来源乃至实战练习题，避免「需要某个素材时挨个搜」。

## 适合谁用

- 设计师 / 前端要快速找到某个素材（图标 / 字体 / mockup）
- 设计新手想系统补齐「设计资源地图」
- 团队培训：把链接发给新人当资源起点

## 资源类别

| 类别 | 用途 |
|------|------|
| 图标 | icon 库集合 |
| 字体 | 字体资源 |
| 样机 | mockup 模板 |
| UI 套件 | UI kit / 组件库 |
| 灵感 | 优秀设计 / 案例站 |
| 练习题 | 设计实战 brief |
