# StyleX Blocks

## 它是什么
[stylexblocks.com](https://stylexblocks.com?v=2) 是一个**组件积木站**，目标是用 [Stylex](https://stylexjs.com)（Meta 开源的 CSS-in-JS 编译期方案）+ [Ark UI](https://ark-ui.com/) 或 [Base UI](https://base-ui.com/) 这套组合，按组件类别聚合可直接拷贝粘贴的高质量 React 组件。开发者不再从零造组件——挑几块拼装，就是一个自家的设计系统。

## 为什么用它 / 适合什么场景
- 想用 Stylex 做样式底层 + Ark UI / Base UI 做无样式行为组件，但懒得一个个配；
- 想搭「轻量、自有、可定制」的设计系统——比 Material UI / Chakra 这种重型库更轻，又比纯 shadcn 多了「选现成的」效率；
- 团队约定使用 StyleX 生态（Meta 内部 / 跨平台代码共享），需要公共积木仓库。

## 关键能力
| 能力 | 说明 |
|------|------|
| 样式底层 | Stylex（编译期 CSS-in-JS，零运行时开销） |
| 行为组件 | Ark UI / Base UI 可选 |
| 组件分类聚合 | 按类别提供可复制 React 块 |
| 自有设计系统 | 选块 → 拼装 → 主题化 |
| 开源 | 代码可读可改 |
