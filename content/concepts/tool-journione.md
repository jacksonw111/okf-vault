# JourniOne Planning Skills（按天可执行的 AI 旅行规划）

## 它是什么

[JourniOne Planning Skills](https://github.com/JourniOne-ai/JourniOne-Planning-Skills) 是 JourniOne-ai 出品的 **Claude / AI Agent 旅行规划技能包**——

- 让 AI 按天排出**可执行的旅行路线**（不是「去 X 市看看」那种废话，而是几点到、吃什么、住哪里、地铁几号线的细颗粒路线）
- 同时输出**带地图、可分享的图文旅行手册**（HTML / PDF）
- 作为 Agent Skills 包，Claude / Claude Code / 其他读 SKILL.md 的客户端都能用

## 为什么用它 / 适合什么场景

| 场景 | JourniOne 的好处 |
|------|-----------------|
| 想让 AI 排真实可走行程 | 输出按天、按时段、带交通 |
| 想要可分享产物 | 直接出 HTML / PDF 手册，发群 / 朋友圈都行 |
| 想给 AI 接旅游信息源 | 技能包内已封装 |
| 自家旅行社 / 内容创作者 | 一键生成定制行程 |

## 关键能力

| 能力 | 说明 |
|------|------|
| 按天路线 | Day 1 / Day 2 / ... 时间块 |
| 时段细分 | 上午 / 午餐 / 下午 / 晚餐 / 夜场 |
| 交通信息 | 地铁 / 步行 / 打车预估 |
| 地图嵌入 | HTML 里直接嵌入地图 |
| 可分享 | 输出 HTML / PDF |
| Agent Skills 形态 | 与 Claude / Claude Code 即插即用 |
