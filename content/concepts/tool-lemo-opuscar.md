# Lemo-Opuscar（39 种影片风格的 AI 短片制作工作流）

## 它是什么

[Lemo-Opuscar](https://github.com/lemomo-ai/lemo-opuscar) 是 lemomo-ai 维护的开源仓库，给想用 AI 做短片的人一套现成的影片风格提示词 + 可复现的纯代码制作流程，省掉自己调风格与搭渲染管线的功夫。

## 关键能力

| 能力 | 说明 |
|------|------|
| 39 种风格 | 每种风格一份 STYLE.md 提示词 + 一支成片当参照 |
| 分组清晰 | 手绘 / 东方传统 / 版画 / 排版 / 信息图 / 卡通 / 游戏 / 电影时代 / 材质 3D |
| 纯代码流程 | 可复现的制作流程（不依赖在线服务 / 闭源工具） |
| 完整成片 | 每种风格都附成片当参照，便于评估效果 |

## 适用场景

- 想做 AI 短片但不会调风格
- 想保持多支短片风格一致
- 想用纯代码流程做可复现的渲染管线
