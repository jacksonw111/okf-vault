# iris (brijr/iris)

## 它是什么
[`brijr/iris`](https://github.com/brijr/iris) 是一个**代码优先**的网站构建工具，把 Astro 的简洁性与组件化开发体验整合，让用户像写组件一样拼装页面，避免被传统 CMS 的繁琐界面卡住。

## 为什么用它 / 适合什么场景
- 想搭个人主页 / 作品集 / 营销落地页，又不想被 WordPress / Webflow 的 GUI 牵着走。
- 喜欢用代码（TypeScript / Markdown / MDX）描述内容，需要可版本控制的站点源文件。
- 需要 Astro 那种「默认零 JS、按需岛屿」的轻量体验，但希望 UI / 工作流更简单。

## 关键能力
| 能力 | 说明 |
|------|------|
| 代码优先 | 不依赖 CMS GUI，所有结构写在源码里 |
| Astro 内核 | 复用 Astro 的轻量、岛屿化、Markdown 支持 |
| 组件化 | 每个区块都是可复用组件，按页面拼装 |
| 静态产物 | 输出静态站点，可托管到任意 CDN / Pages |
