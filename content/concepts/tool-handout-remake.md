# handout-remake

## 它是什么

[handout-remake](https://github.com/xamjiang/handout-remake) 是 xamjiang 开源的「**深色讲义重做**」工具：

- 输入：上课用的**投影片 / PDF / 笔记**
- AI 重做成「适合 iPad 长时间阅读 + 手写作答」的**深色讲义**
- 输出：**全向量 PDF**（任意缩放不糊）

## 为什么用它 / 适合什么场景

- **深色模式护眼**：白天 / 夜里长时间看不刺眼
- **手写作答留白**：用 Apple Pencil 在讲义上随手批注
- **可打印**：纯白底也行，但默认深色讲义更适合自学
- **老师 / 学生**：把白底 PPT / 学术 PDF 改造成适合自学 / 自批注的版本

## 关键能力

| 能力 | 说明 |
|------|------|
| 输入 | 投影片 / PDF / 笔记 |
| AI 重做 | 改版式 / 配色 / 字号适配 iPad |
| 输出 | 全向量 PDF |
| 深色主题 | 护眼、适合夜间阅读 |
| 手写区 | 留白配合 Apple Pencil 批注 |
