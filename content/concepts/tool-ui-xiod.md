# ui.xiod（开源 UI 组件库 / Landing 设计）

## 它是什么

[ui.xiod](https://ui.xiod.dev) 是一个由独立开发者 xiod 维护的**开源 UI 组件库**，配套精心打磨的 Landing 页与文档站点。同作者的另一个项目 [shoogle.dev](https://shoogle.dev) 收录更多视觉探索。

它面向「**想做一个看起来像样的现代前端项目**」的开发者，特点是 Landing 与 Docs 视觉与文档质量都很高。

## 关键能力

| 能力 | 说明 |
|------|------|
| 组件库 | 提供可复制即用的 UI 组件 |
| 高质量 Landing | 站点本身的视觉与排版就是参考 |
| 高质量 Docs | 文档站点的组织与可读性也做得很细 |
| 配套资源 | 与 [shoogle.dev](https://shoogle.dev) 等视觉探索站联动 |

## 适合什么场景

- 想为自己的前端项目找一个「**视觉与文档都不掉链子**」的组件库参考。
- 个人开发者 / 独立项目想要快速搭一个看起来专业的 Landing + Docs。
- 在做前端 vibe coding、想要锁定一种「现代、开源、有质感」视觉风格的团队。
