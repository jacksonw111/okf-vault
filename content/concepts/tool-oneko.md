# Oneko

## 它是什么
React 版的"Oneko"：经典桌面像素猫，会跟着光标走、会打盹、会发消息（"说话"），共 12 套毛色可选。用 shadcn CLI 一行命令即可装到自己项目里，复制后源码归你。

## 关键能力
| 能力 | 说明 |
|------|------|
| 跟光标 | 像素猫会追随鼠标移动 |
| 会打盹 | 闲置时进入休眠状态 |
| 会说话 | 可配置短消息气泡 |
| 12 套毛色 | 默认 / 黑白 / 橘猫 / 奶牛 等 |
| shadcn CLI | 一行命令安装 |

## 适用场景
- 个人作品集 / 落地页的"萌点"装饰
- 营销页 / 等候页 加点怀旧感
- 想给严肃工具添点幽默元素
