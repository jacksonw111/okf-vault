# Conversed（mayeedwin/conversed）

## 它是什么

`mayeedwin/conversed` 是一个 **TypeScript 组件库**（支持 React 和 Angular），把 LLM 的结构化回复**解析成内容块 AST**，渲染为**表格、图表、统计卡片、步骤、时间线等 16 种可交互组件**——直接嵌入聊天界面。

## 为什么用它 / 适合什么场景

- 想要让 LLM 输出不再是一坨 Markdown，而是**真正可点 / 可交互**的组件；
- 团队同时用 React 和 Angular，希望**一套组件库两边都能用**；
- 想做产品级的「结构化 LLM 聊天」体验，而不是只能输出文本。

## 关键能力

| 能力 | 说明 |
|------|------|
| 内容块解析 | LLM 回复 → 内容块 AST |
| 多组件渲染 | 表格 / 图表 / 统计卡片 / 步骤 / 时间线 等 16 种 |
| 双框架 | 同时支持 React 与 Angular |
| 可交互 | 渲染出来的不是死 HTML，是真正可点 |
| 嵌入式 | 直接嵌进现有聊天界面 |
