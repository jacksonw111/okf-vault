# EnvNexus-AI（PuppetWen/EnvNexus-AI）

## 它是什么

`PuppetWen/EnvNexus-AI` 是一款 **Rust + Tauri 2** 写的 **Windows 桌面应用**，**统一管理** Python、Java、Go、Rust、Node.js 等开发工具的**多版本安装和切换**。

## 为什么用它 / 适合什么场景

- Windows 下用多个版本的 Python/Node/Rust/Go 切来切去，`pyenv-win` / `nvm-windows` / `rustup` 各自一套，希望**一个 GUI 统一管**；
- 想要 GUI 而不是命令行；
- 想要**桌面端原生体验**（Rust + Tauri 2，体积小、启动快）。

## 关键能力

| 能力 | 说明 |
|------|------|
| 多语言版本管理 | Python / Java / Go / Rust / Node.js |
| 桌面 GUI | 不用命令行点点点 |
| Rust + Tauri 2 | 小体积、启动快 |
| Windows 优先 | 面向 Windows 桌面用户 |
