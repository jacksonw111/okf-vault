# tendedero

## 它是什么

[tendedero](https://github.com/alejandrobujan/tendedero) 是 alejandrobujan 开源的 **macOS 菜单栏小工具**：

- 把所有截图统一**挂到屏幕顶边的一条线**上（西班牙语 *tendedero* = 晾衣绳）
- 用的时候**拉下来拿**
- 桌面不再被缩略图堆满

## 为什么用它 / 适合什么场景

- **重度截图用户**：每天截图几十张的人，桌面永远堆满缩略图
- **临时暂存**：截图先挂顶上，等会儿要写文档再拉下来插入
- **保持桌面整洁**：临时文件不污染 Desktop 文件夹
- **类 Spotlight / 顶边工具栏范式**：隐藏式 UI，需要时拉出来

## 关键能力

| 能力 | 说明 |
| ------- | ------ |
| 形态 | macOS 菜单栏小工具（menu bar app） |
| 截图暂存 | 自动挂到屏幕顶边 |
| 拉取交互 | 用的时候下拉即可拿图 |
| 桌面整洁 | 不再让截图缩略图堆在桌面 |
| 临时性 | 适合「截图先攒着，等会儿统一处理」的工作流 |
