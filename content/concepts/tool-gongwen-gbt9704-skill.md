# gongwen-gbt9704-skill

## 它是什么

[mizzlelover/gongwen-gbt9704-skill](https://github.com/mizzlelover/gongwen-gbt9704-skill) 把**中文公文格式国家标准 GB/T 9704-2012**做成可一键生成的 DOCX 版式 + 格式校验工具：

- A4 版心
- 字体字号（方正仿宋 / 黑体 / 楷体）
- 标题层级（一级 / 二级 / 三级标题）
- 文号 / 署名 / 日期 / 页码
- **格式校验**：跑完自动查是否偏离标准

## 为什么用它 / 适合什么场景

- AI 生成中文公文材料时常「看起来像公文但格式不对」，本工具直接按国标出。
- 党政机关 / 事业单位 / 国企办公室要把 AI 草稿转成规范公文。
- 想给 AI agent 装一个「公文版式 skill」。

## 关键能力

| 能力 | 说明 |
|------|------|
| 国标严格 | GB/T 9704-2012 全字段对齐 |
| DOCX 直出 | 直接生成 Word 文件 |
| 字体 / 字号 | 仿宋 / 黑体 / 楷体 自动化 |
| 标题层级 | 一级 / 二级 / 三级标题样式 |
| 文号 / 署名 / 日期 | 标准化字段 |
| 页码 | 居中 / 居右等可选 |
| 格式校验 | 生成后自动查偏离 |
