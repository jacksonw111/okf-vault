# LightMarkit

## 它是什么
LightMarkit（`zhtdbobo/LightMarkit`）是基于 Tauri 2、React 和 TypeScript 构建的轻量级桌面 Markdown 编辑器，支持 Windows 和 macOS。

## 为什么用它 / 适合什么场景
- **Tauri 占用低**：相比 Electron 包，启动更快、内存更省。
- **跨平台同代码**：Windows + macOS 同一份代码维护。
- **轻量定位**：相比 Obsidian / Typora，不强加知识库 / 商业化功能。

## 关键能力

| 能力 | 说明 |
|------|------|
| Tauri 2 + React | 现代轻量桌面栈 |
| Windows + macOS | 同源代码双端支持 |
| Markdown 编辑 | 标准 Markdown 写作流 |
