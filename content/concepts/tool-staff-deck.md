# StaffDeck（OpenBMB 企业数字员工平台）

## 它是什么

[StaffDeck](https://github.com/OpenBMB/StaffDeck) 由 **OpenBMB** 开源，目标是把「个人生产力」型 AI 升级为**组织级能力**。它把专业人的工作经验、业务流程、决策标准沉淀成一个个「数字员工」——可在团队内复用、可演进、有可追溯的决策依据。

## 关键能力

| 能力 | 说明 |
|------|------|
| 数字员工封装 | 把分散的经验 / 流程 / 决策标准打包成可调用的 worker |
| 可复用 / 可演进 | 同一数字员工可被多人复用并持续迭代 |
| 可追溯 | 所有调用与决策有审计依据 |
| 组织视角 | 面向团队 / 部门而非单点提效 |
