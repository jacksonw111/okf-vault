# Accessibility Experience Guide（a11y 设计规范：Matt Soriano）

## 它是什么

[Accessibility Experience Guide](https://emesstyle.com/a11y-design) 是 Matt Soriano 出品的**面向体验设计师的 a11y 规范**——把 **WCAG** 等复杂合规标准**提炼为清晰可执行的设计规则**，附视觉示例，方便设计师在画稿阶段就把无障碍要求落进去。

## 解决的问题

- 「**WCAG 文档 80 页、看完还是不知道怎么画**」——设计师卡在合规条款里。
- 「**开发说按钮对比度不够**」——上线前才发现返工。
- 「**键盘党 / 屏幕阅读器用户**」在公司产品里彻底没存在感。

## 适合什么场景

- 设计师需要一份**「看得懂、能落地」** 的 a11y 速查表。
- 设计走查时用来**对照清单**检查新界面。
- 想要一份给非工程师同事的 a11y 教育资料。

## 关键能力

| 能力 | 说明 |
|------|------|
| 形式 | 视觉化设计规范页面 |
| 范围 | 体验设计层（颜色 / 对比 / 焦点 / 文字 / 交互） |
| 风格 | 把 WCAG 条款翻译成「**设计师能直接用的规则**」 |
| 适合 | 设计师走查 / 设计教育 |
