# hunter-community（自部署金融 AI Agent 平台）

## 它是什么

[agentpit-io/hunter-community](https://github.com/agentpit-io/hunter-community) 是给**个人投资者**的**自部署金融 AI Agent 平台**：**行情查询、深度分析、走势预测、机构级投研方法论**装进自己的机器，**不依赖 SaaS 订阅**。

适合不想被 SaaS 投研工具年费绑死、又想要一套完整 AI 投研流水线的中长线投资者。

## 为什么用它 / 适合什么场景

- 想把金融 AI Agent 跑在自己的服务器上，**数据与提示词可控**。
- 希望直接复用"机构级"投研方法论（行情→分析→预测→决策）而不是手写脚本。
- 不想每月付 SaaS 投研订阅费。

## 关键能力

| 能力 | 说明 |
|------|------|
| 行情查询 | 实时 / 历史行情数据接入 |
| 深度分析 | 财报、行业、宏观因子 |
| 走势预测 | 模型驱动的价格 / 趋势预测 |
| 投研方法论 | 内置机构级研报 / 分析流程 |
| 自部署 | 数据与模型都在自己手里 |
