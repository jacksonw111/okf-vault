# Figma Community 开放设计系统合集

## 它是什么

**Figma Community** 上的「**Open design systems**」合集：收录全球 Figma 社区里的**开放设计系统 / UI Kit**。亮点：除了「成品」外，**「制作方法」**也能看到——可学习别人是怎么搭一套设计系统的。

## 为什么用它 / 适合什么场景

- 想找现成的设计系统 / UI Kit 参考。
- 想学「别人怎么搭设计系统」的思路（含 Token / 组件 / 模式）。
- 想让 AI 搭设计系统时有个起点 / 模板。

## 关键能力

| 能力 | 说明 |
|------|------|
| 开放设计系统 | 完整的设计系统 |
| 完整品 + 做法 | 不止成品，还能学过程 |
| AI 起点 | 给 AI 喂设计系统起点 |
| 全球收录 | 各类风格 / 行业都有 |
| Figma 生态 | 直接打开 / fork |
