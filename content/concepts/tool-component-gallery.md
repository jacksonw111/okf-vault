# component.gallery（经典 UI 组件术语图鉴）

## 它是什么

[component.gallery](https://component.gallery/) 是一个**经典 UI 组件的术语图鉴网站**。它系统列出 UI 组件的**正式名称**与对应样式，帮助你与 AI 协作 UIUX 时使用准确的命名。

## 为什么用它

- 「**不要用『弹窗』、『下拉菜单』、『闪光加载』、『菜单栏』来和 AI 交流 UIUX 开发**」——命名正确，交流更顺畅，更容易一发命中。
- 多数设计师 / 开发者只会用最宽泛的术语描述 UI——**和 AI 协作时这种粗粒度语言导致 AI 给出最常见的样式**，而非你要的那个具体组件。
- 「**命名即精度**」：用对组件名 = 让 AI 知道你想要 Modal 还是 Dialog / Drawer / Sheet / Popover。

## 典型用法

- 想实现一个特定组件时，先上 component.gallery **查它的标准名称**
- 用正式名称向 AI 下 prompt，AI 才能精准匹配到对应组件的实现

## 关键能力

| 能力 | 说明 |
|------|------|
| 组件术语图鉴 | 系统列出 UI 组件的正式名称 |
| 视觉示例 | 每个组件配视觉示意 |
| AI 协作友好 | 命名直接对应 prompt 关键词 |
| 持续更新 | 收录主流组件库的标准命名 |
