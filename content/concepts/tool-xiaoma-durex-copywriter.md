# 小马杜蕾斯文案 Skill

## 它是什么

「小马杜蕾斯文案」是一款 Claude Code 用的 Skill，把杜蕾斯 2011–2017 年「黄金期」的文案方法——尤其是「双层语义」「谐音双关」「反向克制」等——拆成 8 条可复用公式 + 260 张原图拆解（主体判断树 / 六套配色 / 排版规矩 / 字体选型 / 商用授权红线），让 Claude 照着写出杜蕾斯风格的文案与海报。

## 为什么用它 / 适合什么场景

- 想要「品牌文案风格沉淀为 Skill」的范例。
- 欣赏杜蕾斯文案风格，希望让 AI 学其套路。
- 想用 Claude Code Skill 形式管理品牌方法论。
- 关心商用授权与字体合规。

## 关键能力

| 能力 | 说明 |
|------|------|
| 8 条文案公式 | 谐音 / 数字双关 / 反向克制等可复用结构 |
| 视觉拆解 | 主体判断树 / 六套配色 / 排版规矩 |
| 字体授权红线 | 商用字体选型建议 |
| Claude Code Skill | 放进 `.claude/skills/` 即可调用 |
| 原图案例库 | 260 张杜蕾斯原图拆解 |
