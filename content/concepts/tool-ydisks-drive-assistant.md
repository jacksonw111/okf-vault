# Ydisks 批量转存助手

## 它是什么
一个**网盘批量操作助手**，主要解决两件事：

1. **批量转存**：把散落在夸克、百度网盘、迅雷等不同网盘的分享链接，**批量转存**到目标账号自己的网盘里。
2. **批量建链**：转存完成后，调用 Ydisks 后端，对每一项资源**批量生成**小红书、抖音等多渠道的**短链**（推广分发用）。

把「一个一个手动转存 + 复制短链」的传统流程压成一次配置自动跑完。

## 为什么用它 / 适合什么场景
- 收集型账号运营：要批量把分享链接转存到自有网盘，再分发到多个内容渠道。
- 资源整合：把散落的网盘内容统一搬到一处。
- 推广分发：转存完即得短链，无需额外短链平台。

## 关键能力
| 能力 | 说明 |
|------|------|
| 支持网盘 | 夸克 / 百度网盘 / 迅雷等 |
| 转存方式 | 批量（多链接一次跑完） |
| 短链输出 | 小红书 / 抖音等多渠道 |
| 工作形态 | 本地客户端 + Ydisks 后端 |
| 节省 | 人工转存 + 人工建链 |
