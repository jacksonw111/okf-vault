# workout-guide（302 个健身动作的 SVG 图示库）

## 它是什么

[`workout-guide`](https://github.com/bryllim/workout-guide) 是 bryllim 维护的开源健身动作图示集——把 302 个常见健身动作各画 **3 帧**统一风格插图（动作起 / 中 / 收），共 **906 张 512×512 SVG**，可用作训练 App、健身记录工具或文章配图。

- 框架无关的 npm 包，按需引入
- 附 Astro 静态画廊站点直接浏览
- 视觉风格统一（不似不同作者拼凑）

## 为什么用它

- 自己拍动作素材贵、慢、风格不一
- 现成 SVG 可缩放、可染色（currentColor），适合做深色 / 浅色双主题
- 「3 帧一动作」足够视觉表达动态，不至于占太大包体
- 用 AI 生成动作插图容易走形，这套是人工统一风格画完的

## 关键能力

| 能力 | 说明 |
|------|------|
| 动作数量 | 302 个健身动作 |
| 每动作帧数 | 3 帧（起 / 中 / 收） |
| 总图数 | 906 张 512×512 SVG |
| 风格 | 统一插画风格 |
| 包装 | 框架无关 npm 包 + Astro 静态画廊 |
| 用法 | 直接 `<img src>` / React / Vue 通用 |
