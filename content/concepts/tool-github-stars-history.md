# GitHub Stars History

## 它是什么

[Marcos66236/github-stars-history](https://github.com/Marcos66236/github-stars-history) 是一个**针对 GitHub 仓库 Star 历史的统计工具**：自动从 GitHub 拉取指定仓库的 Star 时间戳，按时间排序，算出增长曲线与汇总指标，并导出为文件。免去手动翻 stargazers 列表、整理时间戳、对齐日期的重复劳动。

## 关键能力

| 能力 | 说明 |
|------|------|
| 自动拉取 | 一次性获取仓库全部 stargazers 的关注时间 |
| 增长统计 | 按日 / 周 / 月聚合 Star 增量，输出趋势曲线 |
| 数据导出 | 把统计结果落地为可分享的文件（CSV / JSON 等） |
| 多仓库 | 可批量统计多个仓库，便于横向对比 |

## 适合什么场景

- 想追踪自己开源项目 Star 增长曲线、复盘「哪个 PR / 哪篇文章带来了一波流量」的维护者。
- 做行业调研、需要批量对比多个开源项目增速的分析师 / 投资人。
- 想把 Star 数据纳入自己的 dashboard / 数据集的内容创作者。
