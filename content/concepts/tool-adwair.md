# Adwair

## 它是什么

[Adwair](https://github.com/kusaida/Adwair) 是 **kusaida** 出品的 **Linux 图标主题**——把两大风格的优点糅在一起：

- **WhiteSur**：macOS Big Sur 风格的精致
- **Adwaita**：GNOME 默认的原生感

## 为什么用它 / 适合什么场景

- **想要 macOS 精致又不想脱离 GNOME**：Adwair 在两者之间找到折中。
- **图标一致性**：GNOME 用户长期诟病默认图标稀疏，Adwair 补足。
- **典型场景**：GNOME / Pop!_OS / Fedora Workstation 等桌面。

## 关键能力

| 能力 | 说明 |
|------|------|
| 形态 | 图标主题 |
| 风格 | WhiteSur + Adwaita 融合 |
| 安装 | 装完在主题选择里启用 |
| 适用 | Linux 桌面（尤其 GNOME 系） |
